## 〇、🔴 本版改了什么（对照 v2 的同类型错误，共 10 处）

| # | 错误类型 | v2 原文 | 本版修正 |
|---|---|---|---|
| 1 | **显示行做成按钮** | `t_base` 类型=按钮、整行触控切换八度 | `t_base` 改**文本**（纯显示），新增小按钮 `b_oct` 叠放在右端承接触控（⭐ 同类规则：**FPGA 回显的行一律文本，触控拆小按钮**） |
| 2 | **过时波特率文字** | `t_conn`="UART 500K [ONLINE]"、`t_fx_uart`="UART 500K 8N1" | 均改 **"115.2K"**（2026-10-28 板载口 500k→115200 改档，FPGA 侧已同步） |
| 3 | **心跳机制描述过时** | p_hb "FPGA 周期脉冲驱动翻转" | 实际机制：**屏侧 tm0 500ms 闪 + tm1 1500ms 看门狗 + FPGA 每秒发 `tm1.tim=1500`**（RTL 已交付）；p_hb 类型明确为**双态按钮**（sta=图片，pic=0 灰 / pic2=1 绿） |
| 4 | **缺失回显控件** | 无 `t1` | FPGA 实际回显 `t1.txt`（Test Mode：关/4/8/16/32）——**屏上必须有叫 `t1` 的文本控件**，否则该帧被丢弃。已补在底部条 |
| 5 | **led_* 无数据源** | led_dist/led_chor/led_dly 暗灰↔高亮联动 | FPGA **不回显** led 图片切换 ⇒ 初版**省略**（或做静态装饰点）；要联动需 RTL 加发 `.pic` 帧（后续工作） |
| 6 | **字号爆炸** | 11/12/13/14/15/16/18/20/22/24/32/48 共 12 档 | 合并为 **6 档字库**（12/16/20/24/32/48），见 §二 |
| 7 | **特殊符号字库缺口** | ● ➔ ⬅ ★ ► ── · ↕ 直接写在文案里 | 这些符号**不在默认字符集**，⭐ 必须手工加进字库，否则显示方块。见 §七 |
| 8 | **两页重名控件行为未说明** | z_pd/z_vd 在 page0、page1 各有一个 | 合法（控件页私有），但 ⚠️ **FPGA 帧只作用于当前页**，见 §八-1 |
| 9 | **切页陈旧值问题** | 未提及 | b_fx 切到 page1 期间 FPGA 的 page0 更新帧**全部被屏丢弃**，返回 page0 显示旧值。配套方案见 §八-2（**需 RTL 小改**，约半小时，随时可做） |
| 10 | **t_loop 三态配色不可实现** | 空闲灰/录音红/回放绿 | FPGA 只发 `t_loop.txt`、**不发 pco/bco** ⇒ 初版固定配色，状态只改文字（RTL 加发颜色帧 = 后续工作） |
| 11 | 🔴 **触摸命令与 RTL 不符** | `b_dist_hdr` 等发 `printh 65 01 02 01 FF FF FF` | 0x65 触摸帧 body 只有 1 字节（控件 ID），FPGA 只认 ID **0/2**（`uart_ui.v:517-532`）⇒ v2 三个效果器头部按钮**全是空响**。改用翻转变量 `71 19 <bit>`（需 RTL 加 0x19，3 行，§八-2） |
| 12 | **FPGA 已支持但没做按钮** | t_mode/t1 标注"外部硬件按键切换" | RTL 实锤支持屏触摸：ID0=模式翻转、ID2=Test Mode 切档 ⇒ 新增 **`b_mode`**、**`b_test`** 两按钮（§三、§六） |

> - 正文 12~24：**微软雅黑 + 勾加粗**——最接近设计图的 GitHub 风格粗黑体，字重均匀、小字号清晰

> ⚠️ 视觉差异 ≤2px，肉眼无感；6 个库的字符集**统一**（见 §七，一份字符集生成 6 次）。

```
tm0.en=1
```

> 运行逻辑：FPGA 每秒发 `tm1.tim=1500`（RTL 已交付，148 checks PASS）持续复位 tm1 倒计时 ⇒ 联机时 tm1 永不超时；断联 ≤1.5s 后 tm1 超时 → `tm0.en=1` → 圆点闪。
> ⚠️ p_hb 是双态按钮，**手指点它会手动翻状态**——10×10 在角落，基本点不到。

### 切页按钮

**b_fx** 弹起事件：`page page1`
**b_back** 弹起事件：`page page0`

### 基准音切八度（新增 b_oct）

**b_oct** 弹起事件——⭐ 屏侧自记账版（今天就能用，不依赖 RTL 改动）：
```
// 需先建全局变量 va_base（变量控件，vscope=全局，初值 0）
if(va_base.val==0)
{
  va_base.val=12
  printh 71 01 18 FF FF FF
}else
{
  if(va_base.val==12)
  {
    va_base.val=24
    printh 71 01 30 FF FF FF
  }else
  {
    va_base.val=0
    printh 71 01 00 FF FF FF
  }
}
```
> ⚠️ 局限：若**硬件侧**也改过起始音，屏的 va_base 会记偏。彻底修法 = RTL 加循环变量 0x1B（§八-2），届时 b_oct 只发一句 `printh 71 1B 01 FF FF FF`。

### 模式切换（新增 b_mode）

**b_mode** 弹起事件（RTL 实锤支持：触摸 ID 0 = 模式翻转，`uart_ui.v:517`）：
```
printh 65 00 00 FF FF FF
```

### Test Mode 切档（新增 b_test）

**b_test** 弹起事件（RTL 实锤支持：触摸 ID 2，关→4→8→16→32→关，`uart_ui.v:520`）：
```
printh 65 00 02 FF FF FF
```

### page1 五个头部按钮

```
b_pv_hdr：  printh 71 05 01 FF FF FF      // 切档 1（音高颤音）
b_vv_hdr：  printh 71 05 02 FF FF FF      // 切档 2（音量颤音）
```

🔴 **效果器开关三兄弟——v2 的 `printh 65 01 02 01 …` 是错的（空响），改成翻转变量**（等 RTL 加 0x19 后启用）：
```
b_dist_hdr：printh 71 19 01 FF FF FF      // 翻转失真 Bit0
b_chor_hdr：printh 71 19 02 FF FF FF      // 翻转合唱 Bit1
b_dly_hdr： printh 71 19 04 FF FF FF      // 翻转延迟 Bit2
```
> ⚠️ RTL 加好 0x19 之前，这三个按钮**先别绑命令**（绑了也白绑，还可能发垃圾字节干扰解析）。

### ⭐ 返回 page0 主动刷新（🔴 需 RTL 配套，暂缓）

**page0 后初始化事件**（等 §八-2 的 RTL 改完再加）：
```
printh 88 FF FF FF
```

## 八、⚠️ 已知边界与后续工作（⭐ 逐条有主）

### 1. z_pd / z_vd 两页重名（合法但要懂行为）

控件是页私有的，两页各有一个 `z_pd` **不冲突**；但 FPGA 发 `z_pd.val=25` 只作用于**当前显示页**的那个。page1 的 z_pd（深度旋钮）与 page0 的 z_pd（监视弧）本来就是同一个物理量，联机时在哪页哪页活。

### 2. 🔴 RTL 待加三件套（⭐✅ **2026-10-29 已全部落地，tb 148→182 checks PASS**）

> ⭐ 终版清单见 `串口屏v3-搭建清单-20261029.md`（本节留档）。

| # | 改什么 | 屏侧解锁的能力 | 工作量 |
|---|---|---|---|
| A | **0x88 每次收到都全量重发**（现仅首次） | page0 初始化事件 `printh 88 FF FF FF` ⇒ 切页返回永远新值 | ~10 行 + tb 1 判据 |
| B | **翻转变量 0x19**：`fx_mask_o ^= val_q` | page1 三个效果器开关按钮（`71 19 01/02/04`）盲翻转，无状态记账 | ~3 行 + tb 1 判据 |
| C | **八度循环变量 0x1B**：`base_semi 0→12→24→0` | b_oct 单命令循环，不用 va_base 记账 | ~3 行 + tb 1 判据 |

三个都动 `uart_ui.v`，合并一次回归（tb 预计 148→152 checks）。

### 3. t_loop 三态配色

FPGA 只发 `t_loop.txt` 文字。空闲灰/录音红/回放绿需要 FPGA 加发 `t_loop.bco=` / `t_loop.pco=` 帧——RTL 回显 FSM 目前只有 txt/val/tim 三种帧型，加色帧是后续工作。初版固定红底反白。

### 4. Page1 动态数据

z_dg/z_dt/z_cl/z_mx/z_ll/z_lf + t_*_val + cur + gr 目前**无 FPGA 回显帧**。要全动态需在 uart_ui.v 扩字段（每字段约 20 行 RTL + tb 判据）。建议演示前排期评估。

### 5. led_* 状态灯

同 §〇-5，无数据源，本版省略。
