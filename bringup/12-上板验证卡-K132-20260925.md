## 四、⚠️ `'V'` 的格式（⭐ 有坑，⭐ 务必按这个读）

```
`V<state><axis><rej><固定'0'>`
   │      │      │    └── 🔴 **这个 '0' 是【硬编码常量】**，⛔ 不是数据（⭐ 见 K-133）
   │      │      └─────── ⭐ reject_cnt（⭐ 1 位 hex，⭐ 0~9）
   │      └────────────── ⭐ cur_axis（⭐ 1 位 hex）
   └───────────────────── ⭐ state（⭐ 见下表）
```

| ⭐ 字符 | ⭐ 含义 |
|---|---|
| `0` | ⭐ IDLE |
| `1` | ⭐ PROMPT（⭐ 提示按键） |
| `2` | ⭐ SETTLE（⭐ 等稳定） |
| `3` | ⭐ VOTE（⭐ 投票） |
| `4` | ⭐ FIRE（⭐ 发 span） |
| `5` | ⭐ WAITBUSY |
| `6` | ⭐ NEXT |
| **`7`** | 🔴 **DONE（⭐ 已放弃）** |

📌 **举例**：⭐ `V7090` = ⭐ **state 7（DONE）· axis 0 · reject 9**（⚠️ ⛔ **不是** "rej=0x90"）

## 五、⭐ 本次修复改了什么（⭐ 一句话）

```
⭐ `calib_span.v` 的 `S_PROMPT` 从【停 1 拍】改成【停 2 拍】：
   · 第 1 拍：`need_press_o <= 0`
   · 第 2 拍：`need_press_o <= 1`  ⇒ ⭐ 干净的上升沿
⇒ ⭐ `top.v` 的 `ev_need`（⭐ 上升沿检测）**每次重试都会重新触发** ⇒ ⭐ 轴号每次重发
```

📌 **背景**：⭐ 原来 `need_press_o` 一旦拉起就**再也不落**（⭐ `S_SETTLE`/`S_VOTE`/`S_FIRE` 都不清它）
⇒ 🔴 重试回 `S_PROMPT` 时它**本来就是 1** ⇒ ⭐ **没有 0→1 跳变** ⇒ 🔴 **轴号只发第一次**。
