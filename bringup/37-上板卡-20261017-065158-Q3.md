## 二、烧录后按这个顺序验（⭐ 每步给"该看到什么"和"不对时先查什么"）

### 0 · 上电自检（30 秒）
- [ ] 电源灯亮、无异常发烫
- [ ] **HDMI 有画面**（⭐ 波形/李萨如模式都在）
- [ ] **没有持续的"滋滋"声**（⭐ 这是之前的关键回归指标）

### 1 · 键盘发声（⭐ 最先验，因为它一坏就什么都验不了）
```
左/右手板 16 键逐个按
该看到：每个键都出声 + LED 指示灯亮
```
⚠️ 若**全程无声** ⇒ 先查 **ADC 接线**（⭐ 今晚踩过：USB-TTL 的 TX/RX 接反 ⇒ 效果器收不到命令，而我误判成代码 bug）

### 2 · 滑音（这版的重点之一）
```
按键 2（'W'）= 滑音开关 · 按键 7 = 指板/钢琴模式
⭐ 必须在【指板模式】下滑音才生效
手指按住一个音 → 横向往相邻键滑
该看到/听到：音高连续跟随，⛔ 不是"换了一个音"
```
⚠️ 若**几乎不触发** ⇒ 那是 `event_extract` 的 A 判据问题 ⇒ 见 `bringup/34` 的滑音条目

### 3 · LED 曲目指引（⭐⭐ 本版最重要的用户可见修复）
```
灌一首真曲（⭐ 用【网页灌谱】score_studio.html，它已带 bit[4:0]）
⭐ 验两件事：
  ① 示范段：**出声 + 亮灯**（原来"只亮灯不出声"的那段）
  ② ⭐ **换歌/重播后，灯还能亮** —— 这是"LED 重播缺陷"的判据
```
⚠️ 若**一盏灯都不亮** ⇒ `bit[4:0]` 没到（⭐ 用网页导出的 `.bin`，⛔ 别用 `build/score/*` 的旧 hex）
⚠️ 若**只有一盏灯在闪、不换** ⇒ 那是旧的"点名"缺陷，本版应已修

### 4 · 鼓机 + 池（Q3 是本版新修的）
```
开鼓机（四件套 Kick/Snare/HiHat/Tom）+ 同时用手弹鼓
该看到：四件套各响各的，⭐ **不互相偷声**（原来池只有 5 ⇒ 需求 8）
```
⚠️ 若"打着打着少一件" ⇒ 池还是不够 ⇒ 看 `top.v` 的 `RESERVED_N` 是不是 8

### 5 · 效果器（⚠️ 这版**看不见**状态，是已知缺口）
```
串口发 71 10 07 FF FF FF  → 全开（失真+合唱+延迟）
      71 11 <val> ...      → gain（0..254，乘法）
      71 12 <val> ...      → trim（0..254，除法）
该看到/听到：失真削顶、合唱、延迟
```
⚠️ **听不出差别时**：⭐ 这版**没有 `'Z'` 回读** ⇒ 无法确认效果器到底生没生效
  （⭐ 这正是 `K-106` 要补的 —— 当晚为此绕过 2 小时）
  📌 临时判据：`drive 254` + `trim 128` ⇒ **输出应饱和到满幅**（`gain 254` + `trim 254` 会炸，别这么试）

### 6 · 电源/复位稳定性（⭐ 芯片是 GW5AT-60，`RESET` 必须晚于 `VCC`）
- [ ] 反复上电 3 次，每次都能正常出画面/出声
- [ ] 不复位也能重灌（若用 JTAG）

## 三、已知会**看起来像 bug** 但**不是**的现象

| 现象 | 真相 |
|---|---|
| 鼓机高音两件（HiHat/Snare）听着"电子/金属" | ⭐ **噪声表被按音高扫 ⇒ 短周期谐波梳**（HIHAT 只有 ~12 根谱线）—— 设计层面的音色问题，⛔ 不是本版引入的 |
| 失真"感觉没变化" | ⭐ 干声只有 **24.9% FS** ⇒ `drive < 128` 基本不削顶（⭐ 要 `drive 254` 才明显）|
| 长时间不弹，LED 全灭 | ⭐ 这是"停播即清"（`stream_timeout` 1 秒）—— **有意设计** |
| 按 7 切模式，LED 指法变了 | ⭐ 指板表 / 键盘表是两套（⭐ 本来就是）|

## 五、⚠️ 为什么"最新源码"没有位流（诚实说明）

```
能过布线的基线 65aa3c76 : T_Lut = 34000  ✅ 出了位流（⭐ 就是本卡这个）
之后的源码     a75f3dde : T_Lut = 34308（+308）❌ PnR 三次都卡在 Routing Phase 0→1
```
- 那 +308 LUT 来自 Q7/Q2/CLS 那几笔（⭐ 单独看都很小，但**余量本来就只剩这么点**）
- 已试过的补救：`cmt_kick/cmt_tom` 挪到提交拍寄存 ⇒ **实测只省 21 LUT**（⭐ 模型估的 −60~110 是上界）
- ⭐ **下一刀建议**（按实测收益排序，都在 `bringup/34`）：
  1. `tdm_render_mixer` 的 osc/env 读 mux → BSRAM（预估 **−711 LUT**，⭐ 且能消掉 `cnt→mux→DSP` 那条 14/25 热点）
  2. `looper` 读 mux → BSRAM（预估 **−1500 LUT**）
  3. Q4（LED 引用计数，⭐ 需要三个 tb 的期望一起改）

📌 **结论：现在能上板的就是 `20261017-065158-Q3-drum-pool-8.fs`**（0 setup / 0 hold ✓ 功能完整 ✓ 含 Q3 ✓ 含 LED 重播修复 ✓）
