# 上机操作手册 · 全项目

> ⭐ **这本手册是给"手上要动的人"看的**：摸哪个键、拧哪个旋钮、踩哪个脚踏、拨哪个推子；
> 做完之后**看到哪颗灯变什么颜色、听到什么声音、屏上出现什么**；没按预期时**先查什么**。
> ⛔ 不含任何代码、模块、信号、参数名 —— 那些在工程文档里。

---

## 0. 一分钟上手（最短路径）

```
① 接线：J9 排针（ADC 走 N1~N8，电源 N11=+5V / N12=GND，按键灯 N17~N21，调试串口 N25/N26）
② 上电：心跳灯应【慢闪】；HDMI 有画面；喇叭/耳机要有声（没插就一定没声）
③ 烧录：见 §11 开头那个"可烧的位流"
④ 按一个键：应该出声 + 对应指示灯亮
⑤ 出声了 ⇒ 其余功能按 §11 的顺序一条条走
```

⚠️ **三条最容易白折腾的**：
1. **喇叭/耳机没插** ⇒ 一切正常但没声音（心跳灯仍是慢闪，最容易误判）
2. **调试串口接线没交叉** ⇒ 所有串口命令都"没反应"
3. **串口波特率没改** ⇒ 一个字节都收不到（默认 115200 是错的）

## 1. 控制板 · 4×4 矩阵 16 键

**布局**：4 行 × 4 列 = 16 格，**15 个有功能 + 1 个备用**。
**读法**：**列 = 功能组**，同组的功能排在同一列里。

| | 列 0 · 节奏/循环组 | 列 1 · 音色组 | 列 2 · 音高组 | 列 3 · 系统组 |
|---|---|---|---|---|
| **行 0** | 节拍器 | 音色循环 | 滑音开关 | 显示切换 |
| **行 1** | 键盘打鼓 | 推子档位 | 变调 升 | 模式 指板/钢琴 |
| **行 2** | 鼓机节奏型 | 效果器（占位） | 变调 降 | Test Mode |
| **行 3** | **looper 清空（长按 2 秒）** | **loop 发送**（旧位流里是"备用"，按了没反应） | **音高归零** | 标定（短按 = 零点，只发 `T`） |

### 逐键操作与期望

| 操作 | 期望现象 | 不正常的表现 |
|---|---|---|
| 按 **行0列0**（节拍器） | 第 **4** 颗灯开始**每拍暗一下**；听到节拍声 | 灯不动 / 有灯无声 |
| 按 **行0列1**（音色循环） | 第 **1** 颗灯换色：白→青→紫→橙 循环 | 灯不变色 |
| 按 **行0列2**（滑音） | 第 **6** 颗灯在滑音时变**青色** | — |
| 按 **行0列3**（显示切换） | 第 **7** 颗灯：蓝（波形）⇄ 品红（李萨如）；HDMI 画面跟着换 | 画面不变 |
| 按 **行1列0**（键盘打鼓） | 第 **2** 颗灯变**蓝 + 呼吸**（覆盖原来的橙/绿）；再按 16 键变成打鼓声 | 按键仍是乐音 |
| 按 **行1列1**（推子档位） | 第 **3** 颗灯在 **青（颤音）⇄ 紫（变调）** 之间切换；推子改的物理量随之改变 | 灯不变 |
| 按 **行1列2**（变调升） | 第 **6** 颗灯偏**暖橙**；音高整体升半音 | 音高不动 |
| 按 **行1列3**（模式） | 第 **2** 颗灯：**橙 = 指板** ⇄ **绿 = 键盘** | 灯不变 |
| 按 **行2列0**（鼓机节奏型） | 第 **4** 颗灯换色（红/洋红/黄/橙红 = 4 型） | 灯不变 |
| 按 **行2列1**（效果器） | ⚠️ **按了没反应是正常的**（占位，第 8 颗灯恒灭） | — |
| 按 **行2列2**（变调降） | 第 **6** 颗灯偏**冷蓝**；音高整体降半音 | 音高不动 |
| 按 **行2列3**（Test Mode） | 屏上切换测试档；听感/频谱上能数出不同数量的声部 | — |
| **长按 2 秒** 行3列0（looper 清空） | 第 **5** 颗灯回到**暗蓝 = 空闲**；已录内容被清掉 | ⚠️ **短按不清空**（防误触，这是设计） |
| 按 行3列1（loop 发送） | ⭐ **新版本**：立刻导出已录内容（串口吐帧）<br>⚠️ **旧位流**：这个位置是"备用"，**按了没反应是正常的** | — |
| 按 **行3列2**（音高归零） | 音高立刻回到默认（第 6 颗灯变灭） | 音高仍偏移 |
| **短按** 行3列3（标定） | 做一次"零点"标定；串口回 `t` | 回 `!` ⇒ 再等 1 秒（上电自动零点还没跑完） |
| **长按** 行3列3（标定） | ⚠️ **本键实际只发 `T`（零点标定）** —— 长按没有额外功能 | — |

⚠️ **"长按多久"**：looper 清空 = **2 秒**。其他长按没有额外门槛。

## 2. 控制板 · 8 颗 WS2812 指示灯

**一句话原则**：**颜色**管"是哪一档"，**闪不闪**管"开没开/在不在忙"。

| 第几颗 | 管什么 | 颜色含义 | 闪动含义 |
|---|---|---|---|
| **1** | 音色 | 白 = BASS · 青 = GUITAR · 紫 = PIANO · 橙 = PAD | — |
| **2** | 16 键此刻是什么 | 橙 = 指板 · 绿 = 键盘 | **蓝 + 呼吸 = 键盘打鼓**（覆盖前两者） |
| **3** | 推子功能 | **紫 = 变调 · 青 = 颤音** · 灭 = 当前无推子功能 | — |
| **4** | 节奏 | 红 / 洋红 / 黄 / 橙红 = 鼓机 4 型；**绿 = 鼓机关但节拍器开** | **每拍暗一下约 100 ms = 节拍器开** |
| **5** | looper | 绿 = 回放 · 暗蓝 = 空闲 | **红 + 快闪 = 正在录**；**黄 + 快闪 = 武装中（在等小节线）** |
| **6** | EC11 对象 + 音高状态 | 静止时：暖橙 = 变调升 · 冷蓝 = 变调降 · 灭 = 无偏移 · **青 = 滑音中**（优先级最高） | 拧/按 EC11 后 **1 秒内**临时变：**黄 = 正在调 BPM**、**紫 = 正在调音高** |
| **7** | HDMI 显示 | 蓝 = 波形 · 品红 = 李萨如 | — |
| **8** | 效果器 | **灭 = 关**（占位期恒灭） | 预留 |

### 最容易看错的三种组合

| 第 4 颗的样子 | 真实状态 |
|---|---|
| 灭 | 鼓机关 + 节拍器关 |
| **绿 + 每拍暗一下** | 鼓机关 + **节拍器开** |
| 某个节奏型色**常亮** | 鼓机开 + 节拍器关 |
| 某个节奏型色 **+ 每拍暗一下** | 鼓机开 + 节拍器开 |

| 第 5 颗的样子 | 真实状态 |
|---|---|
| 暗蓝 | 空闲（没录没放） |
| **黄 + 快闪** | ⭐ **武装中** —— 按了录，但在等下一小节线，**这时候弹的音不录** |
| **红 + 快闪** | ⭐ **真的在录** —— 这时才弹 |
| 绿 | 回放中 |

## 3. 控制板 · EC11 旋钮

### 两种动作

| 动作 | 作用 |
|---|---|
| **旋转** | 改**当前对象**的值（一格一步） |
| **按压** | **切换对象**：BPM ⇄ 调音高 之间来回 |

⭐ **4 个机械格 = 1 步**（已做过 ÷4）⇒ 转一格就是改 1。

### 两种用法

**① 普通用法（不改模式）**

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 转 EC11（对象 = BPM） | 第 **6** 颗灯临时变**黄**（1 秒后回落）；节拍速度变化 | 灯不变 / 速度不变 |
| 按压一次 | 第 **6** 颗灯临时变**紫**（对象换成"调音高"） | 对象没切 |
| 再转 | 音高整体升降，第 **6** 颗灯变暖橙/冷蓝 | 音高不动 |
| 再按一次 | 切回 BPM | — |

**② 参数调节模式（调效果器那一批参数）**

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 串口发 `p`（小写） | ⭐ 串口**回一帧**：`Ee1...`（`E` `e` `1` 开头） | 不回帧 ⇒ 命令没到 |
| 转一格 | 回一帧，倒数第 3 个字符在 `+`/`-` 之间变，最后一位数字递增（0~9 循环） | 不回帧 |
| 参数模式下转 | ⚠️ **BPM 和音高都不动**（被门住了，这是设计） | 如果 BPM/音高还在动 ⇒ 没进模式 |
| 参数模式下按按钮 | ⚠️ **不回帧、无任何变化**（这是设计） | — |
| 串口发 `o`（小写）+ 一个字节 | 选中第 n 个参数（n = 0~7） | — |
| 再发 `p` | 退出；⭐ **BPM/音高对象恢复到进入前的那个** | 退出后对象变了 ⇒ 异常 |

### 回传帧长什么样（8 个字符）

```
E e 1 + 3 CR LF
│ │ │ │ └─ 已连续步进次数（'0'~'9'，十进制一位）
│ │ │ └─── 这一步是 + 还是 -（'+' / '-'）
│ │ └───── '1' = 参数模式 · '0' = 普通模式
│ └─────── 固定小写 e
└───────── 固定大写 E
```
⚠️ **正好 8 个字符**（6 个可见 + 回车 + 换行）—— 不是 7 也不是 9。

## 4. 推子（左手 / 右手）

### 作用与手感

| 控件 | 性质 | 用途 |
|---|---|---|
| **推子** | 连续行程，可以一扫而过 | **粗调**、快速大范围移动 |
| **EC11** | 一格一个半音，离散 | **精调**，精确 ±1 半音 |

⭐ 两者**改的是同一个量**（整体音高），只是手感与精度不同 —— 都保留。
⚠️ **如实说明**：推子的输出**已经是半音量化的**，不是连续变调。"连续"描述的是**手感**（能平滑扫过很多档），数值上仍是半音步进。

### 操作与期望

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 推左推子 / 右推子 | 音高整体变化；第 **6** 颗灯暖橙（升）/ 冷蓝（降） | 音高不动 ⇒ 查第 **3** 颗灯是不是"灭"（当前无推子功能） |
| 推到底再往回 | 音高跟着回来，不是"跳" | — |
| 按 **行1列1**（推子档位） | ⚠️ **没反应是正常的**（未接消费者） | — |

⚠️ **范围**：整体音高可在 **−12 ~ +12 半音**（一个八度）之间调整。

## 5. 脚踏开关

**共 3 个脚踏位**（PMOD0 排针）：

| 脚踏 | 作用 | 期望现象 |
|---|---|---|
| **延音**（踩住） | 手弹的音**不马上释放**，停在 sustain，松脚才收尾 | 踩住再松手 ⇒ 声音继续；松脚 ⇒ 声音收尾 |
| **looper 录/停** | 按一下开始录（⭐ 先进"武装中"），再按一下停 | 第 **5** 颗灯：**黄快闪 → 红快闪 → 绿** |
| **looper 播/停** | 按一下回放，再按一下停 | 第 **5** 颗灯：绿（回放）/ 暗蓝（停） |

⚠️ **延音只对"手弹"生效**：回放（曲谱/loop）的音不受延音踏板影响 —— 这是设计，⛔ 不是 bug。
⚠️ **looper 没有"清空"脚踏** ⇒ 清空要用控制板 **行3列0 长按 2 秒**。

## 6. 左手板 · 指板（霍尔/位置）

### 是什么
**左手板**是一块**位置感应**的指板：每个"品"是一个模拟通道，手指**按下去的位置**连续可读。
所以它同时能给你：**音高**（按哪个品）+ **力度**（按多深/多快）+ **滑音**（在品之间横向移动）。

⭐ **8 列 × 2 行、上下严格对齐的磁轴网格**，**同一块物理网格**在"钢琴手感"与"指板滑弦"之间切换（只换映射表，硬件只做一次）。指板模式下**纵向差一个八度**。

### 操作与期望

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 按住一个品 | 出声（对应音高） | 无声 ⇒ 先查 ADC 接线（见 §12） |
| **下拨一次**（摇杆） | **只响一次**（⛔ 不"回中又响一次"） | 响两次 |
| 按住两个品，**连拨两次** | **第二个音能出来** | 永远只响第一个 |
| **交替拨弦**（按A→拨→松→按B→拨→松，来回几轮） | **不挂音** | 挂音（一直响不停） |
| 按住一个品，**连拨 3 次** | **每次都要响** | 只响第一次 |
| **换品后松手**（按6→拨→换9→松9） | 正在响的那个音**停掉** | 挂着不停 |
| **正常速度**横向滑过相邻品（⭐ 需先开滑音） | 音高**连续跟随**（不是"跳成另一个音"） | 几乎不触发 ⇒ 见下 |

### ⚠️ 滑音的前提（最容易漏）

```
① 必须切到【指板模式】（控制板 行1列3，第 2 颗灯变橙）
② 必须【打开滑音】（控制板 行0列2，或串口 W）
③ 然后按住一个音，横向往相邻品滑
```
⚠️ **钢琴模式下开滑音不会有滑音** —— 这是设计。

⚠️ **看起来像 bug 但不是**：滑音阈值调得很宽松 ⇒ 一开滑音，音高会有**持续的细微抖动**（每帧都在判定）。默认是**关**的，需要时才开。

## 7. 串口屏

| 项 | 说明 |
|---|---|
| 走哪条线 | ⭐ **就是调试串口那一根**（J9 的 **D14/D15**，波特率 **500000**）—— ⛔ **不是** ESP32 那条 |
| 为什么能共用 | 屏和 PC 调试终端**挂在同一个串口上**，两者看到的是同一路数据 |
| 显示什么 | 参数值、EC11 调节反馈、测试档位等 |
| 能看到什么 | 拧 EC11 时屏上参数值实时变化；参数调节模式下的 `Ee...` 帧也会到屏 |

⚠️ **所以"屏"和"PC 调试终端"是同一个口** —— 要么接屏、要么接 PC，**同一时刻只能接一个**（除非做分线，但那会让两边都收到对方的字节）。

⚠️ 波特率同样是 **500000**（⛔ 不是屏常见的 115200 默认档，屏侧也要改成 500000）。

## 9. 串口（PC 侧上位机）

### 物理层（⭐ 最容易搞错的地方）

| 项 | 值 |
|---|---|
| **波特率** | ⭐ **500000**（⛔ 不是 115200，⛔ 也不是老的 1 Mbaud） |
| 格式 | **8N1** |
| 接线 | ⭐ **必须交叉**：板的 TX → USB-TTL 的 RX；板的 RX ← USB-TTL 的 TX |
| 地 | ⭐ **必须共地** |

⚠️ **踩过的坑**：TX/RX 接反 ⇒ 所有命令"没反应"，曾被误判成代码 bug。
⚠️ 很多 USB-TTL 默认 115200 ⇒ **必须先改成 500000**，否则一个字节都收不到。

### 常用命令（发一个字母，多数会回一个小写字母）

| 发 | 作用 | 回包 |
|---|---|---|
| `P` | 读**位置**（⭐ **用它测链路通不通**，一定会回） | 数值 |
| `T` | 标定"零点" | `t`（⚠️ 不回包也是正常的？—— **会回 `t`**；若回 `!` 见 §12） |
| `S` | 标定"满量程" —— ⚠️ **已决定取消**，新位流将不再响应 | `s`（旧位流才回） |
| `X` | 中止标定 | — |
| `V` / `N` | 读标定状态 / 标定后位置 | 数值 |
| `I` | 切音色（白→青→紫→橙） | `i` |
| `B` | 节拍器 开/关 | `b` |
| `D` | 鼓机节奏型 切下一个 | `d` |
| `K` | 键盘打鼓 开/关 | `k` |
| `W` | 滑音 开/关 | `w` |
| `E` | HDMI 波形 ⇄ 李萨如 | `e` |
| `A` | 模式 指板 ⇄ 钢琴 | `a` |
| `F` / `G` | 变调 −1 / +1 半音 | `f` / `g` |
| `J` | 推子档位切下一档 | `j`（⚠️ 当前无实际效果） |
| `R` / `L` / `C` | looper 录/停 · 播/停 · 清空 | — |
| `Y` | 导出已录内容（14 字节/条） | 帧流 |
| `O` | 实时上行 开/关（每个音一帧 14 字节） | `o` |
| `U` | 指引模式 开/关（**只亮灯不出声**） | `u` |
| `M` | Test Mode 切换 | `4`/`8`/`A`/`B` |
| `p`（**小写**） | 进/出**参数调节模式** | `Ee...` 帧 |
| `o`（**小写**）+ 一个字节 | 选第 n 个参数 | — |
| `Z` | 读**效果器状态**（⏳ 未上板的版本里没有） | 6 字节 |

⚠️ **大小写完全不同**：`O`（大写）= 实时上行；`o`（小写）= 选参数。`P` = 读位置；`p` = 参数模式。

### 两个"要跟一整帧"的命令（`H` / `Q`）

```
发 H（或 Q）之后，必须再灌一整帧（0xA5 + 8 字节），那个帧的第 1 个载荷字节才是数值。
```
🔴 **不这么做会出事**：紧跟着的普通演奏帧会被当成数值 ⇒ **一灌谱就把 BPM 改乱**。

### 效果器参数（帧格式：`71 <序号> <值> FF FF FF`）

| 序号 | 作用 | 常用值 |
|---|---|---|
| `10` | 开关掩码（bit0 失真 · bit1 合唱 · bit2 延迟） | **全开 = `07`** |
| `11` | 失真增益 | `40`(=4.0× 默认) · `C0`(吉他) · `FE`(最狠) |
| `12` | 失真补偿 | `20`(=0.25 默认) · `0B`(吉他) |
| `13` | 延迟/合唱混合 | 0=全干，`FE`≈全湿 |
| `14` | 延迟反馈 | — |
| `15` / `16` | 颤音深度 / 速率 | — |
| `17` | 延迟长度 | `40` ⇒ 约 168 ms |
| `18` | 合唱长度 | `17` ⇒ 约 15 ms |

**按音色配一组（让失真在四种音色下都听得出来）**：

| 音色 | `11` 增益 | `12` 补偿 |
|---|---|---|
| PAD | `40` | `20` |
| BASS | `52` | `19` |
| PIANO | `90` | `0E` |
| GUITAR | `C0` | `0B` |

⚠️ **值最大只能发到 `FE`（254）** —— `FF` 是帧尾标记，发不进去。

## 10. ESP32 与上位机

> **来源**：ESP32 线提供的《上机手册-ESP32与上位机-20261017》已整合进本节。
> FPGA 串口的**命令总表见 §9**（本节不重复），本节只写 ESP32 特有的部分。

### 10.1 硬件连接

| 项 | 接法 |
|---|---|
| **ESP32 电源** | **USB 线独立供电**（⛔ 不要从 FPGA 板取电） |
| **ESP32 ↔ FPGA 串口** | ESP32 **GPIO17(TX)** → FPGA **G21**；ESP32 **GPIO18(RX)** → FPGA **G22**；**GND 必须共地** |
| **波特率** | **500000 8N1**（⛔ 不是 115200，那是串口屏的档） |
| **这条线跑什么** | ESP32 → FPGA：灌谱事件帧；FPGA → ESP32：实时回传帧（14 字节） |
| **FPGA ↔ PC 直连** | USB-TTL(3.3 V) 插 **J9**：转接板 TX → **D14** · 转接板 RX → **D15** · GND 共地，同样 500000 8N1 |
| **ESP32 ↔ PC** | BLE（网页灌谱用），设备名以固件实际广播为准 |
| **电平** | ✅ **两侧都是 3.3 V TTL，⛔ 不需要电平转换**（FPGA 侧 G21/G22 属 BANK2，工程约束明写全 `LVCMOS33` / `BANK_VCCIO=3.3`） |

⚠️ **两个最容易白折腾的**：
1. **TX/RX 没交叉** ⇒ 两边都收不到
2. **FPGA 的串口不在板载调试器上** —— 板载调试器（COM27/28）是它自己的口，⛔ 必须外接 USB-TTL 到 **J9** 才能看到 FPGA 回包

### 10.2 上电与自检

| 步 | 操作 | 期望现象 | 不正常的表现 |
|---|---|---|---|
| 1 | **先给 FPGA 上电** | 心跳灯**慢闪**；HDMI 出图 | 心跳灯**快闪** ⇒ 有故障（见 §12） |
| 2 | **再给 ESP32 上电** | ESP32 板载 LED 亮；串口打印启动信息（含波特率/TX/RX） | 无任何打印 ⇒ 先查 USB 线（⛔ 有些线只供电不传数据） |
| 3 | 等 FPGA 自动标定完成 | FPGA 串口回 **`T`** | 没回 `T` ⇒ 标定没完成，⛔ 先别发别的命令 |

⚠️ **顺序反了会丢帧**：ESP32 先上电会开始灌数据，而 FPGA 还没标定完。

**ESP32 上电后看什么**

| 看什么 | 期望 | 不正常 |
|---|---|---|
| 板载 LED | **慢闪**（心跳） | 常灭 ⇒ 没上电/固件没跑；**常亮不闪** ⇒ 固件卡住 |
| 串口打印 | 有一行明确打出 **波特率=500000、TX=GPIO17、RX=GPIO18** | 打不出 ⇒ 串口没配起来；数字不对 ⇒ 固件被参数覆盖 |
| BLE 广播 | 能搜到设备（网页灌谱才需要） | 搜不到 ⇒ 先确认 ESP32 上电；再看浏览器权限 |

**三步自检（不需要任何外部设备）**：① FPGA 心跳灯在闪 ② ESP32 串口有启动打印 ③ 发 `A` 能回 `a`

### 10.3 上位机（PC 侧）操作

| 场景 | 工具 |
|---|---|
| **直连 FPGA 串口**（调命令、看回包、看回传帧） | 任意串口终端，**要求能"十六进制 + ASCII 双显"、能发十六进制** |
| **灌谱**（放 MIDI） | **浏览器**打开 `esp32/tools/score_studio.html`（⛔ 不用装任何东西） |
| **BLE 调试**（可选） | 网页内置的 Web Bluetooth |

**串口终端怎么配**

| 参数 | 值 |
|---|---|
| 端口 | 设备管理器里看（USB-TTL 是 CH340/CP210x 类，**每次插可能变号**） |
| 波特率 | **500000** |
| 数据位/停止位/校验 | **8 / 1 / 无** |
| 流控 | **无** |
| 显示格式 | ⭐ **十六进制 + ASCII 双显**（看回传帧必须） |
| 换行符 | ⭐ **⛔ 不要加回车换行** —— 命令是单个字母，加了会把 `\r\n` 当命令字节发出去 |

⚠️ **最常见的配错**：波特率配成 115200 ⇒ 现象是"串口乱码"。

**怎么确认命令被受理**：⭐ **收到对应的小写回包**。收到 `x` = 命令合法但当前不接受（⛔ 不是链路问题）；什么都不回 = 链路不通（先查波特率/接线）。

**日志怎么存**：开"保存到文件"，**选十六进制格式**；贴给别人时同时写上**波特率**和**位流日期**。

### 10.4 上行数据（FPGA → ESP32）的解读

**14 字节帧**

```
第 1 字节    0xA5            帧头
第 2 字节    类型             见下
第 3 字节    序号             0..255（只用于短窗口丢帧检测）
第 4~7 字节  时间 tick        32 位，大端；Δt 要按 2^32 取模
第 8 字节    音色/轴号/鼓标志   ← ⭐ 见下面的位定义
第 9~12 字节 相位增量         32 位，大端（决定音高）
第 13 字节   力度             0..255
第 14 字节   校验             前 13 个字节【逐字节异或】（⭐ 含帧头 0xA5）
```

**校验**：第 1~13 字节挨个 XOR，结果写进第 14 字节。收到时同样 XOR 一遍，**对不上 = 这一帧坏了**（⛔ 不是音乐错了，是链路/时钟问题）。

⚠️ **表同步帧更长（68 字节）**：第 3 字节是表号（0=键盘表 / 1=指板表），接着 16 组 × 4 字节，最后 1 字节校验。

**第 8 字节的位定义（🔴 最近更正，旧代码/旧文档是错的）**

```
bit 7      保留
bit 6      is_drum      ← ⭐ 判"这是鼓"只认这一位
bit 5..4   音色（2 位）  鼓事件时这里是鼓型
bit 3..0   轴号（4 位）
```

| bit6 | bit5..4 | bit3..0 |
|---|---|---|
| **1 = 鼓** | **鼓型**（0=Kick 1=Snare 2=HiHat 3=Tom） | 0 |
| **0 = 乐音** | **音色**（0=BASS 1=GUITAR 2=PIANO 3=PAD） | **轴号**（0..15） |

🔴 **两条必须记住**：
1. **`bit3..0` 是轴号，⛔ 不是鼓标记** —— 用它判鼓会把每个音都误判成鼓
2. **判鼓只认 `bit6`**；⚠️ **旧固件该位恒 0** ⇒ 全部显示成乐音，**这是兼容行为、⛔ 不是故障**

**怎么认出一次鼓击**

```
第 8 字节 & 0x40 ≠ 0  ⇒ 鼓击，鼓型 = (第8字节 >> 4) & 0x03
第 8 字节 & 0x40 = 0  ⇒ 乐音，音色 = (第8字节 >> 4) & 0x03，轴号 = 第8字节 & 0x0F
```

**每一类事件在串口上长什么样**

| 事件 | 第 2 字节 | 第 13 字节（力度） | 串口上看到的 |
|---|---|---|---|
| **按下** | `01` | 明显大于 0（弹得轻重大致对应） | `A5 01 <序号> <tick×4> <第8字节> <inc×4> <力度> <校验>` |
| **松开** | `02` | ⚠️ **不可靠，⛔ 不要用它做判断** | `A5 02 ...` |

⚠️ **松开帧的力度字段是 FPGA 侧的已知缺陷**：`note_off` 那拍送出的力度不是 0（实测出现过 250/229/255）⇒ ⛔ 不要用它做任何判断，等修复。

⚠️ **`0x03`/`0x04`/`0x10` 这三个类型字节**：FPGA 侧的事件上行模块**只发 `0x01`/`0x02`**（`b_type = (kind==1) ? 8'h02 : 8'h01`）⇒ 其它类型的出处**待核**。

**音高怎么读（排查用）**：第 9~12 字节是 32 位大端整数 `inc`，频率 = `inc × 50 000 000 ÷ 2^32`。⭐ 手算麻烦 ⇒ 用网页的"回传面板"，它替你解成音名/Hz/轴号/鼓型。

### 10.5 下行命令

🔴 **两条完全不同的路径，⛔ 不要混**：

| 路径 | 介质 | 命令长什么样 | 谁用 |
|---|---|---|---|
| **A. FPGA 串口直连** | USB-TTL → J9 | **单个 ASCII 字母**（无帧头、无回车） | 人在串口终端里调 ⇒ ⭐ **命令表见 §9** |
| **B. ESP32 蓝牙灌谱** | BLE | **私有命令值 0x01~0x04** | 网页灌谱 |

**路径 B：BLE 灌谱命令**

| 命令值 | 功能 | 期望现象 | 不正常的表现 |
|---|---|---|---|
| `0x01` | 清池（重置事件缓冲） | 已灌事件被丢弃，游标归零 | 之后灌谱还是老的 ⇒ 没生效 |
| `0x02` | 查状态 | 网页"实时状态"区刷新（池/容量、已喂帧、总数、溢出、落后、运行） | 全是 `-` ⇒ 状态链路不通 |
| `0x03` | 起播 | 出声 + LED 指引；游标开始走 | 没声音 ⇒ 先看是不是指板模式（发 `A`） |
| `0x04` | 停止 | 声音停；游标停住 | 还在响 |

⚠️ **起播前必须上传完**：中途起播会让池里帧不齐 ⇒ 谱面只放一截。

### 10.6 三个容易踩坑的特殊命令

**① `'Z' <n>` 效果器状态回读 —— 🔴 必须连发两个字节**

| 项 | 说明 |
|---|---|
| **发法** | **两个字节**：先发字母 `Z`，**紧跟一个子命令号**（⭐ 发 **ASCII 字符 `'0'`~`'7'`**，即 0x30~0x37） |
| ⚠️ **只发 `Z` 不回包** | 最容易踩的坑：第二个字节才是"你要读哪一项" |
| **回什么** | **6 字节，全是 ASCII**：`'Z' 'z' <n> <hi> <lo> '\n'` |
| **怎么读** | `<hi><lo>` 是 **16 位值的十六进制文本**（4 个字符）；例 `Zz1023` ⇒ 子命令 1、值 0x0233 |

⭐ **子命令对照表（FPGA 侧已给出，⛔ 之前是"待核"，现在可用了）**

| n | 回读量 | 宽度 | 编码 |
|---|---|---|---|
| `0` | 效果器开关掩码 `en_mask` | 8 bit | 2 位 hex |
| `1` | 失真削顶计数 `dist_clip_cnt` | 16 bit | 4 位 hex |
| `2` | 延迟是否激活 `dly_active` | 1 bit | `00` / `01` |
| `3` | `{chor_active, dly_primed}` | 2 bit | `00`~`03`（bit1=合唱 · bit0=延迟已预热） |
| `4` | 颤音 LFO `trem_lfo` | 16 bit | 4 位 hex |
| `5` | 效果器流水状态 `pipe` | 16 bit | 4 位 hex |
| `6`/`7` | 预留 | — | 恒回 `0000`（⭐ 发得出、看得出，⛔ 不静默） |

**② `'Q'` 设 BPM / `'H'` 设变调 —— 先发字母、再灌一整帧**

| 命令 | 完整字节序列 | 范围 |
|---|---|---|
| `Q` 设 BPM | 发字母 `Q`，**接着发一整帧**（`0xA5` 开头），**帧的第 1 个载荷字节 = BPM 值** | **40..240** |
| `H` 设变调 | 发字母 `H`，**接着发一整帧**，**帧的第 1 个载荷字节 = 半音数** | **0..24** |

⚠️ **为什么是"字母 + 整帧"**：这两个是"臂化式"命令 —— 字母只是"下一帧的头个字节按这个意思办" ⇒ **⛔ 不能只发一个裸数字**。

**③ 事件帧（`0xA5` 开头）**

帧长 **14 字节**（表同步 68 字节）；帧头 `0xA5`（⛔ 与字母命令天然不混，字母都 ≤ 0x7F）；载荷 8 字节；校验 = 前 13 字节逐字节 XOR。

⭐ **PC 直连造帧自检**：发一帧已知内容的 `0xA5` 帧，看 FPGA 是否按预期出声/亮灯 —— 这是把"链路问题"和"内容问题"分开的最快办法。

### 10.7 常见故障排查

| 现象 | 最可能的原因 | 先查什么 |
|---|---|---|
| **收不到任何上行数据** | ① TX/RX 接反 ② 没共地 ③ 波特率不对 ④ 上行回传没开 | ① 对调 TX/RX ② 量 GND ③ 两侧都要 500000 ④ **发 `O` 切换实时上行开关** |
| **收到数据但全是 0** | 旧工具链产物（某字段没填） | 用**新版工具链**重新生成谱子；或直接用网页灌谱 |
| **收到数据但全是 FF** | ① 波特率不匹配（最常见）② 线太长/干扰 ③ 没共地 | ① 改 500000 8N1 ② 缩短线 ③ 查 GND |
| **命令发了没反应** | ① 波特率不对 ② 加了回车换行 ③ 接到了调试器口 | ① 改波特率 ② **⛔ 去掉回车换行** ③ 确认插在 **J9** |
| **发命令回 `x`** | 命令合法但当前状态不接受 | 先完成上电自检（等自动标定回 `T`） |
| **有声音但"鼓判定不对"** | 🔴 用了 `bit3..0`（轴号）当鼓标记 | 改看 **`bit6`**；旧固件 bit6 恒 0 ⇒ 看不到鼓标记是**兼容行为** |
| **鼓型显示成 >3 的值** | 同上：把轴号当鼓型读了（鼓型只有 0~3） | 同上 |
| **串口乱码** | 波特率错（115200 是串口屏的档） | 改 500000 8N1 |
| **按轴没声音** | 在**指板模式**（要等拨弦比较器） | 发 `A` 切回**钢琴模式** |
| **`Z` 不回包** | 只发了一个字节 | 必须**连发两个字节**：`Z` + 子命令号 |
| **网页连不上 BLE** | ① 浏览器不支持 Web Bluetooth ② 设备没在广播 ③ 被别的标签页占用 | ① 换 Chrome/Edge ② 确认 ESP32 上电 ③ **关掉其它占用标签页** |
| **灌谱后只放一截** | 起播发在上传完成前 | 等"上传完"再起播 |

| **8** | 按 **行2列0** 切鼓机节奏型 | 第 4 颗灯换色；听到鼓 | — |

| **10** | 按 **行1列0** 键盘打鼓 | 第 2 颗灯蓝+呼吸；16 键变鼓声；松手能停 | 全变成踩镲 / 挂音 |
| **11** | 灌一首谱（网页灌谱工具） | 出声 + LED 跟着音高走 | 灯全不亮 ⇒ 谱的格式不对 |
| **12** | ⭐ **换一首歌再放** | ⭐ **示范段仍然亮灯** | 这是"LED 重播缺陷"的判据 |
| **13** | 停播，等 **1 秒** | LED **自动清掉**（不挂灯） | 一直挂着 ⇒ 异常 |
| **14** | 同音高叠两个音，松第一个 | ⭐ **灯仍亮**（引用计数生效） | 松第一个就灭 ⇒ 旧版 |
| **15** | 踩 looper 录 → 小节线后弹 → 再踩停 → 踩播 | 第 5 颗灯 黄快闪→红快闪→绿；回放听得到 | 第一个音丢 ⇒ 黄快闪期间就弹了 |
| **16** | 鼓机开着录 loop，回放 | ⭐ **没有幽灵鼓** | 有鼓声 ⇒ 旧版 |
| **17** | 串口发 `P` | **回包**（数值） | 不回 ⇒ 波特率/交叉接线 |
| **18** | 串口发 `T` / `S` | 回 `t` / `s` | 回 `!` ⇒ 等 1 秒再试（上电自动零点未完成） |
| **19** | 发 `71 10 07 FF FF FF` | 失真 + 合唱 + 延迟都可闻 | 听不出 ⇒ 按音色配 `11`/`12`（§9） |
| **20** | 反复上电 3 次 | 每次都能正常出画面/出声 | 有一次不行 ⇒ 电源/复位时序 |

## 12. 出问题怎么办

### 12.1 心跳灯快闪 = 有故障被锁存

⭐ **快闪不会静音**，它只驱动心跳灯。所以"快闪"和"没声音"可能是**两个独立问题**。

| 快闪的时机 | 含义 | 先查 |
|---|---|---|
| **一上电就快闪** | 开机瞬间错过一次，被锁住了 | 复位/时钟；**按一下复位**看是否还立刻闪 |
| 先慢闪、**过一会儿**才快闪 | 运行中真的出问题 | 时钟频率 / 供电 / 温度 |
| 按复位后**立刻又闪** | 每次开机必然发生 | 时钟 / 配置 |

**按复位后"多久开始闪"是最好的判据** —— 复位会清掉锁存。

### 12.2 快闪的 7 个来源（对号入座）

| 来源 | 含义 | 用户能做什么 |
|---|---|---|
| ADC 采集故障 | 采集链路出错 | 查 SPI 接线（见 12.3） |
| 混音渲染超时 | 声音处理卡住了 | ⭐ **会没声音**；查时钟 |
| 事件溢出/丢弃 | 事件太多被丢 | 通常可忽略（偶发） |
| 自动零点跳过/失败 | 某个轴零点没记上 | ⭐ **那个键会不响**；重标 |
| 参数配错 | 节拍器/鼓机参数非法 | 检查设置 |
| ⭐ **某轴从没被采到** | 有轴一直没数据 | ⭐ **直接指向那一片的接线** |
| 帧流失步 | 灌了谱但不出声 | 查谱格式 / 串口 |

### 12.3 没声音 —— 按"拔得掉 / 拔不掉"分

| 外设 | 在哪 | 拔掉会怎样 |
|---|---|---|
| 时钟（晶振） | **板载** | 拔不掉 ⇒ ⛔ 不是它 |
| 音频 DAC + 功放 | **板载** | 拔不掉 ⇒ ⚠️ 但要**外接喇叭/耳机** |
| **ADC（左右手板）** | **扩展板上** | 🔴 **没数据 ⇒ 没声音** |
| 按键灯 | 扩展板上 | 灯不亮，但**不影响声音** |
| 灯带 | 扩展板上 | 灯带不亮 |

### 12.4 ADC 接线的三条硬约束（违反必然出问题）

| # | 约束 | 为什么 |
|---|---|---|
| **1** | 两片的 **MISO 必须各自独立** | 两片同时选中 ⇒ 若并在一起 ⇒ **两个输出对打** ⇒ 数据必错 + **可能打坏 IO** |
| **2** | **CS 不能接反** | 接错片 ⇒ 读到另一片的数据 ⇒ **音高全错** |
| **3** | ⭐ **必须共地** | 不共地 ⇒ 电平飘 ⇒ 数据乱跳 ⇒ 全轴乱按 ⇒ 卡死 ⇒ 快闪 |

**最快的判别实验（5 分钟）**

| 实验 | 结果 ⇒ 结论 |
|---|---|
| ⭐ **把两根 MISO 都断开** | 灯**变慢闪** ⇒ 确认是 ADC 读数乱；还是快闪 ⇒ 不是 ADC |
| 量两根 MISO **之间的电阻** | **导通** ⇒ 🔴 并线了，必须改 |
| 串口发 `P` 读位置 | 全 `4095` ⇒ 饱和；全 `0` ⇒ MISO/片选有问题；各轴 2000~2900 且互不相同 ⇒ **正常** |
| 只接电源、不接任何信号线 | 还快闪 ⇒ 与信号线无关，是板载侧 |

### 12.5 按键不响但灯亮 / 灯不亮但按键响

| 症状 | 查哪里 |
|---|---|
| 按键响，**指示灯不亮** | 按键灯那三根线（锁存/数据/时钟）+ 对应的使能线 |
| 按键不响，**灯正常** | ADC 那一路（见 12.4） |
| 某个**单独的键**不响 | 那一路的 ADC 通道 / 那个键本身 |

### 12.6 串口完全没反应

```
① 波特率是不是 500000（⛔ 115200 一定不行）
② TX/RX 有没有交叉
③ 有没有共地
④ 发 P 试（P 一定会回包）
```

### 12.7 回退到已知可用的位流

```
已知可用：build\bitstreams\20261017-1813-Q4-BSRAM-slide-60MHz.fs
核对 sha256（见 sim\evidence\bitstream-index.md）后再烧
```
⚠️ 它缺 18:13 之后新加的两条功能（loop 发送按钮、EC11 参数联动）⇒ 别当成故障。

### 12.8 出问题请记这四项（反馈时最有用的）

```
1. 症状（看到/听到什么）+ 什么操作之后
2. 烧的是哪个位流（sha256 前 8 位即可）
3. 串口打印（500000 8N1）
4. 灯带状态（哪几颗灯亮、什么颜色、闪不闪）
```
