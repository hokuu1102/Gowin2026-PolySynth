# 上机操作手册 · 全项目

> ⭐ **这本手册是给"手上要动的人"看的**：摸哪个键、拧哪个旋钮、踩哪个脚踏、拨哪个推子；
> 做完之后**看到哪颗灯变什么颜色、听到什么声音、屏上出现什么**；没按预期时**先查什么**。
> ⛔ 不含任何代码、模块、信号、参数名 —— 那些在工程文档里。

---

## 0. 一分钟上手（最短路径）

```
① 接线：J9 排针（ADC 走 N1~N8，电源 N11=+5V / N12=GND，按键灯 N17~N21，调试串口 N25/N26）
② 上电：心跳灯应【慢闪】；HDMI 有画面；喇叭/耳机要有声（没插就一定没声）
③ 烧录：见 §11 开头那个"可烧的位流"
④ 按一个键：应该出声 + 对应指示灯亮
⑤ 出声了 ⇒ 其余功能按 §11 的顺序一条条走
```

⚠️ **三条最容易白折腾的**：
1. **喇叭/耳机没插** ⇒ 一切正常但没声音（心跳灯仍是慢闪，最容易误判）
2. **调试串口接线没交叉** ⇒ 所有串口命令都"没反应"
3. **串口波特率没改** ⇒ 一个字节都收不到（默认 115200 是错的）

## 1. 控制板 · 4×4 矩阵 16 键

**布局**：4 行 × 4 列 = 16 格，**15 个有功能 + 1 个备用**。
**读法**：**列 = 功能组**，同组的功能排在同一列里。

| | 列 0 · 节奏/循环组 | 列 1 · 音色组 | 列 2 · 音高组 | 列 3 · 系统组 |
|---|---|---|---|---|
| **行 0** | 节拍器 | 音色循环 | 滑音开关 | 显示切换 |
| **行 1** | 键盘打鼓 | 推子档位 | 变调 升 | 模式 指板/钢琴 |
| **行 2** | 鼓机节奏型 | **推子锁定** | 变调 降 | Test Mode |
| **行 3** | **looper 清空（长按 2 秒）** | **loop 发送**（旧位流里是"备用"，按了没反应） | **音高归零** | 标定（短按 = 零点，只发 `T`） |

### 逐键操作与期望

| 操作 | 期望现象 | 不正常的表现 |
|---|---|---|
| 按 **行0列0**（节拍器） | 第 **4** 颗灯开始**每拍暗一下**；听到节拍声 | 灯不动 / 有灯无声 |
| 按 **行0列1**（音色循环） | 第 **1** 颗灯换色：白→青→紫→橙 循环 | 灯不变色 |
| 按 **行0列2**（滑音） | 第 **6** 颗灯在滑音时变**青色** | — |
| 按 **行0列3**（显示切换） | 第 **7** 颗灯：蓝（波形）⇄ 品红（李萨如）；HDMI 画面跟着换 | 画面不变 |
| 按 **行1列0**（键盘打鼓） | 第 **2** 颗灯变**蓝 + 呼吸**（覆盖原来的橙/绿）；再按 16 键变成打鼓声 | 按键仍是乐音 |
| 按 **行1列1**（推子档位） | 第 **3** 颗灯循环：**紫（变调）→ 青（音高颤音）→ 黄（音量颤音）→ 紫**；推子改的物理量随之改变 | 灯不变 ⇒ 查控制板排线 |
| 按 **行1列2**（变调升） | 第 **6** 颗灯偏**暖橙**；音高整体**升一个八度**（+12 半音；到顶就停，⛔ 不回绕） | 音高不动 |
| 按 **行1列3**（模式） | 第 **2** 颗灯：**橙 = 指板** ⇄ **绿 = 键盘** | 灯不变 |
| 按 **行2列0**（鼓机节奏型） | 第 **4** 颗灯换色（红/洋红/黄/橙红 = 4 型） | 灯不变 |
| 按 **行2列1**（推子锁定） | 第 **3** 颗灯 **常亮 ⇄ 快闪**：快闪 = 当前档已锁定（推子动了也不改值） | 灯不变 ⇒ 当前档本来就是这个状态，再按一次 |
| 按 **行2列2**（变调降） | 第 **6** 颗灯偏**冷蓝**；音高整体**降一个八度**（−12 半音；到底就停，⛔ 不回绕） | 音高不动 |
| 按 **行2列3**（Test Mode） | 屏上切换测试档；听感/频谱上能数出不同数量的声部 | — |
| **长按 2 秒** 行3列0（looper 清空） | 第 **5** 颗灯回到**暗蓝 = 空闲**；已录内容被清掉 | ⚠️ **短按不清空**（防误触，这是设计） |
| 按 行3列1（loop 发送） | ⭐ **新版本**：立刻导出已录内容（串口吐帧）<br>⚠️ **旧位流**：这个位置是"备用"，**按了没反应是正常的** | — |
| 按 **行3列2**（音高归零） | 音高立刻回到默认（第 6 颗灯变灭） | 音高仍偏移 |
| **短按** 行3列3（标定） | 做一次"零点"标定；串口回 `t` | 回 `!` ⇒ 再等 1 秒（上电自动零点还没跑完） |
| **长按** 行3列3（标定） | ⚠️ **本键实际只发 `T`（零点标定）** —— 长按没有额外功能 | — |

⚠️ **"长按多久"**：looper 清空 = **2 秒**。其他长按没有额外门槛。

## 2. 控制板 · 8 颗 WS2812 指示灯

**一句话原则**：**颜色**管"是哪一档"，**闪不闪**管"开没开/在不在忙"。

| 第几颗 | 管什么 | 颜色含义 | 闪动含义 |
|---|---|---|---|
| **1** | 音色 | 白 = BASS · 青 = GUITAR · 紫 = PIANO · 橙 = PAD | — |
| **2** | 16 键此刻是什么 | 橙 = 指板 · 绿 = 键盘 | **蓝 + 呼吸 = 键盘打鼓**（覆盖前两者） |
| **3** | 推子功能（三个档） | **紫 = 变调 · 青 = 音高颤音 · 黄 = 音量颤音** | ⭐ **快闪 = 该档已锁定**（推子动了也不改值）；常亮 = 实时跟随 |
| **4** | 节奏 | 红 / 洋红 / 黄 / 橙红 = 鼓机 4 型；**绿 = 鼓机关但节拍器开** | **每拍暗一下约 100 ms = 节拍器开** |
| **5** | looper | 绿 = 回放 · 暗蓝 = 空闲 | **红 + 快闪 = 正在录**；**黄 + 快闪 = 武装中（在等小节线）** |
| **6** | EC11 对象 + 音高状态 | 静止时：暖橙 = 变调升 · 冷蓝 = 变调降 · 灭 = 无偏移 · **青 = 滑音中**（优先级最高） | 拧/按 EC11 后 **1 秒内**临时变：**黄 = 正在调 BPM**、**紫 = 正在调音高** |
| **7** | HDMI 显示 | 蓝 = 波形 · 品红 = 李萨如 | — |
| **8** | 效果器 | **灭 = 关**（占位期恒灭） | 预留 |

### 最容易看错的三种组合

| 第 4 颗的样子 | 真实状态 |
|---|---|
| 灭 | 鼓机关 + 节拍器关 |
| **绿 + 每拍暗一下** | 鼓机关 + **节拍器开** |
| 某个节奏型色**常亮** | 鼓机开 + 节拍器关 |
| 某个节奏型色 **+ 每拍暗一下** | 鼓机开 + 节拍器开 |

| 第 5 颗的样子 | 真实状态 |
|---|---|
| 暗蓝 | 空闲（没录没放） |
| **黄 + 快闪** | ⭐ **武装中** —— 按了录，但在等下一小节线，**这时候弹的音不录** |
| **红 + 快闪** | ⭐ **真的在录** —— 这时才弹 |
| 绿 | 回放中 |

## 3. 控制板 · EC11 旋钮

### 两种动作

| 动作 | 作用 |
|---|---|
| **旋转** | 改**当前对象**的值（一格一步） |
| **按压** | **切换对象**：BPM ⇄ 调音高 之间来回 |

⭐ **4 个机械格 = 1 步**（已做过 ÷4）⇒ 转一格就是改 1。

### 两种用法

**① 普通用法（不改模式）**

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 转 EC11（对象 = BPM） | 第 **6** 颗灯临时变**黄**（1 秒后回落）；节拍速度变化 | 灯不变 / 速度不变 |
| 按压一次 | 第 **6** 颗灯临时变**紫**（对象换成"调音高"） | 对象没切 |
| 再转 | 音高整体升降，第 **6** 颗灯变暖橙/冷蓝 | 音高不动 |
| 再按一次 | 切回 BPM | — |

**② 参数调节模式（调效果器那一批参数）**

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 串口发 `p`（小写） | ⭐ 串口**回一帧**：`Ee1...`（`E` `e` `1` 开头） | 不回帧 ⇒ 命令没到 |
| 转一格 | 回一帧，倒数第 3 个字符在 `+`/`-` 之间变，最后一位数字递增（0~9 循环） | 不回帧 |
| 参数模式下转 | ⚠️ **BPM 和音高都不动**（被门住了，这是设计） | 如果 BPM/音高还在动 ⇒ 没进模式 |
| 参数模式下按按钮 | ⚠️ **不回帧、无任何变化**（这是设计） | — |
| 串口发 `o`（小写）+ 一个字节 | 选中第 n 个参数（n = 0~7） | — |
| 再发 `p` | 退出；⭐ **BPM/音高对象恢复到进入前的那个** | 退出后对象变了 ⇒ 异常 |

### 回传帧长什么样（8 个字符）

```
E e 1 + 3 CR LF
│ │ │ │ └─ 已连续步进次数（'0'~'9'，十进制一位）
│ │ │ └─── 这一步是 + 还是 -（'+' / '-'）
│ │ └───── '1' = 参数模式 · '0' = 普通模式
│ └─────── 固定小写 e
└───────── 固定大写 E
```
⚠️ **正好 8 个字符**（6 个可见 + 回车 + 换行）—— 不是 7 也不是 9。

## 4. 推子（左手 / 右手）

### 一句话：推子有三个档，档位决定它管什么

| 档 | 第 3 颗灯 | 推子管什么 | 左推子 | 右推子 |
|---|---|---|---|---|
| **0** | **紫** | **变调**（整体音高） | 参与"差值" | 参与"差值" |
| **1** | **青** | **音高颤音** | 深度 | 速率 |
| **2** | **黄** | **音量颤音** | 深度 | 速率 |

⭐ **换档**：按 **行1列1** 循环（紫→青→黄→紫），或在**串口屏上点对应的效果器**直接跳过去。

### ⭐ 为什么"推子回 0"不会影响变调

变调看的是**两个推子的差值**，⛔ 不是"推多高音就多高"：

```
两个推子都在 0      ⇒ 差值 0   ⇒ 不变调      ← 这就是"回 0"安全的原因
一个在 0、一个在顶   ⇒ 差值最大 ⇒ 升一个八度
反过来              ⇒ 降一个八度
```

⇒ 所以"推子回 0"对**变调档**正好是中性位。

⚠️ 但**两个颤音档用的是推子各自的位置**（左 = 深度、右 = 速率）⇒ 推子一回 0，深度就变 0 = 颤音关掉了。
🔴 **这就是需要"锁定"的原因。**

### 锁定键（行2列1）—— 把当前档的值记住

按一下 **行2列1**：
- 第 3 颗灯变 **快闪** = 该档**已锁定**（推子怎么动都不改值）
- 再按一下 = 解锁（推子重新实时控制）

⭐ **锁定是"每档独立"的** —— 锁了音高颤音，切到音量颤音不会把它解冻。

### ⭐ 完整操作流（调两个颤音，最后还能实时变调）

```
① 屏点 [音高颤音]      → 推子切到档 1（灯变青）
② 推左推子到目标深度    → 实时听到音高颤音
③ 按 行2列1 锁定        → 灯变快闪
④ 推子推回 0            → 颤音保持（因为锁了）
⑤ 屏点 [音量颤音]      → 切档 2（灯变黄），推子从 0 开始 ⇒ 不跳变
⑥ 重复 ②③④
⑦ 切到 [变调]          → 两个推子都在 0 ⇒ 不变调，可以实时调音高
```

⚠️ **解锁那一刻会跳到推子当前位置** —— 这是正常的（"我现在接管了"）。想从当前值继续调，先把推子推到接近的位置再解锁。

### 操作与期望

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 按 **行1列1**（推子档位） | 第 **3** 颗灯循环 紫 → 青 → 黄 → 紫 | 灯不变 ⇒ 查控制板排线 |
| **档 0** 推推子 | 音高变化；第 **6** 颗灯暖橙（升）/ 冷蓝（降） | 音高不动 ⇒ 看第 3 颗灯是不是**快闪**（锁了） |
| **档 1 / 档 2** 推推子 | 颤音变深 / 变快；第 3 颗灯常亮 | 推了没反应 ⇒ 该档锁定了，按 **行2列1** 解锁 |
| 按 **行2列1**（锁定） | 第 3 颗灯 **常亮 ⇄ 快闪** | 灯不变 ⇒ 当前档本来就是这个状态 |
| 推到底再往回 | 音高/颤音跟着回来，不是"跳" | — |

⚠️ **变调范围**：整体音高可在 **−12 ~ +12 半音**（一个八度）之间调整。

### 粒度的分工（都是改同一个音高）

| 控件 | 粒度 | 用途 |
|---|---|---|
| **矩阵键 行1列2 / 行2列2** | **±12 半音（一个八度）** | 粗调、快速换八度 |
| **推子**（档 0） | 半音步进（可一扫而过） | 中调 |
| **EC11**（对象 = 音高） | ±1 半音 | 精调 |
| **串口 `F` / `G`** | ±1 半音 | 精调 |

⚠️ **如实说明**：推子的输出**已经是半音量化的**，不是连续变调。"连续"描述的是**手感**（能平滑扫过很多档），数值上仍是半音步进。

## 5. 脚踏开关

**共 3 个脚踏位**（PMOD0 排针）：

| 脚踏 | 作用 | 期望现象 |
|---|---|---|
| **延音**（踩住） | 手弹的音**不马上释放**，停在 sustain，松脚才收尾 | 踩住再松手 ⇒ 声音继续；松脚 ⇒ 声音收尾 |
| **looper 录/停** | 按一下开始录（⭐ 先进"武装中"），再按一下停 | 第 **5** 颗灯：**黄快闪 → 红快闪 → 绿** |
| **looper 播/停** | 按一下回放，再按一下停 | 第 **5** 颗灯：绿（回放）/ 暗蓝（停） |

⚠️ **延音只对"手弹"生效**：回放（曲谱/loop）的音不受延音踏板影响 —— 这是设计，⛔ 不是 bug。
⚠️ **looper 没有"清空"脚踏** ⇒ 清空要用控制板 **行3列0 长按 2 秒**。

## 6. 左手板 · 指板（霍尔/位置）

### 是什么
**左手板**是一块**位置感应**的指板：每个"品"是一个模拟通道，手指**按下去的位置**连续可读。
所以它同时能给你：**音高**（按哪个品）+ **力度**（按多深/多快）+ **滑音**（在品之间横向移动）。

⭐ **8 列 × 2 行、上下严格对齐的磁轴网格**，**同一块物理网格**在"钢琴手感"与"指板滑弦"之间切换（只换映射表，硬件只做一次）。指板模式下**纵向差一个八度**。

### 操作与期望

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 按住一个品 | 出声（对应音高） | 无声 ⇒ 先查 ADC 接线（见 §12） |
| **下拨一次**（摇杆） | **只响一次**（⛔ 不"回中又响一次"） | 响两次 |
| 按住两个品，**连拨两次** | **第二个音能出来** | 永远只响第一个 |
| **交替拨弦**（按A→拨→松→按B→拨→松，来回几轮） | **不挂音** | 挂音（一直响不停） |
| 按住一个品，**连拨 3 次** | **每次都要响** | 只响第一次 |
| **换品后松手**（按6→拨→换9→松9） | 正在响的那个音**停掉** | 挂着不停 |
| **正常速度**横向滑过相邻品（⭐ 需先开滑音） | 音高**连续跟随**（不是"跳成另一个音"） | 几乎不触发 ⇒ 见下 |

### ⚠️ 滑音的前提（最容易漏）

```
① 必须切到【指板模式】（控制板 行1列3，第 2 颗灯变橙）
② 必须【打开滑音】（控制板 行0列2，或串口 W）
③ 然后按住一个音，横向往相邻品滑
```
⚠️ **钢琴模式下开滑音不会有滑音** —— 这是设计。

⚠️ **看起来像 bug 但不是**：滑音阈值调得很宽松 ⇒ 一开滑音，音高会有**持续的细微抖动**（每帧都在判定）。默认是**关**的，需要时才开。

## 7. 串口屏

| 项 | 说明 |
|---|---|
| 走哪条线 | ⭐ **就是调试串口那一根**（J9 的 **D14/D15**，波特率 **500000**）—— ⛔ **不是** ESP32 那条 |
| 为什么能共用 | 屏和 PC 调试终端**挂在同一个串口上**，两者看到的是同一路数据 |
| 显示什么 | 参数值、EC11 调节反馈、测试档位等 |
| 能看到什么 | 拧 EC11 时屏上参数值实时变化；参数调节模式下的 `Ee...` 帧也会到屏 |

⚠️ **所以"屏"和"PC 调试终端"是同一个口** —— 要么接屏、要么接 PC，**同一时刻只能接一个**（除非做分线，但那会让两边都收到对方的字节）。

⚠️ 波特率同样是 **500000**（⛔ 不是屏常见的 115200 默认档，屏侧也要改成 500000）。

## 8. HDMI 显示器

| 操作 | 期望现象 | 不正常 |
|---|---|---|
| 接屏上电 | 有画面（彩条/波形） | 全黑 ⇒ 查 HDMI 线、查心跳灯是否慢闪 |
| 按 **行0列3**（显示切换） | 画面在**波形** ⇄ **李萨如（XY）** 之间切换；第 **7** 颗灯蓝 ⇄ 品红 | 画面不变 |

## 9. 串口（PC 侧上位机）

### 物理层（⭐ 最容易搞错的地方）

| 项 | 值 |
|---|---|
| **波特率** | ⭐ **500000**（⛔ 不是 115200，⛔ 也不是老的 1 Mbaud） |
| 格式 | **8N1** |
| 接线 | ⭐ **必须交叉**：板的 TX → USB-TTL 的 RX；板的 RX ← USB-TTL 的 TX |
| 地 | ⭐ **必须共地** |

⚠️ **踩过的坑**：TX/RX 接反 ⇒ 所有命令"没反应"，曾被误判成代码 bug。
⚠️ 很多 USB-TTL 默认 115200 ⇒ **必须先改成 500000**，否则一个字节都收不到。

### 常用命令（发一个字母，多数会回一个小写字母）

| 发 | 作用 | 回包 |
|---|---|---|
| `P` | 读**位置**（⭐ **用它测链路通不通**，一定会回） | 数值 |
| `T` | 标定"零点" | `t`（⚠️ 不回包也是正常的？—— **会回 `t`**；若回 `!` 见 §12） |
| `S` | 标定"满量程" —— ⚠️ **已决定取消**，新位流将不再响应 | `s`（旧位流才回） |
| `X` | 中止标定 | — |
| `V` / `N` | 读标定状态 / 标定后位置 | 数值 |
| `I` | 切音色（白→青→紫→橙） | `i` |
| `B` | 节拍器 开/关 | `b` |
| `D` | 鼓机节奏型 切下一个 | `d` |
| `K` | 键盘打鼓 开/关 | `k` |
| `W` | 滑音 开/关 | `w` |
| `E` | HDMI 波形 ⇄ 李萨如 | `e` |
| `A` | 模式 指板 ⇄ 钢琴 | `a` |
| `F` / `G` | 变调 −1 / +1 **半音**（⭐ 精调；矩阵键 行1列2/行2列2 是**八度**粗调） | `f` / `g` |
| `J` | 推子档位切下一档（紫 → 青 → 黄 → 紫 循环） | `j` |
| `R` / `L` / `C` | looper 录/停 · 播/停 · 清空 | — |
| `Y` | 导出已录内容（14 字节/条） | 帧流 |
| `O` | 实时上行 开/关（每个音一帧 14 字节） | `o` |
| `U` | 指引模式 开/关（**只亮灯不出声**） | `u` |
| `M` | Test Mode 切换 | `4`/`8`/`A`/`B` |
| `p`（**小写**） | 进/出**参数调节模式** | `Ee...` 帧 |
| `o`（**小写**）+ 一个字节 | 选第 n 个参数 | — |
| `Z` | 读**效果器状态**（⏳ 未上板的版本里没有） | 6 字节 |

⚠️ **大小写完全不同**：`O`（大写）= 实时上行；`o`（小写）= 选参数。`P` = 读位置；`p` = 参数模式。

### 两个"要跟一整帧"的命令（`H` / `Q`）

```
发 H（或 Q）之后，必须再灌一整帧（0xA5 + 8 字节），那个帧的第 1 个载荷字节才是数值。
```
🔴 **不这么做会出事**：紧跟着的普通演奏帧会被当成数值 ⇒ **一灌谱就把 BPM 改乱**。

### 效果器参数（帧格式：`71 <序号> <值> FF FF FF`）

| 序号 | 作用 | 常用值 |
|---|---|---|
| `10` | 开关掩码（bit0 失真 · bit1 合唱 · bit2 延迟） | **全开 = `07`** |
| `11` | 失真增益 | `40`(=4.0× 默认) · `C0`(吉他) · `FE`(最狠) |
| `12` | 失真补偿 | `20`(=0.25 默认) · `0B`(吉他) |
| `13` | 延迟/合唱混合 | 0=全干，`FE`≈全湿 |
| `14` | 延迟反馈 | — |
| `15` / `16` | 颤音深度 / 速率 | — |
| `17` | 延迟长度 | `40` ⇒ 约 168 ms |
| `18` | 合唱长度 | `17` ⇒ 约 15 ms |

**按音色配一组（让失真在四种音色下都听得出来）**：

| 音色 | `11` 增益 | `12` 补偿 |
|---|---|---|
| PAD | `40` | `20` |
| BASS | `52` | `19` |
| PIANO | `90` | `0E` |
| GUITAR | `C0` | `0B` |

⚠️ **值最大只能发到 `FE`（254）** —— `FF` 是帧尾标记，发不进去。

## 10. ESP32 与灌谱网页

> ESP32 在这套系统里**只做一件事**：把 MIDI 谱子灌进 FPGA。
> 本节的目的是"**怎么点**"，⛔ 不涉及任何数据格式、协议、字节 —— 那些在工程文档里。

### 10.1 接线与上电

| 项 | 做法 |
|---|---|
| **ESP32 电源** | **USB 线独立供电**（⛔ 不要从 FPGA 板取电） |
| **ESP32 ↔ FPGA** | ESP32 的 **GPIO17(TX)** → FPGA 的 **G21**；ESP32 的 **GPIO18(RX)** → FPGA 的 **G22**；**GND 必须共地** |
| **电平** | ✅ 两侧都是 **3.3 V**，⛔ **不用电平转换** |
| **上电顺序** | ⭐ **先 FPGA，后 ESP32**（反了会丢帧） |

⚠️ **TX/RX 一定要交叉**（ESP32 的 TX 接 FPGA 的 RX）。接反了现象是"两边都没反应"。

### 10.2 打开网页

- 用 **Chrome 或 Edge** 打开 `esp32/tools/score_studio.html`
- ⛔ **不用装任何东西**（网页自带 Web Bluetooth）
- ⚠️ **Safari / 部分手机浏览器不支持** Web Bluetooth ⇒ 打不开"连接设备"

### 10.3 网页上的按钮（照这个顺序点）

| 步 | 点哪里 | 期望看到 | 不正常的表现 |
|---|---|---|---|
| 1 | **「连接设备」** | 弹出蓝牙选择框，选到 ESP32 那个设备名 | 弹不出框 ⇒ 浏览器不支持 / 没给蓝牙权限 |
| 2 | **「选择文件」** → 选一个 MIDI | 显示曲名、事件数 | 选了没反应 ⇒ 那个文件不是 MIDI |
| 3 | **「上传」** | 进度条走完，提示上传完成 | 卡住不动 ⇒ 连接断了，回到第 1 步 |
| 4 | **「清空」**（可选，换歌前先点） | 状态区数字归零 | 不归零 ⇒ 其实没连上 |
| 5 | **「开始播放」** | **FPGA 出声** + LED 指引亮起来 | 没声音 ⇒ 见 §12；⭐ 先确认不是"指板模式"（发 `A` 切回钢琴） |
| 6 | **「停止」** | 声音停、游标停住 | 还在响 ⇒ 再点一次 |

### 10.4 网页上"看不到东西"怎么判

| 现象 | 最可能的原因 | 先查什么 |
|---|---|---|
| 「连接设备」弹不出框 | 浏览器不支持 Web Bluetooth | 换 **Chrome / Edge** |
| 搜不到 ESP32 | ESP32 没上电 / 固件没跑 | 看 ESP32 板载 LED 是否慢闪 |
| 能连上，但"实时状态"区全是 `-` | 状态链路没通 | 确认 FPGA 已上电且心跳灯在闪 |

| 播放到一半停住 | 谱子太长、灌的过程中丢了帧 | 重新上传一次再播 |

## 12. 出问题怎么办

### 12.1 心跳灯快闪 = 有故障被锁存

⭐ **快闪不会静音**，它只驱动心跳灯。所以"快闪"和"没声音"可能是**两个独立问题**。

| 快闪的时机 | 含义 | 先查 |
|---|---|---|
| **一上电就快闪** | 开机瞬间错过一次，被锁住了 | 复位/时钟；**按一下复位**看是否还立刻闪 |
| 先慢闪、**过一会儿**才快闪 | 运行中真的出问题 | 时钟频率 / 供电 / 温度 |
| 按复位后**立刻又闪** | 每次开机必然发生 | 时钟 / 配置 |

**按复位后"多久开始闪"是最好的判据** —— 复位会清掉锁存。

### 12.2 快闪的 7 个来源（对号入座）

| 来源 | 含义 | 用户能做什么 |
|---|---|---|
| ADC 采集故障 | 采集链路出错 | 查 SPI 接线（见 12.3） |
| 混音渲染超时 | 声音处理卡住了 | ⭐ **会没声音**；查时钟 |
| 事件溢出/丢弃 | 事件太多被丢 | 通常可忽略（偶发） |
| 自动零点跳过/失败 | 某个轴零点没记上 | ⭐ **那个键会不响**；重标 |
| 参数配错 | 节拍器/鼓机参数非法 | 检查设置 |
| ⭐ **某轴从没被采到** | 有轴一直没数据 | ⭐ **直接指向那一片的接线** |
| 帧流失步 | 灌了谱但不出声 | 查谱格式 / 串口 |

### 12.3 没声音 —— 按"拔得掉 / 拔不掉"分

| 外设 | 在哪 | 拔掉会怎样 |
|---|---|---|
| 时钟（晶振） | **板载** | 拔不掉 ⇒ ⛔ 不是它 |
| 音频 DAC + 功放 | **板载** | 拔不掉 ⇒ ⚠️ 但要**外接喇叭/耳机** |
| **ADC（左右手板）** | **扩展板上** | 🔴 **没数据 ⇒ 没声音** |
| 按键灯 | 扩展板上 | 灯不亮，但**不影响声音** |
| 灯带 | 扩展板上 | 灯带不亮 |

### 12.4 ADC 接线的三条硬约束（违反必然出问题）

| # | 约束 | 为什么 |
|---|---|---|
| **1** | 两片的 **MISO 必须各自独立** | 两片同时选中 ⇒ 若并在一起 ⇒ **两个输出对打** ⇒ 数据必错 + **可能打坏 IO** |
| **2** | **CS 不能接反** | 接错片 ⇒ 读到另一片的数据 ⇒ **音高全错** |
| **3** | ⭐ **必须共地** | 不共地 ⇒ 电平飘 ⇒ 数据乱跳 ⇒ 全轴乱按 ⇒ 卡死 ⇒ 快闪 |

**最快的判别实验（5 分钟）**

| 实验 | 结果 ⇒ 结论 |
|---|---|
| ⭐ **把两根 MISO 都断开** | 灯**变慢闪** ⇒ 确认是 ADC 读数乱；还是快闪 ⇒ 不是 ADC |
| 量两根 MISO **之间的电阻** | **导通** ⇒ 🔴 并线了，必须改 |
| 串口发 `P` 读位置 | 全 `4095` ⇒ 饱和；全 `0` ⇒ MISO/片选有问题；各轴 2000~2900 且互不相同 ⇒ **正常** |
| 只接电源、不接任何信号线 | 还快闪 ⇒ 与信号线无关，是板载侧 |

### 12.5 按键不响但灯亮 / 灯不亮但按键响

| 症状 | 查哪里 |
|---|---|
| 按键响，**指示灯不亮** | 按键灯那三根线（锁存/数据/时钟）+ 对应的使能线 |
| 按键不响，**灯正常** | ADC 那一路（见 12.4） |
| 某个**单独的键**不响 | 那一路的 ADC 通道 / 那个键本身 |

### 12.6 推子推了没反应

⭐ **先看第 3 颗灯是不是"快闪"** —— 快闪 = 该档被**锁定**了，推子动了也不会改值。

| 现象 | 最可能的原因 | 怎么恢复 |
|---|---|---|
| 推子推了，参数完全不动 | ⭐ **该档已锁定**（第 3 颗灯快闪） | 按 **行2列1** 解锁（灯变常亮） |
| 推子推了没反应，灯是**常亮** | 档位不对（比如想调音高颤音，但当前在变调档） | 按 **行1列1** 换档，看灯变青 |
| 档 1 / 档 2 推了没变化 | 深度被推到了 0 | 把推子推上去 |
| 档 0 推了音高不变 | 两个推子位置相同（差值 0 = 不变调） | 一个推上、一个推下才有变化 |
| 换了档，声音突然变了 | ⭐ 正常：换档 = 换这个推子管什么 | 想保住旧值，先按 **行2列1** 锁定再换档 |

### 12.7 串口完全没反应

```
① 波特率是不是 500000（⛔ 115200 一定不行）
② TX/RX 有没有交叉
③ 有没有共地
④ 发 P 试（P 一定会回包）
```

### 12.8 回退到已知可用的位流

```
已知可用：build\bitstreams\20261017-1813-Q4-BSRAM-slide-60MHz.fs
核对 sha256（见 sim\evidence\bitstream-index.md）后再烧
```
⚠️ 它缺 18:13 之后新加的两条功能（loop 发送按钮、EC11 参数联动）⇒ 别当成故障。

### 12.9 出问题请记这四项（反馈时最有用的）

```
1. 症状（看到/听到什么）+ 什么操作之后
2. 烧的是哪个位流（sha256 前 8 位即可）
3. 串口打印（500000 8N1）
4. 灯带状态（哪几颗灯亮、什么颜色、闪不闪）
```
