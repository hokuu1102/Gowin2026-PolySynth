# tools/ - 上板调试期的对照实验脚本（归档）

这些脚本是 2026-09-30「从全黑到出彩条」排查过程中的对照实验工具，
**不是交付物**，保留是为了让排查配方可复现。详见 `../上板调试记录-20260930.md`。

| 脚本 | 做什么 |
|---|---|
| `build-h1-led.ps1` | 给 H1 官方 720p 参考加 `V13` 心跳灯（产出对照码流 F） |
| `build-i-official-640x480.ps1` | 官方加密 IP + 640×480@25.000 MHz（产出对照码流 I，用于隔离"显示器/模式"与"我们的 RTL"） |
| `build-frac-candidate.ps1` | 分数分频时钟候选（`MDIV=17+5/8` → 25.179 MHz，产出码流 E） |

⚠️ 它们写于一次临时排查会话，内含**本机绝对路径**（`C:\Users\cyx\Desktop\...`）
与对**工作副本**的原地改写（改完自动还原）。搬到别的机器/目录前需要调整路径。
