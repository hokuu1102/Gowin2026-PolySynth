## 二、⭐ 逻辑梳理：先确认工作流成立

### 2.1 用户的完整操作流

```
① 屏点 [音高颤音]      → 推子切档 1（第 3 颗灯变青）
② 推 ch2 到目标深度    → 实时听到颤音
③ 按【锁定键】         → 档 1 冻结
④ 推子回 0             → 颤音保持（因为锁了）
⑤ 屏点 [音量颤音]      → 切档 2，推子从 0 开始 ⇒ 不跳变
⑥ 重复 ②③④
⑦ 切 [变调]            → 两推子都在 0 ⇒ 不变调，可实时调音高
```

### 2.2 ⭐ 一个关键发现：变调是**双推子差分**，不是绝对位置

`fader_gear.v:143-149`（已核）：

```verilog
wire [3:0] left_step  = gear_step_of(ch2_i);   // 左推子 0..12
wire [3:0] right_step = gear_step_of(ch3_i);   // 右推子 0..12
wire [5:0] fader_enc6 = 6'd12 + right_step - left_step;   // 0..24，12 = 不变调
```

⇒ **两个推子都在 0 ⇒ `12 + 0 − 0 = 12` ⇒ 不变调** ✅
⇒ **所以"推子回 0"对变调档正好是中性位** —— 用户第 ⑦ 步的直觉是对的，切到变调**不会**一来就降八度。

⚠️ 但要注意语义在档之间**不一致**：
| 档 | ch2 的含义 | ch3 的含义 |
|---|---|---|
| 0 变调 | 左（参与差分） | 右（参与差分） |
| 1 音高颤音 | 深度（绝对） | 速率（绝对） |
| 2 音量颤音 | 深度（绝对） | 速率（绝对） |

⇒ 这正是"必须锁定"的根因：档 1/2 是绝对值，推子回 0 就等于关掉。

## 四、接口定义（⭐ 先定死，子代理才能并行）

### 4.1 `rtl/w3a/fader_gear.v` 新端口

```verilog
module fader_gear (
    // ── 现有端口全部保留（⛔ 不改名、不改宽）──
    ...
    // ── 新增 ──
    input  wire        gear_sel2_i,     // 屏点选：直接跳档 2（单周期脉冲）
    input  wire        gear_sel1_i,     // 屏点选：直接跳档 1（单周期脉冲）
    input  wire        gear_sel0_i,     // 屏点选：直接跳档 0（单周期脉冲）
    input  wire        lock_toggle_i,   // 锁定键：翻转【当前档】的锁定位（单周期脉冲）
    output reg  [11:0] trem_depth_o,    // 档 2 = ch2_i 透传（音量颤音深度）
    output reg  [11:0] trem_rate_o,     // 档 2 = ch3_i 透传（音量颤音速率）
    output reg  [2:0]  hold_o           // 三档锁定状态（bit0/1/2 对应档 0/1/2），给 LED/屏
);
```

**优先级（同拍时）**：`gear_sel0/1/2` > `gear_next_i`（循环） > 保持。

### 4.2 行为表（⭐ 这是全案的契约）

| 条件 | `transpose_semi_o` | `vibrato_depth_o/rate_o` | `trem_depth_o/rate_o` | `gear_o` |
|---|---|---|---|---|
| 复位 | 0（enc=12） | 0 / 0 | 0 / 0 | 1 |
| 档 0 且 `!hold[0]` | 跟随 `fader_enc` | **保持** | **保持** | 0 |
| 档 0 且 `hold[0]` | **保持** | **保持** | **保持** | 0 |
| 档 1 且 `!hold[1]` | 保持 | `ch2_i` / `ch3_i` | **保持** | 1 |
| 档 1 且 `hold[1]` | 保持 | **保持** | **保持** | 1 |
| 档 2 且 `!hold[2]` | 保持 | **保持** | `ch2_i` / `ch3_i` | 2 |
| 档 2 且 `hold[2]` | 保持 | **保持** | **保持** | 2 |
| 复位后 | `hold_o = 3'b000`（**全解锁**，用户裁定） | 0 | 0 | 1 |

**"保持"的实现（关键：⛔ 不能破坏档 1 的零延迟透传）**：

```verilog
// 档 1 时逐位透传（组合），离开档 1 时用影子寄存器保持
always @(posedge clk)
    if (!rst_n)                 begin vib_d_hold <= 12'd0; vib_r_hold <= 12'd0; end
    else if (gear_o == 2'd1 && !hold[1]) begin vib_d_hold <= ch2_i; vib_r_hold <= ch3_i; end

wire [11:0] vib_d_eff = (gear_o == 2'd1 && !hold[1]) ? ch2_i : vib_d_hold;
```

⇒ 档 1 时**组合透传**（与现状逐位相同 ✅）；离开或锁定时读影子寄存器（保持）。

档 2 的 `trem_*` 同构。

档 0 的 `enc_r` 保持：现有 `else enc_next = enc_r` 已经是"保持"，只需把接管条件改成 `(fader_moved || gear0_enter) && !hold[0]`。
