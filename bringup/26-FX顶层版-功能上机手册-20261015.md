# FX 顶层版功能上机手册

适用日期：2026-10-15。验证源码：`0e98a58a8e69b13d779621de4e756b25707ee056`。

本文针对“彩色 FFT + 合并演奏功能 + 效果器顶层接入”候选，按实际操作功能编排。旧操作卡与本文冲突时，不照搬旧卡的命令、显示模式和验收结论。

## 2. 接线、上电和配置

1. 沿用此前 BJ 已验证的 FPGA、左右手板、控制板、HDMI、DAC/音箱接线。本轮没有改端口、时钟或引脚约束，不需要为了 FX 改线。
2. 改线前断电。音箱先静音或调到低音量，确认供电、共地和 DAC 型号后再上电。不要把板载功放的差分扬声器输出当作接地线路输出。
3. 用 Gowin Programmer 打开上表对应的 `.fs`，按已验证的板卡配置执行下载。本文不指定未经现场确认的烧写操作编号，不要求写入非易失存储。
4. 确认 Programmer 成功、原心跳/显示正常，再缓慢提高外部音箱音量。SRAM 配置断电后需重新下载。
5. 串口控制使用原控制 UART，**500000 baud、8N1、无流控**。USB-TTL 使用匹配板卡的逻辑电平、TX/RX 交叉且共地；不要凭旧文档认定板载 USB-C 能透明传输这些命令。

注意：FPGA 接受字符命令的端口与 ESP32 数据链路不要混接；同一串口不要同时由两个电脑程序占用。

## 3. 第一次出声：先做最小测试

1. 所有磁轴松手，等待上电稳定；不要在按住键时重新去皮。
2. 用正常演奏方式发一个单音，保持片刻再松手。检查有起音、持续音、松手后的自然尾音。
3. 连续慢按、快按、换轴，再试和弦；检查没有卡音、随机爆音、声道异常。
4. 全效果档松手后仍有回声属于预期，不能把正常尾音当挂音。持续不衰减、越来越响或出现刺耳异常则立即降低音量并停止测试。
5. 如无声，先确认所选文件、音箱/DAC、标定状态和是否处于测试/打鼓模式，不要先改 RTL 或换引脚。

## 4. 标定与演奏模式

| 操作 | 串口 | 控制板 | 用途 |
|---|---|---|---|
| 去皮 | `T` | 第4行第4列短按后松手 | 全部松手时校准零点 |
| 行程标定 | `S` | 第4行第4列长按约2秒 | 按回传轴号完成行程标定 |
| 取消标定 | `X` | — | 取消当前标定操作 |
| 指板/钢琴切换 | `A` | 第2行第4列 | 切换原有演奏模式 |
| 滑音开关 | `W` | 第1行第3列 | 正常上电默认关闭，按一次翻转 |

标定期间不要演奏、移动传感器或拔线。`S` 后按终端提示的轴号逐轴操作：同一校准通道涉及的两块左手 ADC 板，同号轴需按既有标定要求同时按到底并保持，收到完成提示再松手；不要把“发一次 S”理解成所有轴自动完成。右手板不套用左手同号轴规则。可对照 `bringup/19-标定操作流程-20261001.md`，但以当前回包和实际硬件连接为准。

滑音测试：开启 `W`，按既有指板动作演奏并改变位置，听音高是否连续跟随；再按 `W` 关闭做对比。换音色、松手和重新拨弦后都应能正常恢复，不应遗留挂音。

## 5. 音色、变调和推子

| 功能 | 操作 | 预期 |
|---|---|---|
| 四音色循环 | `I`；或板载 S2；或控制板第1行第2列 | BASS → GUITAR → PIANO → PAD → BASS |
| 升半音 | `G`；或第2行第3列 | 每次升1半音，到限值后不再增加 |
| 降半音 | `F`；或第3行第3列 | 每次降1半音，到限值后不再减少 |
| 推子档位循环 | `J`；或第2行第2列 | 切换原有推子控制档位，不是效果器开关 |
| 编码器对象切换 | 按下原编码器 | BPM/变调对象切换；旋转调整当前对象 |

先用同一单音比较四种音色，再测力度、长音和松手尾音。全效果档会改变音色和动态，不能用它判断原始音色是否逐样本等同 BJ；要判断干声，请使用旁路档并保持相同输入和音量。

## 6. 鼓机和键盘打鼓

| 功能 | 操作 | 说明 |
|---|---|---|
| 背景鼓机开关 | `B`；或第1行第1列 | 当前 SEL_DRUM=1，源B是鼓机，不是旋律声部；上电源B关闭 |
| 鼓节奏型循环 | `D`；或第3行第1列 | BASIC / HOUSE / ROCK / DANCE_FILL |
| 键盘打鼓模式 | `K`；或第2行第1列 | 开关原有键盘打鼓模式，再按恢复 |

先单测旋律，再开启鼓机，避免把背景节奏当成多余杂音。FX 位于混音器之后，鼓机和其他汇合声源也会受到效果处理，不只处理左手旋律。

## 7. 录制、循环回放与导出

| 功能 | 串口 | 操作建议 |
|---|---|---|
| 录制/停止录制 | `R` | 发一次开始，演奏一小段，再发一次停止 |
| 播放开关 | `L` | 开始/停止循环回放 |
| 清空当前层 | `C` | 会丢弃该层事件，确认不需要后再发 |
| 控制板清空 | 第4行第1列长按约2秒 | 防误触；不是短按 |
| 导出录制事件 | `Y` | 使用与14字节上行格式匹配的现有接收/重打包工具 |

建议先只录2～4个音，再回放，检查音符、录制音色、停止和清空。停止音符或清空后可能仍有 FX 尾音；最终应衰减，不应无限持续。

本版沿用合并版的 **14字节 Y 导出**，不提供旧9字节导出兼容档。独立下行事件仍是原9字节协议，不要把两个方向的格式混用。记录的是原有事件，不是把音箱输出录成 PCM 音频。

## 8. HDMI 波形、李萨如和彩色 FFT

`E` 或控制板第1行第4列：**波形 → 李萨如 → FFT → 波形**循环。上电具体显示取决于该构建的 SCOPE_MODE，不靠盲按次数判断，直接看标题。

FFT 特征：2048点，128根填充彩色柱，柱间有黑缝；沿横轴由粉红、橙、黄、绿到青。显示的是频谱，不是时域波形。

| 状态 | 横轴范围 | 说明 |
|---|---|---|
| 正常演奏，N=00 | 约0～12.207kHz | 保持用户选定的×2显示，左低频、右高频 |
| Test Mode | 约0～24.414kHz | 全频段；不能用其位置直接对比正常模式 |

FFT 取自主音量处理后的最终音频：全效果档中它反映处理后的声音，失真可能产生更多高次谐波；合唱/颤音会让频谱随时间变化。不同音色频谱不必覆盖整个屏幕；低音乐器能量偏左正常。不要把正常谐波峰强行要求成平滑曲线。

测试音源：`M` 或第3行第4列，按 **正常 → 4 → 8 → 16 → 32 → 正常**循环。看屏上的 N 确认当前档；回到 **N=00** 后再做正常演奏检查。这里的 N 是测试声部数，**不是 FFT 点数**。单独发 `N` 是位置诊断命令，不是选择 N 挡。

## 9. 本次效果器怎么测试

本轮没有新增运行时效果控制。**第3行第2列“效果器键”仍是占位；串口屏 FX 状态/LED 也不代表本编译档的开关。不要通过它们判断效果有没有开启。**

全效果 `.fs` 的固定参数：

| 效果 | 设置 | 建议听什么 |
|---|---|---|
| 失真 | 开，增益4倍、输出补偿0.25倍，当前选择器仍是硬削波算法 | 起音/强音更粗、谐波增加；不保证每个弱音都明显削波 |
| 合唱 | 开，基准延迟732个样本 | 持续音的厚度、轻微游动；不要误认为和弦多了声部 |
| 延迟 | 开，8192样本，dry/wet=128，feedback=96 | 短音松手后的重复与衰减；延迟约168ms，非精准音乐拍长 |
| 颤音 | 深度128，速率参数7 | 持续音的周期性音量变化；不是滑音/音高颤音 |

延迟换算按约48.828kHz采样率。深度、混合与反馈使用现有整数算法，不把“128”当严格听感50%。首次启动延迟 RAM 需要填充，先演奏约1秒再判断湿声；当前大延迟缓存约0.336秒可填满。

推荐测试顺序：

1. 低音量下弹一个短音，松手，听尾部回声是否逐渐减弱。
2. 弹一个持续音，听合唱厚度与音量周期变化。
3. 在四种音色上重复，并在 FFT 页观察谐波差异。
4. 开启鼓机、播放录制片段，确认同样有声音且控制仍正常。
5. 降低主音量，检查包括湿声在内的最终输出随之降低。

这一个 `.fs` 同时开启四种效果，无法凭它独立验收每一种算法；要严格 A/B，需另外生成单效果/旁路固定档并重新验收。本文不表示那些单效果固件已经生成，也不要求现场重编译。

## 10. 串口高级功能与注意事项

`O` 是原有实时上行开关，`U` 是原有指引模式开关；这轮没有修改 ESP32、指引逻辑或协议。应配合同版本 ESP32/上位机验证，不靠纯字符终端猜二进制回包。

`H`（绝对变调）和 `Q`（BPM）需要后续协议载荷，不能当作只发一个字母就完成设置。`P/N/V` 是原有诊断入口，不等同于演奏/显示操作；不要套用旧文档中把 Q 当显示切换的写法。此处不提供未经本手册逐字节验证的自制二进制帧，请使用工程既有配套工具。

## 12. 上机记录与问题判断

记录：文件完整路径、下载时间、档位、音色、N显示、演奏模式、滑音/鼓机/回放状态、音箱音量和异常录像。

| 现象 | 优先确认 |
|---|---|
| FX键没效果 | 本轮正常限制：效果由编译参数固定，不受该键控制 |
| 松手仍有声音 | 区分延迟尾音和无衰减挂音；录制、鼓机、Test Mode 是否仍开 |
| 声音周期性起伏 | 全效果档有颤音与合唱，先用旁路档A/B |
| FFT峰很靠左 | 正常低频能量分布，不要求每种音色铺满横轴 |
| FFT与旧版不一样 | 确认×2/全频段、N以及是否开启失真；最终音频已改变 |
| 标定不通过/按键无声 | 看回包、连线和逐轴标定过程，不靠不断加音量解决 |
| 爆音、断续、输出异常 | 立即降音量，保存复现条件；不能因为仿真/STA通过就排除实板问题 |

验收勾选：单音、和弦、四音色、力度、松手释放、指板/钢琴、滑音、鼓机、键盘打鼓、录制/回放/清空、三种HDMI显示、N恢复00、两路音频（有对应硬件时）、FX短音与长音、湿尾音随主音量降低。最后对照默认旁路档复验原功能。
