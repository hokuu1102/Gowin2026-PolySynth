## 二、⭐⭐ 最高优先：**示波器抓位对齐**（⭐ 20 分钟）

> 🔴 **这是本次上机【唯一能定性】"低频小 + 失真"的测量。**
> ⭐ 因为仿真止于 `sample_mono`，⭐ **其他 9 条假设都排除了** ⇒ ⭐ **只剩这一条没测**。

### ⭐ 接法

| ⭐ 探头 | ⭐ 接到 |
|---|---|
| **CH1** | ⭐ `I2S2_LRCK`（⭐ 引脚 **`E22`**） |
| **CH2** | ⭐ `I2S2_DIN`（⭐ 引脚 **`D22`**） |
| ⭐ 触发源 | ⭐ **CH1**，⭐ **下降沿**（⭐ = 左声道起点） |
| ⭐ 时基 | ⭐ **~2 µs/格**（⭐ 一帧 20.48 µs） |
| ⭐ 地夹 | ⭐ 接 GND |

### 🔊 **播放内容**：⭐ 让它**持续响一个低音**

⭐ **问题**：⭐ 自检和弦只响 **1 秒**（⭐ 且是 A4/C#5/E5 高频），⭐ **不是低频**。

📌 **⇒ 用【按键】制造持续低音**：
```
⭐ 上电 → 等 1 秒（⭐ 自检和弦响完）→ ⭐ **按住一个琴键不放**
⇒ ⭐ 那个键会持续发声（⭐ A2=110Hz 或 D3=147Hz）
```

### 🔴 判据（⭐ 关键）

```
⭐ 标准左对齐（⭐ PCM5102A 的 `FMT`=3V3 时应如此）：

   LRCK:  ‾‾‾‾‾|________|‾‾‾‾‾‾        ← 下降沿 = 左声道数据开始
   DIN :  ------|X X X X X X X X|----  ← ⭐ 数据必须【紧贴】下降沿开始
                ↑
                ⭐ 第 1 个 BCK 就该有数据

🔴 若 DIN 在下降沿后【空了 1 个 BCK】才开始
   ⇒ 🔴 **位对齐差 1 位** ⇒ ⭐ **这就是"低频小 + 失真"的根因！**
```

### ⭐ 若确认差 1 位 ⇒ **改法**

```
⭐ `top.v` 的 `u_i2s_tx_ext` 的 `.MSB_DELAY (0)` 改成 `(1)`
   ⇒ ⭐ 一行改动 ⇒ ⭐ 重跑 PnR（⭐ ~10 分钟）⇒ ⭐ 再烧
⚠️ 但注意：⭐ 你实测过 `MSB_DELAY=1` **完全没声**（⭐ `dac_tone` 三档实测定案）
   ⇒ ⚠️ **若真差 1 位又"改不得"，⭐ 说明问题在别处**（⭐ 先记录下来）
```

## 六、🔴 接线（⭐ 照这张，⛔ 别凭直觉）

| ⭐ 模块丝印 | ⭐ 接到 | ⚠️ |
|---|---|---|
| `VIN` | **5V** | 🔴 **不是 3.3V**（⭐ 模块有 `MIC5219` LDO） |
| `GND` | GND | ⭐ 共地 |
| `LCK` | **`E22`** | ⚠️ **三根挨着，逐根对** |
| `DIN` | **`D22`** | ⚠️ 同上 |
| `BCK` | **`F20`** | ⚠️ 同上 |
| `SCK` | **GND** | 🔴 **必须接地**（⭐ 内部 PLL 要求） |
| `XSMT` | **3V3** | 🔴 **低 = 软静音** |
| `FMT` | **3V3** | ⭐ = 左对齐 |
| `FLT` / `DEMP` | GND | ⭐ 本次可试 `FLT`→3V3 |

### ⚠️ 丝印陷阱（⭐ 上次三根全错）

```
🔴 模块丝印只标 6 个脚（VIN/GND/LCK/DIN/BCK/SCK）
⚠️ 而排针 JP1 实际有 11 个脚
   （11/10 VCC · 9 GND · 8 FLT · 7 DEMP · 6 SCK · 5 BCK · 4 DIN · 3 LRCK · 2 FMT · 1 XSMT）
⇒ 🔴 **FLT/DEMP/FMT/XSMT 是【没标注】的**
⭐ **务必先确认 1 脚位置（方形焊盘），按丝印名逐根接**
```
