## 二、⭐⭐ 关键约束：**两块板必须【同号键同时按】**

⭐ **这是硬件结构决定的，⛔ 不是软件 bug**：

```
⭐ cal_ch_mux = sp_busy_r ? sp_ch : at_ch      （⭐ top.v，⭐ 两片【共用同一个 ch】）
⭐ calib_span 的 span_o = {N_ADC{1'b1}}        （⭐ 两片【同拍广播】）
⇒ 🔴 若只按板 2 的同号键、⭐ 板 1 那个键没按
   ⇒ ⭐ 板 1 的 raw 仍是"松手值" ⇒ ⭐ calib 判 err=1
   ⇒ ⭐ top.v 的 cal_err_any 置起 ⇒ 🔴【整轴被拒】（⭐ RJ_CAL_ERR）✅
```

⇒ ⭐ **操作要求**：⭐ **对每一根轴，⭐ 同时按住【两块板上同一个键号】的键到底** ✅
⭐ **用户已确认可以做到** ✅（⭐ 一个人两只手即可 ✅）

## 三、⭐ 逐轴流程（⭐ 一次一根轴）

⭐ **对轴 `k = 0,1,2,…,15` 重复**：

| ⭐ 步 | ⭐ 动作 | ⭐ 期望回包 | ⚠️ 不对时 |
|---|---|---|---|
| **1** | ⭐ 发 **`'S'`** | ⭐ 回 **`s`**（受理） | ⚠️ 只回 `!` ⇒ ⭐ 看原因码 |
| **2** | ⭐ 看是否回 **轴号**（⭐ 如 `0`） | ⭐ 回 `0`~`9`/`A`~`F` | ⚠️ 不回 ⇒ ⭐ 见 §五 |
| **3** | ⭐ **两块板同时把轴 `k` 的键按到底**，⭐ **保持不动** | ⭐ 稳定后回 **`.`**（完成） | ⚠️ 回 `!` ⇒ ⭐ 该轴被拒（⭐ 见 §五） |
| **4** | ⭐ **松手** | ⭐ 自动进入下一根轴（⭐ 回下一个轴号） | — |
| **5** | ⭐ 重复到 16 根轴走完 | ⭐ 最后回 **`T`**（⭐ 全部完成 ✅） | — |

⭐ **回包样例**（⭐ 今晚 `tb_span_axis_over_uart` 实测复现过 ✅）：
```
s 0 . 0 . 0 ! 0 ! ... T
│ │ │ │
│ │ │ └─ ⭐ '.' = 该轴标定完成
│ │ └─── ⭐ '!' = 该轴被拒（⭐ 需重试）
│ └───── ⭐ 轴号（⭐ 十六进制：0~9 A~F）
└─────── ⭐ 's' = 'S' 受理
```

⚠️ **`!` 是【可重试】的** —— ⭐ 重标同一根轴**不算失败** ✅（⭐ `REJECT_MAX=8` 才放弃 ✅）
