## 三、一条命令

```powershell
# 今天就能跑的全部验证（仿真 + 工具自检）
powershell -NoProfile -ExecutionPolicy Bypass -File bringup\run_all.ps1

# 加上 Gowin 全流程（多花约 2 分钟；会写 impl/，但 impl/ 已被 gitignore）
powershell -NoProfile -ExecutionPolicy Bypass -File bringup\run_all.ps1 -WithGowin
```

> ⚠️ `run_all.ps1` **故意写成全 ASCII**：本机 PowerShell 5.1 会把无 BOM 的 UTF-8 按 GBK 解码，
> 中文注释会变乱码并报语法错（见经验库 `U46` / `files/20-代码/已知问题与风险清单.md` `K-38`）。
