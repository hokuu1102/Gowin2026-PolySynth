# HDMI当前模式回显修正

基线为5589795。用户澄清屏幕文字应显示当前选中的模式，斜杠表示三选一。
旧清单R5d要求固定文字，导致uart_ui的ECH_F_HDMI将三个名称直接拼接。
本次恢复按st_scope_i选择：0=HDMI: 波形，1=HDMI: 李萨如图，2=HDMI: 频谱；无效值沿用波形兜底。
顶层已有scope_mode_r到st_scope_i的连接，模式变化触发也已存在。本次只修改文字载荷选择，不改实际HDMI渲染、模式循环、DSP或音频链路。
测试覆盖握手与切页全量回显、0→1→2→0模式切换、长文案切短文案无残留、状态不变不重发，以及发送中切换保持前帧完整并发送新模式。
旧烧录件仍保留，源码修正必须重新编译烧录后才能体现在板上。实机切换效果待验收。
