# 串口屏联调后续清单实现（2026-11-02）

基线为已发布51线交付0da99f09b7a389690d7393ed3c89a24ce5dacac1。旧交付源码、烧录件、标签保留。本次先本地提交，不推送。
本说明对应用户后续清单，取代旧说明中“未锁定离档仍保持”和“速率百分比仍用FX源”的行为约定。

## 修改及协议

- R2补充：真实数值帧`71 11 6F FF FF FF`复现载荷误当raw-o并自动进入参数模式，新增触摸/数值帧载荷隔离；raw-p切换和raw-o下一字节载荷仍按旧协议工作，A5事件帧的隔离与优先级保留。
- R2：`6F <0..7>`选择参数并自动进入EC11参数模式。重复选择保持模式开启。首次进入保存原BPM/变调对象，退出按原串口小写p切换协议恢复；保留参数号低3位的旧映射规则。没有重复实现FX限幅/步进。屏幕b_back按清单增加 `printh 70 FF FF FF`，在已进入参数模式后退出。
- R3：上一版已接通 `71 05 <0/1/2> FF FF FF`，本次保留合法值校验、单拍脉冲、直选优先级和实际切档自动锁存，重复点当前档不改锁定。
- R3b：活动未锁档即时跟随推子；非活动未锁档的四个fader_gear颤音输出清零；已锁档继续输出影子值。实体/J循环切档不自动锁定；屏直选切档先锁存，所以屏直选后可保留原效果。锁定键仍翻转当前档，解锁立即跟随推子。只改输出mux，不改量化、enc_r或影子更新规则。既有独立屏幕/串口FX源优先级保留。
- R4/R4b：z_pr/t_pr_val/j_pr与原音高频率文本同取st_prate_i，随该输入变化统一重发；z_vr/t_vr_val/j_vr与原音量频率文本同取st_vrate_i，随其变化统一重发。移除FX速率镜像及其旧仪表触发，但FX速率寄存器与实际DSP控制仍保留。音量百分比0..31缩放，31及以上饱和99；乘法显式扩宽。推子满量程时音量频率23.1Hz、仪表99%、数字99%。音高原始满量程频率文本仍为本工程原映射12.0Hz，没有修改LFO。
- R5：上一版0 SEMI保留。R5b：鼓机只显示当前所选Pattern I..IV，关闭时仍显示预选节奏；不改变独立启停或事件门控。R5c：踏板改[PEDAL ON]/[PEDAL OFF]。R5d后续更正：用户澄清斜杠表示三选一，HDMI文字按当前模式显示“HDMI: 波形”“HDMI: 李萨如图”或“HDMI: 频谱”，切换时同步回显。此前按清单原文拼接固定文字的行为已修正，实际HDMI模式逻辑未改。
- R9：新增st_hold_i三位输入，顶层先声明后接线，新增t_lock及t_lock_info，握手/切页全量包含这两个字段，锁定位变化重发两项，档位变化重发当前档锁定文字。控件名缓存由9字节扩到11字节，待发位由57扩到59位，发送背压及帧快照保留。
- 锁定编号裁定：新t_lock采用工程原始档号0/1/2（0变调、1音高、2音量），符合清单验收“hold=010→档1已锁”；t_lock_info只列[1]/[2]，不列变调锁。清单示例里gear+1与验收文字矛盾，本版不使用该加1。既有t_gear/gr的旧显示编号不在本次清单改动范围内。
- R6/R8：沿用现有触摸请求、全局回传开关up_enable_r、真实状态回显和evt_upstream门控。回传关闭后不再接收新的任何事件，之前已经入队的帧可发完；没有恢复松键尾事件特例。R7未提供新的具体实机故障，保留既有按键到状态再回显链并做相关回归。R10鼓机背景色按用户要求暂缓。

## 屏端配套（用户手动改）

未提供p0.HMI或TFT，未修改屏幕二进制工程。请按新清单S1/S2/S3/S4设置头部颜色、参数按钮、b_back及遮挡位置。
t_drum.txt_maxl至少12，t_pedal至少12，t_hdmi至少33，t_lock至少12，t_lock_info至少14；字体库须包含新锁定词与原HDMI汉字。
颤音按钮变灰的分支不发关机命令，不会自动关闭颤音；实际效果仍由档位、锁定和深度决定。

## 上板重点

1. 点任一参数按钮后直接转EC11，检查对应数值和仪表同步变化；参数模式退出后恢复原BPM/变调对象。
2. 不锁定，实体切走音高/音量档，检查该推子来源的输出归零；锁定后切走保持。屏直选则先自动锁存原档。
3. 音量档速率拉满：z_vr/j_vr为99，t_vr_val为99%，t_vr为23.1Hz。音高速率仪表和百分比同样同步。
4. 锁定音高/音量时t_lock_info分别显示锁定[1]/[2]/[1][2]，解锁后只移除对应项。变调锁不列在汇总中。
5. 鼓机独立关闭时仍显示预选Pattern，切型保持四型循环，不会自动打开；验证踏板/HDMI新文案。
6. 验证实时回传实体键、屏按钮和串口O能控制同一实际开关，关闭后新按键事件不再进入上行。

仿真结果和原生时序以交付目录报告为准；未跑全量回归，实机触摸、听感、BLE和长稳仍待烧录后验收。
