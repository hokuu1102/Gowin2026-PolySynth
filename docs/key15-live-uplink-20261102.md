# 原标定键改为实时回传开关

本次修正基线：`f8bbdad`（53.587 MHz 按键回传版本）。该版本源码和烧录文件保留；本次按用户要求移除“关闭后继续转发松键”的例外。

- 控制板矩阵 idx15，逻辑第4行第4列，消抖后松手切换实时回传。
- 上电关闭；短按、长按都在松手时只切换一次；不再触发实体键标定。
- 与串口 `O`、屏幕“实时上行”共用 `up_enable_r`，屏幕显示实际状态。同拍多个请求只切换一次。
- 保留上电自动标定及原有串口 `T` 标定，接线、引脚、时钟、14字节回传协议和 ESP32 固件均不变。
- 关闭后停止接收所有新事件，包括 note_on、note_off 和 pluck，不再补发松键消息。首次开启前后使用相同的关闭逻辑。
- 关闭前已经接收的事件按原顺序发完，避免截断半帧；队列排空后，关闭状态下继续按键、松键、拨弦均不产生新的回传帧。下游队列中已经接收的字节也可能需要先发完。
- 不清空、暂停或修改本地音频、灌谱、指示灯和 Loop。发送队列不因关闭而冻结，因此在下游恢复可写时继续排空，不等待再次开启。

边界：不改变原 FIFO 深度及溢出策略。若下游持续阻塞导致 FIFO 溢出，仍通过现有 drop/overflow 计数报告；不能据此保证任意超负载下不丢事件。没有新增强制 all-notes-off 协议或重新开启时的持音快照。

新增关闭回归：开启后关闭，在队列排空后反复注入 ON/OFF/pluck，要求零新增回传；保留阻塞、半帧、重新开启、实际矩阵键及串口/屏幕同步等相关验证。原生编译及时序证据保存至 `D:\ChatGPT\Outputs\FPGA-key15-uplink-disable-fix-20261102`；最终结果以该目录交付清单为准。
