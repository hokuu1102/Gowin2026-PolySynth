# 串口发送 FIFO 的 BSRAM 映射验证

基于 `380d95c069caeb97610ddf6dece02ca4101bfe88`，原串口屏修订版本保留。整机默认参数 place=1/route=0 出现 PR0004，506 条网络未布通；place=0/route=0 同样失败，659 条网络未布通。另有参数重试仍在进行，不能将未完成的构建记为成功。

本候选只在 `uart_tx_fifo.v` 的存储数组声明上增加厂商综合指令 `syn_ramstyle="block_ram"`。队列深度仍为 64，数据宽度仍为 8；读写、计数、满空判断、busy 握手、溢出和清零逻辑均未改动。RTL 功能语句、其他模块、引脚与时序约束均保持原样，没有关闭 HDMI、频谱、Loop、效果器或诊断功能。

语法依据：现有工具自带 `SUG550-2.4E_GowinSynthesis User Guide.pdf`，PDF 第 80–82 页（正文 72–74 页）。指令放在数组声明和分号之间，作用于本数组；没有全局强制所有存储器映射为 BSRAM。

## 已完成验证

- 在同一 C1/I0 器件上对完整 FIFO 接口、深度 64 进行独立原生综合，0 错误、0 警告。结果为 1 块 BSRAM、31 个寄存器、45 个 LUT。独立综合保留全部 8 位数据输入，不能把其数量直接与整机中常量优化后的 FIFO 数量混算。
- 使用该原生综合网表以及安装目录内的 GW5A `prim_sim.v` 厂商模型，与冻结提交的 FIFO RTL 逐周期对比全部公开输出。50,512 个时钟、8,389 次发送启动全部一致，包含首字节启动周期、背压、深度 64 的满空及绕回、饱和溢出、清除时再次溢出，以及读写期间复位。
- 综合后的真实 BSRAM 模型参与上述比较；这不是仅运行会忽略综合指令的 RTL 仿真。
- 现有深度 8/64 容量及绕回用例、默认深度 8 的 50,412 周期接口等价用例、并发清除/丢弃用例均通过；静态检查 7/7 通过。没有重跑无关的全部回归。
