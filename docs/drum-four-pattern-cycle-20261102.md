# 鼓机恢复四节奏型循环

基线为本地锁定切档修复 `f01a0e7`（报告 Fmax 54.640 MHz，实际 50 MHz 门禁通过）。旧源码与烧录件保留；本轮不推送远端。

## 操作

- 实体矩阵 idx8、串口 D、屏幕 b_drum：只切换节奏型，Ⅰ→Ⅱ→Ⅲ→Ⅳ→Ⅰ，不再包含关闭状态。
- 实体矩阵 idx0、串口 B：沿用独立的源B启停开关；当前默认源B为鼓机。
- 上电仍关闭鼓机。关闭时可预选节奏型，不自动开机；重新开启保留所选节奏，不强制回到Ⅰ。
- 屏幕 t_drum 和鼓机指示灯跟随实际鼓机启用状态；关闭时显示关，开启后显示选中的节奏型。
- 键盘打鼓、曲谱鼓事件、Loop、实时回传及三档效果锁定功能保持原控制规则。

## 原因与改动

旧顶层为节奏切换额外维护 `drum_on_r`，使第四型之后进入关闭状态，同时又受到独立 `met_on_r` 开关键控制。两层开关使节奏切换兼做关闭。

本轮恢复独立两位节奏计数器，按切型请求自然回绕；不再保存第五状态。鼓机启用状态从原有源选择、编译期总闸与运行时开关键组合得到，屏幕、指示灯和音符事件门控一致。未改变四套节奏内容、BPM、复位对齐、力度或鼓声音色。
