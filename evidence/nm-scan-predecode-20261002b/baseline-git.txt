    （u_tx_fifo LUT 65→66、calib_span 262→259、looper 4225→4184）。
    
    【修复】对回传锥加宽松、非 exclusive 的区域约束（constr/top.cst）：
      GROUP h5_ret = { "tx_byte_*" "u_tx_fifo/*" "g_sound.u_calib_span/reject_o_*" };
      GRP_LOC h5_ret R[45:73]C[1:148];
    Gowin 语法要点（SUG1018 §2.4.1，两句缺一则无效）：对象必须是原语实例（⛔ 不能用模块名）；
    多个对象在一个花括号内【空格分隔】（逗号会 CT2000）；必须带层次路径（裸 push_ok_* 会 CT1135）；
    区域列上限为 148（超了 CT1101）。该约束只限制放置范围，⛔ 未放宽任何时序要求、未加 false path。
    
    【结果】clk_sys 44.757 → 50.040 MHz，setup 违例 21 → 0，hold 0，pixel_clk 127.906 MHz，
    器件 C1/I0，PA1019/ERROR = 0；原最差路径 calib_span → u_tx_fifo 已退出最差路径，
    新的最差为 g_sound.u_note_manager/scan_cnt_1 → best_env_0/CE，slack +0.016。
