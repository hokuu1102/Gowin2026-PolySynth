## 已组合的修复

| 项目 | 内容 |
| --- | --- |
| 行程比例滑音 | 按两轴校准行程比例跟随；手指停住，音高停住，不再自动滑向 B |
| 切模式释放 | 多轴持音记录保留至对应 OFF，避免切模式后松键无法释放 |
| 指板连续拨弦 | 保留已触发轴的释放记录，避免旧音符遗留 |
| 滑音持音与释放 | A 松开、B 按住时保持原声部；结束时释放一次，取消过期或重复 OFF |
| FIFO 溢出清零 | 清历史状态与新丢弃同拍时保留新丢弃，标志为 1、计数为 1 |
| 通知逻辑优化 | 无新增周期，减少通知状态使能逻辑；公开 UART/SPI/I2S 逐拍等价已核验 |
| 验收加强 | 未知值、无明确结论、负向测试及诊断复现分别处理；补真实双 UART 隔离测试 |

完整保留原有功能。系统和音频仍用 50 MHz 直接时钟体系；没有新增系统 PLL、CPU、HLS。
现有 HDMI 时钟实现未改。硬件 ADC 参数未改，Y 导出仍为 9 字节，FFT 暂不新增。
滑音仍在指板模式通过 W 开关，键盘模式不执行滑音。

FIFO 写入分拍**不在本版中**。备选完整历史位于 `a9227e3`；本机同时保留
`codex/backup-fifo-writepipe-20261014` 分支。该备选多占 287 CLS，故未升为本版。
