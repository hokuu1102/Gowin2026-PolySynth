# 修法 1 实验：限幅前裕量 −6 dB → −12 dB（2026-10-04 20:10）

## 背景（已定位的根因）

`tdm_render_mixer.v:410-434` 的复音归一化是 **`gain(N) = 128/√N`**（Q8.7），
设计注释明确写着「**`1/√N` 会【超】不削顶所需的增益**（实测 N=32 时超 5.66 倍）
⇒ ⭐ 所以必须配【软限幅】兜底」。

按设计自己的定标（单 voice 峰值 ≈ 65532、满幅 2^23）算：

| N | 增益 | 峰值/满幅 | 越过 87.5% 软限幅阈值的倍数 |
|---|---|---|---|
| 1 | 128 | 1.00× | 1.14× |
| 2 | 90 | 1.41× | 1.61× |
| **3** | 74 | ⭐ **1.73×** | **1.98×** |
| 4 | 64 | 2.00× | 2.29× |

⇒ ⭐ **N≥2 已超阈值、N=3 近 2 倍** ⇒ 软限幅进入二次软膝/平台 ⇒ 听感"破/爆破"。

**为什么只有音色 0(BASS) 和 3(PAD)**：设计里那句「日常 1~4 音完全不失真」**假设包络≈满**，
而实际持续段包络由 `sustain` 决定 —— BASS **0.70** / PAD **0.90** 保持高电平 ⇒ 越界；
GUITAR **0.30** / PIANO **0.40** 衰减掉 ⇒ 不越界。

**用户实测**：轻按不出现 ✅ · 3 个及以上出现 ✅ ⇒ 与"电平越界"判断一致 ✅

## 本次改动（一行参数）

```
rtl/top.v:4292   .OUTPUT_HEADROOM_SH  (1) → (2)      // −6.02 dB → −12.04 dB
```

⚠️ **代价**：整体音量降 6 dB（`master_mix` 的主音量可补，但右手板音量当前**没生效**，
   所以这 6 dB 暂时补不回来）
