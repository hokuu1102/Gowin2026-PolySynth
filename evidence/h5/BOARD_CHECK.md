# H5 上板操作与验收记录表

本任务尚未执行 H5 硬件烧录或观察显示器。下列是待执行步骤与预期，不能当作实测结果。

1. 使用 Tang Console 60K，核对器件 `GW5AT-LV60PG484AC1/I0`、Device Version B。
   接好已验证的 HDMI 显示器、演奏输入和原有音频输出。沿用现有接线。
2. 在 Gowin Programmer 中选择本轮生成的 `evidence/h5/Gowin2026_H5.fs`，
   使用 **SRAM Program**。先核对 `main-timing-summary.txt` 中的 SHA-256；
   上板前也应阅读 `REPORT.md` 中仍未通过的项目（如果有）。
3. 复位并等待初始化。显示器应识别 640×480，黑底，中心线在 y=240。
   默认时钟为 25.000 / 125.000 MHz，实际刷新率为 59.5238 Hz。
4. 静音时绿色波形与中心线重合；有信号时绿色波形覆盖暗灰中心线。
   环形历史首次填满及帧快照完成前，只显示暗灰中心线。
5. 弹奏单音、改变力度/主音量、切换音色并弹奏和弦：绿色波形幅度与形状应
   随 `master_mix` 的实际输出变化；大幅度信号可在顶部/底部被显示钳位。
   未使用零交叉触发，波形相位移动属于当前设计预期。
6. 核对原有音频仍正常，V13 的 `led_heartbeat` 仍约 1 Hz。
   本次没有替换主工程的心跳逻辑；不要用 bringup 的“快闪表示失锁”解释主工程心跳。
7. 留存显示器照片或视频、音频/演奏联动观察和 V13 心跳观察，再填写结果。
