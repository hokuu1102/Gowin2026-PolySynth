# 右手板缺失导致快闪（2026-10-12）

结论：右手板未连接导致 ADC2 端点数据告警；不是新增采样 / Mixer / FIFO 代码故障。Q 切换修复已获得实板确认，保留。

## 实板证据

```text
!F1 004 004 004 009E75B3 1
current=004 [ADC2]
sticky=004 [ADC2]
first=004 [ADC2]
first_fault_ms=207.69638
```

COM14，500000 baud / 8N1，原始记录为 `evidence/fault_diag_20261012/red_adc2_first_fault.log`。时间符合默认 200 ms 启动窗口之后约 16 帧 / 8 ms 的判据。Mixer、事件、曲谱、Looper、合流与 TX FIFO 的报告位均为 0。随后确认右手板实际上未接，解释了这一症状。

## 原说法 → 更正 → 原因

原说法：最新 Q 修复版仍快闪，可能还有代码缺陷。

更正：本次快闪为右手板缺失的正常告警；不再为该现象改动故障逻辑。

原因：真实 UART 首次 / 累计故障掩码只标记 ADC2，且缺板事实已确认。仅掩码不能独立证明断线，因此结论是实板记录与实际接线状态共同支持的，而不是单凭端点值定罪。
