# 引导模式使用说明

面向使用者的一页说明。目标场景只有一个：**练琴**——只听背景，看灯弹引导轨。

---

## 1. 这个模式是干嘛的、什么时候用

| 项目 | 说明 |
|---|---|
| 用途 | 练琴时**只听背景 + 看灯弹引导轨**。引导轨的灯告诉你该在什么位置打，但**它自己不发声**，不会把你要打的东西替你打出来。 |
| 什么时候用 | 想跟着谱面练某一条轨（鼓、贝斯、旋律等）时；想在有节拍器的情况下逐段过谱时。 |
| 什么时候不用 | 只想听成品回放、不需要提示时，保持「启用」为关即可，行为与之前完全一致。 |

一句话：**背景轨出声，引导轨只亮灯，节拍器帮你数拍。**

---

## 2. 界面在哪、每个控件什么意思

- 上位机页面：`esp32/tools/score_studio.html`
- 本地服务：`127.0.0.1:8777`
- 启动方式：`esp32/tools/start_score_studio.bat`
- 位置：页面**左侧**的卡片，名字叫**「引导模式」**
- 注意：左栏的卡片变多了，**左栏可以上下滚动** —— 找不到某张卡片时往下滚。

| 控件 | 标识 | 类型 | 默认值 | 作用 |
|---|---|---|---|---|
| 启用 | `gd_on` | 开关 | **关** | 总开关。关着时本模式全部不生效，页面与设备行为跟以前一样。 |
| 引导轨 | `gd_track` | 下拉（单选） | 待确认 | 指定哪一条轨作为「引导轨」。该轨**只亮灯不出声**。 |
| 节拍器 | `gd_met` | 开关 | **关** | 是否叠加节拍器。 |
| 节拍器音型 | `gd_style` | 下拉 | **beat** | 节拍器的打法，三选一：`beat` / `off` / `four`。 |
| 引导范围 | `gd_scope` | 下拉 | **保留其他轨** | 决定引导轨**以外**的内容去留。`all` = 保留其他轨（引导轨 + 节拍器 + 其他轨当背景一起出声）；`solo` = 只有引导轨（除引导轨和节拍器外全部丢掉，**最纯粹的练习模式**）。 |
| 鼓声 | `gd_drum` | 下拉 | **节拍器** | 决定**鼓从哪来**。`met` = 节拍器（丢掉谱面的鼓轨，只放节拍器）；`track` = 谱面鼓轨（只放谱面自己的鼓，不放节拍器）；`both` = 两者都要。 |
| 状态行 | `gd_sum` | 文本（只读） | — | 汇总当前设置，用来看「现在到底开了什么」。 |

> 默认值写死：**启用 = 关，节拍器 = 关，音型 = beat，引导范围 = 保留其他轨（`all`），鼓声 = 节拍器（`met`）。**

---

## 3. 标准操作步骤

1. **打开 MIDI**（把谱面文件载入）。
2. **勾音轨**：在「音轨选择」里勾出你想听到的背景轨（取消勾选哪条，右侧卷帘里那条就消失 —— 见第 5 节）。
3. **选引导轨**：在「引导模式」卡片的「引导轨」下拉里选一条轨。
4. **开节拍器**：打开「节拍器」开关（需要时）。
5. **选音型**：在「节拍器音型」下拉里选 `beat` / `off` / `four`。
6. **选引导范围**：`all` 保留其他轨当背景，`solo` 只留引导轨 + 节拍器。
7. **选鼓声**：`met` 只放节拍器，`track` 只放谱面鼓轨，`both` 两者都要。
8. **一键上传**：把当前配置下发到设备。
9. **起播**：开始播放，按第 4 节的预期现象核对。

> 提示：引导轨即使没在「音轨」里勾选，程序也会**强制保留它**，否则灯不亮。

---

## 4. 预期现象

| 对象 | 预期 |
|---|---|
| 引导轨 | **只亮灯，不出声**（LED 提示引导轨的落点）。 |
| 背景轨 | 正常出声（**引导范围 = 保留其他轨** 时）。 |
| 节拍器 | 响，并且**跟着谱面变速走**（谱面快它就快，谱面慢它就慢）。 |
| LED | **只提示引导轨**，不是所有轨都点灯。 |

按「引导范围」和「鼓声」两个下拉，实际出声的内容如下：

| 设置 | 实际出声 |
|---|---|
| 引导范围 = 保留其他轨（`all`，默认） | 引导轨 + 节拍器 + 其他已勾选轨（当背景一起出声）。 |
| 引导范围 = 只有引导轨（`solo`） | 引导轨 + 节拍器；其他旋律轨全部丢掉（谱面鼓轨是否保留由「鼓声」决定）。 |
| 鼓声 = 节拍器（`met`，默认） | 谱面鼓轨被丢掉，鼓声全部来自节拍器。 |
| 鼓声 = 谱面鼓轨（`track`） | 不放节拍器，鼓声全部来自谱面鼓轨。 |
| 鼓声 = 两者都要（`both`） | 谱面鼓轨和节拍器都出声。 |

注意：**「节拍器」开关开着，不等于节拍器一定会响** —— 若把「鼓声」选成 `track`，节拍器会被丢掉（此时以「鼓声」为准）。

---

## 5. 右侧卷帘：所见即所灌

右侧钢琴卷帘画的内容，就是**一键上传实际会灌下去、实际会出声的那一份**（含背景轨）。规则：

| 情况 | 卷帘里画什么 |
|---|---|
| 左边「音轨」取消勾选某条 | 卷帘里那条**立刻消失**（卷帘跟着「音轨」勾选走）。 |
| 引导模式开着 | 画的就是**实际会出声的**内容：含背景轨；鼓按「鼓声」下拉的选择（`met` 时卷帘里没有谱面鼓轨，`track` 时没有节拍器）。 |
| 引导范围 = 只有引导轨（`solo`） | 卷帘里只剩引导轨（+ 节拍器，+「鼓声」选到的谱面鼓轨）。 |

要点：**卷帘 = 会出声的内容**，所以「看到的」和「听到的」不会对不上。卷帘与 LED 不是一回事 —— LED 只提示引导轨，卷帘画全部会出声的内容。

## 6. 常见疑问排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 灯不亮 | 引导轨没被正确保留 / 位流不是新的 / 引导轨选错 | 先确认引导轨选择正确；再确认设备已刷入**支持 bit6 的新位流**；确认上传已成功。 |
| 引导轨也出声了 | 多半是**位流没更新**（旧位流不认 bit6） | 重新烧写新位流后再上传配置。旧位流下 bit6 被忽略，引导轨会照常出声，但**不会损坏任何现有功能**。 |
| 节拍器不响 | 节拍器开关没开 / 音型选成了不合适的档位 / **「鼓声」选成了 `track`（此时节拍器被丢掉）** / 上传未生效 | 打开「节拍器」，选一个音型（如默认 `beat`），把「鼓声」改回 `met` 或 `both`，重新一键上传。 |
| 节拍器少了一下 | **与谱面鼓同件落点太近时会跳过那一下** | 这是**设计如此**：跳过后不会被前一下的 note-off 掐掉，避免出现半截音。若把鼓声选成『节拍器』（默认），谱面鼓轨被丢掉 ⇒ 节拍器不再被避让、整拍都响。 |
| 卷帘里少了某条轨 | 「音轨」里没勾那条 / 「引导范围」选了 `solo` / 「鼓声」选成 `met` 把谱面鼓轨丢掉了 | 卷帘画的就是实际会出声的内容：把那条轨在「音轨」里勾上，或把「引导范围」改回 `all`，或把「鼓声」改成 `track` / `both`。 |
| 找不到某张卡片 | 左栏卡片变多了，需要滚动 | 在**左栏上下滚动**，找不到的卡片多半在下方。 |
| 想关掉怎么办 | — | 把「启用」开关关掉（或关掉「节拍器」只留引导轨），重新上传即可，回到普通回放行为。 |

## 7. 跟「音轨选择」「音色下拉」「卷帘」的关系

| 控件 | 选择方式 | 管什么 |
|---|---|---|
| 引导轨（`gd_track`） | **单选** | 指定唯一一条「只亮灯不出声」的轨。 |
| 引导范围（`gd_scope`） | 单选 | 引导轨**以外**的内容去留：`all` 保留其他轨 / `solo` 只留引导轨 + 节拍器。 |
| 鼓声（`gd_drum`） | 单选 | 鼓从哪来：`met` 节拍器 / `track` 谱面鼓轨 / `both` 两者。 |
| 音轨选择 | **多选** | 决定哪些轨作为背景出声；**同时决定卷帘里画哪些轨**（取消勾选 = 卷帘里消失）。 |
| 音色下拉 | — | **只管音色**，不影响引导/背景的路由，也不影响卷帘里出现哪些轨。 |

要点：**引导轨是单选，音轨选择是多选，音色下拉只管音色。** 三者互不替代。卷帘跟着「音轨」勾选走，再叠加「引导范围」「鼓声」的裁剪 —— 所以**卷帘里画的 = 实际会灌下去、会出声的**。

## 8. 机制说明（原文照抄）

- 引导轨的事件置 64 位事件字 `bit6=1`（仅指引），FPGA 侧按它路由，**只进 LED 指引链、不进发声链**。
- 引导轨音符**只点灯不出声**，其余轨当背景正常出声。
- LED **只显示引导轨**，不是所有轨。
- 节拍器用**鼓机事件生成**，不是 FPGA 内置，所以**跟着谱面变速走**。
- 音型三选一：`beat`（默认）1 底鼓 / 2 嗵鼓 / 3 军鼓 / 4 嗵鼓 + 每拍踩镲；`off` 同上但踩镲落反拍；`four` 踩镲每拍 + 底鼓 1/3 + 军鼓 2/4。
- 节拍器**与谱面鼓同件落点太近时会跳过那一下**；若把鼓声选成『节拍器』（默认），谱面鼓轨被丢掉 ⇒ **节拍器不再被避让、整拍都响**。
- 引导范围（`gd_scope`）：`all` = 保留其他轨当背景一起出声；`solo` = 除引导轨和节拍器外全部丢掉。
- 鼓声（`gd_drum`）：`met` = 丢掉谱面鼓轨、只放节拍器；`track` = 只放谱面鼓轨、不放节拍器；`both` = 两者都要。
- **卷帘（所见即所灌）**：卷帘画的、一键上传灌的、实际出声的是**同一份**内容 —— 先按「音轨」勾选过滤，再按「引导范围」「鼓声」裁剪，所以取消勾选哪条，卷帘里那条就消失。
- FPGA 侧要出**新位流**才认 bit6；**旧位流下 bit6 被忽略**，引导轨会照常出声，但**不会损坏任何现有功能**。
- 引导轨即使没在「音轨」里勾选，程序也会**强制保留它**，否则灯不亮。
- 上位机页面是 `esp32/tools/score_studio.html`，本地服务 `127.0.0.1:8777`，由 `esp32/tools/start_score_studio.bat` 启动。
