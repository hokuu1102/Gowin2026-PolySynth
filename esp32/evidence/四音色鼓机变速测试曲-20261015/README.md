# 四音色 + 鼓机 + 变速 + 复音 · funk 测试小段子（2026-10-15）

**这是什么**：给「曲谱上位机」（`esp32/tools/score_studio.html`）灌谱用的一小段曲子。
**单一风格 = funk**（16 分交错切分的贝斯 / 单音 chank 吉他 / 反拍 clav 和弦 / 弦乐铺底）。
**8 小节、约 18 秒** —— 尽量短，但每一小节都在测东西。

一次把**五件事**都测到：

| # | 测点 | 在曲子里的位置 |
|---|---|---|
| 1 | **四个音色**同时出声（BASS / GUITAR / PIANO / PAD） | 第 3~6、8 小节 |
| 2 | **鼓机四件**都响（Kick / Snare / HiHat / Tom） | 第 3~6、8 小节 |
| 3 | **变速**（104 → 116 → 92 BPM，三个 tempo 点） | 第 1 / 3 / 7 小节头 |
| 4 | **和弦**（同一时刻多个音，逼上位机把音摊到多条轴） | 第 3 小节起，clav 每反拍一个三音和弦 |
| 5 | **复音**（能一个一个数出来） | **第 7 小节：每半拍进一个音，最后 10 个音同时响** |

## 一、⭐ 硬约束：四个音色各占一个互不重叠的音区

| 音色 | 音区 | 频率 |
|---|---|---|
| BASS | 38~52 | 73~165 Hz |
| PAD | 52~60 | 165~262 Hz |
| GUITAR | 61~71 | 277~494 Hz |
| PIANO | 72~83 | 523~988 Hz |

**为什么必须这样**：两个音色发**同一个频率**时，两个 voice 的相位互相干涉
（`mid2evt.py` 文件头写过："可能变响、变薄、或在起音处打拍子，听起来像被敲了两次"）。

📌 **这不是推测**：用户实测反馈"第一次变速之后怪怪的，好像两个音色没对上"，
用 `verify_piece.js` 判据 ⑨ 量出来是 **44 处**跨音色同音高重叠，
而且**从第 3 小节开始**（8+9+9+9+9）—— 第 3 小节正是第一次变速、也是钢琴进来的地方。
例子：`PAD+PIANO 音高 64（E4）tick 11520~12240`，钢琴 stab 打在 PAD 正在延音的同音上。

⇒ ⭐ 现在**按音区把音高隔开**，让"同音高"在结构上不可能发生（而不是事后检查）；
判据 ⑨ 会再核一遍（当前 **0 处**）。

## 三、编曲（一小节一个和弦：Dm7 G7 Cmaj7 A7 Dm7 G7 Cmaj7 Dm7）

| 小节 | 速度 | Bass | Guitar | Piano | Pad | 鼓 |
|---|---|---|---|---|---|---|
| 1 | 104 | ✓ | - | - | - | kick + hat |
| 2 | 104 | ✓ | ✓ | - | - | kick + hat |
| 3 | 116 | ✓ | ✓ | ✓ | ✓ | 全鼓（提速 drop） |
| 4 | 116 | ✓ | ✓ | ✓ | ✓ | 全鼓 |
| 5 | 116 | ✓ | ✓ | ✓ | ✓ | 全鼓 |
| 6 | 116 | ✓ | ✓ | ✓ | ✓ | 全鼓 + tom 过门 |
| **7** | 92 | └── **复音阶梯：每半拍进一个音** ──┘ | | | | kick + hat |
| 8 | 92 | ✓ | ✓ | ✓ | ✓ | 收尾 + 鼓探针 |

各轨的节奏型（都在 `gen_test_piece.py` 顶部的表里，可直接改）：

- **Bass**：16 分交错，根音 / 五度交替（每小节 10 个音，如 `0 · 240 · 720 · 960 · 1440 · 1680 · 1920 · 2400 · 2640 · 3120`）
- **Guitar**：单音 chank，9 个短音（140 tick）切在 16 分上
- **Piano**：clav 三音和弦，反拍 4 个（480 / 1440 / 2400 / 3360）
- **Pad**：整小节长音
- **鼓**：kick `0 · 1440 · 1920 · 3120` · snare `960 · 2880` · hat `480 · 2400 · 3360`

### 复音阶梯（第 7 小节，Dm7）——怎么数

每半拍（480 tick）进一个音，**全部撑到小节末**，所以最后 10 个音**同时响**：

| 进来的时刻 | 轨 | 音 | 累计同时在响 |
|---|---|---|---|
| 拍 1 | Pad | F3 A3 C4（三音一起） | 3 |
| 拍 1 | Bass | D2 | 4 |
| 拍 1.5 | Guitar | D4 | 5 |
| 拍 2 | Piano | D5 | 6 |
| 拍 2.5 | Guitar | F4 | 7 |
| 拍 3 | Piano | F5 | 8 |
| 拍 3.5 | Guitar | A4 | 9 |
| 拍 4 | Piano | A5 | **10** |

十个音**音高互不重复**且横跨四个音区 ⇒ 既数得清、也不打架。
10 声 < 可用轴 15 条 ⇒ 不抢轴；也远低于 FPGA 的 32 voice 上限。
**想单独验复音：只听第 7 小节，从 1 数到 10。**

## 六、已知问题的探针（结果要按这个读）

### 1. 鼓同时敲（第 8 小节第 4 拍）

主 groove 里 kick / snare / hat 的落点**互不相同**；只有**第 8 小节第 4 拍**
故意让 `kick + snare + hihat` 同 tick 一起敲。

- 该处听到**三件都响** ⇒ 问题已修
- 只听到**一件** ⇒ 就是 `same_hit` 复用那条未解决项
  （`files/20-代码/ESP32侧追问-同时敲多个鼓与same_hit-20261014.md`）

### 2. 两条转换路的差异（实测）

| 路 | 四音色 | 变速 | 复音 | 鼓 |
|---|---|---|---|---|
| 网页 `score_studio.html`（本曲判据） | 4 个都对 | 3 个 tempo 点 | 峰值 10 | **有**（axis 15） |
| `tools/mid2evt.py`（Python） | 4 个都对 | 3 个 tempo 点 | 峰值 10 | **整条丢掉**（`drums_excluded=130`） |

⇒ **要测鼓就必须走网页那条**。
