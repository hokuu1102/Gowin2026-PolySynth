# 多音色【同时】探针（2026-10-14）

**用途**：验证「多个音色能否真的同时响」。

⭐ **为什么需要它**：用户报「同一时间有两个音色，但听不到同时」——
查证发现是 `demo_scale.hex` **本身**三条轨时间不重叠：

```
axis 0 (BASS)   : tick      0 .. 7200
axis 2 (PIANO)  : tick   3840 .. 19200
axis 1 (GUITAR) : tick   8160 .. 100320
```

⇒ 「一个播完才响另一个」是**谱面如此**，⛔ 不是通路缺陷。

**本探针**：三条轨【完全重叠】——都在 tick 0 起音、tick 3840 止。
