## 一、⭐ 实测环境

| 项 | ⭐ 值 |
|---|---|
| 芯片 | `ESP32-S3 (QFN56) (revision v0.2)` + `Embedded PSRAM 8MB` |
| MAC | `94:a9:90:2d:a6:60` |
| **ESP32 口** | ⭐ **`COM29`**（`USB\VID_303A&PID_1001`）—— ⭐ 板载 USB，供电 + 日志 |
| **USB-TTL** | ⭐ **`COM31`**（`USB-SERIAL CH340`，`VID_1A86&PID_7523`） |
| 波特率 | ⭐ **1000000**（1 Mbps，与固件 `BLE_BAUD` 一致） |
| 固件 | ⭐ **`esp32/uart_test/`（一次性诊断固件）** —— ⛔ 不是正式 `ble` 固件 |
| 日期 | 2026-09-30 |

### 1.1 ⚠️ 接线（⭐ 交叉 + 共地）

```
ESP32-S3                        CH340
────────                        ─────
GPIO17  (UART1 TX)  ────────→   RXD    ⭐ 主线
GND     ────────────────────    GND    🔴 必须共地
                                VCC/5V ⛔ 未接
```

⚠️ **`GPIO18`（UART1 RX）本测试未接** —— 本固件只发不收。

## 二、⭐⭐ 验收判据（⭐ 逐条对，⛔ 不只看"跑完了"）

| # | 判据 | ⭐ 目标 | ⭐ **实测** | |
|---|---|---|---|---|
| **1** | 收到字节数 | 972 | ⭐ **972** | ✅ |
| **2** | **9N 对齐** | 是 9 的整数倍 | ⭐ **True**（108 帧） | ✅ |
| **3** | **帧头** | 全 `0xA5` | ⭐ **`{0xa5: 108}`** —— ⛔ **无其他帧头** | ✅ |
| **4** | ⭐⭐ **序号连续性** | 0..107 无缺口 | ⭐ **`NONE`**（零错位） | ✅ |
| **5** | 首帧 | `A5 00 00 00 00 00 00 00 00` | ⭐ 一致 | ✅ |
| **6** | 末帧 | `A5 00 00 00 00 00 00 00 6B` | ⭐ `0x6B` = **107** | ✅ |
| **7** | ESP32 侧写入 | 每轮 324 字节 | ⭐ **3 轮全是 `wrote 324`** | ✅ |
| **8** | 短路写 | 无 | ⭐ **无 `SHORT WRITE`** | ✅ |

### 2.1 ⭐⭐ 判据 4 为什么是最强的一条

⭐ **固件发的帧体是【递增序号】**（`seq` = 0,1,2,...）—— 这是**故意设计**的：

> ⚠️ 如果 1 Mbps 下**丢掉任何一个字节**，后续**所有帧都会错位**，
> 🔴 序号**立刻**就对不上了。

⇒ ⭐ **"序号恰好是 0..107 且无缺口"通过 = 物理层一个字节都没丢、没多、没错位。**
⚠️ 这比"只比对长度"强得多。

## 三、⚠️ 本次验收**证明了什么 / 没证明什么**

| ✅ **证明了** | ⛔ **没证明** |
|---|---|
| ⭐ `GPIO17` **物理引脚**能正确输出 | 🔴 **正式固件的水池/放水逻辑**（⭐ 本固件**绕过了整条 pool 链路**） |
| ⭐ **1 Mbps** 波特率下不丢字节 | 🔴 **tick 限流节奏**（⚠️ 根本没走限流） |
| ⭐ **UART 外设**配置正确 | 🔴 **FPGA 会出声**（⚠️ `play_seq` 在 `top.v` 仍未例化） |
| ⭐ **CH340 能稳定跑 1 Mbps** | ⚠️ **起播矛盾**（⛔ 未解决，见裁定单） |

🔴 **特别强调**：本固件**绕过了** `pool_feed` → `frame_filter` → `pool_pump`
⇒ ⚠️ **它绿了 ≠ 正式固件的数据通路就是对的。**

## 五、⚠️ 复现步骤（⭐ 一条命令级）

```powershell
# ① 烧诊断固件（⚠️ COM29 换成实际 ESP32 口）
cd C:\Users\hokuu\Desktop\FPGA\FPGA2026-esp32\esp32\uart_test
. "C:\Espressif\tools\Microsoft.v5.5.PowerShell_profile.ps1"
idf.py -p COM29 flash

# ② 开抓（⚠️ COM31 换成实际 USB-TTL 口）+ 同时复位 ESP32
cd ..\tools
python uart_rx_check.py --port COM31 --baud 1000000 --seconds 18 --dump 6 --save "..\evidence\uart_test_capture.bin"
#    ⭐ 必须在抓取【进行中】时复位 ESP32（⚠️ 固件上电 5.3 s 就发完了）
```

⚠️ **时序是关键**：固件只发一次 ⇒ **先开抓，再复位**，⛔ 顺序不能反。
