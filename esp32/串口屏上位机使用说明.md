| # | 做什么 | ⭐ 填什么 |

### 2.1 ⭐⭐ 工程编码：**必须选 `UTF-8`**（🔴 开弓没有回头箭）

| 编码 | 能不能用 | 说明 |
|---|---|---|
| ⭐⭐ **`UTF-8`** | ✅ **选这个** | ⭐ **与 ESP-IDF 源码里的字符串天然一致**（见下） |
| ✅ `GB2312` | ⚠️ 能用但要转换 | ⚠️ 简体中文可用，但**与 ESP32 发的字节不一致** |
| ⛔ `ascii` | 🔴 **不能用** | 只能 ASCII ⇒ **中文写不进去** |
| ⛔ `big5` | 🔴 **不能用** | 只能**繁体**中文 |
| ⛔ `shift_jis` | 🔴 **不能用** | 只能**日文** |
| ⓘ `GBK` | ⚠️ 通常没有这个选项 | GBK 是 GB2312 的超集；⚠️ 上位机一般只给 GB2312 |

> ⭐ **只有 `GB2312` 和 `UTF-8` 支持简体中文**（官方 QA27 原文）。

#### 🔴 为什么必须 UTF-8 —— 决定性理由

⭐ 官方 [QA121](http://wiki.tjc1688.com/QA/QA121.html) 原文：

> 传输汉字时，**需要保证两边的编码是一致的**，即两边都是 GB2312 或者两边都是 UTF-8

⚠️ **「淘晶驰」三字的实际字节**：

| 编码 | 字节 | 每字 |
|---|---|---|
| `GB2312` | `CC D4 BE A7 B3 DB` | 2 字节 |
| ⭐ **`UTF-8`** | `E6 B7 98 E6 99 B6 E9 A9 B0` | 3 字节 |

⇒ 🔴 **ESP32 固件里发给屏的字符串（如 `"状态：播放中"`），在 C 源码里就是 UTF-8**
（⚠️ 工具链按 UTF-8 处理源文件，**没法方便地写 GB2312**）
⇒ ⭐ **选 UTF-8 才两边天然一致，零转换。**
⇒ 🔴 **选 GB2312 ⇒ 屏上中文变乱码。**

#### 🔴 为什么现在就要定死

⭐ 官方 [QA86](http://wiki.tjc1688.com/QA/QA86.html) 原文：

> ⚠️ **最好一开始就确定编码，不建议修改工程编码，会导致乱码等问题**
> ……**不要直接复制过去，要在新的工程中手动输入**（否则仍是原编码）

⇒ ⭐ **这是"开弓没有回头箭"的决定。**

#### ⚠️ 一条连带硬约束

🔴 **工程编码 与 字库编码 必须一致**（官方 QA27 原文）：
> 工程编码和字库编码应一致，否则**混用不同字库编码的控件之间相互赋值将会乱码**

⇒ ⭐ **工程 = UTF-8，字库也 = UTF-8，⛔ 别一个 GB2312 一个 UTF-8。**

## 三、⭐⭐ 拖控件（照控件清单）

⭐ **完整清单在** `esp32/串口屏控件清单.md` —— 含 7 个控件的 **ID / 类型 / 坐标 / 初值**。

### 3.1 在哪画

```
左侧/顶部工具栏有控件图标  →  点一个  →  在中间画布上拖出一个框
                                          ↓
                              右侧属性栏改 ID / 坐标 / 字号
```

| 要用的控件 | 在工具栏找 |
|---|---|
| **文本**（`t0` `t1` `t2` `t3`） | 图标是 **`T`** 或「文本」 |
| ⭐ **滚动文本**（`g0`） | 「滚动文本」/ Scrolling text |
| ⭐ **进度条**（`j0`） | 「进度条」/ Progress bar |
| ⭐ **数字**（`n0`） | 「数字」/ Number |

> ⚠️ **为什么曲谱名用【滚动文本】而不是文本**：
> ⭐ 320 px 宽、24 号字 ⇒ ⚠️ **纯 ASCII 曲名只能放约 21 字符**
> （`曲谱：` 占 3 个中文 ≈72 px）⇒ 🔴 **长歌名必然截断**。
> ⭐ **滚动文本不限长度**（⭐ 但⚠️ 会一直动，`tim` 可调慢）。

### 3.2 ⚠️ 最关键的一条：**控件 ID 必须改对**

⭐ 固件是按 **ID** 拼命令的（`t0.txt=`、`j0.val=` …）

| 做了什么 | 后果 |
|---|---|
| ✅ ID 改成清单里的名字 | 正常 |
| 🔴 ID 保持默认（如 `t0` 恰好撞对） | ⚠️ 碰运气 |
| 🔴 ID 写成别的（如 `txt0`） | 🔴 **屏收不到那条命令，那格永远不变** |

> ⭐ **在右侧属性栏的「objname」/「ID」里改**（⚠️ 不同版本叫法不同）。

### 3.3 ⭐⭐ 怎么加**初值**（上电时显示的内容）

⭐ **位置**：**选中控件 → 右侧属性栏 → 直接改那个属性**（⛔ 不用写命令）。

| 控件类型 | ⭐ **属性名** | ⭐ 本工程填什么 | ⚠️ 引号 |
|---|---|---|---|
| **文本**（`t0` `t1` `t2` `t3` `t4`） | ⭐ **`txt`** | `曲谱：----` 等 | ⚠️ **属性栏里⛔ 不加引号** |
| ⭐ **数字**（`n0`） | ⭐ **`val`** | `0` | ⚠️ 数字，⛔ 不加引号 |
| ⭐ **进度条**（`j0`） | ⭐ **`val`** | `0` | ⚠️ 同上 |

> 🔴 **最容易搞错的一条**：官方属性表原文 ——
> **`txt` 是字符串属性、`val` 是数值属性**。
> ⚠️ **在上位机属性栏里是"直接填值"**，⛔ **不要自己加引号**；
> ⭐ **引号是【串口命令】才需要**的（`t0.txt="xxx"`）。

⭐ **逐控件初值清单**：

| ID | 类型 | 属性 | ⭐ 填这个 | 字号 |
|---|---|---|---|---|
| `t0` | 文本 | `txt` | `曲谱：` | ⭐ **24** |
| ⭐ `g0` | **滚动文本** | `txt` | `----` | ⭐⭐ **48** |
| `j0` | 进度条 | `val` | `0` | — |
| `n0` | 数字 | `val` | `0` | ⭐ **48** |
| `t1` | 文本 | `txt` | `待机` | ⭐⭐ **48** |
| `t2` | 文本 | `txt` | `0/0` | ⭐ **32** |
| `t3` | 文本 | `txt` | `BT --` | ⭐ **32** |

> ⭐ **坐标与尺寸见 `esp32/串口屏控件清单.md` §2.1**（48 号字排版，占满 320×240）。

⚠️ **初值里的中文同样需要字库** —— 否则**画布上就已经是方块**了
（⭐ 这反而是好事：**一眼就能看出字库没做对**）。

### 3.4 ⚠️ 顺手必须设的几个（⭐ 同在那个属性栏）

| 属性 | ⭐ 设什么 | 为什么 |
|---|---|---|
| ⭐ **`objname`** | ⭐ **`t0` / `g0` / `j0` / `n0` …** | 🔴 **固件按这个 ID 发命令**，⚠️ 名字不对那格永远不变 |
| ⭐ **`font`** | ⭐ `g0`/`t1`/`n0` 选 **48 号**；`t0` **24**；`t2`/`t3` **32** | ⚠️ **字号必须是你【做过的字库】里有的**（⭐ 见 §3.0 分库表） |
| ⭐ **`vscope`** | ⭐ **`全局`** | ⭐ 让值**跨页面保留**（⚠️ 不设则切页回来会回初值） |
| 🔴 **`txt_maxl`**（文本/滚动文本才有） | ⭐ **`g0` 给 60**、其余给够 | 🔴 官方原文：`txt_maxl` **"不可通过指令修改"** ⇒ ⚠️ **填小了事后改不了、文字会被截断** |

> 🔴 **`txt_maxl` 是个真坑**：⭐ **一开始就要给够**（曲谱名可能 40+ 字符，⛔ 别留 20）。

### 3.4.1 ⭐ `g0`（滚动文本）**额外**要设的

| 属性 | ⭐ 设什么 | 为什么 |
|---|---|---|
| **`dir`** | **1**（从右往左） | ⭐ 歌名常用方向（0左→右 / 1右→左 / 2上→下 / 3下→上） |
| **`tim`** | **500** | ⚠️ 滚动周期 ms，**最小 80** ⇒ 太小会晃眼 |
| **`dis`** | **4** | 滚动幅度像素（**2~50**） |
| **`en`** | **1**（开启滚动） | — |
| 🔴 **`isbr`** | **0**（⛔ 不换行） | 🔴 官方警告：**"滚动文本不建议换行显示，会导致显示效果有问题"** |

### 3.5 ⭐ 初值 vs 运行值（搞清楚这个就不迷糊）

```
初值（属性栏填的）              ← ⭐ 上电 / 切页时显示
      ↓
固件发 g0.txt="09_Conjurer"     ← ⭐ ESP32 连上后覆盖它
```

| 场景 | 显示什么 |
|---|---|
| 屏刚上电、蓝牙没连 | ⭐ **初值**（`曲谱：` / `----` / `待机` / `BT --`） |
| 蓝牙连上、开始灌谱 | ⭐ **固件推的值** |
| ⚠️ 断电重启 | ⚠️ **回到初值**（⭐ 正常，固件会重刷） |

⇒ ⭐ **初值的作用**：**让"还没连上"时屏不是空的** —— ⭐ 演示观感好很多。

### 3.6 ⚠️ 初值填完报错怎么办

| 报错 | ⭐ 原因 |
|---|---|
| **"XXX初始值无效"** | ⚠️ 属性填了非法值（⭐ 官方 QA9 专讲这个） |
| **中文显示成方块** | 🔴 **字库没做/没下** ⇒ 见 §四 |
| **文字显示不全** | ⚠️ **`txt_maxl` 留太小** |
| **"字库ID无效"** | ⚠️ 控件引用的字库没生成 |

## 五、⭐⭐ 写 `program.s`（波特率 + 上电初始化）

### 5.1 在哪

⭐ 左侧工程树里有一个 **`program.s`** 文件（⚠️ ⛔ 不是界面上的属性框）。

### 5.2 写什么（⭐ 照着抄）

```c
// 以下代码只在上电时运行一次
bauds=115200     // 通信波特率（必须与 ESP32 的 BLE_HMI_BAUD 一致）
dims=100         // 亮度 0-100
recmod=0         // 关闭主动解析
bkcmd=0          // 关闭错误信息返回
page 0           // 上电显示第 0 页
```

🔴 **三条硬要求**：

| # | 要求 | 为什么 |
|---|---|---|
| **1** | ⭐ **等号两边⛔ 不要有空格** | ⚠️ 官方原文：**否则会报错** |
| **2** | 🔴 **`page 0` 必须是最后一行** | ⚠️ 官方原文（重复了 6 遍）：**`page` 指令后面的代码不会执行** |
| **3** | ⭐ **`bauds` 必须与固件一致** | ⚠️ 一边改了另一边没改 = **完全收不到** |

> ⚠️ **下载波特率 ≠ 通信波特率**（⭐ 官方说明）：
> 下载时上位机用 921600 联机，**下载完会自动切回 `bauds` 设的 115200**。
> ⇒ ⭐ **不用担心两者冲突**。

## 八、⚠️ 常见坑（⭐ 都是官方明确说过的）

| # | 现象 | ⭐ 原因 / 对策 |
|---|---|---|
| **1** | 中文显示成方块/不显示 | 🔴 **字库没做或没下进去** ⇒ 回到第四节 |
| **2** | 发命令屏没反应 | ⚠️ 三个可能：① 波特率不一致 ② ⛔ 忘了 `FF FF FF` ③ 上电第一条被杂波吃掉 ⇒ ⭐ **先发 `00 FF FF FF` 清缓冲** |
| **3** | 下载失败 / 联机失败 | ⚠️ 换 USB-TTL（官方点名 CH340）；⭐ 或改用 **SD 卡下载** |
| **4** | 报"字库ID无效" | ⚠️ 控件引用的字库没生成 |
| **5** | 报"初始值无效" | ⚠️ 控件属性填了非法值 |
| **6** | 文件太大放不下 | 🔴 **本屏 Flash 只有 4 MB** ⇒ ⚠️ 别勾全部汉字、少放背景图 |
| **7** | 上电后界面被杂波搞乱 | ⭐ **先发 `00 FF FF FF`**（固件已实现，⚠️ 手动调时也要做） |
