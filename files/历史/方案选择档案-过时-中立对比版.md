## 一、先固定"要实现的六件事"

| # | 功能 | 赛题依据 | 技术要求 |
|---|---|---|---|
| 1 | **选音 / 音高** | 基础要求 1「选音」 | 离散或连续 |
| 2 | **触发 / 拨弦** | 基础要求 1「触发、拨弦」 | 事件型，越低延迟越好 |
| 3 | **力度（音量）** | 拓展要求 2「力度动态」 | 连续最好 |
| 4 | **滑音** | 拓展要求 2「滑音」 | 需要连续或准连续音高 |
| 5 | **颤音** | 拓展要求 2「颤音」 | 4～7 Hz 低频调制（**对延迟不敏感**） |
| 6 | **LED 演奏指引** | 拓展要求 4「脱机演奏 LED 曲目指引」 | FPGA 实时输出 |

**两条全局约束**

- 控制 → 出声总延迟 **≤10 ms**（拓展 ≤5 ms 且确定性）
- 赛题**不限制手数与传感器种类**：只规定「维度」数量，并写明「**自主设计演奏交互形态**」

## 二、模块分工与映射（讨论起点）

### 2.1 三个模块

```text
┌────────────────┐    ┌────────────────────────┐
│   左手区        │    │   右手区                │
│   选音 / 音高    │    │   拨弦（触发）           │
│                │    │   颤音（推子 / 电容条）   │  ← 两者互斥，不同时操作
└────────────────┘    └────────────────────────┘
```

| 模块 | 归属 | 候选器件 |
|---|---|---|
| **选音（音高）** | **左手** | 磁轴阵列 ／ 电容滑条 ／ 电容面 ／ FSR+电容 |
| **拨弦（触发）** | **右手** | 微动开关 ／ 光电遮断 ／ 磁性拨弦件 ／ 电容触摸 |
| **颤音** | **右手**（与拨弦二选一，不冲突） | **推子** 或 **电容条**（本质等价，见 2.3） |
| 力度 | 跟随选音模块 | 磁轴行程 ／ FSR ／ 光电遮挡深度 |
| LED 指引 | 跟随主模块 | 见 §六 |

> ✅ **有颤音时就不用拨弦，两者二选一** → 右手可以同时承担两件事，不需要第三只手。
> ➡️ 因此**三个模块可以完全独立**：左手区、右手区、颤音模块（放右手可及处）。

### 2.2 ⚠️ 关键修正：跨面约束只约束"同一只手"

```text
✅ 左手在「选音区」、右手在「拨弦/颤音区」
   → 两只手各管一块 → 两块区域可以完全独立
   → 不在同一平面没关系，不在同一块板上也没关系

⚠️ 但若"同一只手"要在两个高度不同的区域之间移动
   （例：左手从磁轴区移到旁边的电容区）→ 仍会卡顿
```

**为什么**：跨面卡顿的根因是"**必须先抬手 → 动作断裂**"（§详见详版 §D）。
两只手本来就各自独立动作，**不存在"从 A 面移到 B 面"这个动作**，所以不构成问题。

> ➡️ 上版把这条原则写得太宽，**这里收窄**：
> **同平面要求只在"同一只手需要在多个区域之间切换"时才成立。**

### 2.3 颤音模块：推子与电容条是同一个东西

| | 推子 / 滑杆 | 电容条 |
|---|---|---|
| 输出 | 一维连续量 | 一维连续量 |
| 延迟 | **确定** | 不确定（内部滤波/基线跟踪） |
| 手感 | 有行程、有阻尼感 | 无行程（平面） |
| 磨损 | 有（碳膜/导电塑料） | **无** |
| 环境 | 抗汗抗湿 | 怕汗、怕湿 |
| 结构 | 需要开槽与固定 | 贴在面板下即可 |

> ✅ **两者对外都只是"一路一维连续量"** → **可以做成同一个接口**，
> 先按一种做，后期直接互换，不用改架构。**这是一个低风险的可替换模块。**

> ✅ **关于手部负载：不冲突。**
> **有颤音时就不用拨弦，两者是二选一** —— 演奏中不会同时操作。
> ➡️ 所以**颤音与拨弦都可以交给右手**，右手区可以同时放这两个器件，也可以做成可换模块。
> （这意味着"右手负载过重"的顾虑不成立，不需要为它单独安排第三只手。）

### 2.4 参考形态（一种可能）

```text
        左手区（选音）                        右手区（拨弦 + 颤音）
   ┌───────────────┐               ┌──────────────────────────┐
   │ ▤ ▤ ▤ ▤ ▤ ▤   │               │   拨弦件 ▼                │
   │  磁轴阵列      │               │   ─────────────           │
   │               │               │   颤音：推子 / 电容条      │
   └───────────────┘               └──────────────────────────┘
        ↑ 手指横向划过 = 滑音            ↑ 拨弦 与 颤音 二选一

   两个区域可以在一块板上，也可以是两块独立的板
   （两区不必共面、不必同高度 —— 因为是两只手各管一块）
```

## 三、各方案详细展开（同一模板）

> 每个方案都按 **五功能映射 → 结构 → 优点 → 难点 → LED 可行性 → 乐器形态** 展开，便于横向比较。
> ⚠️ 读下面内容前请先记住 §2.2：**"跨面卡顿"只对同一只手成立**，不再是各方案的通用扣分项。

### 方案 A · 磁轴阵列 + 线性霍尔

| 功能 | 承担器件 | 说明 |
|---|---|---|
| 音高 | 磁轴位置（离散） | 一个轴 = 一个音；划过一排 = 滑奏 |
| 力度 | 磁轴行程（连续） | 需要**线性霍尔**（数字霍尔只有 0/1） |
| 颤音 | 磁轴行程的 4～7 Hz 分量 ／ 或独立推子 | 两种做法都可行 |
| 拨弦 | 微动开关 ／ 磁轴本身 | — |
| LED | 轴座 PCB 上的灯珠 | 键盘生态成熟 |

```text
   ┌── 键帽 ──┐
   │    磁铁 ↓ ↓ ↑
   ├── 定位板 ────────────────┐
   │  霍尔  霍尔  霍尔        │  轴座 PCB
   │  ▣     ▣     ▣   ← LED   │
   └──────────────────────────┘
```

| 优点 | 难点 / 风险 |
|---|---|
| 提供**真实按压手感**（行程、回弹、段落） | 键帽**锁死手指位置** → 键位内连续移动做不到 |
| **一个硬件支持两种乐器形态**：键盘类 + 指板类 | 键位**离散**，连续滑音只能近似 |
| 非接触检测 → 无磨损、无噪声电位器问题 | 每轴一路模拟量 → **通道数多**，需多通道 ADC / 多路复用 |
| 抗汗手、湿度、温度 | 需**逐个标定**（霍尔中点偏置 + 安装公差） |
| 延迟确定（无电容基线跟踪） | 相邻磁轴**磁场串扰**需处理 |
| 可 3D 打印验证手感 | 机械公差敏感（打印孔径、同轴度） |
| 键盘生态可借（定位板、轴座、键帽、灯位） | 机身偏厚 |

| LED 可行性 | 说明 |
|---|---|
| ⭐ **最好** | 轴座 PCB 有标准灯位；透光轴体 + 透光键帽现成；单轴单灯，逐键指引直观 |

**乐器形态**：键盘式电子乐器 / 无弦指板式乐器
**同类先例**：磁轴键盘（Wooting 类）、各类 MIDI 键盘控制器

### 方案 B · 全电容触摸面（二维）

| 功能 | 承担器件 | 说明 |
|---|---|---|
| 音高 | 触摸面 X 轴（连续） | 可做真正的连续滑音 |
| 力度 | 接触面积 / 耦合强度 近似 | **没有真实压力，只能近似** |
| 颤音 | 触摸面 Y 轴（连续） | 天然适合 |
| 拨弦 | 触摸事件（接触/离开） | — |
| LED | 面板下方的灯珠 | 需要面板半透 |

```text
   ┌───────── 触摸面板（平整，可半透）──────────┐
   │  ⊞ ⊞ ⊞ ⊞ ⊞ ⊞ ⊞ ⊞ ⊞   ← 电极网格 / 滑条   │
   ├────────────────────────────────────────────┤
   │  电极 PCB  +  LED（面板下方）               │
   └────────────────────────────────────────────┘
         手指在同一个面上滑动 → X = 音高，Y = 颤音
```

| 优点 | 难点 / 风险 |
|---|---|
| **单指二维手势最自然**（最接近真乐器） | ⚠️ **没有真实压力维度** → 力度只能靠接触面积近似，表达力弱 |
| **表面完全平整** → 不存在跨面卡顿问题 | 汗手 / 湿度 / 温度影响基线 |
| 无机械件 → 无磨损、寿命长、厚度薄 | 需持续**基线跟踪**，否则漂移 |
| 外形自由度最高（可做曲面） | **延迟不确定**（内部滤波与基线跟踪） |
| 电极可一次蚀刻成型，加工简单 | 二维高分辨率需要**大量电极与走线**（通道数爆炸） |
| | LED 与电极同板 → **驱动噪声会污染电容基线** |

| LED 可行性 | 说明 |
|---|---|
| 中 | 需要**半透面板**；灯珠与电极同板 → 必须分时/分区、加屏蔽，否则影响触摸读数 |

**乐器形态**：无弦指板 / 海绵垫式控制器（Roli Seaboard、Haken Continuum 路线）
**同类先例**：Roli Seaboard、Haken Continuum、各类电容触摸 MIDI 控制器

### 方案 C · FSR 压力面 + 电容滑条

| 功能 | 承担器件 | 说明 |
|---|---|---|
| 音高 | 电容滑条（连续） | 滑音自然 |
| 力度 | FSR 压力（连续） | 真实的压力维度 |
| 颤音 | 电容滑条上的往复运动（需算法分离） | ⚠️ 与滑音共用一路信号 |
| 拨弦 | 微动开关 ｜ FSR 阈值 | — |
| LED | 面板下方 | FSR 薄膜会遮光 |

```text
   ┌── 电容滑条（音高）──────────────────────┐
   │  ══════════════════════════════════     │
   ├── FSR 压力区（力度）────────────────────┤
   │  ███   ███   ███                        │
   └─────────────────────────────────────────┘
```

| 优点 | 难点 / 风险 |
|---|---|
| 结构**极薄**，几乎不占垂直空间 | ⚠️ **FSR 是外购薄膜 → 原型阶段无法用 3D 打印验证手感** |
| 力度真实连续；音高连续 | ⚠️ FSR **迟滞与长期漂移**，需机械限位防过压 |
| 两个功能分属两个器件，逻辑清晰 | ⚠️ **FSR 与电容共存时干扰最大**：导电膜屏蔽电场 + 压力形变与位置**动态耦合**（标定不掉） |
| | 滑音/颤音共用一个电容信号 → 需算法分离，会引入滑窗延迟 |
| | 电容本身延迟不确定 |

| LED 可行性 | 说明 |
|---|---|
| 偏低 | FSR 薄膜基本不透光；灯珠要么做在薄膜**开孔**处，要么移到边缘 |

**乐器形态**：无弦吉他 / 单板式乐器
**同类先例**：各类 DIY 无弦 MIDI 吉他

### 方案 D · 光电对管阵列（遮光式"虚拟弦"）

| 功能 | 承担器件 | 说明 |
|---|---|---|
| 音高 | 哪一根光路被遮断（离散）/ 遮挡位置（连续） | 对射排布可做"竖琴"式 |
| 力度 | 遮挡深度（部分遮挡）近似 | **不是真实压力** |
| 颤音 | 遮挡位置的高速往复 | — |
| 拨弦 | 遮断事件（即"拨弦"本身） | 天然就是拨弦动作 |
| LED | 发光管本身就是光源 | 视觉上最自然 |

```text
   发射排                         接收排
   │LED││LED││LED││LED│   ════→   │PD││PD││PD││PD│
        ↑     ↑     ↑
      手指遮断某一条 → 对应音符触发 / 位置判定
```

| 优点 | 难点 / 风险 |
|---|---|
| **非接触、无磨损、响应极快** | 受**环境光**干扰（需要调制解调 / 遮光罩） |
| **"拨弦"动作本身就是遮光** → 概念极其贴合"无弦乐器" | 积灰影响；需要机械遮光结构 |
| 发光管即视觉元素 → **LED 指引天然可做** | 精度受光斑大小限制；多路之间可能**光学串扰** |
| 元件便宜、可大量排布 | 功耗高于霍尔方案 |
| 结构可以做得很薄 | 力度维度弱（只能靠遮挡深度近似） |

| LED 可行性 | 说明 |
|---|---|
| ⭐ **天然** | 发光管与指引灯可以合二为一；"哪根弦被拨"直接点亮对应光柱 |

**乐器形态**：激光竖琴 / 无弦电子乐器
**同类先例**：Laser Harp、各类光学位移 MIDI 控制器

### 方案 E · 微动开关阵列（传统键盘式，最保守）

| 功能 | 承担器件 | 说明 |
|---|---|---|
| 音高 | 开关位置（离散） | — |
| 力度 | ❌ **无**（或按"按下速度"近似） | ⚠️ 直接缺一个维度 |
| 颤音 | 推子 / 旋钮 / LFO | 必须外挂 |
| 拨弦 | 开关事件 | — |
| LED | 键盘 PCB 灯位 | 生态最成熟 |

| 优点 | 难点 / 风险 |
|---|---|
| 最简单、最可靠、延迟最低、最确定 | ⚠️ **没有力度维度** → 需靠推子/旋钮补，且难以自然 |
| 器件最便宜、最易采购、最易替换 | 无法做连续音高，也不易做滑音 |
| 键盘生态与 LED 方案完全现成 | 表达力最弱，"电子乐器"特色不明显 |
| 3D 打印件只需做定位板 | — |

| LED 可行性 | 说明 |
|---|---|
| ⭐ 最好 | 与磁轴方案同等的成熟度（同一套键盘生态） |

**乐器形态**：键盘式电子乐器
**同类先例**：各类键盘 MIDI 控制器、电子琴

### 方案 F · 混合方案（两种传感器分工）

> 不是"二选一"，而是**按功能拆给最合适的器件**。

| 组合示例 | 音高 | 力度 | 颤音 | 说明 |
|---|---|---|---|---|
| F1 磁轴 + 电容 | 磁轴（离散） | 磁轴行程 | 电容条 | 正交分工，互不抢信号 |
| F2 磁轴 + 推子/电容条 | 磁轴 | 磁轴行程 | 推子/电容条 | **改动量最小**，最快能跑通 |
| F4 电容 + 光电 | 电容 | 光电（遮挡深度） | 推子/电容条 | 全无机械件，最"未来感" |
| F5 主手 + 副手分置 | 任意（主手） | 任意（主手） | 副手独立控制区 | **赛题不限手数**，双手分工完全合规（即当前推荐分工） |

> ❌ **已排除的组合：FSR + 磁轴** —— 磁轴本身已提供力度，FSR 属重复投入（见 §三 方案 C 注）。
> ❌ **也无需为"力度"再配一个传感器** —— 任何已经有连续行程/压力读数的方案都不需要额外加力度器件。
>
> ⚠️ **混合方案的硬约束（已收窄）**：**同一只手**不要让它在两个高度不同的平面之间移动 ——
> 实测证明会明显卡顿（高度差 + 台阶 + 必须先抬手）。
> ✅ 但**不同手各管一块区域时不受此限**，两区可以完全独立（§2.2）。

| LED 可行性 | 说明 |
|---|---|
| 中～高 | 取决于主传感器的形态；跟随主传感器走 |

**乐器形态**：按组合而定，自由度最高
**同类先例**：多数商业合成器都是混合式（键盘 + 调制轮 + 触摸条）

> **看得出来各方案各有短板，没有一项全绿** —— 这正是需要讨论的地方。

### 三点必要的注释（避免误读）

**注 1：电容不是"真正连续"的，它同样是离散的**

- 电容触摸也是由**一个个独立电极**组成的，**做不到数学意义上的连续**
- 所谓"连续"是**离散电极 + 插值算法**近似出来的
- 所以"电容 vs 磁轴"在连续性上的差别，**不是有无之分，而是"等效分辨率"的差别**：
  | | 离散单元尺度 | 插值空间 |
  |---|---|---|
  | 磁轴 | **键距约 19mm**（人体工学决定的键距，很难再小） | 单元大 → 插值只能"猜"中间，精度有限 |
  | 电容 | **电极间距可做到 5～8mm 甚至更小** | 单元小 → 插值精度高得多 |
- ➡️ 结论：**电容的等效音高分辨率明显更高，但它依然是"离散 + 插值"，而不是真连续。**
  两者都需要插值算法，差别在**单元尺寸**。

**注 2：手感"可自行迭代性"是什么意思**

- 这一项**不是**"打样成本/排期"（打印机是自有的，打样不是问题），而是：
  **手感依赖的那个核心零件，能不能自己设计/更换来迭代。**
- 磁轴：手感由**轴体**决定 → 可以换线性轴/段落轴、换弹簧、调定位板高度 → **迭代空间大**
- 电容：**没有行程可调** → 手感谈不上迭代，只能改表面材质
- FSR：手感由**外购薄膜成品**决定（厚度、硬度、面积都是买来就固定的）→ **迭代空间最小**
- 光电 / 微动：可通过换元件与结构件调整 → 迭代空间较大

**注 3：跨面卡顿已不再是通用扣分项**

- 见 §2.2：该约束**只对"同一只手"成立**
- 本表"表面平整度"这一项反映的是**同一只手在区域内移动的顺滑度**，
  不再代表"方案整体会被卡顿否决"

---

## 五、可以组合，不是二选一

**最容易被忽略的一点**：上面六个功能**不需要由同一种传感器承担**。

```text
音高    ← 可以是磁轴 / 电容 / FSR / 光电          （左手区）
力度    ← 可以是磁轴行程 / FSR / 光电遮挡深度      （跟随音高器件）
颤音    ← 推子 / 电容条（本质等价，可互换）/ LFO   （独立模块）
拨弦    ← 可以是微动 / 光电遮断 / 触摸事件          （右手区）
LED     ← 跟随主传感器形态
```

**所以真正要讨论的不是"选哪个方案"，而是"每个功能交给谁"。**

> ⚠️ 但注意一个**已被收窄**的约束（§2.2）：
> **同一只手**若要在两个高度不同的区域之间移动，会卡顿；
> **不同手各管一块则不受此限。**
> ➡️ 所以按当前分工（左手选音 / 右手拨弦 / 颤音独立模块），**三个模块可以完全独立，不必共面。**

## 六、LED 演奏指引：横向比较

| 承载方式 | 做法 | 优点 | 难点 |
|---|---|---|---|
| **键盘灯位** | 轴座 PCB 上的灯珠（单灯或 RGB） | 生态最成熟；逐键指引最直观 | LED 与霍尔同板 → 需分区分线防噪声 |
| **面板下埋光** | 触摸面板 / 亚克力板下的灯珠 | 可做整片光效 | 面板需半透；灯与电极同板 → 噪声污染基线 |
| **侧发光导光** | 侧发光灯珠 + 导光板 / 导光柱 | 光线均匀、可做长条光带 | 需要导光结构件 |
| **发光管自身** | 光电方案的发射管 | 天然、零额外结构 | 受方案限制 |
| **独立灯带** | 乐器边缘的 RGB 灯带 | 与传感器完全解耦（**最省心**） | 指引精度低，只能做整体氛围/进度 |

**通用注意**：

1. **驱动方式**：单线级联灯珠（WS2812 类）只需 **1 根 IO**，但刷新时序要占逻辑资源；也可用移位寄存器（如 74HC595）串行驱动
2. **供电与去耦**：多灯珠峰值电流大 → **独立供电 + 就近去耦**，不要与模拟传感器共用一条电源走线
3. **对 FPGA 侧的影响**：LED 指引需要解析曲目数据并实时驱动 → 与音频引擎**并行**，会占用逻辑资源与 BRAM，**需要 FPGA 侧一起评估**
4. **指示内容可以分层**：只做"下一个音是哪个键"（简单）→ 到"整段曲目滚动预览"（复杂）
5. **与传感器共板的噪声**：无论哪种方案，**LED 驱动走线应与模拟传感器走线分开**，并考虑分时（LED 刷新时避开 AD 采样窗口）

## 七、硬件难点清单

> 按模块分类，并标注**哪些方案会碰到**，便于对号入座。
> ⚠️ 这些难点**大部分与方案选择无关，是"做电子乐器"本身就要过的关**。

### 7.1 传感器信号链

| # | 难点 | 说明 | 涉及方案 |
|---|---|---|---|
| 1 | **模拟小信号的分辨率** | 线性霍尔输出随行程的变化可能只有几十～几百 mV，ADC 有效位数要够 | 磁轴 |
| 2 | **多通道实时性** | N 通道 × 采样率 = 总吞吐；单 ADC 轮询会按通道数分摊速率 | 磁轴 / FSR / 光电 |
| 3 | **逐个标定（一致性）** | 霍尔中点偏置、灵敏度、安装公差各不相同 → 要么逐个标定，要么选容差宽容的器件 | 磁轴 / FSR |
| 4 | **通道间串扰** | 磁场：相邻磁铁的相互影响；电场：相邻电极的相互影响 | 磁轴 / 电容 |
| 5 | **数字 vs 模拟输出** | 数字霍尔只有 0/1 → **拿不到连续力度**（陷阱选项） | 磁轴 |
| 6 | **一路信号承载两个维度** | 若同一路行程既要给力度又要给表情 → 必须按频段分离 | 磁轴 |
| 7 | **延迟不确定** | 触摸 IC 内部有滤波与基线跟踪 → 端到端延迟**不可控** | 电容 |
| 8 | **迟滞与漂移** | 压力—电阻曲线有迟滞；长期有漂移 → 需限位与标定 | FSR |
| 9 | **环境光干扰** | 光电对射受室内光/阳光影响 → 需调制解调或遮光罩 | 光电 |
| 10 | **汗手 / 湿度** | 湿手时电容读数漂移，需基线跟踪 | 电容 |

### 7.2 机械 / 结构

| # | 难点 | 说明 |
|---|---|---|
| 1 | **FDM 打印公差** | 孔径常比模型小 **0.1～0.3 mm**（材料收缩 + 挤出膨胀）→ 轴体卡涩 |
| 2 | **圆孔椭圆度 / 摆放方向** | 孔的圆度随打印摆放变化 → 需让孔轴平行 Z 轴或竖打 |
| 3 | **同轴度 / 垂直度** | 定位板孔、轴座、磁铁位置偏差 → 轴体被"别"住 |
| 4 | **高度齐平** | 多个模块若要在同一平面过渡，高度差需控在 **±0.1 mm** 量级 |
| 5 | **磁吸附加阻力** | 磁铁吸铁质件（铁螺丝、钢定位板）→ 附加吸力与偏磨 |
| 6 | **键帽挡电场** | 绝缘键帽会遮蔽电容检测 → 想同位置叠电容不可行 |
| 7 | **表面摩擦一致性** | 打印件 / 板材 / 覆膜摩擦系数不同 → 手指滑动有"顿挫" |
| 8 | **长期进灰与磨损** | 机械件积灰影响手感；键帽边缘长期摩擦指腹不适 |
| 9 | **敲击噪声** | 机械轴体的"哒哒"声可能被麦克风或现场扩声拾取 |
| 10 | **整体厚度** | 轴体行程 3.5～4 mm + 定位板 + 轴座 PCB → 机身偏厚 |

### 7.3 电源与噪声

| # | 难点 | 说明 |
|---|---|---|
| 1 | **数字 / 模拟分区** | 传感器模拟小信号与数字开关噪声必须**分区、分地** |
| 2 | **LED 大电流** | 多灯珠峰值电流可达安培级 → **独立供电 + 就近去耦**，不与模拟传感器共用电源走线 |
| 3 | **LED 与传感器共板** | 驱动走线会通过寄生参数耦合进模拟通道 → 走线分开，必要时**分时**（LED 刷新避开 AD 采样窗） |
| 4 | **地环路 / 底噪** | 音频部分与数字部分共用电源会产生底噪 → 需要干净的模拟电源与地 |
| 5 | **开关瞬态毛刺** | LED 刷新、时钟翻转会在模拟通道上产生毛刺 → 需 RC / 磁珠 / 屏蔽 |

### 7.4 时钟与延迟

| # | 难点 | 说明 |
|---|---|---|
| 1 | **时钟预算** | 50 MHz ÷ 48 kHz ≈ **1041 clk / sample** —— 够用，但不能浪费 |
| 2 | **延迟预算分级** | 触发 / 音高必须低延迟；颤音 / 调制不敏感 → 分配要合理 |
| 3 | **确定性** | 拓展目标要求 ≤5 ms **且无抖动** —— 任何"看情况"的处理路径都会破坏确定性 |
| 4 | **串口屏不能进演奏通路** | UART + 触摸扫描延迟不可控 → 只能做 UI |
| 5 | **采样节拍与音频节拍对齐** | 传感器采样率 ≠ 音频采样率 → 需要同步或重采样机制 |

### 7.5 接口与 IO

| # | 难点 | 说明 |
|---|---|---|
| 1 | **电平匹配** | 主控 3.3 V LVTTL；外设若是 5 V 需要电平转换 |
| 2 | **引线 / 飞线的可靠性** | 板上多引出的 IO 焊接不便；**飞线接触不良会造成间歇性、难复现的故障**（已有实测教训） |
| 3 | **一线一信号 vs 总线化** | 每信号一线 → 走线多、排查难 → 应尽量走总线（I2C / SPI） |
| 4 | **连接器是故障点** | 分板设计引入连接器，连接器本身是常见故障源 |

### 7.6 音频输出

| # | 难点 | 说明 |
|---|---|---|
| 1 | **I2S 时序与 MCLK** | 注意主从模式与 MCLK 需求（部分模块可省 MCLK） |
| 2 | **电平与接口匹配** | DAC 输出是 Line level → 接功放的 **AUX IN**，**不能接乐器 INPUT** |
| 3 | **底噪与哼声** | 电源与地处理不好会出现嗡声 / 底噪 |
| 4 | **输出摆幅匹配** | 需确认 DAC 输出摆幅与后级输入灵敏度匹配 |

### 7.7 PCB 与装配

| # | 难点 | 说明 |
|---|---|---|
| 1 | **板卡划分** | 传感器板 / 接口板怎么分 → 决定后期改机械时要不要重画板 |
| 2 | **电极与模拟走线** | 电容电极走线要远离干扰源；模拟走线要短、要包地 |
| 3 | **屏蔽与隔离** | 必要时加接地屏蔽层 / 隔离带 |
| 4 | **公差累积** | 多零件叠加后公差累积，会放大手感问题 |

### 7.8 验证与调试

| # | 难点 | 说明 |
|---|---|---|
| 1 | **手感无法用仪器测** | 只能人手试 + 主观评价 → 需要多人多轮试 |
| 2 | **行程曲线必须画出来** | 判断"连续还是阶跃"要看曲线，不能靠感觉 |
| 3 | **端到端延迟要实测** | 从传感器触发到音频输出的延迟需要专门的测量方法 |
| 4 | **干扰只能小样板验证** | 共板 / 相邻干扰无法靠计算，必须做小样板实测 |
| 5 | **间歇性故障** | 飞线 / 连接器导致的故障难复现 → 焊死、双绞、加伴地回流 |

## 八、每个方案的最小验证实验

> 目标：**用最少的钱和时间，验证每个方案最大的不确定性**。

| 方案 | 最大不确定性 | 最小验证 |
|---|---|---|
| **A 磁轴** | ① 行程曲线是否连续单调（线性霍尔）② 相邻磁轴磁场串扰 | 画"行程 ↔ 输出电压"曲线；单轴按下看邻轴读数 |
| **B 全电容** | ① **端到端延迟是否够** ② 有效挡位分辨率能到多少 ③ 按压面积→力度够不够用 | 1 条滑条 + 触摸 IC，测延迟；数清有效挡位；试按压力度 |
| **C FSR** | FSR 与电容共存的干扰有多大；迟滞与漂移 | 1 片 FSR + 1 条电容条相邻摆放，看基线漂移与迟滞曲线 |
| **D 光电** | 环境光与光学串扰 | 1 对发射/接收管，室内光下测信噪比与响应 |
| **E 微动** | 力度维度能否用其他方式补足 | 试"按下速度"能否算出可用的力度 |
| **F 混合** | 两种器件相邻时的互相干扰 | 各方案主器件的干扰测试（同上） |

> 💡 **两个模块可以并行验证**（因为它们本来就独立）：
> **左手区（选音）方案** 与 **颤音模块（推子 / 电容条）** 各自单独测，互不等待。

## 十、小结（不做推荐，仅归纳）

- **六个功能可以任意组合**，真正要讨论的是"每个功能交给谁"
- **按当前分工**：左手选音 ／ 右手拨弦 + 颤音（二者互斥，不冲突）／ 三个模块互相独立、**不必共面**
- **各方案的典型短板**（都是客观限制，不是偏好）：
  - 磁轴 / 微动：音高离散（单元约 19mm）、表面有凸起
  - 电容：**没有真实压力**、延迟不确定、怕汗、**而且它本身也是离散的**（只是单元更小）
  - FSR：**手感由外购成品决定、迭代空间最小**；与电容耦合最严重
  - 光电：怕环境光与积灰、力度维度弱
- **LED 指引**：磁轴 / 微动 / 光电生态最好；电容次之；FSR 最麻烦 —— 但**任何方案都能做**，只是做法不同
