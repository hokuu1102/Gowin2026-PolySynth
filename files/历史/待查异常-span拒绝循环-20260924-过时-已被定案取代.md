# 🔴 待查异常：`'S'`（span）反复回 `0!` 循环（2026-09-24 晚）

> **状态**：🔴 **未结案** —— 根因缩小到 `S_VOTE` 的离散度检查
> **现象**：⭐ 发 `'S'` ⇒ `s` + 轴号 `0` + 一串 `!`（⭐ `s0!0!0!0!...`）
> **关联**：`K-126`（回包丢弃，✅ 已修）· `K-127`（轴位，⭐ 待办）

---

## 〇、⭐⭐ 一句话

```
⭐ 发 'S' ⇒ 收到 `s 0! 0! 0! 0! ...`
   · `s` = 受理
   · `0` = 轴号（请按轴 0）
   · `!` = 被拒（reject）
⇒ 🔴 `calib_span` 反复"提示按轴 0 → 被拒" ⇒ 标定走不下去
```

## 二、🔴 当前的根因假设（⭐ 待验证）

### 2.1 ⭐ 时间账（⭐ 关键推理）

```
⭐ 参数：⭐ STABLE_NEED=8 · VOTE_N=8 · VOTE_TOL=96 · WAIT_TIMEOUT_CLK=50M(1秒)
⭐ 每通道帧率：⭐ 2000 Hz ⇒ 500 µs/帧

⭐ 正常路径：⭐ S_SETTLE(8帧=4ms) + S_VOTE(8帧=4ms) + S_FIRE ≈ **8 ms/轮**
⭐ 超时路径：⭐ 1 秒/轮（⭐ S_SETTLE 或 S_VOTE 超时）
```

⇒ ⭐⭐ **用户描述"突然就一长串" ⇒ ⚠️ 若是 8ms/轮 ⇒ 10 轮只要 80ms**
⇒ ⭐ **那 reject 来自 `S_FIRE` 的【离散度检查】**：
```verilog
if ((vmax - vmin) > VOTE_TOL) begin   // VOTE_TOL = 96
    reject_o <= 1'b1;                 // ⇐ 就是这个
```

### 2.2 ⚠️ 我之前的推断有漏洞

```
🔴 我根据"几次 'P' 读数稳定（Δ≈1）"就断定"抖动不是问题"

⇒ ⭐⭐ **长时间平均稳定 ≠ 短时间连续稳定** —— ⚠️ 这两者可以完全不一致。

```
