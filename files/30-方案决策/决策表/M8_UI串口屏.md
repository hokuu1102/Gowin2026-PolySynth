## 二、本模块关键点

- 🔴 **演奏链路与 UI 链路必须分离** —— 串口屏的触摸扫描 + UART 传输延迟**不可控**，
  **不能进 ≤5 ms 的确定性通路**。屏只做 UI，**不做演奏输入**
- ✅ 接口只有 4 根：`5V / GND / TX / RX`（**不阻塞其他模块**）
- 💡 可视化（波形 / 频谱 / 李萨如）在 FPGA 内生成数据，屏只负责显示 → 协议要设计好"数据帧"
