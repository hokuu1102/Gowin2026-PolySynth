## 一、`rtl/drivers/adc_farm.sv`（丙 · `smellripple`）

### 改动 1 · 参数化扩展，支持 5~6 片（`K-85`，提交 `202a28b`）

| 项 | 说明 |
|---|---|
| **为什么** | 你提过"后面可能加板子，希望能支持 5 个甚至 6 个" |
| **做了什么** | `N_ADC` 由**写死 3** 改为**参数化可变**：<br>· 扇出由 `assign adc_cs_n[1]/[2] = ...` 改为 **`generate for (g=1; g<N_ADC; g++)`**<br>· 影子移位寄存器由两个独立寄存器改为 **`reg [23:0] miso_shift [1:N_ADC-1]`** 数组<br>· ⭐ **新增**通用端口 `sample_data_packed[N_ADC*12-1:0]` |
| **⭐ 端口兼容** | ⭐ **`sample_data0/1/2` 保留为别名** ⇒ ⛔ **既有 tb 与集成不用改一行** |
| **⭐ 关键结论** | 并行帧时间**与片数无关**（所有片同时扫同一通道号）⇒ 5/6 片**仍是 5094 Hz/通道** |
| **引脚代价** | 每片 **+2**（`CS` + `MISO`）⇒ 6 片共 **11 脚**（Dock 有 80 可用脚） |

### 改动 2 · 修别名越界（`K-89`，提交 `8bb7847`）⚠️ **这是我自己引入的 bug**

| 项 | 说明 |
|---|---|
| **问题** | 我为兼容加的 `sample_data0/1/2` 别名是**无条件**的 ⇒ ⚠️ **`N_ADC<3` 时索引越界** |
| **实测现象** | `N_ADC=2` 时 **`sample_data2 = xxx`（X）** |
| **修法** | 改用 `generate` 保护：固定 3 片宽的 `sample_data_alias[35:0]`，`g < N_ADC` 时接真实数据，**否则接 `12'd0`** |
| **验证** | ✅ `N_ADC=2` ⇒ `data2=000`；✅ `N_ADC=3` 仍 PASS；✅ 回归 25/25 |

> ⚠️ **一句话**：**`N_ADC` 是公开参数，设 2 就会拿到 X** —— 现已修好。

## 二、`rtl/drivers/calib.sv`（丙 · `smellripple`）

### 修 bug：**整个模块原本根本没进综合**（`K-91`，提交 `42e1257`）🔴

| 项 | 说明 |
|---|---|
| **怎么发现的** | 我把采集三模块加进 Gowin 工程跑综合，**直接失败** |
| **报错** | `ERROR (EX3863) : Syntax error near '''` ×4<br>`ERROR (EX3928) : Module 'calib' is ignored due to previous errors` |
| **根因** | 源码里有 4 处 **SystemVerilog 带宽度强制转换**：<br>`24'(FULL) << 8` / `IW'(ITER)` / `PW'(FULL)` / `DW'(FULL)`<br>⭐ 而工程把 `.sv` 按 **Verilog-2001** 编译 ⇒ 语法不合法 |
| **⚠️ 为什么仿真没发现** | ⭐ **iverilog 接受这些写法** ⇒ **`tb_calib` 一直全绿**，只有跑**真综合**才暴露 |
| **修法** | 改成 Verilog-2001 的有宽度 `localparam`（⛔ **纯语法、零行为变化**） |
| **验证** | ✅ 综合 `exit 0`、`Compiling module 'calib'`；✅ **回归 25/25**（`tb_calib` 仍全过 ⇒ 行为等价） |

> ⚠️ **同一个坑 `tlc5916_driver.sv` 里已经记过一次**（`longint'()` 在 Gowin 不可用）。
> 📌 **纪律建议（全项目）**：⭐ **`.sv` 文件里 ⛔ 不要用任何 SV 专有构造**
> （强制转换 `N'()` / `longint` / `logic` / `always_ff` / `typedef` / `interface` …）；
> ⭐ **判据 = 必须真的跑过一次 Gowin 综合**，⛔ "iverilog 过了"不算。
> ⚠️ 另：**Verilog-2001 不能对 `integer` 参数做位选**（`FULL[DW-1:0]` 非法）⇒ 先落成向量。

## 三、`rtl/w3b/oscillator_bank.v`（乙 · `cyxxxx`）

### 改动 1 · `TIMBRE_N/W` 加宽（`K-86`，提交 `8bb7847`）

| 项 | 说明 |
|---|---|
| **问题** | 原 `TIMBRE_N=2, TIMBRE_W=1` ⇒ ⚠️ **只能选 2 种音色** |
| **为什么不够** | ① **四大件**（BASS/GUITAR/PIANO/PAD）需 **4 种**<br>② ⭐ **Looper"一层一件乐器"**需 **≥3 种**同时存在 |
| **改动** | `TIMBRE_N: 2→4`、`TIMBRE_W: 1→2` |
| **⭐ 影响面** | ⭐ **只有一个引用点**（`timbre_id_i` 端口）⇒ **自动随参数加宽**，⛔ 端口名/语义不变 |
| **验证** | ✅ 回归 **25/25**（`tb_w1_interfaces` 传 `1'b0` 仍合法，零扩展） |

### 改动 2 · ⭐ **空桩去桩：64 路独立振荡器**（`T55`，提交 `ac23754`）

> ⚠️ **原文件是"接口骨架"**：注释自称 *"W1-1 interface skeleton only"*，**输出全接 0**。

| 项 | 说明 |
|---|---|
| **填了什么** | ⭐ **64 个独立相位累加器**（`generate` 展开）+ **1 个共享 512×16 波表 pROM**（TDM 取回） |
| **⭐ 端口变化** | ⛔ **端口一个没删/没改**；⭐ **只新增 2 个带默认值的参数**：<br>· `VIB_REF_INC = 38_700_000`（颤音参考增量）<br>· `DBG_LANE = 0`（调试观测选哪个 lane） |
| **为什么不用 DDS IP** | ⭐ `K-83` 定量复核：**DDS IP 每实例自带 ROM 且加密不可合并** ⇒ 64 实例最省也要吃 **97% BSRAM**；**自己写只要 131 kbit（共享波表）** |
| **TDM 时序** | 每帧 **66 拍**（64 lane + 2），远小于 **1024 拍**预算 ⇒ 余量 15× |
| **⭐ 评分证据** | ⭐ 综合网表里 **`gen_lane` 展开 64 个实例（0..63）** ⇒ **评委可机械核验"64 个独立振荡器"** |

## 七、📌 接口契约变更（**唯一一处，请留意**）

⭐ **`note_manager` 的延迟从 `≤ 4 拍` 改成 `≤ 34 拍`**（`0.68 µs`）

| 项 | 说明 |
|---|---|
| **原因** | 原写法时序不收敛（`K-103`）：三级候选选择是**一条组合优先级链**（~96 级、118.5 ns）⇒ 交付顶层 `Fmax` **8.424 MHz**、**1408 违规** |
| **修法** | 改成**每拍考察一个 voice**，扫完 32 拍再提交 |
| **⛔ 端口** | **一字未改** ⇒ **接口不用动**，只有"等待拍数"要调 |
| **⚠️ 对 tb 的影响** | 若你的 tb 假设"发事件后 1~4 拍就生效" ⇒ 改成**等 ≤34 拍**（或等 `alloc_valid`） |
| **✅ 听感/复音/端到端延迟** | ⭐ **全部不变**（`gate` 只在每 1024 拍采样；仍是 32 voice / 64 振荡器） |
| **依据** | `files/20-代码/W3接口冻结表.md` §四（已更新） |

> 📄 详细说明见 `files/历史/待发通知-note_manager延迟契约-过时-已并入待发通知合并版.md`
