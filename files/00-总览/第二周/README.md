## 一、⭐⭐ 六个"必须知道"的定案（2026-09-20，⛔ 不再讨论）

| # | 事项 | ✅ 定案 |
|---|---|---|
| **1** | **`POLY_TARGET`** | ⭐ **保持 32**（`OSC_PER_VOICE=2` ⇒ **64 个独立振荡器**）—— 已算过：典型演奏 24、峰值 33，⭐ **32 够**，靠抢占兜峰值 |
| **2** | **音色数** | ⭐ **`TIMBRE_N = 4`**：**BASS / GUITAR / PIANO / PAD**（配方见 `音色设计.md` §一之二） |
| **3** | **Looper** | ⭐ **3 层**（贝斯/吉他/钢琴各一层）+ **现场弹 1 件** ⇒ **四大件** |
| **4** | **鼓机** | ⭐ **纯合成**（⛔ 无 PCM），走**专用 voice**（⛔ 不占 `POLY_TARGET`） |
| **5** | ⭐ **`adc_farm` 走并行** | ⭐ **三片各自 `CS`、同时扫**（`SCLK`/`MOSI` 同源扇出）⇒ 8 笔 × 24.5 µs = **196 µs ⇒ 5094 Hz/通道** ✅<br>⛔ 串行 24 笔 = 589 µs ⇒ **1698 Hz（达不到 2 kHz）** ⇒ **已排除** |
| **6** | ⭐⭐ **振荡器必须自己写，⛔ 不用 DDS IP** | ⚠️ **DDS IP 每实例自带 ROM 且加密不可合并** ⇒ 64 实例最省配置也要吃 **97 % BSRAM**；⭐ **自己写只要 131 kbit（共享波表）** ⇒ 详见 `K-83` |

### ⭐ 另两条已确认的决定

| 项 | 决定 |
|---|---|
| **打击包络** | ✅ ⭐ **新建 `perc_env_bank.v`**（⛔ **不改队友的 `envelope_bank`**）—— ⚠️ 现有 `adsr` 的 `DECAY=4` ⇒ 从峰值衰到 sustain 要 **14 720 帧 = 300 ms**，而 click 需要 **10~20 ms** |
| **复音数** | ✅ ⭐ **保持 `POLY_TARGET=32`**（⛔ 不碰队友约束 `POLY_TARGET×OSC_PER_VOICE ≤ 64`） |
| ⚠️ **模型文件不入库** | ⭐ `.gitignore` 已加 `model/pcb/*.step` |
| ⚠️ **板卡** | ✅ **Tang Console 60K**（⭐ 2026-09-22 夜拍板，⛔ 不是 NEO Dock）⇒ ⚠️ 换板差异见 `未完成工作总账.md` §〇之二 |

## 二、⭐⭐ 五层优先级（**从底往上，⛔ 不许跳层**）

> ⚠️ **这张图的依赖关系【长期有效】** —— ⭐ **排期会变，依赖不会变。**
> ⚠️ **v1 曾漏掉最大的一块**：**让板子真的出声**（⭐ `top.v` 曾 `sample_mono = 0` 送静音、
> `note_manager`/`mixer` 不存在、`oscillator_bank`/`tdm_render_mixer` 是空桩）。

```
① 焊板 + 通电自检              ← ⭐⭐ 唯一时间敏感项（⚠️ 硬件未到手 ⇒ 仍挂起）
     左手板 → 右手板 → 通电（先只上电源，⛔ 不插 FPGA 板）
                 ↓
② P3 波表上板最小验证           ← ⭐⭐ 最高风险的未知量，越早越好
     ⚠️ $readmemh 外部 .mem 在 GW5AT-60 不加载 ⇒ ROM 全 0、没声音但仿真正常
                 ↓
③ ⭐⭐ 接通出声链                ← ✅ 已完成（T54/T55/T56/T57 + 修 K-103）
     note_manager（32 voice）→ oscillator_bank 去桩 → tdm_render_mixer 去桩 → top.v 集成
                 ↓
④ 音乐时钟 + 节拍器             ← ✅ 已完成（beat_gen T32/P1 · metronome T33）⇒ ⭐ 已能"自动功能出声"
                 ↓
⑤ 鼓机 → Looper → Test Mode     ← ⭐ 功能亮点 + 评分必需
     合成鼓 → 步进音序器 → looper.v → test_mode（⚠️ 现为空桩，属乙）
```

> ⚠️ **注意依赖**：⭐ **自动功能（④⑤）全部依赖 `note_manager`（③）** ——
> 节拍器/鼓机/Looper 走的都是**事件通路** ⇒ ⛔ **③ 不做，④⑤ 也做不了**（⭐ ③ 已完成）。
>
> 🔴 **⭐ 甲的本周主线（⚠️ 2026-09-23 更正，见 `第二周计划-v4` §二）**：
> ⭐⭐ **W3a 采集链打通（🔴 按琴键要出声）** —— ⚠️ **不是蓝牙/曲谱**（⭐ 那条线属加分项）。
> ⚠️ **背景**：之前把加分项（曲谱/蓝牙）当主线做了两天，
> ⭐ **而"乐器能不能用"的根本（采集链语义层）反而没动**。

## 三、⭐ 配额（**用户拍板：按需分配，⛔ 不平均**）

⇒ 其中 **`LIVE_RESERVE` 8**（手弹硬保）+ **Looper 共享池 19**

| 层 | 上限 | 硬保 |
|---|---|---|
| **贝斯** | **2** | ⭐ **2（硬保）** |
| **吉他** | **8** | — |
| **钢琴** | **12** | — |

⭐ 上限之和 22 > 池子 19 ⇒ **谁用得多谁多拿**；**被抢顺序**：⭐ **钢琴 → 吉他 → 贝斯**。
