| **6** | ⭐⭐ **振荡器必须自己写，⛔ 不用 DDS IP**（2026-09-20 定量复核） | ⚠️ **DDS IP 每实例自带 ROM 且加密不可合并** ⇒ 64 实例最省配置也要吃 **97 % BSRAM**；⭐ **自己写只要 131 kbit（共享波表）** ⇒ 详见 `K-83` |

## 二、⭐ 五层优先级（**从底往上，不许跳层** · v2）

> ⚠️ **v1 漏了最大的一块**：**让板子真的出声** ——
> `top.v` 第 97 行 `sample_mono = 0`（**顶层送静音**）、`note_manager`/`mixer` **不存在**、
> `oscillator_bank`/`tdm_render_mixer` **是空桩** ⇒ ⭐ **M1 只证明了"1 个 voice 能出声"，32 复音链是断的**。

```
① 焊板 + 通电自检              ← ⭐⭐ 本周头号（板子到手了，唯一时间敏感项）
     左手板（9/20 到）→ 右手板（9/22 到）→ 通电（先只上电源，⛔ 不插 FPGA 板）
                 ↓
② P3 波表上板最小验证           ← ⭐⭐ 最高风险的未知量，越早越好
     ⚠️ `$readmemh` 外部 .mem 在 GW5AT-60 不加载 ⇒ ROM 全 0、没声音但仿真正常
                 ↓
③ ⭐⭐ 接通出声链（v2 新增）      ← ⭐⭐ 本周主战场（评分主体，v1 完全没排）
     note_manager（32 voice）→ oscillator_bank 去桩 → tdm_render_mixer 去桩 → top.v 集成
                 ↓
④ 音乐时钟 + 节拍器             ← ⭐ 第一次"自动功能出声"
     beat_gen（PPQN=960）→ metronome.v ⇒ ⭐【此处就能上板听到拍子】
                 ↓
⑤ 鼓机 → Looper → Test Mode     ← ⭐ 功能亮点 + 评分必需
     合成鼓（Kick/Snare/Hat）→ 步进音序器 → looper.v（可叠加演奏）→ test_mode（⚠️ 现为空桩）
```

> ⚠️ **注意依赖**：⭐ **自动功能（④⑤）全部依赖 `note_manager`（③）** ——
> 节拍器/鼓机/Looper 走的都是**事件通路** ⇒ ⛔ **③ 不做，④⑤ 也做不了**。
