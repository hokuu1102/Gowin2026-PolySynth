| **1** | **`POLY_TARGET`** | ⭐ **保持 32**（`OSC_PER_VOICE=2` ⇒ **64 个独立振荡器**）—— 已算过：典型演奏 24、峰值 33，⭐ **32 够**，靠抢占兜峰值 |

| **3** | **Looper** | ⭐ **3 层**（贝斯/吉他/钢琴各一层）+ **现场弹 1 件** ⇒ **四大件** |
| **4** | **鼓机** | ⭐ **纯合成**（⛔ 无 PCM），走**专用 voice**（⛔ 不占 `POLY_TARGET`） |
| **5** | ⭐ **`adc_farm` 走并行**（2026-09-20 拍板） | ⭐ **三片各自 `CS`、同时扫**（`SCLK`/`MOSI` 同源扇出）⇒ 8 笔 × 24.5 µs = **196 µs ⇒ 5094 Hz/通道** ✅<br>⛔ 串行 24 笔 = 589 µs ⇒ **1698 Hz（达不到 2 kHz）** ⇒ **已排除** |
| **6** | ⭐⭐ **振荡器必须自己写，⛔ 不用 DDS IP**（2026-09-20 定量复核） | ⚠️ **DDS IP 每实例自带 ROM 且加密不可合并** ⇒ 64 实例最省配置也要吃 **97 % BSRAM**；⭐ **自己写只要 131 kbit（共享波表）** ⇒ 详见 `K-83` |
