### ⚠️ 一条本轮的【工具教训】（⭐ 记下来防复发）

⭐ **`edit` 的锚点必须【逐字符】对齐** —— ⭐ 本轮我两次失手，⭐ 原因是：
🔴 **标题里用的是【全角引号】`"` `"`，⭐ 而我 `old_string` 写的是【半角】`"`** ⇒ ⚠️ **不匹配**
⇒ ⭐ **机械做法**：⭐ **含引号/括号/破折号的锚点，⭐ 先用 `grep` 把那一行原样取出来，⭐ 再复制成 `old_string`** ✅

#### ⚠️ 追加一条（⭐ R16 实测）：⭐ **`pwsh` 里【不要把 `$(if ... '...')` 嵌在 `"..."` 字符串内】**

🔴 **症状**：⭐ `ParserError: UnexpectedToken` ＋ ⭐ **整条命令 exit 1**（⭐ ⛔ 不是逻辑错，⭐ 是**根本没跑**）
⭐ **最小复现**：`"x = $(if ($a -gt 1) { 'high' } else { 'low' })"` ⇒ ⭐ **PS 5.1 解析失败**
⭐ **为什么**：⭐ `$( )` 里有**单引号字符串**时，⭐ 外层 `"..."` 的解析会**提前终止**
⭐ **机械做法（三选一）**：
① ⭐ **先算进变量，再拼字符串**：`$v = if (...) {'high'} else {'low'}; "x = $v"` ✅ **最稳**
② ⭐ **用 `-f` 格式化**：`"x = {0}" -f $v` ✅
③ ⭐ **改用 `if/else` 分段 `Write-Output`** ✅
⛔ **不要**为了省事把 `if` 塞进字符串插值里
