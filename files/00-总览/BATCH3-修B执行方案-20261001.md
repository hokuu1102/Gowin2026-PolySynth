### 改动 ① — `pool_mask`：按【轴】→ 按【来源】

⭐ **现状**（`:489-502`）：
```verilog
    // ── ⭐ 池掩码：由**锁存后的** `cur_axis` 决定（⛔ 不是活的 `note_axis_i`）──
    wire [POLY_TARGET-1:0] pool_mask;
    genvar pg;
    generate
        for (pg = 0; pg < POLY_TARGET; pg = pg + 1) begin : gen_pool
            if (RESERVED_N == 0)
                assign pool_mask[pg] = 1'b1;
            else
                assign pool_mask[pg] = (cur_axis >= RESERVED_AXIS)
                                       ? (pg >= NORMAL_N)
                                       : (pg < NORMAL_N);
        end
    endgenerate
```

⭐ **改为**：
```verilog
    // ── ⭐ 池掩码：由**锁存后的** `cur_src` 决定（⭐ 2026-10-01 修B：⭐ 按【来源】选，⛔ 不按轴）──
    //   🔴 **原缺陷**：⭐ 按 `cur_axis >= 14` 选池 ⇒ ⭐ **物理键 14/15（G#3/A#3）被送进保留池**
    //      ⇒ 🔴 而保留池只有 `RESERVED_N=5` 个 voice、⭐ 且被"鼓 voice"语义占用 ⇒ ⭐ 那两个键不响 ✅
    //   ⭐ **为什么按来源是对的**：⭐ 保留池的本意是"**给节拍器/鼓机专用**"（⭐ `T33b`），
    //      ⭐ 那是【来源】属性（⭐ `src != 0`），⛔ **不是【轴号】属性** ✅
    //      ⇒ ⭐ 现场手弹（`src == 0`）**无论按哪个键**都该进普通池 ✅
    //   ⚠️ 用 `cur_src`（⭐ 锁存后的）⛔ 不用活的 `note_src_i`（⭐ 与 `cur_axis` 同一纪律）
    wire [POLY_TARGET-1:0] pool_mask;
    genvar pg;
    generate
        for (pg = 0; pg < POLY_TARGET; pg = pg + 1) begin : gen_pool
            if (RESERVED_N == 0)
                assign pool_mask[pg] = 1'b1;
            else
                assign pool_mask[pg] = (cur_src != 3'd0)
                                       ? (pg >= NORMAL_N)
                                       : (pg < NORMAL_N);
        end
    endgenerate
```

### 改动 ② — `voice_drum_o`：**同一个信号**派生（⭐ §26.3-e）

# 🔴🔴 更正（⭐ 2026-10-01 00:48 实测得出，⭐ **覆盖上面第一版的规则**）

## ⚠️ 第一版写的 `cur_src != 3'd0` 是**错的** —— ⭐ 会打破 looper

⭐ **实测证据**（⭐ `top.v` 的三路源）：
```
top.v:3349  .a_src_i (src_a_src)   ← ⭐ 源 A（live 手弹 / score 曲谱 / demo）
top.v:3364  .b_src_i (3'd3)        ← ⭐ 源 B（鼓机 / 节拍器）= 3
top.v:3379  .c_src_i (3'd4)        ← ⭐ 源 C（looper）= 4
```
⇒ 🔴 若用 `src != 0` ⇒ ⭐ **looper（src=4）也会被打上"鼓"标志** ⇒ ⭐ **回放全走噪声表** ❌❌

## ✅ 正确规则（⭐ 从**原始实现**里读出来的，⛔ 不是我推的）

⭐ **原始实现所在分支**：⭐ `feat/pool-src`（⭐ 提交 `9ae0335`，⭐ 后被 `3527f6d` revert ✅）
⭐ **它的注释原文**：
> ⭐ **进不进保留池由【源】决定（`cur_src == SRC_AUX`），⛔ 不再由轴号决定**
> ⭐ `src_r[i] == SRC_AUX`（⭐ 即"这个 voice 是**源 B**（节拍器 / 鼓机）起的音"）

⇒ ⭐⭐ **规则 = `src == SRC_AUX`（⭐ `SRC_AUX` ≡ 源 B ≡ `3'd3`）** ✅

| ⭐ 源 | ⭐ `src` | ⭐ 进哪个池 | ⭐ `voice_drum_o` |
|---|---|---|---|
| ⭐ live 手弹 | **0** | ⭐ **普通池** ✅ | ⭐ **0（⛔ 不是鼓）** ⇒ ⭐ **键 14/15 正常发声** ✅ |
