## 二、⭐⭐ 摇把与推子变调的关系（⭐ 用户问的，⭐ 已答 ✅）

| ⭐ | ⭐ 摇把（whammy）| ⭐ 推子变调 |
|---|---|---|
| ⭐ 回中 | ⭐ **弹簧回中** ✅ | ⭐ **不回中** ✅ |
| ⭐ 量化 | ⭐ **连续** ✅ | ⭐ **量化到半音** ✅ |
| ⭐ 用途 | ⭐ **演奏弯音**（⭐ 表情 ✅）| ⭐ **设定调性**（⭐ Transpose ✅）|

⭐⭐ **实现关键**：⭐ **先相加、⭐ 再查表** ⇒ ⭐ **只用一个乘法器** ✅

```
⭐ 总半音偏移 = 推子半音（⭐ 量化 ✅）＋ 摇把偏移（⭐ 连续 ✅）
⭐                       └── 相加 ──┘
⭐                             ↓
⭐                ⭐ 一个比例表 ＋ 一个乘法器 ✅
```

⚠️ ⭐ **如果各走一个乘法器 ⇒ 成本翻倍** ⚠️ —— ⭐ 实测教训：⭐ 一个"**每 lane 的变量移位器**"
就吃了 **+2202 LUT**（⭐ T2 实测 ✅）⇒ ⭐ **乘法器绝不能每 lane 一份** ✅

## 三、🔴🔴 **本设计最关键的一条：乘法器必须【时分复用】**

### ⭐ 问题

⭐ "实时变调"意味着 ⭐ **所有正在响的音都要跟着变** ⚠️
⇒ ⭐ 朴素做法是**每 lane 一个乘法器** ⚠️ ⇒ ⭐ **32 个 32×17 乘法器** ⚠️⚠️ ⇒ ⭐ **LUT 爆炸** ✅

### ⭐ 解法：⭐ 共享 1 个乘法器 ＋ **轮转更新**

| ⭐ | ⭐ 做法 |
|---|---|
| ⭐ **一个乘法器** | ⭐ 每拍算 **一个 lane** 的 `inc × ratio` ✅ |
| ⭐ **轮转** | ⭐ 32 拍转完一圈 ✅ ⇒ ⭐ `32 / 48 kHz = `**`0.67 ms`** ✅ |
| ⭐ **够不够** | ⭐ ⭐ **完全够** —— ⭐ 换调是**人手的动作**（⭐ 几十 ms 级 ⚠️）⭐ 而且 ⭐ **短滑音过渡正好掩盖这 0.67 ms** ✅✅ |
| ⭐ **先例** | ⭐ ⭐ **本项目已经这么做了** —— ⭐ `tdm_render_mixer` 就是"**共享 1 个 DSP**" ✅（⭐ 见架构说明 ✅）|

📌 ⭐ **判据**：⭐ 轮转一圈的时间必须 **≪ 短滑音过渡时间** ✅（⭐ `0.67 ms ≪ 几十 ms` ✅）

## 四、⭐ 档位表（⭐ 2 档启用 ＋ 2 档预留 ✅）

| ⭐ 档 | ⭐ CH2（左推子）| ⭐ CH3（右推子）| ⭐ 状态 |
|---|---|---|---|
| **0** | ⭐ **降调** 0 → **−12** 半音 | ⭐ **升调** 0 → **+12** 半音 | ⭐ **启用** ✅ |
| **1** | ⭐ 颤音深度（⭐ 现状 ✅）| ⭐ 颤音速率（⭐ 现状 ✅）| ⭐ **启用** ✅ |
| **2** | ⭐ 摇把范围 | ⭐ 摇把速率 | ⭐ **预留** ⚠️ |
| **3** | ⭐ 主音量微调 | ⭐ — | ⭐ **预留** ⚠️ |

⭐ **档 0 的映射**（⭐ "各占半程" ✅）：
```
⭐ 左推子（CH2）：⭐ 0 → 12 档（⭐ 每档 1 半音 ✅）⇒ ⭐ 半音偏移 = −档位 ✅
⭐ 右推子（CH3）：⭐ 0 → 12 档 ⇒ ⭐ 半音偏移 = +档位 ✅
⭐ ⇒ ⭐ 每半音的行程 = ⭐ 满程 / 12（⭐ 比"居中为零"的 /24 好一倍 ✅）
```

⭐ **切档**：⭐ 阶段① **串口命令**（⭐ 复用空闲字母 ⚠️ 或 ⭐ 带帧命令 ✅）⇒ ⭐ 阶段② **物理按键** ✅

## 五、⭐ 变调核心（⭐ `note_manager` 内 ✅）

### ⭐ 比例表（⭐ 25 项，⭐ 显式 `case` ✅ —— ⭐ §54 ① ✅）

```verilog
// ⭐ Q1.15 无符号定点（1.0 = 32768）；⭐ 17 位（⭐ 因为 +12 半音 = 2.0 = 65536 ✅）
// ⭐ 用【显式 case】而⛔ 不是运行期幂运算（⭐ 与 axis_map 查表同一纪律 ✅）
function [16:0] semi_ratio_of;
    input [4:0] idx;              // ⭐ 0..24 ⇒ ⭐ 半音 −12..+12
    case (idx)
        5'd0 : semi_ratio_of = 17'd16384;   // ⭐ −12 ⇒ 0.5
        // ⭐ … 中间按 2^(n/12) 填 …
        5'd12: semi_ratio_of = 17'd32768;   // ⭐   0 ⇒ 1.0
        // ⭐ …
        5'd24: semi_ratio_of = 17'd65536;   // ⭐ +12 ⇒ 2.0
        default: semi_ratio_of = 17'd32768; // ⭐ 兜底 = 不变调 ✅
    endcase
endfunction
```

### ⭐ 旁路 mux（⭐ §54 ② ✅）

```verilog
// ⭐ 总半音 == 0 ⇒ ⭐ 逐位恒等【由构造保证】（⭐ 乘法器不在通路上 ✅）
wire trans_bypass = (trans_total == 5'd0);
```

### ⭐ 短滑音过渡（⭐ 用户裁定 ✅）

⭐ 目标半音**跳变**时 ⚠️，⭐ 当前半音**逐步逼近**（⭐ 每拍 ±1 档 ⚠️ 或 ⭐ 更细 ✅）
⇒ ⭐ 避免"咔"的一声 ✅ ＋ ⭐ **顺带掩盖乘法器的轮转延迟** ✅✅
