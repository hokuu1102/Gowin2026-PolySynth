## 一、⭐ 本周期做了什么（⭐ 5 个修复 ＋ 1 次推送）

### 1.1 ⭐⭐ 真正的根因：**起音时振荡器相位没有复位**（⭐ `aaecc7d` ✅）

> ⭐ **这是本周期最重要的发现** ✅ —— ⭐ 前面 4 个修复都不是它 ✅

**用户原话（⭐ 决定性证据）**：
> *"我快速地每次都按到底，用微分积分的思想来看，就和长按的音量变化是一样的，
> 还是失谐的正弦波的音量起伏"*

⭐ **推理链**：⭐ 快速连按 = ⭐ **对拍频包络做【采样】** ✅ ⇒ ⭐ **每次起音的音量 =
失谐两 lane 当时的相位关系**（⭐ 0.25× ~ 2.0× ✅）✅

**🔴 代码根因**（`rtl/w3b/oscillator_bank.v`）：
```verilog
//  ⛔ 原行为
if (lane_active) phase_q <= phase_q + lane_inc;   // ⚠️ 无 else ⇒ 未激活时保持相位
//  ⭐ phase_seed 只在 rst_n_i 用一次
```
⇒ ⭐ **第一个音之后，`phase_seed` 设计的 0°/90° 初相关系就丢失了** ✅
⇒ 🔴 **每次起音的叠加幅度随机** ✅

**✅ 修法**：
```verilog
if (!test_mode_i && lane_active && !lane_active_d)
    phase_q <= phase_seed;        // ⭐ 起音（上升沿）⇒ 回到设计初相
else if (lane_active)
    phase_q <= phase_q + lane_inc;
```

⭐⭐ **这【正是设计者本来的意图】** —— ⭐ `phase_seed` 的注释原文：
> *"给它一个 1/4 周期初相 ⇒ 起音时一个是 `sin`、一个是 `cos`
> ⇒ ✅ 既不抵消、也不叠加（幅度平稳）"*

⇒ ⭐ **它就是为"起音"设计的** ✅ ⛔ **却只接到了复位** ✅

**⚠️ 两个必须知道的点**：
1. ⭐ **只在 `!test_mode_i` 做** —— ⭐ test-mode 判据建立在"相位照常前进"之上 ✅
   （⭐ 实测：不加这个门 ⇒ **红 5 条** ✅）
2. ⭐ 旧判据⑨ **先 `rst_n` 对齐相位** ⇒ 🔴 **恰好绕过了本 bug** ✅
   ⇒ ⭐ 新增判据⑩「同深度两次起音必须逐位相同（⭐ **不复位**）」✅
   ⭐ **非空洞性**：⭐ 去掉上升沿载入 ⇒ ⭐ **⑩ 变红且只有它红**（⭐ 已实测 ✅）
