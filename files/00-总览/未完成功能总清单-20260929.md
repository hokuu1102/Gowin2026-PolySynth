## 四、最小实现路径

| 功能 | 路径 |
|---|---|
| 起始音 / 实时变调 | `uart_ui.base_semi_o`（已存在）→ `top.v` 用 `ui_base_commit` 锁存 → 接入 `axis_map` / `note_manager` 的音高基址；半音级需扩展 `uart_ui` 控件或走推子 ADC |
| 推子摇把 / 变调 | `right_analog_ctrl`（CH1/2/3）→ 增加功能选择寄存器（串口命令或串口屏控件）→ 将 CH2/CH3 读数路由到颤音深度 / 变调 / 摇把 |
| 延音踏板 | `.cst` 增加引脚 → `sync_input` + `debounce` → `note_manager`：踏板期间 `note_off` 只关 gate、不关包络 |
| 曲谱与 looper 共存 | `seq_arb` 的 score 口当前二选一（`SCORE_UART_ENABLE`）→ 增加一级仲裁，或给 looper 单独入口接入 `evt_merge` |
| LED 指引 | 曲谱 / `note_manager` 事件 → 音符到灯位映射 → `led_data`（已存在） |
| HDMI | `.cst` 增加 TMDS 引脚 → 视频时序（HSYNC / VSYNC / DE）→ 波形取 `master_mix` → 李萨如用两路样本 → 频谱需 1024 点流水 FFT |
| 效果器 | 先实现延迟（BSRAM 环形缓冲）→ 接入 `master_mix` 之前 → 启用串口屏 `fx_sel` |
| 鼓机验证 | `top.v` 参数 `SEL_DRUM = 1` → PnR → 上板试听 4 个节奏型 |

## 六、待定项：多按键控制板 + 旋钮

数量与布局待定，一旦确定需更新本节与第三周计划 §6.5。

| 项 | 影响 | FPGA 侧建议 |
|---|---|---|
| 多按键 | 引脚预算（拓展板 IO 有限） | 矩阵扫描（新建 `key_matrix`）或 74HC165 并转串；避免一键一 IO |
| 旋钮（电位器） | ADC 通道预算（`adc_farm` 为 3 组 × 8 通道，右手已占 3） | 先核算通道数 |
| 旋钮（EC11 编码器） | 无额外接口成本 | `debounce` 自带 EC11 支持（`enc_cw` / `enc_ccw` / `enc_sw_down` / `enc_err`），优先选用 |
| 软件接口 | 三个入口需同构 | 按键模块只产生单周期脉冲，复用 `calib_cmd` 语义，下游不改 |
| 拓展板预留 | 按键排针、旋钮接口、踏板、HDMI 座 | 引脚清单须与 `constr/top.cst` 对齐 |
