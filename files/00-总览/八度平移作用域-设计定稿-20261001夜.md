# §一、⭐ 现状（⭐ 逐行核实，⛔ 不是转述）

## 1.1 现在怎么做的

```verilog
// rtl/w3b/note_manager.v:1265-1267（gen_pack 内，每 voice 一份）
assign voice_phase_inc_o[g*PHASE_W +: PHASE_W] =
    (base_oct_r == 2'd0) ? phase_r[g] : (phase_r[g] << base_oct_r);
```

| ⭐ 特征 | ⭐ 后果 |
|---|---|
| ⭐ 在**输出侧** | ⭐ 对**所有 voice 无条件** ⇒ ⭐ **不分来源** |
| ⭐ **每 voice 一份** | 🔴 **32 份** ⇒ ⭐ **+2202 LUT**（⭐ 摊销 ≈ **68.8 LUT/份**） |
| ⭐ 只有 **`<<`（左移）** | 🔴 **只能升八度** |
| ⭐ 注释自述的理由 | ⭐ "`phase_r` 有**三条写入路径** ⇒ 放输入只覆盖两条 ⇒ ⭐ **滑音会绕过移位**" |

## 1.2 ⭐⭐ `phase_r[g]` 的写入路径【全清单】（⭐ 本次设计的核心输入）

| ⭐ # | ⭐ 路径 | ⭐ 语句 | ⭐ 触发条件 | ⭐ 值从哪来 |
|---|---|---|---|---|
| 0 | 硬复位 | `:740` | `!rst_n_i` | 常量 0（⛔ 非音高路径） |
| **1** | ⭐ **同轴重触发**（复用 voice 起音） | `:1123` | `ST_RETRIG` ＋ `same_en_r` | ⭐ `cur_inc` ← **FIFO**（`note_phase_inc_i`） |
| **2** | ⭐ **提交 / 新占 voice 起音** | `:1221` | `ST_COMMIT2` ＋ `cmt_en_r` | ⭐ `cur_inc` ← **同一条 FIFO** |
| **3** | 🔴 **滑音 `pitch_upd`** | `:969` | `live_mask && axis 匹配 && src 匹配` | ⭐ **独立端口** `pitch_upd_value_i`（⛔ 不经 FIFO、⛔ 不经 `evt_merge`） |

⭐⭐ **两条必须记住的结论**：
1. 🔴 **"起音"其实是【两条】路径**（`:1123` 同轴重触发 ＋ `:1221` 新占提交）⇒ ⚠️ **只按注释改一处会漏一条** ✅
   ⭐ 好消息：⭐ 这两条**共用同一条 FIFO 链** ⇒ ⭐ **改 `note_phase_inc_i` 一处即可同时覆盖** ✅
2. 🔴 **滑音是独立端口** ⇒ ⭐ **任何"在 `evt_merge` 之后注入"的方案，结构上都覆盖不到它** ⚠️
   ⭐ 且它**当前唯一的实际驱动源就是 looper**（`param_extract.pitch_valid_o` 恒 0 ⇒ `pe_pitch_v` 恒 0）✅

# §三、⭐ 平移规则（⭐ 按拍板，⭐ 一行可判）

| ⭐ 来源 | ⭐ `src` 编码 | ⭐ 是否平移 | ⭐ 理由 |
|---|---|---|---|
| **手弹（live）** | `0` | ✅ **平移** | ⭐ 用户要"整机移调" |
| 曲谱回放（score） | `1` | ✅ 平移 | ⚠️ **待你确认**（⭐ 见 §六-2） |
| 演示（demo） | `2` | ✅ 平移 | ⚠️ 同上 |

# §四、⭐ 有符号档位（⭐ 支持 `-2`）

## 4.1 ⭐ 编码方案（⭐ 推荐 A）

| ⭐ 方案 | ⭐ 屏侧发什么 | ⭐ RTL 怎么解 | ⭐ 评价 |
|---|---|---|---|
| **A（⭐ 推荐）** | ⭐ **无符号偏移量** `0..4`（⭐ 0 = `-2` 档 · 2 = 0 档 · 4 = `+2` 档） | ⭐ `oct_off = val − 2`（⭐ 3 位有符号） | ⭐ **屏侧好发、RTL 好判** · ⭐ 向后兼容性可保留（⭐ 旧值 0/12/24 不再使用） |
| B | ⭐ 有符号补码 | ⭐ 直接用 | ⚠️ 屏侧发负值麻烦 |

⭐ **范围**：⭐ `oct_off ∈ [-2, +2]`（⭐ C2 ~ C6）· ⭐ 越界 ⇒ ⭐ **夹紧**（⛔ 不回 0，⭐ 避免"跳到 C4"这种惊吓）⚠️ **待确认**

## 4.2 ⭐ 应用（⭐ 有符号移位）

```text
⭐ oct_off == 0 ⇒ ⭐ 逐位恒等（⛔ 不走移位器 —— ⭐ 保持现有"由构造保证"的做法）
⭐ oct_off >  0 ⇒ ⭐ phase_inc << oct_off
⭐ oct_off <  0 ⇒ ⭐ phase_inc >> (-oct_off)
```

| ⭐ 项 | ⭐ 结论 |
|---|---|
| ⭐ 右移的安全性 | ✅ ⭐ `phase_inc` 是**无符号** ⇒ ⭐ Verilog 的逻辑右移**正确**（⛔ 不是算术右移） |
| ⭐ 精度损失 | ✅ ⭐ 32 位 inc 右移 1~2 位 ⇒ ⭐ 相对误差 ≈ `2^-30` ⇒ ⭐ **可忽略** |
| ⚠️ 音域 | ⚠️ ⭐ `-2` 档下最低音到 **C2（65 Hz）** ⇒ ⭐ **要听感验证波表在这个音域的可用性**（⭐ 需上板） |
