⭐ §54 给了 4 条，⭐ **T2 只需前 3 条**（⭐ 第 4 条是 T3 的"带帧绝对量命令" ✅）：

| ⭐ | ⭐ §54 要求 | ⭐ T2 怎么落 |

### ⭐ 具体改动（⭐ 2 个文件）

**`rtl/w3b/note_manager.v`**（⭐ +约 25 行）

```verilog
// ⭐ 新增两个端口（⭐ 与现有端口同风格）
input  wire [6:0]  base_semi_i,      // ⭐ 起始音偏移（⭐ 八度×12：0=C4 · 12=C5 · 24=C6）
input  wire        base_commit_i,    // ⭐ 提交脉冲（⭐ 单周期）

// ⭐ 起始音锁存：⭐ 只在 commit 拍更新，⭐ 且【先校验再提交】（⭐ §54 ③）
//   📌 用【显式 case】而⛔ 不是除法 —— ⭐ 运行期 `/12` 会引一个除法器 ⚠️
//      ⇒ ⭐ 与 `axis_map`"查表不做运行期指数"是**同一条纪律** ✅
reg [1:0] base_oct_r;
always @(posedge clk_i) begin
    if (!rst_n_i) base_oct_r <= 2'd0;
    else if (base_commit_i) begin
        case (base_semi_i)
            7'd0 : base_oct_r <= 2'd0;   // ⭐ C4（默认）
            7'd12: base_oct_r <= 2'd1;   // ⭐ C5
            7'd24: base_oct_r <= 2'd2;   // ⭐ C6
            default: base_oct_r <= 2'd0; // 🔴 非法值 ⇒ ⭐ 回到 0，⛔ 不写进去
        endcase
    end
end

// ⭐ 输出：⭐ 显式旁路 mux（⭐ §54 ②）—— ⭐ oct=0 时**逐位恒等由构造保证** ✅
assign voice_phase_inc_o[g*PHASE_W +: PHASE_W] =
       (base_oct_r == 2'd0) ? phase_r[g]
                            : (phase_r[g] << base_oct_r);
```

⚠️ **为什么移位放在【输出】而⛔ 不是【输入】**：⭐ `phase_r` 有三条写入路径
（⭐ 起音 `:1095` · ⭐ 提交 `:1193` · ⭐ **滑音 `pitch_upd` `:941`**）
⇒ ⭐ 放在**输入**只覆盖前两条 ⇒ 🔴 **滑音会绕过移位**（⭐ 不一致 ✅）
⇒ ⭐ **放在输出**则**三条路径全覆盖** ✅（⭐ 符合 `0.12`"枚举所有同类路径" ✅）

## 三、⭐ 判据（⭐ 新建 `tb/w3b/tb_base_semi.sv`）

| ⭐ | ⭐ 判据 | ⭐ 怎么判 |
|---|---|---|
| **T1** | ⭐ **默认（oct=0）逐位恒等** | ⭐ 任意 `note_phase_inc` ⇒ ⭐ `voice_phase_inc_o` **逐位相同**（⭐ 这是 §54 ② 的"由构造保证" ✅）|
| **T2** | ⭐ **oct=1 精确 ×2** | ⭐ 灌 `base_semi=12` ⇒ ⭐ 输出 = 输入 `<< 1` ✅ |
| **T3** | ⭐ **oct=2 精确 ×4** | ⭐ `base_semi=24` ⇒ ⭐ 输出 = 输入 `<< 2` ✅ |
| **T4** | ⭐ **非法值被拒** | ⭐ 灌 `base_semi=13` / `=36` / `=127` ⇒ ⭐ **oct 回 0**（⭐ ⛔ 不接受）✅ |
| **T5** | ⭐ **只在 commit 拍更新** | ⭐ `base_semi` 变了但⛔ 不发 commit ⇒ ⭐ oct **不变** ✅ |
| **T6** | ⭐ **三条写入路径都受影响** | ⭐ 起音 / ⭐ 提交 / ⭐ **滑音** 之后 ⇒ ⭐ 输出都带移位 ✅ |
| **T7** | ⭐ **复位** | ⭐ `rst_n` ⇒ ⭐ oct = 0 ✅ |
| ⭐ **非空洞性** | ⭐ 把旁路 mux 的 `<< base_oct_r` 去掉 | 🔴 **T2/T3/T6 必须变红** |
