# §0 一页速查（⭐ 只记这一页也能弹）

## 0.1 接线（⭐ 顺序不能反）

```text
① 左手板 1（片0）→ Console 的 J9：N1=MCP_CLK · N2=MOSI · N3=MISO · N4=CS · N11=+5V · N12=GND
② 左手板 2（片1）→ Console 的 J9：N1=MCP_CLK · N2=MOSI · N5=MISO · N6=CS · N11=+5V · N12=GND
③ 右手板 A（片2）→ Console 的 J9：N1=MCP_CLK · N2=MOSI · N7=MISO · N8=CS
                     拨弦比较器 → PMOD1 的 IO6(TRIG_UP) / IO7(TRIG_DN)
④ USB-TTL       → J9：TX→N26(D14) · RX→N25(D15) · GND→J9 的 GND
⑤ 音箱          → 外置 DAC 模块（PCM5102A）的 3.5mm 口 → 音箱 Line In
⑥ 最后插 USB-C 供电（Console 的 /USB_JTAG/ 口）
```

| ⭐ 项 | ⭐ 值 |
|---|---|
| **串口** | ⭐ **500000 · 8N1 · ⛔ 无流控**（⚠️ ⛔ **不是 1000000** —— 照旧文档配会收到**乱码且不报错**） |
| **⛔ 绝不能做** | 🔴 **板载 `J5` 是 BTL 喇叭输出 ⇒ 直连有源音箱会烧**（⭐ 要用音箱就走外置 DAC） |
| **⛔ 绝不能做** | 🔴 **带电插拔 SPI 排线**（可能闩锁）⇒ ⭐ 先断电再插拔 |
| **⛔ 别按 `Y12`** | ⭐ 那是 `Key_in[1]`（ESP32 预留）；⭐ **复位键是 `AA13`**（板上 S2 旁那个） |
| ⭐ **上电顺序** | ⭐ **先把左手板 2 插好，再上电**（⚠️ 否则它的 `MISO` 悬空被上拉 ⇒ 零点被记成 4095 ⇒ **看起来像"第二块板坏了"**）；⭐ 补救：上电后发 `'T'` 重记零点 |

## 0.2 串口命令卡（⭐ 14 个字母）

| ⭐ 命令 | ⭐ 做什么 | ⭐ 回包 |
|---|---|---|
| **`T`** | ⭐ **重记零点**（16 轴，tare）—— 上电后 / 零点漂移时用 | ⭐ `t` ⇒ **1~2 秒后 `T`**（大写 = 完成） |
| **`S`** | ⭐ 行程标定（span）—— ⚠️ **用户已裁定【放弃】，⛔ 一般不用**（见 §5.3） | `s` ⇒ 逐轴轴号 ⇒ `.` 成功 / 拒绝码 ⇒ 最后 **`D`**（⚠️ 粘滞，第二轮不再出现） |
| **`X`** | ⭐ 中止标定（⭐ **每轮 `S` 之前必须先发**） | `x` |
| **`P`** | 读**原始码**（诊断） | `P<通道号><4 位十进制>`（8 字节） |
| **`V`** | 读 `calib_span` 内部状态（诊断） | `V<state><axis><rej_hi><rej_lo>`（**7 字节**） |
| **`N`** | ⭐ 读**标定后的 `pos`**（⭐ 每次自动切下一轴，诊断主力） | `N<轴号><4 位十进制>`（8 字节） |
| **`M`** | Test Mode（强制 4 / 8 / 16 / 32 个振荡器） | — |
| **`R`** | ⭐ **looper 录 / 停**（⭐ **切换**） | ⛔ **无回包** |
| **`L`** | ⭐ **looper 播放 / 停**（⭐ **切换**） | ⛔ **无回包** |
| **`C`** | ⭐ **looper 清空**（⭐ **边沿，不是切换**；⭐ 顺带**停录 + 停播**） | ⛔ **无回包** |
| **`I`** | ⭐ **切音色**：BASS → GUITAR → PIANO → PAD → BASS | ⛔ **无回包** |
| **`B`** | ⭐ **源 B 开关**（⭐ **当前位流里 = 鼓机开关**） | ⛔ **无回包** |
| **`D`** | ⭐ **鼓机节奏型** 切下一个（⭐ **立刻生效，不用等小节**） | ⛔ **无回包** |
| **`K`** | ⭐ **键盘打鼓模式** 开 / 关 | ⭐ **回 `'k'`**（⚠️ **14 个里唯一有回包的**） |

> 🔴 **⭐ 最容易误解的一条**：⭐ **除了 `K`，其它命令【一个字节都不回】** —— ⛔ **不要因为"没回包"就以为命令没生效**（⭐ 生效反馈只有**听声音**）。
> ⚠️ **另一个坑**：⭐ 裸字母命令与**串口屏载荷共用一条 `uart_rx`** ⇒ ⚠️ 屏上发数据时若载荷里出现 `D`/`K`/`I`/`B` 等字节，**会被当成命令误触发**（⭐ 已知缺陷 `P0-4`，⛔ 尚未修）。

⚠️ **切到指板模式后"按了没声"是正常的** —— ⭐ 缺的是**右手拨弦硬件**（⭐ 板 A 的拨弦比较器）。

# §2 演奏操作

## 2.1 力度（⭐ 位置式，按多深就多响）

| ⭐ 项 | ⭐ 值 |
|---|---|
| 公式 | `vel = 64 + (pos × 263) >> 10`，⭐ **饱和到 255** ⇒ ⭐ 输出 **64 ~ 255**（⭐ 约 192 级） |
| 满行程 | ⭐ **744**（⭐ 当前量纲档；⭐ 满按恰好饱和） |
| **触发阈** | ⭐ `pos ≥ 64` ⇒ 按下（⭐ = 行程的 **8.6%**） |
| **释放阈** | ⭐ `pos < 32` ⇒ 松手（⭐ = **4.3%**，⭐ **迟滞 2:1**） |
| 不应期 | ⭐ **60 帧 ≈ 30 ms**（⭐ 防重复触发） |
| 实时跟随 | ⭐ **按住时力度持续跟随行程**（⭐ 每轴 328 µs 刷新一轮）· ⭐ 抬起即冻结 |

⚠️ **力度相关的一个已知限制**：⭐ `param_extract` 那套"双阈值测速法"力度 **有意不使用**（⭐ 不是漏接线）。

## 2.2 起音

⭐ 触发瞬间取值：⭐ 若 `pos < 64` 就按下（非常轻）⇒ 用固定 **200**；⭐ 否则用**位置式算出的力度**。

## 2.3 ⚠️ 滑音 / 双音 —— 🔴 **本版未实现**

| ⭐ 项 | ⭐ 现状 |
|---|---|
| 手弹**横向移动 → 滑音** | 🔴 **没有实现** —— `event_extract.slide_*` **恒 0** |
| **双压插值**（相邻两键之间连续） | 🔴 **两种模式都【已关闭】**（`frac` 恒 0）⇒ ⭐ **每个键一个固定音** |
| 唯一会变音高的来源 | ⭐ **looper 回放**（⭐ 回放插值会驱动 `pitch_upd`） |

⭐ **为什么会关**（⭐ 上板实测教训）：⭐ 早期用 `pos` 低位当插值系数 ⇒ **按得深音就滑** ⇒ 上板症状"所有音高一样 / 一个键两个音色很尖"。
⇒ ⭐ **所以现在按得深只改力度，⛔ 不改音高**。

## 2.4 音色（4 种）

| ⭐ `'I'` 顺序 | ⭐ 音色 | ⭐ 波形 |
|---|---|---|
| 0 | **BASS** | 三角波 |
| 1 | **GUITAR** | 锯齿波 |
| 2 | **PIANO** | 零直流 25% 脉冲 |
| 3 | **PAD** | 波表 |

⭐ **两个入口等效**：串口 `'I'`（循环）· 面板 **S2 键**。
⚠️ ⭐ **音色在"起音那一刻"锁存** ⇒ ⭐ **只对【新按下】的音生效**，正在响的音不变。

# §3 ⭐⭐ looper（循环录音）

## 3.1 三条命令的**精确语义**

| ⭐ | ⭐ 语义 | ⭐ 落到 looper |
|---|---|---|
| **`R`** | ⭐ **切换**（录 ↔ 停） | ⭐ 单周期**边沿**（`rec_req` / `stop_req`） |
| **`L`** | ⭐ **切换**（播 ↔ 停） | ⭐ **电平** `play_en` |
| **`C`** | ⭐ **边沿**（⛔ 不是切换） | ⭐ 清空 ＋ ⭐ **同时把录/播两个开关都复位** |

## 3.2 ⭐ 再按一次会怎样（`R` 有 4 种情形，⭐ 逐条记）

| ⭐ 当前状态 | ⭐ 再按 `R` |
|---|---|
| 空闲（没录过） | ⭐ 起录 —— ⚠️ **但先进"待起录"，等小节线**才真录 |
| **待起录** | ⭐ **取消**（⭐ 有旧录音就回到"待播"态，⛔ **不清**） |
| **正在录** | ⭐ 停录 ⇒ ⭐ **逐轴补发 `note_off`**（⭐ 录时还按着的音会停） |
| **回放中** | ⭐ **重录**（⭐ 先补发 `note_off`，再起录） |

⭐ **`L`**：第 1 次 ⇒ 等小节线后**循环回放**；再按 ⇒ 停播（⭐ 正在响的 loop 音**补发 `note_off`**，⚠️ **录音保留**，下次从头播）。
⭐ **`C`**：⭐ **清空 + 停录 + 停播**（⭐ 回放中按会先补发 `note_off` 再清）。

## 3.3 ⭐ 长度与小节对齐

| ⭐ 项 | ⭐ 值 |
|---|---|
| **最短** | ⭐ **1 小节 = 3840 tick = 2.0 s** @120 BPM（⭐ 没录满也**强制补足到 1 小节**） |
| **最长** | ⚠️ **没有显式上限** —— 只有两条**编码约束**：⭐ **2048 个事件**（满了**静默丢**）· ⭐ tick 位宽 20 位 ≈ **273 小节 ≈ 9.1 min**（超了**静默回绕**） |
| **对齐到几拍** | ⭐ **4 拍 = 1 小节** |
| **三条对齐** | ⭐ ① **起录**等小节线 ② **停录**量化到**最近的整小节** ③ **起播**等小节线 |
| ⚠️ **对齐何时生效** | 🔴 ⭐ **要等【第 2 个小节线】**（≈ **4 s** @120 BPM）—— ⭐ 在此之前三条对齐**全部旁路**（⭐ 行为退回"不对齐"） |
| ⭐ 踩着小节线按 `R` | ⭐ **不白等**，立刻起录 |

## 3.4 ⭐ 能力边界（⭐ 演示前必须知道）

| ⭐ 项 | ⭐ 结论 |
|---|---|
| **层数** | ⭐ **单层**（⭐ 设计里的 3 层**未实现**） |
| **回放带力度吗** | ⭐ **带** —— ⭐ 端点取"本音期间的**峰值**力度"（⛔ 不是松手那一刻的），⭐ 并在起音→峰值之间**线性插值** |
| 🔴 **不录什么** | 🔴 ⭐ **不录 `vel_upd`（实时力度跟随）/ `pitch_upd`（滑音）** ⇒ ⭐ **回放的力度与滑音【必然和现场不同】**（⭐ `K-160`，⭐ **用户裁定暂不修**） |
| **与曲谱能否同时用** | ⭐ **能**（`SCORE_UART_ENABLE = 1`） |
| **清空清哪一层** | ⭐ **只有第 0 层**（⭐ 因为只有一层） |
| **掉电后还在吗** | 🔴 **不在** —— ⭐ 录音存在 BSRAM 里，⭐ **断电即丢** |
| ⚠️ **录完会自动播吗** | ⚠️ **不会** —— ⭐ **必须再发 `L`**（⭐ 除非录之前 `L` 已经开着） |
| ⚠️ **录制时能听见自己弹吗** | ⭐ **能**（⭐ 现场音同时进 `note_manager`） |
| ⚠️ **打鼓模式下按 `R` 录到什么** | 🔴 ⭐ **录到的是【原始音高事件】，⛔ 不是鼓**（⭐ looper 的监听点在"键盘打鼓替换"的**上游**）—— ⚠️ 此点**无文档、无 tb 覆盖** |

# §4 鼓机 · 节拍器 · 键盘打鼓

## 4.1 ⭐ 鼓机（`'B'` 开关 · `'D'` 切型）

| ⭐ 件 | ⭐ 音高 | ⭐ 默认力度 |
|---|---|---|
| **底鼓 Kick** | ≈ **60 Hz** | 230 |
| **军鼓 Snare** | ≈ **480 Hz** | 200 |
| **踩镲 HiHat** | ≈ **1920 Hz** | 140 |
| **嗵鼓 Tom** | ≈ **200 Hz** | 190 |

| ⭐ `'D'` 顺序 | ⭐ 节奏型 | ⭐ 要点 |
|---|---|---|
| 0 | ⭐ **BASIC** | Kick 1/5/9/13 · Snare 5/13 · 镲每奇数步 · ⛔ **无嗵鼓** |
| 1 | ⭐ **HOUSE** | Kick 1/5/9/13 · Snare 5/13 · 嗵鼓 8/16 · 镲在**后半拍** |
| 2 | ⭐ **ROCK** | Kick **1/7/9/15** · Snare 5/13 · 嗵鼓仅 step 14 |
| 3 | ⭐ **DANCE_FILL** | Kick **1/5/8/9/13** · 嗵鼓 **5 下**（8/11/14/15/16） |

⭐ **切换立刻生效**（⭐ 不用等小节线 —— ⭐ "边听边切"就是靠这个）。
⭐ **步长 = 一个 16 分音符**（240 tick）· ⭐ **速度跟节拍器同一个 `beat_gen`** ⇒ ⭐ **天然同拍**。
🔴 ⭐ **上电不会自己响** ⇒ ⭐ **必须先发 `'B'`**（⭐ 复位时是关的）。
⚠️ ⭐ **`'B'` 是"源 B 开关"**（⭐ 名字叫节拍器，⭐ 实际管的是当前选中的那一路 —— ⭐ 当前 = 鼓机）。

## 4.2 ⚠️ 节拍器

| ⭐ 项 | ⭐ 值 |
|---|---|
| 开关 | ⭐ 同一个 `'B'` |
| 从强拍起 | ⭐ **是**（⭐ 打开后等**最多一个拍周期 ≈ 0.5 s** 才响第一声） |
| 拍号 | 4/4 · 强拍 1760 Hz / 弱拍 880 Hz · 力度 220 / 132 |
| 速度 | ⭐ **固定 120 BPM**（⚠️ **不能改** —— 实时变速**方案已定、⛔ 未实装**） |
| 🔴 **当前位流** | 🔴 ⭐ **节拍器【不响】** —— ⭐ 因为 `SEL_DRUM = 1`（源 B 二选一，⭐ 当前选了鼓机）⇒ ⚠️ **要听节拍器得改 `SEL_DRUM = 0` 重新 PnR** |

## 4.3 ⭐ 键盘打鼓模式（`'K'`）

⭐ **映射 = `axis[3:2]`**（⭐ 每 **4 个相邻轴** = 同一件鼓）：

| ⭐ 轴 | ⭐ 位置 | ⭐ 鼓件 |
|---|---|---|
| **0~3** | 板1 **右两列** | ⭐ **嗵鼓** |
| **4~7** | 板1 **左两列** | ⭐ **底鼓** |
| **8~11** | 板2 **右两列** | ⭐ **军鼓** |
| **12~15** | 板2 **左两列** | ⭐ **踩镲** |

| ⭐ 项 | ⭐ 结论 |
|---|---|
| 音色 | ⭐ **固定**（PIANO，⭐ ⛔ **不受当前音色影响**） |
| 力度 | ⭐ `max(键盘力度, 本件基础力度)` ⇒ ⭐ **轻敲也够响、重敲能到 255、力度跟随保留** |
| 音高功能 | 🔴 ⭐ **失效**（⭐ 换成 4 档固定频率）⇒ ⭐ **再发一次 `'K'` 即恢复** |
| 回包 | ⭐ **回 `'k'`**（⭐ 唯一的回包） |
| ⚠️ 已知限制 | ⚠️ ⭐ **手敲鼓与鼓机共用同一个保留池（5 个 voice）** ⇒ ⭐ **同时用会丢音** ⇒ ⭐ 手敲时先发 `'B'` 关掉鼓机 |

# §5 标定与诊断

## 5.1 `'T'` 重记零点（⭐ 最常用）

⭐ **什么时候做**：① 每次上电后（⭐ 自动也会做一次）② 零点漂移时 ③ **左手板 2 忘了先插就上电之后**。
⭐ **看到什么**：⭐ 发 `T` ⇒ 回 **`t`** ⇒ **1~2 秒后回 `T`**（⭐ 大写 = 全部 16 轴完成）。
⭐ **验收**：⭐ 连发 `'N'`，⭐ 松手时该轴应读 ≈ **`0000`**。

## 5.2 ⭐ `'N'` 读 `pos`（诊断主力）

| ⭐ 读数 | ⭐ 含义 |
|---|---|
| 松手 ≈ **`0000`** | ✅ 正常 |
| 满按 ≈ **`00744`** | ✅ 正常（⭐ 当前量纲档） |
| 松手 ≈ **`1023`** | 🔴 该轴**被静止守卫跳过**（⭐ `zero` 无效）⇒ ⭐ 发 `'T'` 重记 |
| 满按 ≈ **`04095`** | 🔴 **烧成旧版位流了**（⭐ 这是版本指纹） |

⚠️ `'N'` 每 16 次才回到同一轴 ⇒ ⭐ **要按 `<轴号>` 字段筛**。

## 5.3 ⚠️ `'S'` 行程标定 —— 🔴 **用户已裁定【放弃】**

> ⭐ **用户原话**：「其实我感觉不太需要 span 标定了。甚至说按照当前进度写一个死的数据都可以，span 改了太久了一直都没有改好」

⇒ ⭐ **结论**：⭐ **归一档放弃，写死实际行程档** —— ⭐ 当前生效的四个数：`TRIG_TH = 64` · `REL_TH = 32` · `TRAVEL_TARE = 744` · `pos_to_vel` 斜率 `×263`。
⭐ 代码**不删**：⭐ `'S'` 命令还在、`calib_span` 还例化，⛔ 只是**不推荐用**。
⚠️ **代价**：⭐ 换定位板高度 / 换板 ⇒ 行程变 ⇒ ⭐ **这四个数必须一起重算**。

## 5.4 诊断命令

| ⭐ | ⭐ 回什么 | ⭐ 用来判断 |
|---|---|---|
| **`P`** | 当前扫描通道的**原始码** | ADC 读数 / 通道是否活（⭐ 松手 ≈2110 · 触底 ≈1241） |
| **`V`** | `calib_span` 内部状态 | ⭐ 标定卡在哪一步（`1`=反复重试 · `2`=稳定判定过不去 · `3`=收不齐帧 · `7`=已放弃） |
| **`N`** | 标定后的 `pos` | ⭐ 见 §5.2 |

# §6 ⭐ 现象速查（症状 → 原因 → 怎么办）

| ⭐ 症状 | ⭐ 最可能原因 | ⭐ 怎么办 |
|---|---|---|
| **完全没声** | `PA_EN_n`(`Y14`) 不为高 / ADC 没读到 | ⭐ 先量 `Y14` **必须高** |
| **一上电就恒响** | 所有轴被判"按下"（`pos` 恒高） | ⭐ 没做 `tare` / 极性反了 ⇒ 发 `'T'` |
| **某几个键怎么按都不响** | 零点被记成"按下位" ⇒ `pos ≡ 0` | ⭐ 发 `'N'` 读该轴：松手 ≈0000 = 正常；⭐ 否则发 `'T'` |
| **某个轴一直响 / 挂音** | 该轴被守卫跳过（`zero_vld=0` ⇒ `pos=1023` ≫ 64） | ⭐ `'N'` 松手 ≈**1023** = 被跳过 ⇒ 发 `'T'` |
| **全体挂音** | `STILL_TOL` 相关 | ⭐ 已 8→48；⭐ 仍出现 ⇒ 查 `raw` 抖动本身 |
| **松手后一直响** | ① looper 清空不补发 `note_off`（⭐ `K-158` **已修**）② 挂音（上一行） | ⭐ 先发 `'C'` 清 looper |
| **偶发尖音**（非常用力敲才复现） | `K-150`，**未根除** | ⭐ **用户同意暂时搁置** |
| **串口没回话 / 乱码** | ⚠️ **波特率错**（旧文档写 1000000）· 线没插好 · 发了字符串 | ⭐ 确认 **500000** ＋ ⭐ 发**单个 ASCII 字符** |
| **发了命令没反应** | ⭐ **除 `K` 外都没回包** —— ⭐ 这**是正常的** | ⭐ 靠**听声音**判断 |
| **鼓机不响** | 源 B 上电静音 | ⭐ **发 `'B'`** |
| **节拍器不响** | 🔴 当前 `SEL_DRUM = 1`（源 B = 鼓机） | ⭐ **设计如此**，要节拍器得改参数重烧 |
| **颤音 / 右手推子无效** | 🔴 `RIGHT_ADC_ENABLE = 0` | ⭐ 要联调需改 1 **重跑 PnR** |
| **按轻按重一个样** | 力度阈值与实际行程不匹配 | ⭐ 查 `.POS_FULL` 是否匹配实际行程 |
| **音色切了没立刻变** | 音色在起音那刻锁存 | ⭐ 只对**新按下**的音生效（⭐ 正常） |
| **起始音升八度后正在响的音没跟着移** | ⭐ 设计如此 | ⭐ 只对**下一次起音**生效（⭐ 正常） |
| **手敲鼓 + 鼓机同时响 ⇒ 丢音** | 共用保留池（5 个 voice） | ⭐ 手敲鼓时先发 `'B'` 关掉源 B |
| **莫名其妙切了音色 / 鼓机** | 🔴 裸字母命令与**串口屏载荷撞字节** | ⭐ 已知缺陷 `P0-4`（⛔ 未修）⇒ ⭐ 屏别发含命令字母的数据 |
| **怀疑烧错版本** | — | ⭐ 满按发 `'N'`：≈**00744** = 新 ✅ ／ **04095** = 旧 🔴 |
| **心跳灯不闪** | 烧录失败 / 时钟没起 | ⭐ 重烧；⭐ 示波器量 `V22`（50 MHz） |
