## 二、⭐ 本轮改了什么（⭐ 两个修复 + 一个门控）

### ✅ 修复 1：`pos` 行程上界夹紧（⭐ `K-153`）

**文件**：⭐ `rtl/drivers/calib.sv`

```verilog
parameter integer MAX_TRAVEL = 1023,      // ⭐ 新增
reg [DW:0] span_r [0:NCH-1];              // ⭐ 新增（该轴标定行程码）
wire [DW:0] dcode  = (raw > zero_r[ch]) ? (raw - zero_r[ch]) : 0;
wire [DW:0] dlim   = ((span_r[ch] != 0) && (span_r[ch] < MAXT)) ? span_r[ch] : MAXT;
wire [DW:0] dclamp = (dcode > dlim) ? dlim : dcode;
prod_r <= dclamp * gain_r[ch];            // ⭐ 用【夹紧后】的差值
```

**为什么**：⭐ 上板实测 `|Δpos|` 峰值 **2193**，⭐ 而满行程只有 **744** ⇒ 🔴 **2.9 倍**。
⭐ 根因：⭐ 原代码只夹到 `FULL = 4095`（⭐ **输出满量程**），⛔ **不是该轴的真实行程**；
⚠️ 且 `gain` 停在默认 `256`（=1.0，⭐ 因为 span 标定从未成功）⇒ `pos` = **裸的 `raw − zero`**。

**⚠️ 一个我踩过的坑**：⭐ 我第一版只夹 `span_r[ch]` ⇒ 🔴 **那是空操作**
（⭐ `span_r≠0` ⟺ `gain` 已标定 ⟺ `pos` 本来就被 `FULL` 夹住）
⇒ ⭐ **必须加【不依赖标定】的硬上界 `MAX_TRAVEL`** ✅

### ✅ 修复 2：`vel_upd` 变化率限幅（⭐ `K-154`）

**文件**：⭐ `rtl/w3b/note_manager.v`

```verilog
// ⭐ 模块级（⚠️ 必须在模块级 —— Verilog-2001 "声明先于语句"）
reg [AXIS_W-1:0] vu_ax_pend_r;
reg [VEL_W-1:0]  vu_val_pend_r;
reg              vu_pend_r;

if (vel_upd_valid_i) begin          // ⭐ 锁存目标（⛔ 永不清零）
    vu_ax_pend_r  <= vel_upd_axis_i;
    vu_val_pend_r <= vel_upd_value_i;
    vu_pend_r     <= 1'b1;
end
if (sample_tick_i && vu_pend_r) begin
    for (i = 0; i < POLY_TARGET; i = i + 1)
        if (gate_mask[i] && (axis_r[i] == vu_ax_pend_r)) begin
            if      (vu_val_pend_r > vel_r[i] + 8'd8) vel_r[i] <= vel_r[i] + 8'd8;
            else if (vu_val_pend_r + 8'd8 < vel_r[i]) vel_r[i] <= vel_r[i] - 8'd8;
            else                                      vel_r[i] <= vu_val_pend_r;
        end
end
```

**参数**：⭐ **每音频采样拍最多 ±8** ⇒ ⭐ 满量程 255/8 = 32 拍 = **0.65 ms**（⭐ **用户拍板值**）

**为什么**：⭐ 原来 `vel_r[i] <= vel_upd_value_i;` ⇒ **每 clk 可整值跳**；
⭐ 而 `top.v:1944` 的 `vu_vel = pos_to_vel(pos)` 在 `pos ≥ 744` 就饱和 255
⇒ ⭐ **用力敲打 ⇒ `pos` 猛跳 ⇒ `vel_r` 一拍从 64 跳到 255 ⇒ 包络电平瞬间跳**
⇒ 🔴 **瞬时超限幅器 ⇒ 削波 ⇒ "又响又尖"**（⭐ **这是假设，⭐ 见 §四**）

**⚠️ 两个必须知道的点**：
1. ⭐ **⛔ 不能挂每 clk** —— ⭐ 那样 255 拍 = 5.1 µs，⚠️ **仍比音频周期（20 kHz = 50 µs）快** ⇒ 🔴 **还是台阶**
2. ⭐ **必须用挂起寄存器** —— ⭐ `vel_upd_valid_i` 是 **1 拍脉冲** ⇒ ⚠️ 直接 `& sample_tick_i` 会**丢掉绝大多数更新**
