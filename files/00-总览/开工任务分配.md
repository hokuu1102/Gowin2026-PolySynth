## 一、💻 代码线 —— ⭐ **现在就能开工，不依赖任何器件**

> ⭐⭐ **这是当前唯一"完全不被卡住"的一条线。** 用手上那块**基石板**即可
> （⚠️ 基石板引脚 ≠ Dock，**两块板各写一份 `.cst`，别混用**）。

### 第 0 批地基（按顺序，见 `files/20-代码/代码总览图.md` §二）

| 序 | 交付 | 判据 |
|---|---|---|
| **1** | Gowin 工程 + `rtl/` 目录树 + `constr/top.cst` | 能综合、能下载、不报错 |<!-- refcheck:ignore-line -->
| **2** | `clk_gen.v` —— `÷1024` → `tick_audio` | 示波器看到 **48.828 kHz** |
| **3** | `i2s_tx.v` | ⭐ **3.5 mm 耳机口听到持续单音** |
| **4** | ⭐⭐ **A4b：`wavetable` 上板验证** | ⚠️ **必须给出明确结论**：`$readmemh` 到底加载没加载 |
| **5** | `test_mode.v` 最小版 | 频谱软件能数出 **4/8/16/32 个独立谱峰** |
| **6** | ADSR + 单 voice 双振荡器（有余力） | 听起来**像乐器** |

> ⚠️ **第 4 项为什么单独拎出来**：`$readmemh` 外部 `.mem` 在 **GW5AT-60 上可能不加载**
> → **ROM 全 0 → 没声音，但仿真完全正常**。不先验，联调时"没声音"会淹没在一堆问题里。
> 📄 背景见 `files/20-代码/音色设计.md`

> 📌 **同时要冻的**：`files/20-代码/W3接口冻结表.md`（v0.1 → v1.0）—— ⭐ 它现在就能冻，
> 因为 `POLY_TARGET` / `OSC_PER_VOICE` 早有默认值（32 / 2），且**改它不动接口**。

## 二、🔌 硬件线 —— 分「能画」与「要等货」

### ✅ 现在就能画（不依赖器件）

| # | 任务 | 谁 | 说明 |
|---|---|---|---|
| **1** | ⭐ **画封装库** | 两人 | `TLC5916ID`(SOIC-16) / `MCP3208`(SOIC-16) / `LM393DR`(SOIC-8) / `EC11` / `13×13 摇杆` / `75 mm 推子` —— ⭐ **前三个可直接从立创下载** |
| **2** | ⭐ **`P2` 电源板** | 电源负责人 | 拓扑已定：**DC 12 V → 单个 Buck → 5 V ──┬── 数字 5 V<br>　　　　　　　　　　　　　　　　　　　　　└── LC → 5V_A**<br>⚠️ **具体型号/电感/电容由负责人定**（📄 `files/10-硬件/电源方案.md` §三） |<br>⚠️ Buck 的**拓扑已定、具体型号由电源负责人定** → ⭐ **可以开画** |
| **3** | ⭐ **`P1` 的布局规划** | P1 负责人 | Dock 的 `J13`/`J14` 位置已知 → 可以开始排 **双排母座 + XH2.54 座**<br>⚠️ 先定「几个 XH 座、各多少 pin」 |
| **4** | ⭐ **3D 建模** | 用户 | 拨片打印件（装在摇杆杆上）—— ⚠️ **等摇杆到货量尺寸** |

### ⏳ 要等器件到货

| # | 任务 | 等什么 |
|---|---|---|
| **5** | ⭐⭐ **`P3` 左手区板 ×2** | 磁轴（**已买**）+ 霍尔 + ADC 到货 → **量尺寸**（轴体底座外廓、磁铁位置） |
| **6** | ⭐⭐ **`P4` 右手区板** | 摇杆 + 推子 + ADC 到货 → **量尺寸**（摇杆定位柱、推子长度） |
| **7** | ⭐ **左手区尺寸链重算**（C12） | 磁轴到货 |
| **8** | ⭐ **拨片打印件尺寸** | 摇杆到货（杆长、行程角度、回中力） |

### ⚠️ 到货后**立刻做**的四步（`files/10-硬件/采购与验证清单.md` §三）

| # | 动作 | 判据 |
|---|---|---|
| **1** | ⭐ **用卡尺量磁轴底座最大外廓** | **≤15 mm** → 现有设计成立，可以画板 |
| **2** | ⭐ **测「电压 ↔ 行程」曲线**（霍尔 + 3.3 V + 万用表 + 垫片试高度） | 画成曲线 → 定**阈值**与**霍尔位置** |
| **3** | **多片一致性**（可选但有用） | 20 片霍尔同批一致性 |
| **4** | **接口与连线**（拿 ADC 后做） | SPI 通信通 |

## 三、⭐ 建议的三人分工（**待会上落实**）

> ⚠️ `W3a`/`W3b`/`W3c` 是**架构边界，不是人头** —— 下表只是**建议**。

| 人 | 主要职责 | 现在立刻能做的 |
|---|---|---|
| **硬件 A**（用户） | `P3` ×2 + `P4` + **建模/3D 打印** | ⭐ **画封装库** + **等货后量尺寸** + **拨片建模** |
| **硬件 B** | `P2` 电源板（＋可能 `P1`） | ⭐ **画 `P2`**（拓扑已定、Buck 有库存） |
| **软件 C** | 第 0 批地基（→ 之后接 W3 的一块） | ⭐⭐ **建工程 → `clk_gen` → `i2s_tx` → 出声 → A4b 验证** |

> 💡 **如果只有两人能上代码**：软件 C 做第 0 批地基，硬件 A/B 在等货期间**先画封装库**
> （`TLC5916ID`/`MCP3208`/`LM393DR` 从立创下载 + `EC11`/摇杆/推子自己量画）。
