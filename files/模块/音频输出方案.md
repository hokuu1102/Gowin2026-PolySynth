## 一、先把链路拆成两段（这是全部问题的关键）

音频输出其实是**两段**，很多"接不上/推不响"的问题都来自把两段混为一谈：

```text
   ┌─────────── 第一段：数字 → 模拟 ───────────┐  ┌──── 第二段：模拟 → 可听 ────┐
   │                                          │  │                            │
FPGA ──I2S──> DAC ──→ Line Out（线路电平，小信号）──→ ① 有源音箱（内置功放）
   │                                          │  │    ② 功放模块 → 小扬声器
   └──────────────────────────────────────────┘  └────────────────────────────┘
```

| 段 | 交付什么 | 谁来做功放 |
|---|---|---|
| **第一段** | 把数字音频变成 **Line level 模拟信号** | —— |
| **第二段** | 把 Line level **放大成能推喇叭的功率** | ① 音箱内部 ／ ② 我们自己加 |

> ### 🔴 一句话结论
> **DAC 模块出来的信号是"线路电平"，推不动扬声器。**
> **接有源音箱 = 用音箱里的功放；接小扬声器 = 必须自己加一级功放。**
> 所以"两种方案"并不是两个 DAC，而是**同一路 Line Out 后面分两路走**。

## 二、推荐方案：**一路 Line Out，两路输出**

```text
                        ┌──────────────────────────────┐
FPGA ──I2S──> DAC 模块  │  Line Out                    │
                        └───────┬──────────────┬───────┘
                                │              │
                    ┌───────────▼───┐    ┌─────▼──────────┐
                    │ 3.5mm 面板插座 │    │ 功放模块        │
                    │ （立体声）     │    │                │
                    └───────┬───────┘    └─────┬──────────┘
                            │                  │
                            ▼                  ▼
                    有源音箱 / 场地音响      小扬声器（4Ω/8Ω）
                    （用它的 AUX IN）       （功放直推）
```

**两种接法（任选其一或都做）**

| 接法 | 做法 | 优点 | 注意 |
|---|---|---|---|
| **① 直接并联** | DAC 输出同时接两路 | 最简单，两种场合都能用 | 前提：**两路输入阻抗都 ≥10 kΩ**（有源音箱 AUX 一般 10k~47k，功放模块 10k~50k）→ 一般都满足 |
| **② 带开关插座自动切换** | 用**带常闭触点的 3.5mm 插座**：不插插头时给功放使能；插入插头时断开功放 | **插入音箱自动静音内置喇叭**，最优雅；也省电、避免双路底噪叠加 | 需要插座带开关触点，多一根检测/使能线 |

> ⚠️ **不要同时用两个输出还不控制音量**：两路叠加容易过载失真。建议只开一路，或其中一路关掉功放供电。

## 三、四种实现路线对比

| 方案 | 器件组合 | 能接有源音箱 | 能推小扬声器 | 优点 | 缺点 |
|---|---|---|---|---|---|
| **A** | DAC 模块 单独 | ✅ | ❌ | 最简、音质最好（用音箱自带功放） | 没音箱就不出声 |
| **B** ⭐ | **DAC 模块 + 模拟功放模块** | ✅ | ✅ | **两种场合都覆盖**；DAC 只管音质，功放只管出力，职责清晰 | 多一块功放 + 一路电源 |
| **C** | I2S 直入功放模块（如 MAX98357A 类） | ❌ | ✅ | **省掉 DAC**，一块搞定，最省器件 | 输出是**功率级 + BTL**，**不能接 AUX IN**；没有 Line Out |
| **D** | **B + C 并行**（同一组 I2S 并联给两个模块） | ✅ | ✅ | 两条支路都在数字侧分叉，互不影响 | 多一块模块；走线更多 |

> **推荐 B**：用最小的器件量覆盖"两种场合"，而且职责最清楚。
> **D 只在"想要内置喇叭用数字功放（效率高、体积小）"时才值得**——注意两条 I2S 可以**共用**（同 BCLK/LRCLK/数据并联），不必占用两套 IO。

## 四、怎么接：从 3.5mm 到小扬声器（接线级）

### 4.1 3.5mm 立体声的针脚定义

```text
       Tip ───────── 左声道 L
      Ring ───────── 右声道 R
    Sleeve ───────── 公共地 GND
```

### 4.2 完整接线链

```text
DAC 模块
  3.5mm 输出
      │
      ▼  3.5mm 公头 → 3 芯线（或 3.5mm 转接线夹端子）
┌────────────────────────────────────────────┐
│  功放模块                                   │
│                                            │
│   L_IN   R_IN   GND        ← 输入侧         │
│   VCC(5V)  GND             ← 供电侧         │
│                                            │
│   OUT_L+  OUT_L−  OUT_R+  OUT_R−  ← 输出侧  │
└────┬────────────────┬──────────────────────┘
     ▼                ▼
  左小喇叭         右小喇叭
  （4Ω / 8Ω，功率 ≥ 功放输出）
```

### 4.3 ⚠️ 三个必须避开的坑

| # | 坑 | 后果 | 做法 |
|---|---|---|---|
| **1** | **BTL 桥接输出不能共地** | 把 `OUT_L−` 和 `OUT_R−` 连在一起、或接到公共地 → **短路烧芯片** | 每个声道的 `+` / `−` **只接自己的喇叭两端**，两个 `−` 之间不连 |
| **2** | 功放没输入耦合电容 | 直流偏置进入功放 → 冲击声/发热 | 若功放模块输入端没有隔直电容，**自己串 1µF~10µF** |
| **3** | 功放与 DAC 共用一条电源走线 | 功放峰值电流把 DAC 电源拉出纹波 → 底噪/削波 | **独立供电 + 就近去耦**（100µF 电解 + 0.1µF 陶瓷） |

### 4.4 音量控制放哪一级

| 位置 | 做法 | 评价 |
|---|---|---|
| **数字侧（推荐）** | FPGA 内乘一个音量系数 | 无额外硬件、能和 UI 联动、不引入噪声；⚠️ 衰减太多会损失有效位数 → 内部位宽留够（建议 ≥20 bit 中间位宽） |
| 模拟侧 | DAC 与功放之间加 **10 kΩ 双联电位器** | 直观，但多一个元件、多一处接触噪声 |
| 功放侧 | 用带音量旋钮的功放模块 | 省事，但旋钮位置固定、不易联动 UI |

> **建议：数字音量为主**（接 UI），**模拟预置为辅**（固定一个合适的增益，留出调整余量）。

### 4.5 上电/复位防爆音（pop noise）

上电瞬间 DAC 与功放状态未定时会产生"啪"声，现场扩声时很尴尬。三个办法（可叠加）：

| 办法 | 做法 |
|---|---|
| **控制上电顺序** | 先让 DAC 上电稳定（延时 100~200 ms）→ 再使能功放 |
| **用静音/使能引脚** | DAC 有 MUTE 引脚就上电保持静音；功放用 EN 脚控制 |
| **数字侧渐入** | 开机后音量在 10~50 ms 内从 0 渐升到目标值 |

> ➡️ 这就是为什么 **FPGA 侧要预留静音/使能引脚**（见 §六）。

## 六、⭐ FPGA 侧应预留什么接口

### 6.1 信号引脚清单

| # | 信号 | 方向 | 必需性 | 说明 |
|---|---|---|---|---|
| 1 | `I2S_BCLK` | 输出 | **必需** | 位时钟（FPGA 作主） |
| 2 | `I2S_LRCLK`（WS） | 输出 | **必需** | 左右声道帧时钟 = 采样率 |
| 3 | `I2S_DIN` | 输出 | **必需** | 串行音频数据 |
| 4 | `I2S_MCLK` | 输出 | 建议预留 | 主时钟。多数模块内部 PLL 可省，但**预留一根不亏** |
| 5 | `DAC_MUTE` / `DAC_EN` | 输出 | 建议 | 上电静音，**防爆音** |
| 6 | `AMP_EN` | 输出 | 建议 | 控制功放使能：上电顺序 + 插入音箱时自动关闭内置喇叭 |
| 7 | `AUDIO_RST` | 输出 | 可选 | 部分模块有复位脚 |
| 8 | 电平 | —— | —— | **3.3 V LVTTL**（注意：若模块是 5 V 逻辑需电平转换） |

> **最小集 = 3 根**（BCLK / LRCLK / DIN）；**建议集 = 6 根**（+ MCLK / MUTE / AMP_EN）。
> 这 6 根**一次预留到位**，后面换模块不用改板。

### 6.2 电源与地

| # | 项 | 说明 |
|---|---|---|
| 1 | **3V3** | DAC 数字侧；来自板载 3.3 V |
| 2 | **5V** | 功放模块用（J14 上有 5V） |
| 3 | **GND ×2~3 根** | ⚠️ 功放电流大，**地线要多留几根/加粗**；模拟地与功率地**单点连接** |
| 4 | 去耦位 | DAC 电源并 0.1µF；功放电源并 100µF + 0.1µF |

### 6.3 ⭐ 时钟方案（这里有一个值得先想清楚的点）

板载时钟是 **50 MHz**，而想要的采样率是 **48 kHz**：

```text
50 MHz ÷ 48 kHz = 1041.67  ← 不是整数
```

**结论：用整数分频拿不到精确的 48.000 kHz。** 但这**不是问题**，原因很重要：

> **音高 = 相位增量 × fs / 2^N**。
> 只要相位增量是**按同一个 fs 反算**出来的，输出**音高就是精确的**。
> fs 的偏差只体现在"名义采样率"上，**听觉完全不可辨**。
>
> （混响时间、LFO 频率同理，都是按同一个 fs 自洽的。）

**推荐时钟分频（全是整数、无抖动）**

```text
MCLK  = 50 MHz ÷ 4  = 12.500 MHz   = 256 × fs   ✓
BCLK  = MCLK ÷ 4    =  3.125 MHz   =  64 × fs   ✓
LRCLK = MCLK ÷ 256  = 48.828 kHz   ← fs（每通道 32 个 BCLK 时隙）
```

| 指标 | 值 |
|---|---|
| 得到的分频 | ÷4、÷4、÷64 —— 两个计数器即可 |
| MCLK / fs | **精确 256 倍**（DAC 最希望的比率） |
| BCLK / fs | **精确 64 倍**（32 bit 时隙/通道，标准帧格式） |
| fs 偏差 | +1.7%（相对名义 48 kHz）—— **对音高无影响** |

> ⚠️ **什么时候必须要精确的 48.000 kHz**：要与**外部设备同步**时（如 SPDIF、多设备共用时钟）。
> **本项目不需要** —— 我们是自成一体的乐器。

> 💡 **对比一下"随手分频"的坑**：若取 BCLK = 50 MHz ÷ 16 = 3.125 MHz，LRCLK = BCLK ÷ 64 = 48.83 kHz —— 结果**恰好和上面一样**（因为 16×64 = 4×256）。所以直接用 ÷16 / ÷64 的两个计数器也行，**顺手**。

### 6.4 测试点

| 预留 | 用途 |
|---|---|
| BCLK / LRCLK / DIN 各一个测试点 | 用示波器/逻辑分析仪抓 I2S 时序，**排查"没声音"的第一步** |
| DAC 模拟输出测试点 | 看波形是否为期望的正弦，判断问题在数字侧还是模拟侧 |

### 6.5 布局与隔离（PCB 阶段）

| # | 注意 |
|---|---|
| 1 | 功放是**全板电流最大**的器件 → 独立供电、就近去耦、远离模拟传感器 |
| 2 | **D 类功放的开关噪声**可能耦合进 I2S 与传感器模拟通道 → 布局上分开，必要时加磁珠/屏蔽 |
| 3 | 音频输出走线**远离时钟线与 LED 驱动线** |
| 4 | 模拟地 / 数字地 / 功率地**分区 + 单点连接** |

## 七、两种场合的验收方式

| 场合 | 接法 | 验收标准 |
|---|---|---|
| **排练/开发** | DAC Line Out → 现有音响 **AUX IN** | 能出声、无爆音、底噪可接受 |
| **演示/比赛** | DAC Line Out → 场地音响 AUX IN | 音量足够覆盖场地 |
| **自带喇叭** | DAC Line Out → 功放模块 → 小喇叭 | 能独立出声，不依赖外接音箱 |

> ⚠️ **不要接音响的 INPUT**（那是乐器输入口，电平与阻抗都不匹配）。

## 八、验证步骤（按顺序做，能快速定位问题在哪一段）

| # | 步骤 | 通过标准 |
|---|---|---|
| 1 | 示波器看 **I2S 三线**（BCLK/LRCLK/DIN） | 频率正确、数据有变化 |

| 6 | 反复**上电/复位**听**爆音** | 无明显"啪"声 |
