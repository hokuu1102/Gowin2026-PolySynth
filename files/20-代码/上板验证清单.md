## 一、⭐⭐ P0：验证 B3 挂音的**唯一可达根因 E1**

### 背景（复审实测确认）

```
top.v:1783  .REL_TH(12'h050) = 80
event_extract.v:318  off 判据 = (pos < REL_TH)
calib.sv:148/159     pos = (raw > zero) ? (raw - zero) * gain >> 8 : 0
⭐ zero 由 calib_autotare 在【上电 200 ms 一次性】写入，此后【永不刷新】
⇒ 若某通道 zero 偏低（冷启动未稳 / 定位板高度变化 / 温漂）
⇒ ⭐ 静止 pos 长期 ≥ 80 ⇒ note_off 永不生成 ⇒ 永久挂音
```

⭐ **为什么这条解释力最强**：

| 用户实测 | E1 的解释 |
|---|---|
| **音高 = 我按过的键** | ✅ 挂的是键盘轴（轴 0~7）的 voice |
| **按同键不能清** | ✅ **松手位就是 `pos` 的物理下限** |
| **按所有键不能清** | ✅ 同上 |
| **按了几次以后才触发** | ✅ 漂移是渐进的 |
| **断电才清** | ✅ ⭐ 只有重新上电才重记零点 |

### 步骤 ①：`'N'` 扫 16 轴（⭐ 格式已修正）

```powershell
python tools\board_probe.py COM32 --send "N,N,N,N,N,N,N,N,N,N,N,N,N,N,N,N"
```

⭐ **回包格式**：**8 字节** `N<轴号 hex><4 位十进制>CR LF`
⭐ **`np_axis_r` 每次请求自动 +1** ⇒ 连发 16 次正好扫完**轴 0 → 15**（✅ 这点是对的）
⚠️ **轴号是十六进制**（`0`~`F`），⛔ 不要读成十进制

| 观察 | 结论 |
|---|---|
| 🔴 **挂音轴的静止 `pos` ≥ 80**（或跨 80 抖动） | ⭐ **确认 E1** ⇒ 修法见 §四 |
| ✅ 挂音轴 `pos ≈ 0` | ⚠️ 排除 E1 ⇒ 转查 `note_manager` 侧 |
| ⭐ **轴 8~15 应恒为 0** | 第二片 ADC 未接 ⇒ 上拉 ⇒ `raw=4095` ⇒ `tare` 把 `zero` 写成 4095 ⇒ `pos≡0` |

### ⭐ 步骤 ②：**决定性共症状**（⭐ 比读 `'N'` 更便宜、更决定性）

```
E1 成立时，key_on[该轴] 会【永久卡在 1】
⇒ event_extract.v:299 的 if (!key_on[scan_axis]) 使该轴【永远进不了 ON 分支】
⇒ ⭐ 该键此后【完全不再响应】（不只是挂音）
```
| 观察 | 结论 |
|---|---|
| 🔴 挂音后，**该键再按没有任何新音** | ⭐ **命中 E1** |
| ✅ 该键还能正常触发 | ⚠️ 排除 E1 |

### ⭐ 步骤 ③：漂移时间线（⭐ 最有说服力）

```
① 刚上电（tare 刚做完）：记录 16 轴的静止 pos
② 跑 30 分钟（弹或不弹都行）
③ 再记录 16 轴的静止 pos
判据：⭐ 若某轴的静止 pos 从 ≈0 涨到 ≥80 ⇒ ⭐ 坐实"冷启动 tare + 漂移"
```
📌 **旁证（项目自己的历史数据）**：松手码 09-23 = **2110** → 09-25 = **2171**
⇒ ⭐ **已漂 61 码**，而阈值只需 **80 码**。

## 四、⭐ E1 的修法选项（⭐ 待决策，需上板证据）

| # | 修法 | 优点 | 代价 |
|---|---|---|---|
| **1** | ⭐ **`note_manager` 加看门狗**：`gate_r=1` 持续超过 N 秒 ⇒ 强制清 gate | ⭐ **机制无关**，一次兜住**所有**"`note_off` 永不到达"的路径 | ⚠️ 长按 N 秒会断音 ⇒ N 取 **60 s** 以上 |
| **2** | ⭐ **`calib_autotare` 加稳定判定**（对比 `calib_span` 已有 `STABLE_NEED`/`VOTE_N`/`TOL`） | ⭐ **上游根因**：零点记错是静默的 | 需要新状态机 |
| **3** | ⭐ **运行时漂移监测 / 自动重零点**（全键松开时重记 `zero`） | ⭐ **真正修掉 E1** | 需要"全键松开"检测 |
| **4** | 重算 `REL_TH`（现 80，依据已作废） | 便宜 | ⚠️ 阈值改动影响所有轴手感 |
| **5** | `event_extract` 加"`key_on=1` 且 `pos` 长期不变"的强制 off | 在事件层兜底 | ⚠️ 与"按住不动"混淆 |

📌 ⭐ **推荐顺序**：先做 **2 + 3**（上游根因），再加 **1**（兜底）。
