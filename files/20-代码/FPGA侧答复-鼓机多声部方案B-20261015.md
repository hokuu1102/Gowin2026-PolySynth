## 一、⭐ 选定：方案 B

### 1.1 轴分配（⭐ 采用你们的提议，两边**必须同一份**）

| 件 | **`axis`** | `inc`（⭐ = `phase_inc >> 10`，⛔ 不变） | 备注 |
|---|---|---|---|
| **Kick** | **12** | 5 243 | |
| **Snare** | **13** | 41 943 | |
| **HiHat** | **14** | 167 772 | ⚠️ 与节拍器同轴号，⭐ **但不冲突** —— 见 §1.2 |
| **Tom** | **15** | 17 476 | |

⭐ **判据（FPGA 侧）**：曲谱事件 **`axis >= 12` ⇒ 是鼓**（4 位轴号 ⇒ 等价于 `axis[3:2] == 2'b11`）。
⛔ **旋律轨改用 `axis 0..11`**（12 条，比现在少 3 条）。

### 1.2 ⭐ 为什么 `axis 14` 是安全的（⛔ 不是疏忽）

`axis 14` 确实是**节拍器**的 `AXIS_ID`（`rtl/w3c/metronome.v:48`），⚠️ 但两者**不会互相干扰**，因为：

```
same_hit[sg]  = (... ) && (axis_r[sg] == cur_axis) && (src_r[sg] == cur_src)   ← note_manager.v:720-722
note_off 判据 = (gate_r|retrig_low) && (axis_r[i]==cur_axis) && (src_r[i]==cur_src)  ← :1317-1320
```

⭐ **两条判据都要求【来源】相同**：
· 节拍器 = `SRC_AUX(3'd3)`（⭐ 由 `top.v` 打标）
· 谱面鼓 = `SRC_KDRUM(3'd5)`

⇒ ⭐ **同轴号、不同源 ⇒ 各自占各自的 voice、互不打断、`note_off` 也清不到对方** ✅

### 1.3 ⭐ 为什么 B 够用（你们那三个用例逐条）

| 用例 | 方案 B 之后 | 为什么 |
|---|---|---|
| **A** 同一 tick 敲两件 | ✅ **两件都响** | 两个 `axis` ⇒ `same_hit` 不命中 ⇒ **各占一个 voice** |
| **B** 前一件没释放时后一件进来 | ✅ **不互相顶** | 同上（⚠️ 但见 §2.3，你们对"长音"的预期要改） |
| **C** 不重叠（对照） | ✅ 仍然两件都响 | 与现在一致 ⇒ ⛔ 不引入回归 |

⭐ **而且它⛔ 不碰 `T38` 防挂音纪律**：`note_off` 仍然是"清所有同轴同源"（`note_manager.v:1317-1338`，⭐ 一个字不改）⇒
⚠️ **任何一个鼓的 `note_off` 一定清得掉它自己的 voice** ⇒ ⛔ **不会新增挂音路径** ✅

📌 ⭐ **这是 B 相对 A 的最大优势**（见 §3.2 第 2 条）。

## 二、⚠️ 三条更正（⭐ 请务必看 2.1 和 2.3）

### 2.1 ⭐ 你们 Q1 问的"键盘打鼓"其实是**两件不同的事**

你们写"键盘打鼓（`drum_gen`）是不是同样的限制？它也是 `AXIS_ID = 15`" ——
🔴 **`drum_gen` 是【板载鼓机】（源 B），⛔ 不是键盘鼓垫**。两者行为**不同**：

| | 轴号 | 来源 | 同时敲两件 |
|---|---|---|---|
| **键盘鼓垫**（`key_drum_r` 模式） | ⭐ **每个垫子 = 它自己的物理键 ⇒ 不同轴**（`top.v:5249` `src_a_axis` 原样带下去，只用 `axis[3:2]` 选乐器，`top.v:5275`） | `SRC_KDRUM` | ✅ **已经能两件同时响**（不同轴 ⇒ `same_hit` 不命中） |
| **板载鼓机** `drum_gen` | **恒 15**（`drum_gen.v:68`） | `SRC_AUX` | 🔴 **同样单声部**（四件共用一轴一源） |
| **PC 灌的谱** | **恒 15**（现状） | `SRC_KDRUM`（`seq_arb.v:204`） | 🔴 **单声部**（本次要修的） |

⇒ ⭐ **所以"手打两个鼓垫"本来就没问题** —— 你们担心的那一条不成立 ✅
⇒ ⚠️ 但 **板载鼓机（`drum_gen`）确实还是单声部**：⚠️ 那是**独立的一条**（源 B），
　 ⭐ 若你们也需要它多声部，请**另提一条需求** —— 它的四件也是靠 `INC_*` 区分的，
　 改法会不一样（⛔ 不能靠换轴，因为它轴号写死在参数里、且节拍器共用源 B）。

### 2.2 ⭐ 你们没提到的一条：**踩镲垫（`axis 12-15`）与谱面鼓【同轴同源】**

⚠️ 这条是**方案 B 之后仍然存在**的残留限制（⭐ 如实说，⛔ 不藏）：

```
键盘鼓垫的乐器分配 = axis[3:2]     （top.v:5275）
  axis 0-3   ⇒ 嗵鼓      axis 4-7  ⇒ 底鼓
  axis 8-11  ⇒ 军鼓      axis 12-15 ⇒ 踩镲     ← ⚠️ 就是新的鼓轴段
键盘鼓垫 src = SRC_KDRUM（top.v:5344）  ·  谱面鼓 src = SRC_KDRUM（seq_arb.v:204）
```

⇒ 🔴 **谱面鼓落在 `axis 12-15`，而键盘的【踩镲垫】恰好也在 `axis 12-15`、来源也相同**
⇒ ⚠️ **边灌谱边按踩镲垫 ⇒ 会互相顶（复用/被 `note_off` 掐掉）**

📌 **处置**：⭐ **记为已知限制**（⛔ 不改 B 方案）—— 理由是"边放谱边手打鼓"本身是边缘用法；
　 ⭐ 若你们认为必须支持，⭐ **备选**：鼓轴改用 `0/4/8/12`（⭐ 与键盘各件乐器的**首个轴**对齐）
　 ⇒ ⚠️ 代价是判据从"`axis >= 12`"变成"`axis % 4 == 0`"、且旋律轴**被打散**（0..15 里挖 4 个洞）。
　 ⇒ ⭐ **我方建议维持 `12/13/14/15`**（连续、判据一行、你们改动最小）。

### 2.3 🔴 **用例 B 的听感模型不准**（⭐ 这条会改你们的验收预期）

你们写用例 B 是"kick ON（长）→ 2400 hihat ON ⇒ **kick 的长音不被打断**"。
🔴 **但鼓【本来就没有"长音"】** —— 保留池 voice 的**混音电平**走的是 `perc_env_bank`
（`top.v:5957-5962` 的 `env_level_mix`，⭐ 保留池那 5 路换成 `perc_level`）：

```
perc_env_bank 的触发 = nm_gate 的【上升沿】（top.v:5900-5906）
⇒ 触发之后【自己衰减】，⛔ 不看 gate 电平、⛔ 不被 note_off 打断
⇒ 实测时长（DECAY_STEP=33，top.v:5930-5934）：
   Kick 36.6 ms · Snare 31.8 ms · HiHat 22.2 ms · Tom 30.2 ms
而你们的 note 时长 480 tick ≈ 9.8 ms（按音频采样 20.48 µs 算）
```

⇒ ⭐ **结论：鼓响得比它的 note 【更长】**，`note_off` 只负责**把 voice 还回池子**，⛔ 不负责"切断声音"。
⇒ ⭐ **所以用例 B 真正能听到的**：⚠️ **不是"长音被切短"，而是"后一件把前一件的 voice 抢走 ⇒ 前一件的尾巴被换成了后一件的音色"** ✅
⇒ 📌 **请把用例 B 的预期改成**：⭐ **两件都响，且各自的音色/时长都完整**（⭐ 这才是多声部的判据）。

## 六、⚠️ 残留限制（⭐ 如实列出，⛔ 不藏）

### 6.1 ⭐ 同一件鼓相邻两次间隔 < 480 tick ⇒ 仍会被"噎"

⭐ **方案 B 只隔离了【跨件】**。同一件鼓（同轴同源）相邻两次若间隔 < 该件的 note 时长：

```
后一次的 note_on 到达时，前一次的 note_off 可能还没来 ⇒ same_hit 命中 ⇒ 复用/重触发
（或：前一次的 note_off 落在后一次的 note_on 之后 ⇒ 把后一次一起清掉）
```

⇒ ⭐ **约束从"全体 ≥ 480"放宽成"同一件 ≥ 480"** ✅
📌 ⭐ **对真实鼓型够用**（底鼓/军鼓几乎不会在 10 ms 内重复敲），
　 ⚠️ 若将来要连击同一件（滚奏），⭐ **需另做**（⭐ 思路：`same_hit` / `note_off` 对鼓**再比 `inc`**，
　 ⚠️ 但那会动到 `same_hit` 那条历史上出过大量 setup 违例的路径，⛔ 不建议现在做）。

### 6.2 ⚠️ 踩镲垫 vs 谱面鼓（⭐ 见 §2.2）
