## 一、【最高优先级】R10 — 长帧发不全（TX FIFO / 背压）

### 一句话

**屏没问题、编码没问题、帧也生成了 —— 是 FPGA 发出去的帧只发了一半。**

### 实测分界线（上板）

| 会正常显示的字段 | 帧长 | 不动的字段 | 帧长 |
|---|---|---|---|
| `t_timbre` = `GUITAR` | ~22 B | `t_mode` = `钢琴模式 [PIANO]` | ~36 B |
| `t_drum` = `Pattern II` | ~26 B | `t_slide` = `关闭 (GLIDE OFF)` | ~31 B |
| `t_bpm` = `120` | ~20 B | `t_kd` = `打鼓: 关闭 [音符演奏]` | ~45 B |
| | | `b_uplink` = `● 实时上行: 开启` | ~38 B |

⇒ **≤26 字节能过，≥31 字节过不去。**

### 已排除屏的原因

用串口助手直接把 `t_mode.txt="钢琴模式 [PIANO]"` + `FF FF FF`（UTF-8）发给屏：

```
74 5F 6D 6F 64 65 2E 74 78 74 3D 22 E9 92 A2 E7 90 B4 E6 A8 A1 E5 BC 8F
20 5B 50 49 41 4E 4F 5D 22 FF FF FF
```

**屏正常显示** ⇒ 屏、字库、UTF-8 编码全部没问题。

### 已排除「没生成」

仿真（临时 tb，`feed 71 11 50` 改增益）：

```
z_dg frame after gain change = 1  (capn=35)
mode before = 1 / mode after = 0 / t_mode frame = 1  (capn=35)
t_slide frame = 0  (capn=36)     ← 只出去 1 帧，t_slide 丢了
```

⇒ 帧都生成了，是**发出去之后丢了**。

### 根因

```verilog
uart_tx_fifo #(.DEPTH(8)) u_tx_fifo ( ... );   // 只有 8 格
```

一帧 20~52 字节，115200 下每字节约 87 µs。
若 echo FSM 没按 `tx_busy_i` 背压、一拍硬推一个字节 ⇒ 第 9 个字节起全丢 ⇒ 屏收到半帧 → 整帧作废。

### 改法（四条）

1. `DEPTH(8)` → **≥ 64**
2. echo FSM 每次 `ech_push` 前判 `tx_busy_i`，忙就等
3. 确认 `top.v:1728` 的 `.tx_busy_i(ui_tx_busy)` 里 `ui_tx_busy` 真的是 `~txf_ready`（剩余 < 2 即置忙）
4. 把 FIFO overflow 引成可观测计数器（与 `err_cnt` 同款），转 EC11 时看它涨不涨

### 改完会一起好的 8 条

`t_mode` · `t_slide` · `t_kd` · `b_uplink` · 效果器参数指针 · page0 底部三个灯 · `t_loop` 录音色 · `t_pedal`/`t_hdmi`

## 二、【新】S6 — 头部按钮「状态记忆」（屏端）

### 现象

1. page1 点头部按钮 → 效果器开、按钮变彩色
2. 切到 page0 再回 page1 → **按钮变回灰色**（页面重新初始化，`bco` 回 52857）
3. FPGA 里效果器**还开着**
4. 再点一次 → 屏以为「关→开」，实际发 `71 19` **XOR** ⇒ **把开着的关掉**
5. 结果：屏显示彩色、实际是关的 —— 完全反相

### 修法

**① `Program.s` 声明**（`dim=100` 之后，必须带 `int`、逗号连一行）：

```
int fx0=0,fx1=0,fx2=0
```

> ⚠️ **不要用 `va0/va1/va2`** —— TJC 里 `va` 是变量控件的保留前缀，
> 直接写会报「变量名称无效:va0」+「索引超出了数组界限」。

**② `page1` 初始化事件**

```
if(fx0==1){ b_dist_hdr.bco=64608 }else{ b_dist_hdr.bco=52857 }
if(fx1==1){ b_chor_hdr.bco=2016  }else{ b_chor_hdr.bco=52857 }
if(fx2==1){ b_dly_hdr.bco=38943 }else{ b_dly_hdr.bco=52857 }
printh 88 FF FF FF
```

**③ 三个头部按钮弹起事件**

```
if(fx0==0){ fx0=1 b_dist_hdr.bco=64608 printh 71 19 01 FF FF FF }else{ fx0=0 b_dist_hdr.bco=52857 printh 71 19 01 FF FF FF }
if(fx1==0){ fx1=1 b_chor_hdr.bco=2016  printh 71 19 02 FF FF FF }else{ fx1=0 b_chor_hdr.bco=52857 printh 71 19 02 FF FF FF }
if(fx2==0){ fx2=1 b_dly_hdr.bco=38943 printh 71 19 04 FF FF FF }else{ fx2=0 b_dly_hdr.bco=52857 printh 71 19 04 FF FF FF }
```

**④ `page0` 初始化事件**

```
if(fx0==1){ t_dist_st.txt="失真 [开]" led_dist.val=1 }else{ t_dist_st.txt="失真 [关]" led_dist.val=0 }
if(fx1==1){ t_chor_st.txt="合唱 [开]" led_chor.val=1 }else{ t_chor_st.txt="合唱 [关]" led_chor.val=0 }
if(fx2==1){ t_dly_st.txt="延迟 [开]" led_dly.val=1 }else{ t_dly_st.txt="延迟 [关]" led_dly.val=0 }
```

> 局限：这是「屏自己记账」。若 FPGA 侧被别的入口改了（串口 `71 10`、重下载），`fx` 不会跟着变。
