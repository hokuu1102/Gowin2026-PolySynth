## 三、逐项功能验证（每项都写清"能红判据"）

### 3.1 串口（控制面）

- 口：`uart_rx` = **D14 / J9 N26**（USB-TTL 的 TX → FPGA），`uart_tx` = **D15 / J9 N25**
- 参数：**500 000 baud · 8N1**
- 命令是**裸 ASCII 字母**（不要套 `0xA5` 帧；帧内的字母会被当载荷忽略）

| 命令 | 作用 |
|---|---|
| `I` | 切下一个音色（0→1→2→3→0） |
| `B` | 节拍器 开/关 |
| `D` | 鼓机节奏型 切下一个 |
| `K` | 键盘打鼓 开/关 |
| `R` | looper 录/停（切换） |
| `L` | looper 播放（切换） |
| `C` | 清空 looper |
| `J` | **推子档位切下一档**（0 = 变调 · 1 = 颤音） |
| `F` / `G` | **变调 降/升 1 半音**（只在**档 0** 有效） |
| `H` | 变调 **带帧绝对量**（下一帧第一个载荷字节 = 编码 0..24） |
| `T`/`S`/`X` | 标定（tare / span / abort） |
| `M` | Test Mode（**本码流无效** —— 见 §五） |

### 3.3 T3 实时变调（本次的重点功能）

1. **上电 = 档 1（颤音）**，推子仍是颤音（这一档是"零回归"口径：应与旧版听不出区别）
2. 发 **`J`** 切到**档 0**
   怎么知道切过去了：**听** —— 档 1 时推子给的是颤音、档 0 时推子给的是变调（音高会变），
   这就是档位切换的判据（原来那颗指示 LED 随灯带一起不验了）
3. 档 0 下（三种都能用）：
   - **左推子** = 降调（半程）· **右推子** = 升调（半程）
   - 串口 **`F`** 降 1 半音 / **`G`** 升 1 半音
   - 串口 **`H`** 直接给绝对量
4. 判据：升满 **12 半音 = 高一个八度**（听得出）· 回 **0 半音则恢复原音高**
5. 已知（不用报为 bug）：换档 / 换八度 / 滑音之后**最多 32 拍（0.64 µs）**才生效
   ⇒ 听觉上不可闻（这是"影子数组"架构的代价）

### 3.4 鼓的扫频（已知副作用，请专门听这一项）

- 怎么触发：打鼓（节拍器/鼓机 或 发 `K` 用键盘打鼓）
- 期望：**底鼓有"先高后低"的音高包络**（这是本设计早就有的特性）
- 已知问题：影子数组是**轮转刷新**的，若 `note_on` 距采样拍 **< 32 拍**
  （概率上界 3.1%，且只在该 lane **换了鼓种**时）
  那一次鼓音的"扫频深度"可能取错（例如底鼓少一点"闷下去"）
  不影响音高、不影响音量、不影响发声与否
- 请这样听：连续打鼓、**故意换鼓种**（底鼓 ↔ 嗵鼓 ↔ 军鼓）
  看有没有"偶尔一次鼓的音头不对"
- 报回来请写：哪个鼓、大约多少次里出现一次（便于我判断是否与 3.1% 对得上）
