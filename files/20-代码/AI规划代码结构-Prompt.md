你是资深 FPGA 数字设计工程师。请为一个已确定硬件形态的项目规划【RTL 代码结构与接口】。

## 一、项目
2026 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新赛道 · 选题二：
「基于 FPGA 的实时多音色合成电子乐器引擎」。
乐器形态：双排八列（16 轴位）磁轴网格 + 右手区（拨弦摇杆 / 两个推子 / 音量）+ 状态显示。

## 二、平台与硬约束
- 目标器件：高云 Gowin（Tang Mega 60K Dock 底板），工具链 Gowin EDA
- ⛔ **不用 PLL、不用硬核 CPU、不用 HLS** —— 严格 RTL
- ⛔ 工程路径必须**全 ASCII**（中文路径会导致综合报 SORT-1002）
- 系统时钟直接用 50 MHz 晶振，音频时钟由它分频得到

## 三、赛题评分口径（决定架构取舍，必须吃透）
- 必达：**控制维度 ≥2**（冲 ≥3）｜**复音 ≥4**（冲 ≥32）｜**控制→出声 ≤10 ms**（冲 ≤5 ms 且**确定性**）｜**音色 ≥2**
- **吞吐量 = 同时活跃的【可闻】独立振荡器数 × 实际输出采样率**
  - ⭐ **波表查表：一片波表无论几路复用，只算 1 个振荡器**
  - ⭐ **加法合成：按参与运算的正弦分量个数统计**
  - ⭐ FM 的调制器不计入吞吐量
  - ⇒ 判据是「**相位/频率寄存器是否每路独立**」；加法器/乘法器**允许 TDM 共享**
- ⛔ **严禁预录 PCM**；必须真实合成

## 四、已定的音频时钟（不要改）
MCLK = 50 MHz ÷ 4 = 12.5 MHz
BCLK = MCLK ÷ 4 = 3.125 MHz
LRCLK = MCLK ÷ 256 ≈ 48.828 kHz
（⛔ 不要用 PLL 生成系统时钟，实测会炸）
Dock 引脚：I2S_BCLK = Y17 ｜ I2S_LRCK = AB17 ｜ I2S_DIN = AA16 ｜ PA_EN = AB16（**低有效**）
⭐ **系统时钟脚待复核**：官方 Tang Mega 60K 示例把板载 50 MHz 约束在 **`V22`/`LVCMOS33`**；
旧文档里的 `F13` 属于**基石板**（不用于本项目）；`AB12`/`LVCMOS15` 是 MS5351 可编程时钟输入。
⇒ 正式板必须按 `V22` 并核对实板版本，⛔ 不要沿用 `F13`。
⭐ **复位源待定**：官方示例候选 `Y12`/`LVCMOS15`/`PULL_UP`；仓库约定 `rst_n` 低有效同步复位。
若不用外部按键复位，需明确采用哪种 Gowin GSR/POR 方案 —— **顶层接口不得默认为已冻结**。

## 五、硬件接口（外设全挂在 FPGA 上）
1. **左手区板 ×2**：各 1 片 `MCP3208`（8 通道 12 bit SPI）读 8 个线性霍尔 `HAL49E`；
   两板**各自一条排线、各自一个 `CS`**（⛔ 不可共用一个 CS，否则 MISO 双驱）
   每板出：`CS / SCK / MOSI / MISO`（四线，均已成对配地）
2. **左手区指示灯**：每板 1 片 `TLC5916`（8 路恒流 sink）
   - ⚠️ `OE(ED2)` **低有效**（低=输出使能），内部自带 500 kΩ 上拉 → 悬空即灭
   - ⚠️ `LE(ED1)` **移位期间必须保持低**，8 bit 移完再打一个宽脉冲上锁存
   - ⛔ `OE` 上**绝不能出现"一个 CLK 宽的窄脉冲"**（会进 Special Mode）
   - `R_EXT = 2.4 kΩ` → 约 7.8 mA/路（不做 PWM 调光）
3. **右手区板 A**（模拟输入）：1 片 `MCP3208`
   - `CH0` = 摇杆（拨弦，回中单轴）｜`CH1` = 音量｜`CH2` = 推子1｜`CH3` = 推子2｜`CH4~CH7` 接地备用
   - 摇杆另经 `LM393` 双路比较器输出 **`UP` / `DOWN`** 两路 0/1（**µs 级延迟**，用于拨弦事件）
   - ⭐⭐ **比较器输入必须接在 RC 之前（原始信号侧）** —— 这是"`UP/DOWN` 延迟 <5 ms 可证明"的**硬件前提**；
     接在 RC 之后延迟会变成 1~3 ms 且随动作速度变化，该论证当场失效
   - 每路模拟输入前有 **`1 kΩ + 10 nF`** RC（截止 ≈16 kHz、τ = 10 µs）
   - ⭐ **ADC 轮询口径（精确表述，别误读）**：**同一通道两次采样间隔 ≥5 ms**；
     **同一片 ADC 内的 8 个通道可以 0.5 ms 间隔顺序扫描**（整片帧周期 0.5 ms）。
     ⛔ 不要读成"帧内通道间隔 5 ms" —— 那会让 8 通道扫完要 40 ms，左手 16 键直接废掉
4. **右手区板 B**（人机）：`OLED 0.96″`（**SSD1306 / SPI**，信号 `D0(SCLK)/D1(MOSI)/RES/DC/CS`，⛔ 只写不读）/
   `EC11` 编码器（A、B、SW）/ 4 个按键 / 4 个双色灯（**共阳极**，由 1 片 `TLC5916` 驱动，8 路用满）
   - ⛔ **不用 `74HC165`**：按键与编码器**直连 FPGA 引脚**（165 的 `QH` 无三态，与 ADC 的 `MISO` 硬并会抢线）
   - ⭐ **灯的移位 `CLK` 与 ADC 的 SPI `SCK` 不是同一条**，各自独立
5. **串口屏** `TJC X2` 7″（挂在转接板上，UART）
6. **右手区拨弦/按键抗抖**：机械触点一律 `10 kΩ` 上拉 + `100 nF`；⭐ 所有"悬空会有害"的输入（`CS`/`OE`/`LE`/`PL`/`MISO`）都已有上下拉

## 六、已定的功能参数（编译期可调，改它不动接口）
- 键位 **16 固定**；`POLY_TARGET = 32`；`OSC_PER_VOICE = 2`；FM 先留接口后加
- 两种映射：**键盘模式 / 指板模式**（只改映射表，不改硬件）
- 音色 ≥2；音量 = **数字音量**（电位器 → ADC → FPGA 乘系数）
  - ⭐ **`B10K` 是线性电位器 → 位置→增益必须套对数映射**（否则转一点就爆音、转半圈没变化）
  - 建议做法：ADC 高 5~6 位做索引 → 32~64 点查表（曲线可随时改）
- 颤音：两个推子分别控 **深度 / 速率**（速率由 FPGA 生成 1~12 Hz，⛔ 不是人手抖）
  - ⚠️ 深度两端要留**死区 + 迟滞**；速率变化要**斜率限制**，否则听到音高跳变
- 单音实时变调 = **只改相位增量 `phase_inc`，⛔ 绝不重置相位累加器**（重置=咔哒声）
- 状态显示：OLED 只显示数据（不做菜单）；编码器旋转调值、按压切换对象环（音色/八度/`N`）；
  4 个按键 = 模式 / 测试模式 / 静音 / 推子参数页；4 个双色灯做兜底状态指示
- ⭐ **Test Mode 必须是正式功能**（决赛现场会重新验证）：同时输出 N 路不同频率的单音，
  `N = 4 / 8 / 16 / 32` 可在现场切换，且**视频里要能读出 N**
