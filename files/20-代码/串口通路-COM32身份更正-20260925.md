## 一、🔴 更正：`COM32` 的真实身份

⭐ 实测 `VID_FAED PID_4873` 是一个**复合设备**（⭐ Windows 枚举出 4 个接口）：

| ⭐ 接口 | ⭐ 设备 | ⭐ 说明 |
|---|---|---|
| `MI_00` | ⭐ **Horco CMSIS-DAP v2** | 🔴 **调试器（JTAG）** |
| `MI_01` | ⭐ HID-compliant vendor-defined | ⭐ 调试器的 HID |
| **`MI_02`** | ⭐ **USB 串行设备（`COM32`）** | 🔴 **DAP 的 CDC 串口** |
| `MI_04` | ⭐ USB Mass Storage | ⭐ 存储 |

### ⚠️ 交接文档 §九.4 的原文是错的

```
🔴 原文: "COM32 是 USB-TTL（VID_FAED）；板载 BL616 是另一个口"
⭐ 事实: ⭐ VID_FAED **就是**板载调试器（含 BL616）
        ⇒ 🔴 **COM32 是【板载 DAP 的 CDC】，⛔ 不是外接 USB-TTL**
```

⚠️ **用户已确认**：⭐ "虽然不是 usb-ttl，但是也能进行串口通信，是一个 daplink"
⇒ ⭐ **它确实能串口通信**（⭐ DAP 提供 CDC）—— 🔴 **但它是否接到 FPGA 的 UART 是另一回事**。

## 三、🔴 那为什么不通（⭐ 两个可能）

```
① 🔴 **DAP 的 CDC 串口⛔ 没有接到 FPGA 的 UART**
   ⭐ 本项目 FPGA 的 UART 引脚是 `D14`(rx)/`D15`(tx) = ⭐ **`J9` 的 `N26`/`N25`**
   ⚠️ 而 DAP 的 CDC 走的是 **BL616** —— 🔴 **BL616 与 FPGA 之间是内部连线，
      是否连到 `D14`/`D15` 【未核实】**（⭐ 需要查 Console 原理图）

② ⚠️ **接线**（⭐ 若用的是外接 USB-TTL）
   ⭐ 交接文档要求：⭐ `USB-TTL.TX → J9·N26`、⭐ `USB-TTL.RX → J9·N25`、⭐ `GND → J9·GND`
   ⚠️ 而 `N25`/`N26` 紧挨 `N24`（LED）⇒ 🔴 **容易数错针**
```
