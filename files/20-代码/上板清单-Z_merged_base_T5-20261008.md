## 二、⭐ T1 的 7 项复验（本次上板的**主任务**）

出处：`files/00-总览/第三周/第三周计划-v1.md:54`
（已知 2026-09-30 实测：**鼓机 ✅ · looper ✅**；**其余 5 项未报** ⇒ 本次要重跑全部 7 项）

| # | 项 | 怎么验 | 预期 | 实测 |
|---|---|---|---|---|
| **1** | **失谐** | 单音长按 3~5 秒，听 | 有**缓慢的"起伏"**（拍频 `T = 512/f`；低音更慢更明显）。⚠️ **这是设计意图，⛔ 不是 bug** | |
| **2** | **4 音色** | 串口发 `65 49 FF FF FF` 循环切，或面板 S2 | BASS → GUITAR → PIANO → PAD → BASS，**四者音色可辨** | |
| **3** | **按音色 ADSR** | 对每个音色弹一下，注意起音/衰减 | **PAD 起音最慢（30 ms，慢渐入）** · **GUITAR 衰减最快（拨弦感）** · BASS/PIANO 居中 | |
| **4** | **looper 音色** | 录一层（`65 52 FF FF FF`）→ 播放（`65 4C FF FF FF`） | 回放**保持录制时的音色**（不变成当前音色） | |
| **5** | **S2 切音色** | 按面板 S2 | 与串口 `'I'` 等效，**能切** | |
| **6** | **串口 `B` 节拍器** | 发 `65 42 FF FF FF` | **节拍器开/关切换**（再发一次切回）；节拍器响时**键盘音量不应被压低** | |
| **7** | **鼓机** | 发 `65 44 FF FF FF` 切节奏型 | 节奏型**逐个切换**、能出声 | |

## 六、串口命令速查（**HEX 模式**，⛔ 不是 ASCII 文本）

```
波特率 500000 8N1    帧格式：65 <命令字> FF FF FF
```

| 命令 | 帧（HEX） | 作用 |
|---|---|---|
| `T` | `65 54 FF FF FF` | tare（归零标定） |
| `S` | `65 53 FF FF FF` | span（满行程标定，逐轴） |
| `P` | `65 50 FF FF FF` | 回传**原始码** `af0_pol`（诊断） |
| `N` | `65 4E FF FF FF` | 回传**标定后 `pos`**（诊断） |
| `V` | `65 56 FF FF FF` | 回传 span 内部状态 |
| `I` | `65 49 FF FF FF` | 切音色 BASS→GUITAR→PIANO→PAD |
| `B` | `65 42 FF FF FF` | 节拍器开/关 |
| `D` | `65 44 FF FF FF` | 鼓机节奏型切下一个 |
| `K` | `65 4B FF FF FF` | 键盘打鼓模式开/关 |
| `R` | `65 52 FF FF FF` | looper 录/停切换 |
| `L` | `65 4C FF FF FF` | looper 播放切换 |
| `C` | `65 43 FF FF FF` | looper 清空该层 |
| `F` | `65 46 FF FF FF` | 变调降 1 半音 |
| `G` | `65 47 FF FF FF` | 变调升 1 半音 |
| `M` | `65 4D FF FF FF` | Test Mode 循环 |

⚠️ **接线**：`uart_rx` = **D14** / `uart_tx` = **D15**（`constr/top.cst` 已核对）。
但 `第三周计划-v2-实测修正版.md` 另记「走 `J9` 排针 `TX→N26` / `RX→N25`，⛔ 板载 USB-C 走不通」
⇒ ⭐ **以实测为准**，两个都试一下。
