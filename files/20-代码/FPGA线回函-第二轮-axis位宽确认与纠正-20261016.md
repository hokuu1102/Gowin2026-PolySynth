## 三、✅ 你们的 dt 键方案：我核了位身份，成立

```text
axis = dt 键 = ((dt & 3) << 1) | (dt >> 2)
  dt 0→0 · 1→2 · 2→4 · 3→6 · 4→1 · 5→3 · 6→5 · 7→7     （8 个互不相同 ✓）
```

位身份核对（⭐ 三件事同时成立，因为 `bit19` **就是** `axis` 的 LSB）：

| 要成立的事 | 为什么成立 |
|---|---|
| `drum_type = {bit19, timbre[8:7]}` | `bit19` = `axis` 的 LSB = `dt >> 2` ⇒ `{dt>>2, dt&3}` = `dt` ✓ |
| 八件天然隔离 | 八个 `axis` 值互不相同 ⇒ `(axis, src)` 退化成唯一键 ⇒ `note_off` 只清自己那件 ✓ |
| 旋律不让轴 | `(axis, src)` 是两维匹配 ⇒ 数值重叠无妨（`SRC_SCORE` vs `SRC_KDRUM`）✓ |

⭐ **你们那条便宜判据「`axis & 1` 必须等于 `drum_type >> 2`」正是上面这个恒等式**，一眼就能抓到"axis 与 bit19 打架"的写法错误。我方也会在 `tb_seq_arb` 里加同一条（机械校验，不靠眼睛）。

## 四、⚠️ 由此带出一条你们和我都要改的连带项

既然**轴号是 voice 的定位键**，那"同一件鼓"必须在**所有来路**上落到**同一个轴**，否则同一件鼓的不同来路会**叠成两个 voice 而不是重触发**：

```
来路 A：曲谱灌进来的鼓（SRC_KDRUM）—— 你们写 dt 键 ⇒ 轴 0/2/4/6/1/3/5/7
来路 B：键盘打鼓（SRC_KDRUM）      —— 目前用哪个轴？
来路 C：内部鼓机 drum_gen（SRC_AUX）—— 目前用哪个轴？
```

如果 B/C 用的轴与 A 不同，那么"跟着谱面一起打鼓"时：

```
谱面的 Kick（轴 0）与手打的 Kick（轴 ?）=> 不同轴 => 【两个 voice 同时响】
=> 听感：底鼓变厚（甚至相位打架），而不是"重触发一下"
```

⭐ **我方会做的**：把 `drum_gen`（来路 C）与键盘打鼓（来路 B）的**鼓轴赋值统一成同一张 dt 键表**（`rtl/w3c/drum_inc_defs.vh` 已经是共享常量文件，正好把这张 `dt→axis` 表也放进去 ⇒ 三处引用同一份）。
