## 2. 改动内容（只改一个变量：宽度）

| 项 | 改前 | 改后 |
|---|---|---|
| `cnt_q` / `head_q` / `tail_q` | `reg [15:0]` ×3 | `[CNT_W-1:0]` / `[PTR_W-1:0]` ×2 |
| `push_n` | `wire [15:0]` | `wire [1:0]`（最大 3） |
| `off_a/off_b/off_c` | `wire [15:0]` | `wire [OFF_W-1:0] = 2 位`（最大 2） |
| `tail_off()` | `function [15:0]`（内部 `[15:0] r`） | `function [PTR_W-1:0]`（内部 `[SUM_W-1:0] r`） |
| `cnt_after_pop` / `cnt_next` | `[15:0]` | `[CNT_W-1:0]` / `[SUM_W-1:0]`（**先零扩展再相加**） |
| `head`/`tail` 推进 | 直接 `+16'd1` / `+push_n` | **先在 `SUM_W` 里算**（`head_next`/`tail_sum`/`tail_wrap`/`tail_next`） |

**宽度推导**（`localparam`）：`CNT_W = clog2(DEPTH+1)` · `PTR_W = clog2(DEPTH)` · `SUM_W = clog2(DEPTH+3)` · `OFF_W = 2`
⇒ ⭐ **`DEPTH=6`（`top.v` 交付态）⇒ 3 / 3 / 4 / 2**；`DEPTH=4`（`tb_evt_merge`）⇒ 3 / 2 / 3 / 2

**必须逐位保持**（⛔ 一处未动）：弹出优先 · 同拍最多 3 源推入 · 满队列丢弃 + `sticky` · 槽位回绕 · 轮转优先级（只有 A、B 都到才翻面）· 按源统计 · `valid` 严格单周期 · **16 位诊断计数器**（`collision_cnt_o`/`merged_cnt_o`/`drop_cnt_o`）

**范围**：`rtl/w3c/evt_merge.v`（+46/−28）· `tb/w3c/tb_evt_merge.sv`（**只新增** DEPTH9 用例）· `tb/w3c/tb_evt_merge_diff.sv`（新差分 tb）· `tb/models/evt_merge_ref.v`（旧 RTL 副本，供差分）
