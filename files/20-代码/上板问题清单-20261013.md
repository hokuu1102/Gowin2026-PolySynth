## ✅ P1 · `'A'` 命令不生效 —— **已修复**

### 🔴 根因（**实测确认，不是推断**）
`calib_cmd.v` 有一道**总闸** `byte_is_cmd`：

```verilog
372: wire byte_is_cmd = byte_is_tare | ... | byte_is_recdump;   ← 总闸
493: end else if (byte_is_cmd) begin                            ← 命令必须过这道门
535:     if (byte_is_mode_sw) mode_sw_req_o <= 1'b1;            ← 我上次只加了这里
```

**只加"出脉冲"分支、忘了加进总闸** ⇒ `'A'` **连"命令"都不算**
⇒ `cmd_cnt_o` 不加、`mode_sw_req_o` 不出脉冲、不回包、`mode_o` 不变 ✓ **与上板现象完全一致**。

📌 **同一个坑在代码里已是第三次**（`:380-382` 的"四个新字母"、`:385-387` 的 `'Y'`），
⭐ 而那两条注释**就写在总闸旁边** —— 我还是漏了。

### 修法
把 `byte_is_mode_sw` 加进 `byte_is_cmd`（`:389`）+ 顺手修 `:535` 的缩进（8 → 24 空格）。

### 判据（**新增，改前必红**）
`tb/w3a/tb_calib_cmd.sv` 加了 7 条：

| 判据 | 改前 |
|---|---|
| `'A' outside a frame raises mode_sw_req exactly once` | 🔴 **FAIL** |
| `'A' increments cmd_cnt_o (4 -> 5)` | 🔴 **FAIL**（`cmd_cnt` 不加 = 铁证） |
| `'A' can be sent repeatedly` | 🔴 **FAIL** |
| `each 'A' pulse is exactly ONE cycle wide` | 🔴 **FAIL** |
| `'A' INSIDE a frame payload raises NOTHING` | 🔴 **FAIL** |
| `'A' does NOT cross-fire any other command` | ✅（本来就没串扰） |

**修后：全绿（`通过 2 / 共 2`）** ✅

## ✅ P2 · 颤音推子（CH2）几乎无感 —— **已修复**

### 🔴 根因（**代码里自己记录着**）
`vibrato_lfo.v:57-77`：`P0-19`（2026-10-09）为修"低音翻负错音"用了**限幅止血版**：

```verilog
depth_eff = (depth_raw_i > 120) ? 120 : depth_raw_i;   // 旧
```

⇒ ⭐ **推子只有最底 2.9%（120/4095）有效**，**2.9%~100% 全部恒定 = 满深度**
⇒ 🔴 **推子等于一个开关** ✓ 与用户描述**一字不差**。

### 修法
改成**全行程线性映射**：`depth_eff = depth_raw_i × 120 / 4096`（⭐ `120 = 64+32+16+8` ⇒ ⛔ 不用乘法器）

**三条保证全部保持**：
- 最大深度**仍是 120**（= ±50 cents @ A4）⇒ **永不翻负** ✅
- **滞回比较的仍是原始推子值**（`depth_raw_i <= DEPTH_OFF`）⇒ 死区/门限语义**逐位不变** ✅
- `depth_raw_i = 4095` ⇒ `depth_eff = 119`（≤120）⇒ 原上限判据仍绿 ✅

⚠️ **我自己踩了一次**：第一版把 `>>12` 写成 `depth_mul[18:7]`（= `>>7`）⇒ **深度大 32 倍**
（实测峰值 **30712** vs 上限 960）⇒ **正是原上限判据当场抓住的** ✅

### 实测对比

| 推子位置 | 改前 | **改后** |
|---|---|---|
| 满行程（4095） | 952 | **952**（上限不变 ✓） |
| **中点（2048）** | **952（被限死）** | **480（恰好一半 ✓）** |

### 判据（**新增，改前必红**）
`tb/w3b/tb_vibrato_lfo.sv` 加 2 条：
- `full-travel usable: mid-fader depth is clearly BELOW full-travel depth` ← 改前**必红**
- `full-travel usable: mid-fader depth is clearly NON-ZERO (fader really does something)`

## 🟢 P2b · **颤音深度随音高剧烈变化**（✅ **已裁定：不改**，2026-10-15）

> ⭐⭐ **用户 2026-10-15 裁定**：*"暂时不改吧，评委应该听不懂，我们自己也没怎么听出来，这个暂时有就行。"*
>
> ⇒ **结论：保持现状（方案 a）**，⛔ 不做"按比例颤音"的结构改动 ✓
> 📌 **理由**：① 功能**是有的**（颤音真的在颤，只是深度随音高变）；
> ② 主观听感上**评委听不出、我们自己也听不出**；③ 低音区可用**推子下半段**规避 ✓
>
> 🔴 **将来若有人想动**：先确认"确实有人听出来了"，再回来读下面的三个方案 ——
> 这**不是 bug**，是**共享乘法器**的固有性质（设计取舍）⇒ 改它是**功能增强**，不是修错 ✓

### 现象（**实测换算**）
`oscillator_bank` 的颤音是**绝对偏移**（`vib_off = VIB_REF_INC × mod >> 15`），
⭐ **⛔ 不按各 lane 基频比例** ⇒ **同一个"满深度"，不同音高差 28 倍**：

| 音名 | 频率 | inc | **满深度颤音幅度** |
|---|---|---|---|
| **E1** | 41.2 Hz | 3,623,993 | 🔴 **471 cents**（接近半音，像警报） |
| B1 | 61.7 Hz | 5,430,712 | 328 cents |
| E2 | 82.4 Hz | 7,248,866 | 252 cents |
| A2 | 110 Hz | 9,675,710 | 192 cents |
| A3 | 220 Hz | 19,351,420 | 99 cents |
| **A4** | **440 Hz** | 38,702,840 | ✅ **50 cents**（**设计目标，只有这里对**） |
| A5 | 880 Hz | 77,405,680 | 25 cents |
| **E6** | 1318 Hz | 115,976,578 | 🔴 **17 cents**（几乎听不出） |

**换算依据**：`VIB_REF_INC = 38_700_000`（`oscillator_bank.v:92`）按 **A4** 定；
`vib_off_peak = 9448.2 × depth_eff`，满深度 `depth_eff = 120` ⇒ `vib_off = 1,133,784`；
`cents = 1200 × log2((inc + vib_off)/inc)`；`fs = 48,828.1 Hz`（由 A4 的 `bv` 反推）。

### 🔴 为什么当年这么设计
`oscillator_bank.v:299-304` 的注释：
> *"颤音：**共享**一个乘法器算偏移（⛔ 不给每 lane 配乘法器 —— 那要 64 个 DSP）"*
> *"⚠️ 这是**共享的绝对偏移**（⛔ 不是每 lane 按各自基频比例）"*

### 与 P2（已修）的区别
| 层 | 现象 | 状态 |
|---|---|---|
| **P2 · 推子行程** | 只有最底 2.9% 有效，其余恒定 | ✅ **已修**（全行程线性映射） |
| **P2b · 深度随音高变** | 低音过猛、高音太弱 | ⏳ **待裁定**（绝对偏移的固有性质） |

### 三个方案（⏳ **建议先上板听 P2 的效果再定**）

| 方案 | 代价 | 效果 |
|---|---|---|
| **a. 接受现状** | **0** | 用推子下半段（低音区别拧太大） |
| **b. 真按比例**（代码里叫"结构修法 B"） | **1 DSP + ~1024 FF + 32 拍状态机** | 处处 50 cents ✅ |
| **c. 分档近似** | ~1024 LUT（每 voice 一个变长移位） | 分 4~6 档近似比例 |

📌 **b 的代价没当年想的那么贵**：`DSP` 空 **96 个**、`Register` 只用 **31%**
（已占的 25,590 CLS 理论上还能塞 32,775 个 FF 而 CLS 不涨）
⇒ ⭐ **真正贵的是那个 32 拍状态机**，⛔ 不是乘法器或 FF。

⚠️ **注意**：`P0-19` 那个"翻负"门限（最低弦 `depth_raw ≥ 287`）在**限幅时代**是问题；
⭐ 现在上限是 120 ⇒ **永不翻负** ✅ —— 但**低音区满深度的 471 cents 仍然"过猛"**（⛔ 不是 bug，是听感问题）。
