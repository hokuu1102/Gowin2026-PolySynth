## 一、⭐ 烧哪个（两档，⛔ 不能互换）

| 档 | 路径 | 配置 | 时序 | 什么时候烧 |
|---|---|---|---|---|
| ⭐ **A（默认）** | `sim/evidence/rightadc-default-20261009/Gowin2026-rightboard-default.fs` | **`RIGHT_ADC_ENABLE=1`** | **60.784 MHz** · 余量 **+1.730 ns** · 0/0 | ⭐ **接着右手板**时（交付树默认就是它） |
| **B** | `sim/evidence/p0-fixes-delivery-20261009/Gowin2026-p0fixes-leftboard.fs` | `=0` | 0/0 | ⛔ **只接左手板**时用 |

### ⚠️ 三条铁律（队友手册 §〇）

1. ⭐ **A 必须接着右手板才烧** —— 它会扫**第 3 片 ADC**，没接板子会读到**悬空通道** ⇒ **可能出幻影音**
2. ⛔ **B 别在接了右手板的机器上烧** —— 第 3 片不扫描 ⇒ 右手板整条线不工作
3. ⚠️ `RIGHT_ADC_ENABLE` 是**编译期参数**（`rtl/top.v:292`）⇒ **没有运行时开关，两个码流不能互换**

⚠️ 还有两个旧档（`a3-proper` / `final-batch`）和一个 **⛔ 绝对别烧的已回退变体**（`a3-drum-raw-20261008/Gowin2026-a3-REVERTED-variant.fs`）—— 见队友手册 §〇 表。

### ⭐ A 档的时序来历（本轮最硬的东西）

| 阶段 | Fmax | 最差 slack |
|---|---|---|
| 原始 `=1` 档 | 🔴 **46.613 MHz** | 🔴 **−3.272 ns** |
| ＋颤音流水 | ≈55.16 | +0.051 ⚠️ |
| ＋A3 | ≈57.0 | +0.642 |
| ⭐ **＋P0-03/P0-04（本版 A）** | ⭐ **60.784 MHz** | ⭐ **+1.730 ns** |

⇒ 余量 **+0.051 → +1.730 ns（34 倍）**，且最差路径**换人了**（`u_note_manager/axis_r[3]`）
⇒ T3 写侧 + TDM 两条结构性长路径**都不再是绑定项** ✅

## 二、⭐ A 档测试步骤（队友手册 §二 A1~A13）

> ⚠️ **A2 不过就别往下测了**（幻影音 = 通道映射错，后面全白测）

| 步 | 操作 | ⭐ 判据（过/不过） | 实测 |
|---|---|---|---|
| **A1** | 接线（**接右手板**）→ 上电 | ⭐ **绝对静音**（不碰任何键）；⭐ **心跳灯在闪** | |
| **A2** | ⭐⭐ **先查幻影音**：右手板推子/摇杆**一动不动** | ⭐ **⛔ 不许有任何音自己触发** | |
| **A3** | 右手板推子（CH2/CH3） | ⭐ 颤音**深度/速率**跟随；⛔ **不出现"倒放"怪音**（P0-19） | |
| **A4** | 右手板摇杆 / 音量 | ⭐ 音高 / 音量跟随 | |
| **A5** | 串口 `T`(tare) → `S`(span) | ⭐ **片 2 的轴能标上**（`'P'` 可读片 2 的 pos）；需所有轴静止/按到底 | |
| **A6** | 右手板按键 | ⭐ 音高对（对照 `axis_map`） | |
| **A7** | ⭐ **满力度**（验 **P0-01**） | ⭐ 用力敲到最大 ⇒ **音量不掉**（🔴 改前瞬间掉到 −31 dB + ~1.5 kHz 颤音） | |
| **A8** | ⭐ **串口屏 + 演奏**（验 **P0-02**） | ⭐ 屏刷新数值时同时演奏 ⇒ **不出现"按所有键都清不掉的挂音"**（🔴 改前必现，⭐ **你实测过的症状**） | |
| **A9** | ⭐ **命令分块发**（验 **P0-05**） | ⭐ 脚本把一条 9 字节命令**分两次 write()** ⇒ **不被当命令执行** | |
| **A10** | ⭐ **HDMI 波形**（验 **P0-18**） | ⭐ 满幅信号**不再削平**（🔴 改前 −6.58 dBFS 就饱和：满幅正弦像方波、满幅方波整屏纯绿） | |
| **A11** | 力度 / 变调 / looper / 鼓机 / 节拍器 | ⭐ 逐项过 | |
| **A12** | 失谐拍频 | ⭐ 长音有 **~1.72 Hz** 缓慢起伏（⭐ **是设计**，⛔ 不是 bug） | |
| **A13** | 4 音色切换（`'I'`） | ⭐ 音色明显不同 | |

### ⚠️ A 档的**已知功能盲区**（队友诚实说明）

```
=1 档的功能判据只到「第 3 片扫描通路是活的」（tb/top/tb_right_adc.sv 双实例差分 7/7）
⇒ 通道映射 / 标定对不对，只能上板看
```

## 六、串口命令（⭐ **500 kbaud**，⛔ 不是 115200）

```
帧格式：65 <命令字> FF FF FF        HEX 模式，⛔ 不是 ASCII 文本
```

| 键 | 帧（HEX） | 作用 |
|---|---|---|
| `T` | `65 54 FF FF FF` | tare 归零 |
| `S` | `65 53 FF FF FF` | span 满行程（逐轴） |
| `P` | `65 50 FF FF FF` | 回传**原始码**（诊断） |
| `N` | `65 4E FF FF FF` | 回传**标定后 pos**（诊断） |
| `V` | `65 56 FF FF FF` | span 内部状态 |
| `I` | `65 49 FF FF FF` | 切音色 |
| `B` | `65 42 FF FF FF` | 节拍器开/关 |
| `D` | `65 44 FF FF FF` | 鼓机节奏型 |
| `K` | `65 4B FF FF FF` | 键盘打鼓 |
| `R` | `65 52 FF FF FF` | looper 录/停 |
| `L` | `65 4C FF FF FF` | looper 播放 |
| `C` | `65 43 FF FF FF` | looper 清层 |
| `F` / `G` | `65 46` / `65 47 FF FF FF` | 变调降/升 1 半音 |
| `M` | `65 4D FF FF FF` | Test Mode 循环 |

⚠️ **接线**：`uart_rx`=D14 / `uart_tx`=D15（`top.cst` 核对）；队友 v2 另记「走 `J9` `TX→N26`/`RX→N25`，板载 USB-C 走不通」⇒ **以实测为准，两个都试**
