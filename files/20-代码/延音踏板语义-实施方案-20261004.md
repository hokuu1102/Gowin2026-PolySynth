# 延音踏板语义（T5）实施方案 — 2026-10-04

> **任务来源**：第三周计划 v1 §3.1 任务表 **T5** ——「延音踏板语义：踏板按下期间 `note_off` 只关 gate、不关包络」，判据「踩下后松手音不消失」。
> **约束**（用户 2026-10-04）：**不动时序** —— 本轮不做任何资源/时序优化（顺手项一律搁置），只做本功能。
> **排期原定**：10/3。

---

## 一、目标

1. **功能**：踩住延音踏板时，松键（`note_off`）**不启动包络释放**，音继续保持在 sustain；**松开踏板**时，所有被踏板留住的音**同时释放**。
2. **零回归**：踏板未踩时（`pedal_sus_i = 1`，硬件上拉空闲），行为与现在**逐位相同**。
3. **不破坏现有契约**：所有现有 tb **一个都不用改**（关键：未连接的 tb 端口是 `Z`，必须按"未踩"处理 —— 照抄 `top.v` 里节拍器按键那套 Z-safe 写法）。
4. **四道门**：综合 `ERROR=0` · 聚焦 tb 全绿 · 一次干净 PnR 出 `.fs` 且无 `PR0004` · 全量回归「通过数 == 共数」。

## 三、语义定稿（含我替你定的口径）

| # | 口径 | 定法 | 依据 |
|---|---|---|---|
| 1 | 踏板按住期间 `note_off` 做什么 | **只关 gate（`gate_r <= 0`），不启动包络释放**；包络保持在 sustain | 任务原文 |
| 2 | 松开踏板时做什么 | **所有被踏板留住的音同时释放** | 钢琴/延音踏板的标准行为 |
| 3 | 踏板**在松键之后**才踩下 | **不复活**已释放的音 | 标准行为（只影响"踩下期间发生的 `note_off`"） |
| 4 | **哪些源**受踏板影响 | **只影响手弹（`src = 0`）** | 节拍器/鼓机/looper 回放的 `note_off` 若被留住，会破坏节奏与鼓的衰减；且 `note_off` 里"清力度目标"那一条本来就只对 `cur_src == 0` 生效（`note_manager.v:1115`），口径一致 |
| 5 | 踏板踩下时**再按同一个键** | **正常重触发**（新音接管，旧的留音位清掉） | 复用现有 `same_hit` 重触发路径 |
| 6 | 换音色/切档/换八度是否受影响 | **不影响** —— 只动 gate，不动音高链 | 与本功能无关 |
| 7 | 参数开关 | 不加 `SUS_PEDAL_EN` 开关 | 踏板未踩时 `sus_hold_r` 恒 0 ⇒ 逐位零回归是**构造性成立**的，不需要开关 |

**待你确认的两条**：口径 **4**（只影响手弹）与口径 **2**（松踏板全放）。若你要"踏板也留住 looper 回放的音"，改一个 `cur_src` 判据即可（一行）。

## 四、设计（改动最小、不碰音高链）

### 4.1 新增一个每 voice 的"留音位"

```verilog
reg [POLY_TARGET-1:0] sus_hold_r;   // 该 voice 被延音踏板留住
```

### 4.2 两条输出的 OR（唯一碰包络的地方）

```verilog
assign voice_gate_o   = gate_mask | sus_hold_r;          // 原：gate_mask
assign live_mask      = gate_r | retrig_low | env_active_r | sus_hold_r;
assign voice_releasing_o = live_mask & ~gate_mask;       // 语义不变：gate=0 但还在响
```

> 原理：包络引擎只看 gate。`gate_r = 0` 但 `sus_hold_r = 1` ⇒ 引擎看到的仍是 1 ⇒ **停在 sustain，不进入释放**；松踏板时 `sus_hold_r` 落 0 ⇒ 引擎自然释放。
> **不改 `envelope_bank` / `adsr` 一行** —— 这是本方案最关键的一点（共享引擎的 32 拍轮转不受影响）。

### 4.3 置位（`note_off` 里）

在 `note_manager.v:1092-1103` 的循环里，对匹配的 voice 加：

```verilog
if (sus_pedal_r && (cur_src == 3'd0)) sus_hold_r[i] <= 1'b1;   // 只留住手弹
```

### 4.4 清零（四条路径，缺一不可）

| 路径 | 位置 | 为什么 |
|---|---|---|
| 松踏板（整体清） | `always` 块里检测 `sus_pedal_r` 的下降沿 ⇒ `sus_hold_r <= 0` | 主路径 |
| 重触发 | `:1055` 置 `gate_r` 处 | 新音接管，防叠音 |
| 提交/分配 | `:1283` 置 `gate_r` 处 | 同上 |
| 复位 + 释放 voice（`gate_r <= 0` 的清理路径 `:800`/`:1048`） | 各清理点 | 防挂音纪律：voice 被回收时留音位必须跟着清 |

### 4.5 顶层接线（`top.v`）

```
pedal_sus_i (F18, 异步)
  → sync_input #(.W(1), .STAGES(2))     // 先同步（K-62 纪律）
  → debounce  #(.NKEY(1), .CLK_HZ(50_000_000), .DB_MS(5), .ACTIVE_LOW(1))
  → sus_pedal_r（低有效 ⇒ 踩下 = 1）
  → u_note_manager .sus_pedal_i()
```

- 同时把 `pedal_sus_i` **从 `reserved_in_xor` 里摘掉**（它已有消费者了 —— 这是 `top.v:4764-4766` 明写的纪律）。
- **Z-safe**：未连接 ⇒ `Z` ⇒ 按"未踩"处理（用 `===` 判 `0`）。照抄节拍器按键那段的写法，保证**现有 tb 一个都不用改**。

## 六、验证计划（判据先行）

### 6.1 模块级 tb（`tb_note_manager_sus.sv`）—— 6 条判据

| # | 判据 | 能红的方式 |
|---|---|---|
| S1 | 不踩踏板：`note_on` → `note_off` ⇒ `voice_gate_o` 落 0（**与现在逐位相同**） | 把 OR 去掉 ⇒ 仍然过（这条是回归判据） |
| S2 | 踩住踏板：`note_on` → `note_off` ⇒ **`voice_gate_o` 仍为 1**（包络不释放） | 不实现置位 ⇒ 红 |
| S3 | 松踏板 ⇒ 该 voice 的 `voice_gate_o` 落 0（且**只有**被留住的那些落 0） | 不实现整体清零 ⇒ 红 |
| S4 | 踩住踏板 + **同轴再按** ⇒ 正常重触发，`sus_hold_r` 被清（⛔ 不叠音） | 不清重触发路径 ⇒ 红 |
| S5 | 踩住踏板时，**非手弹源**（`src != 0`）的 `note_off` **照常释放** | 去掉 `cur_src==0` 判据 ⇒ 红 |
| S6 | 松键之后才踩踏板 ⇒ **不复活**（该 voice 保持释放） | 把置位写成"踏板电平"而非"`note_off` 瞬间" ⇒ 红 |

### 6.2 端到端 tb（`tb_sustain_pedal.sv`）—— 3 条判据

| # | 判据 |
|---|---|
| E1 | 踩踏板 → 按键 → 松键 ⇒ `HP_DIN` **继续有变化**（还在响），且**幅度与按住时同量级** |
| E2 | 同一次按键**不踩踏板** ⇒ 松键后回到静音（对照，防"假绿"） |
| E3 | 松踏板 ⇒ 音频在包络释放时间内衰减到静音 |

> E2 是**反向对照**：只有"踩 ⇒ 有声 且 不踩 ⇒ 无声"同时成立，才证明踏板真的在起作用（否则一个"永远出声"的坏实现也能过 E1）。

### 6.3 四道门（每步都跑）

1. 综合门：`ERROR=0`
2. 聚焦 tb：`tb_note_manager_sus` + `tb_sustain_pedal` + `tb_note_manager` + `tb_adsr` + `tb_envelope_bank` + `tb_transpose` + `tb_top_sound` + `tb_top_m0`
3. 干净 PnR：出 `.fs`、无 `PR0004`、`0/0`
4. 全量回归：「通过数 == 共数」

## 七、风险与回退

| 风险 | 应对 |
|---|---|
| 改 `note_manager` 碰到音高链（T3 影子数组） | 只加"每 voice 一位 + 两条 OR"，⛔ 不碰 `phase_tr`/`rot_cnt`/乘法器；聚焦 tb 里带 `tb_transpose` 复验 |
| 未连接的 tb 因 `Z` 误判成"踩下" | Z-safe（`===` 判 0）＋ 全量回归兜底（现有 13 个例化 `top` 的 tb） |
| 去抖参数不合适（机械踏板） | `DB_MS=5` 与现有按键一致；做成 parameter，上板可调 |
| 留音位泄漏（挂音） | 四条清零路径 + S4/S6 判据 + 全量回归里的 `tb_nm_no_leak`/`tb_looper_tail` 等防挂音 tb |
| 时序变差（不动时序的前提） | 只加 FF 与 OR，逻辑深度不增；PnR 后与 `56.351 MHz` 对照，若明显变差则报告（不自行优化） |

**回退**：本功能全部集中在 `note_manager.v` + `top.v` 两处，`git revert` 单个提交即可；实施前先 `git tag pre-sus/<日期>` 备份。
