## 六、附：怎么复现（30 秒）

1. 连 BLE → 打开上位机 → **确保在回传模式**
2. 手上弹几个音（**手弹路**，⛔ 不要放灌谱）
3. 中途发 1~4 次 `I` 切音色
4. 看回传统计那行 **「音色0数 / 乐音数」**：
   - 显示 `N / N` ⇒ 就是本邮件说的问题 ✅
   - 显示 `0 / N` 或部分 ⇒ 说明已带上，请告诉我们（我们就撤这条）
