### 实测判据结果（2026-10-14 亲自跑过）

```
PASS: fx_delay (priming / hard bypass / dry mix / echo timing /
      feedback decay / chorus modulation / saturation / stream)
```

| 覆盖的契约 | 内容 |
|---|---|
| priming | 延迟线填满前湿声保持静音（防开机"半截回声"） |
| hard bypass | `fx_en = 0` 时输出与输入**逐位相同** |
| dry mix | `mix = 0` 时输出与输入**逐位相同** |
| echo timing | 回声精确落在配置的延迟上（65280 拍） |
| feedback decay | 每次重复都更小，两次重复之间没有杂音 |
| chorus modulation | 抽头随 LFO 移动、双向、在配置深度内 |
| saturation | 高反馈时钳位而不是回绕 |
| stream | 一进一出、不丢不重、`valid_o` 不连续两拍高 |

### 设计要点

| 项 | 值 |
|---|---|
| 延迟线 | `AW = 14`，16384 样点 × 18 bit |
| 延迟时长 | 16384 ÷ 48828.125 = 335.5 ms |
| BSRAM | 16384 × 18 = 294 912 bit ÷ 18 432 = 16 块 |
| 挂载点 | `tdm_render_mixer` → `fx_delay` → `master_mix` → `i2s_tx` |
| 为什么在 `master_mix` 之前 | 音量关到底时回声也一起消失，与真机一致 |
| 流水线 | 4 级（N..N+4），`valid_i` 须为脉冲、间隔 ≥4 clk（真实链路 1024 clk/样点） |
| 18 bit 而非 24 bit | 量化底噪约 −108 dBFS，远低于 DAC 本身，多花 6 块换 6 个低位不值 |

## 三、拟新增的效果

### 3.1 失真 / Fuzz

失真是**无记忆非线性**，只看当前一个样点，所以 **BSRAM = 0**。

```
y[n] = f( x[n] )
```

用户裁定（2026-10-14）：**先只做硬削，留三个空位。**

| 档 | 做法 | DSP | LUT | 本期 |
|---|---|---|---|---|
| 硬削 | `xg = x×gain`（gain 取 1/2/4/8，用移位）→ `clamp(xg, −T, +T)` | 0 | ~60 | 做 |
| 空位 1 | 软削：分段线性 `\|xg\|>a ⇒ y = a + (\|xg\|−a)>>1` | 0 | ~150 | 留位 |
| 空位 2 | Fuzz：非对称阈值（`T1 ≠ T2`） | 0 | ~100 | 留位 |
| 空位 3 | 预留（位压缩 / 过载 / 自定义曲线） | — | — | 留位 |

软削不要用三次方（`y = x − x³/3`），那要 2 个乘法器，不值。

"留位"的准确含义：只留接口/参数槽位，不实例化逻辑，零资源成本。

#### 三个必须做的细节

| # | 细节 | 为什么 |
|---|---|---|
| 1 | 输出电平补偿 | 失真把 RMS 抬起来，不补偿会顶到 `master_mix` 的饱和 |
| 2 | 挂载顺序：失真在时间类效果之前 | 与真实效果器链一致（drive → modulation → time） |
| 3 | DC 阻断器（**留接口**） | 非对称削波会引入直流偏置，顶掉功放动态余量。一阶高通 `y = x − x_prev + 0.99×y_prev`，移位近似约 40 LUT。本期只做硬削（对称），可先不做，但做 fuzz 时必需 |

#### 一个如实的取舍：不做过采样

失真会产生超过 Nyquist 的谐波，理论上有混叠。正经做法要过采样（需滤波器 + 更多资源）。建议不做，理由：混叠在失真里本来就是"脏"的一部分；资源换来的听感提升不明显；用户已裁定"评委听不出来差别"。

#### 增益可调（用户裁定：能调就调）

见 §6.4 的 EC11 两层设计。

### 3.2 音量颤音 Tremolo

核心洞察：`vibrato_lfo.v` 已经存在（音高颤音），复用它的 LFO 输出，只把调制目标从"相位增量"改成"幅度"。

用户裁定：**与音高颤音共用推子，用「推子功能键」切换。**

```
推子功能键（键盘 idx 5，等同 'J'）：
  按一下：推子的作用对象在【音高颤音】与【音量颤音】之间切换
  不需要额外推子，左手板推子数量不变
  状态由 WS2812 灯 5（推子功能灯）显示
```

| 项 | 评估 |
|---|---|
| 实现 | 在 `master_mix` 的增益通路上加一级 LFO 调制 |
| DSP | 0，幅度调制用移位（`sample >> k`，k 随 LFO 变） |
| LUT | 约 80~150 |
| BSRAM | 0 |
| 改动 | 要碰 `master_mix`，但它已有乘法器，可能 0 额外 DSP |
| 推子即参数 | 深度 / 速率，与音高颤音同一套交互 |

#### 在链里的位置：最后一级（紧挨 `master_mix`）

| 理由 | 说明 |
|---|---|
| 最便宜 | `master_mix` 已有乘法器，可能 0 额外 DSP |
| 音乐上正确 | 真实音箱自带的 tremolo 就是后级，调制整个信号（含回声） |
| 与推子同处一条增益链 | 用户要求共用推子，推子本来就在那条链上 |
| 互相独立 | 关掉延迟不影响颤音，关掉颤音不影响延迟 |

另一种味道是放在延迟之前（回声里带颤音）。将来要换只改 `fx_chain` 里的连线顺序，不用动 `fx_trem` 本体。

### 3.3 混响 Reverb

用户裁定：**暂时先不做，留位。**

| 做法 | 质量 | BSRAM | LUT | 本期 |
|---|---|---|---|---|
| 正经 Schroeder（4 梳 + 2 全通） | 像混响 | ~33 块 | ~800 | 不做 |
| 简易 2 梳（共用现有延迟线） | 像"短延迟+反馈"，不像真混响 | 0 | ~200 | 留位 |

"留位"= 只留第 4 个掩码位 + `fx_chain` 里留一个旁路占位，零资源成本。

若将来要做，优先做简易版（共用延迟线，零额外 BSRAM），但要如实说：简易版听感上不像音乐厅混响，只是"有空间感"。

## 四、效果器链架构

### 4.1 核心洞察：一条延迟线 + 多个抽头 = 多个时间类效果

```
            ┌──────────── 16384 样点环形缓冲（16 块 BSRAM）────────────┐
            │  写指针 ──►│                                              │
 dry ─►[失真]─►│      ▲30ms      ▲45ms          ▲335ms                 │─►[干湿]─► out
 (0 BSRAM)  │    混响梳1      混响梳2          延迟抽头                 │
            └──────────────────────────────────────────────────────────┘
                 合唱 = 对某个抽头做 LFO 调制 + 线性插值
```

四个效果共用同一条缓冲，只是读地址不同，BSRAM 只花一次。

### 4.2 链的顺序

```
dry ─►[失真]─►[合唱]─►[延迟]─►[混响·留位]─►[音量颤音]─► out
        ↑       ↑       ↑         ↑            ↑
        └───────┴───────┴─────────┴────────────┴── 各一个 enable 位
```

顺序依据：真实效果器链是 drive → modulation → time-based → 后级。失真先塑造谐波，调制再加动感，时间类铺空间，音量颤音在后级调制整个信号（含回声）。

混响那级留位不实例化，链上是直通，零成本。

### 4.3 每级的"零回归"保证

```verilog
out = en ? effect(in) : in        // 硬旁路，en=0 时数值逐位相同
```

- `fx_delay` 的判据已证："with fx_en=0 the output is bit-identical to the input"
- 全部 enable = 0 时输出与今天数值逐位相同，169 个 tb 不受影响

一个要如实说清的细节：旁路走的是同一条流水线（`fx_delay` 里是 `fx_out = en_s2 ? mix_sat : dry_s2`，旁路取 `dry_s2`），数值相同，但时序差 4 拍 = 80 ns。相对 10 ms 的延迟预算可忽略。

### 4.4 接口改动（按"多留拓展性"设计）

```verilog
// 现在（uart_ui.v:106）
output reg  [1:0]  fx_sel_o,        // 只能选 1 个
// 改成
output reg  [7:0]  fx_en_mask_o,    // 8 bit 掩码
```

位分配（留了 3 位给将来）：

| 位 | 效果 | 本期 |
|---|---|---|
| `[0]` | 失真（硬削） | 做 |
| `[1]` | 合唱 | 做 |
| `[2]` | 延迟 | 做 |
| `[3]` | 混响 | 留位 |
| `[4]` | 音量颤音 | 做 |
| `[5..7]` | 预留（压缩 / 相位 / 均衡 / 八度…） | 留位 |

失真档位选择（留三个空位）：

```verilog
output reg  [1:0]  fx_dist_sel_o,   // 0=硬削(本期) 1=软削 2=fuzz 3=预留
```

### 5.3 按最终裁定重算（混响不实例化，零资源）

| 效果 | BSRAM | DSP | LUT | 本期 |
|---|---|---|---|---|
| 失真（硬削） | 0 | 0 | ~60 | 做 |
| 延迟 | 16 | 0 | ~300 | 做 |
| 合唱（复用延迟线） | 0 | 0 | ~150 | 做 |
| 音量颤音 | 0 | 0 | ~120 | 做 |
| 混响 | 0 | 0 | 0 | 留位 |
| 旁路 mux ×4 | 0 | 0 | ~80 | 做 |
| 电平补偿 + DC 阻断接口 | 0 | 0 | ~60 | 做 |
| 合计 | **16** | **0** | **~770** | |

```
加完预估：
  BSRAM  69 + 16 = 85 / 118   →  72%   宽裕
  DSP    22      = 22 / 118   →  19%   宽裕
  LUT  40731 + 770 ≈ 41501    →  69%   够
  CLS  25509 + ~480 ≈ 25989   →  87%   紧（余约 3 960）
```

LUT 到 CLS 的换算：实测比约 `40731 / 25509 ≈ 1.6`，所以 770 LUT 约 480 CLS。

**结论**：LUT 够用；CLS 会到 87%，紧但可行。若将来加混响（+200 LUT），CLS 会到 88%。

### 6.2 串口屏：FPGA 独立的一路，但与 PC 共用物理 UART

用户澄清 + RTL 核实：

| 事实 | 出处 |
|---|---|
| `rtl/w3c/uart_ui.v` 就是串口屏（淘晶驰 TJC X2）人机交互层 | 文件头 |
| 它挂在 `uart_rx`（D14/D15，PC 那路 USB-TTL） | `top.v` 例化 `u_uart_ui` 用 `ur_done`/`ur_data` |
| 已有指令表（文本指令）和 TX 通路 | `tx_start_o` / `tx_data_o` |
| **FPGA 现在不往屏上发** | `top.v` 把 `tx_busy_i` 钉死成 `1'b1`，注释"本版只接收屏的控制帧" |
| 屏的协议：返回帧统一 `0xFF 0xFF 0xFF` 结尾；帧头是返回码（`0x65` 触控 / `0x70`·`0x71` 参数 / `0x88` 握手） | `uart_ui.v` 文件头 |
| FPGA 与 ESP32 另有独立 UART | `esp_uart_tx_o`(G21) / `esp_uart_rx_i`(G22)，PMOD0 针 9/10。**已查清：收发都占满了** —— RX 是曲谱上传通路（`u_uart_rx_esp`），TX 是 14 B 实时上行帧（`u_evt_upstream`） |

用户裁定：**屏和 PC 共用一路 UART，所以做成二选一。**

设计要点：

- 加一个"串口归属"开关（模式位）：`PC 调试` 或 `屏`，二者互斥
- 归属屏时，`uart_rx` 的字节只喂 `uart_ui`；归属 PC 时只喂 `calib_cmd` / `evt_uart_rx` 等
- `uart_tx` 同样二选一，避免 PC 回包和屏指令混在一条线上
- 归属切换用键盘或 EC11，状态用一颗灯表示（避免"为什么串口没反应"的困惑）

**已确认（2026-10-14）**：ESP32 那一路（G21/G22）收发都已占用，屏无法改走那路，二选一是必需的。

### 6.3 WS2812 灯位：控制板 7 颗全满，但拓展板有 3 根预留

控制板 7 颗（`ctrl_ws_o` C22）已全部分配（`led_indicator.v` 权威）：

| 灯 | 用途 | 档位 |
|---|---|---|
| 0 | 音色 | 4 档（白/青/紫/橙） |
| 1 | 节拍器 | 绿，按拍点闪 |
| 2 | 鼓机节奏型 | 4 档（红/洋红/黄/橙红） |
| 3 | 键盘打鼓 | 蓝 |
| 4 | looper | 4 态（空闲暗蓝 / 录音红快闪 / 回放绿常亮 / 武装中黄快闪） |
| 5 | 推子功能 | 4 档（变调紫 / 颤音青 / 摇把黄预留 / 灭） |
| 6 | 指板/键盘 | 橙/绿 |

**拓展板另有 3 根预留**（`ws_strip_o[2:0]`，PMOD1 针 11/12/9，W19/W20/F19），现在恒 `3'b000`。

所以效果器显示**不用改硬件**，用一根预留带即可。

建议分配：

| 位置 | 显示什么 |
|---|---|
| 控制板灯 5（推子功能） | 扩展语义：变调 / 音高颤音 / 音量颤音 / 摇把。**复用现有灯，不新增** |
| 拓展板灯带 1 | 效果器光标位置（5 个效果，可用 5 颗灯或 1 颗变色表示档位） |
| 拓展板灯带 1（另一颗） | 当前链里各效果的开关状态 |

`led_indicator` 加一路的代价（规格文档 §49 已写）：子系统引出 2~3 位（约 5 LUT）＋ 表里加一个 case（约 30 LUT）＋ 灯序里加一颗。不需要动 PHY。

### 6.4 EC11 两层设计（含失真增益可调）

需要三种动作：移动光标、开关效果、调参数。一个编码器 + 一个按键要装下：

```
第 1 层（默认）：选效果
  旋转 = 沿链移动光标（失真 → 合唱 → 延迟 → 混响 → 颤音 → 回失真）
  短按 = 开关光标所在的那个效果

第 2 层：调参数
  旋转 = 调当前效果的参数
         失真：增益（档位或连续）
         延迟：时间 / 反馈 / 干湿
         合唱：速率 / 深度
         颤音：深度 / 速率
  短按 = 回到第 1 层
```

进入第 2 层的方式（三选一，待定）：

| 方式 | 优点 | 缺点 |
|---|---|---|
| 长按 EC11 切换层 | 不用额外按键，状态可用灯表示 | 需要记住当前在哪层（靠灯） |
| 键盘 idx 5 兼作层切换 | 与"推子功能键"共用，语义偏 | 一个键两种用途，容易混 |
| 另配一个键 | 最清晰 | 键盘 16 个已排满，只剩 idx 13/14 |

建议：**长按 EC11 切换层**，层状态用拓展板一颗灯表示。理由是键盘已经排满，而 EC11 长按在项目里已有先例（键盘 idx 12 就是长按清空 looper）。

失真增益的可调范围：硬削的 `gain` 取 1/2/4/8 用移位（零 DSP），所以档位是 2 位（4 档）。若要连续可调就得用乘法器，与"零 DSP"冲突，建议先用 4 档。

## 九、一句话总结

| 问题 | 答 |
|---|---|
| 能实现效果器链吗 | 能，而且便宜。串联本身只花约 80 LUT，贵的只有延迟线（16 块 BSRAM） |
| 失真简单吗 | 最简单。零 BSRAM、零 DSP，硬削只约 60 LUT |
| 音量颤音贵吗 | 不贵。复用 `vibrato_lfo`，约 120 LUT、零 BSRAM、零 DSP |
| LUT 够吗 | 够（69%），但 CLS 是瓶颈（会到 87%） |
| 混响要做吗 | 已定：暂不做，留位（留位 = 零资源成本） |
| 怎么自由选择 | EC11 旋转选 + 按压开关；长按进第 2 层调参数；WS2812 显示状态；串口屏显示详细链；键盘 LED 不参与 |
| 不用的效果器影响链路吗 | 音质不影响（旁路数值逐位相同）；时序差 4 拍 = 80 ns（可忽略）；资源照占（`en` 是运行期信号） |
