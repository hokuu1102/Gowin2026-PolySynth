> **收件人**：FPGA 线
> **提出人**：ESP32 线
> **紧急度**：🟡 **不阻塞**灌谱通路，但它决定"能不能灌一份正常鼓谱"
> **前置**：`ESP32侧追问-同时敲多个鼓与same_hit-20261014.md`
> —— 那份只问了 `same_hit` 这一半；**这份补上 `note_off` 那一半，并给了可直接灌的最小复现。**

---

## 〇、结论一句话

**下行灌谱的鼓（`axis 15` / `SRC_KDRUM`）同时只能响一件。**
两处 RTL 合起来才完整：`same_hit`（同轴同源 ⇒ 复用）＋ `note_off`（清掉所有同轴同源）。
⚠️ **PC 侧绕不过去**（`axis==15 ⇒ 鼓` 是 RTL 里写死的），所以只能请你们定方案。

## 一、问题事实

### 1.1 RTL 证据（两处，缺一不可）

**① `rtl/w3b/note_manager.v:720-722`** —— 同轴同源就复用（**对鼓没有豁免**）：

```verilog
assign same_hit[sg] = (gate_r[sg] | retrig_low[sg] | env_active_r[sg])
                    && (axis_r[sg] == cur_axis)
                    && (src_r[sg]  == cur_src);
```

**② `rtl/w3b/note_manager.v:1305-1321`** —— `note_off` 清的是**所有**匹配的 voice：

```verilog
// note_off：清掉【所有】同轴位且 gate 高的 voice（同源才清）
if ((gate_r[i] | retrig_low[i]) && (axis_r[i] == cur_axis) && (src_r[i] == cur_src))
    gate_r[i] <= 1'b0;
```

**③ `rtl/w3c/seq_arb.v:204`** —— 曲谱里 `axis 15` 一律打成鼓源：

```verilog
wire [NW-1:0] score_src_w = (score_axis_i == 4'd15) ? SRC_KDRUM : SRC_SCORE;
```

⇒ 而**四件鼓（kick/snare/hihat/tom）共用 `axis 15`**（我方上位机就是按你们 2026-10-14 答复
"四件共用 AXIS_ID=15，靠 phase_inc 区分" 发的），**源也相同**。三条合起来的后果：

| # | 情形 | 结果 |
|---|---|---|
| a | **同一 tick 敲两件** | 第二件命中 `same_hit` ⇒ 复用第一个 voice ⇒ **只响一件** |
| b | **前一件还没释放时后一件进来** | 同上（`env_active_r` 也算命中，连释放尾巴都算） |
| c | **任何一个鼓的 `note_off`** | 清掉**所有**同轴同源且 gate 高的 voice ⇒ **把别的鼓一起掐掉** |

### 1.2 最小复现（可直接灌，3 个用例）

📄 `esp32/evidence/鼓机单声部-最小复现-20261015.hex`（12 个事件字，已用 `score_word.py` 校验）

| 用例 | tick | 事件 | 若是多声部应听到 | 若是单声部（我方结论） |
|---|---|---|---|---|
| **A** 同一 tick 敲两件 | 0 / 480 | kick ON + hihat ON，480 后都 off | 两件都响 | **只响一件** |
| **B** 前一件没释放 | 1920 / 2400 / 2880 / 3840 | kick ON（长）→ 2400 hihat ON | kick 的长音不被打断 | **kick 在 2400 被顶掉**（长音变短） |
| **C** 对照：不重叠 | 5760 / 6240 / 6720 | kick ON（6240 off）→ 6240 hihat ON | 两件都响 | **两件都响**（⭐ 这条是**对照**，证明不是"鼓根本不响"） |

（`python gen_drum_probe.py --out <路径>`，内部就是按 64 位布局直接打包）

### 1.3 为什么这件事重要

**标准 funk/rock 鼓型要求同时发声。** Berklee 的鼓教材
（[Funk and Rock Drum Rhythms](https://online.berklee.edu/takenote/basic-funk-for-drums/)）
给的定义是：**底鼓落 1/3 拍、军鼓落 2/4 拍、踩镲连续八分**——
底鼓与踩镲必然同 tick 或重叠。⇒ 在本硬件上**这种鼓型打不出来**。

我方实测（本测试曲，`esp32/evidence/四音色鼓机变速测试曲-20261015/`）：

- 鼓**必须写成"一条线"**：每个八分音符上最多一件，且相邻落点间隔 **≥ 480 tick**
  （480 = 鼓的 note 时长；比它近，后一下就会被前一下的 `note_off` 掐掉）
- 只要写成"一条线"，上板就没有缺件、没有互相切
- ⇒ 结论：**约束是真的**，我方已按它写谱，但代价是鼓永远是"单声部音序器"的味道，
  ⛔ 做不出正常鼓组的律动

### 1.4 PC 侧为什么绕不过去

- 改轴号：`axis 15` 之外的轴会被 `seq_arb.v:204` 判成 `SRC_SCORE` ⇒ 鼓变成乐音
  （这正是 2026-10-14 修过的老问题，⛔ 不能回退）
- 改时长：note 时长就是 gate 长度 ⇒ 加长会让"前一件还没释放"的窗口更大，
  **反而制造更多 1.1(a)(b) 的撞车**（我方实测过，见下）
- 拆成多条轨：⚠️ 我方上位机的鼓轨最终都会落到 `axis 15`（这是判"是不是鼓"的唯一判据）

> 实测记录：我方试过把鼓时长从 480 加长到 1920，结果相邻鼓之间全变成重叠，
  缺件反而更严重；**480 tick 是"不撞车"与"不切音"两条约束的交点**。

## 二、需求：三个方案，请挑一个

### 方案 A（我方推荐）：鼓 voice 改成"一次性"，并让 `same_hit` 对鼓再比 `inc`

1. **鼓不吃 `note_off`**：`cur_src == SRC_KDRUM` 时跳过 `ST_DECIDE` 的 off 分支
   ⇒ 鼓由自己的包络跑完自动释放（这样**不违反 T38 防挂音纪律**——释放由包络负责）
2. **`same_hit` 对鼓再比 `inc`**：同轴同源但**不同音高 ⇒ 不复用**
   （与"四件靠 phase_inc 区分音色"的语义正好一致）

**好处**：鼓天然多声部；同一 tick 敲两件都能响；鼓花/齐奏正常
**代价**：需要确认"包络跑完自动释放"这条路径存在（见第三节问题 2）
**风险**：同时发声的鼓数变多 ⇒ 占 voice。⚠️ 请你们评估 `POLY_TARGET` 够不够
（我方实测：用户那份真实谱面的**鼓峰值并发 = 3**，见 `ESP32侧追问-同时敲多个鼓与same_hit-20261014.md` §1.2）

### 方案 B：四件鼓分到四个轴

例如 kick/snare/hihat/tom = `axis 12/13/14/15`，并相应放宽判据（如 `axis >= 12 ⇒ 鼓`）。

**好处**：改动小、语义清楚；`same_hit`/`note_off` 一个字都不用改
**代价**：
- `axis==15 ⇒ 鼓` 这个判据要跟着改，**双方要同时改**（我方上位机）
- 我方可用旋律轴从 15 条降到 12 条（⚠️ 实测某份真实谱面峰值并发 10，仍够用，余量变小）
- ⛔ 仍要小心：同一件鼓在同一 tick 敲两次（同一 inc）还是会撞

### 方案 C：只把 `note_off` 对鼓豁免（`same_hit` 不动）

**好处**：改动最小（一行判断）
**代价**：1.1(a)(b) 仍在 ⇒ **同一 tick 敲两件还是只响一件**
⇒ 我方认为 **C 只解决一半**，除非 A/B 都做不了
