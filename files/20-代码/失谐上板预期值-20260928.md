## 🔴🔴 一、先说一个会让你白跑的问题：**示波器设置必须改**

```
⭐ 现有设置（DS0006 那批）：50 ns/点 · 10000 点 ⇒ 窗口只有 【500 µs】
🔴 而拍周期是 【2.77 ~ 3.91 s】 ⇒ ⭐ 窗口差 【5500 ~ 7800 倍】 ⇒ ⛔ 根本看不到拍！
```

⭐ **必须改成**（要看到 ≥1 个完整拍周期）：

| 项 | 旧（DS0006） | ⭐ **新（本轮用）** |
|---|---|---|
| 时基 | 50 ns/点 | ⭐ **≈ 400 µs/点** |
| 水平档位 | — | ⭐ **≈ 400 ms/div**（10 div ≈ 4 s） |
| 采样点数 | 10000 | 10000（或长存储） |
| 窗口 | 500 µs | ⭐ **≈ 4 s** |

📌 ⭐ **或者用"滚动模式 / 长存储"** 抓 5 s，再量包络的**峰-峰间隔**。
📌 判据 D1 要的是"**相邻两个包络峰之间的时间**"，⛔ 不是波形周期。

## ⭐ 二、拍周期的客观预期值（⭐ 精确公式）

```
⭐ 第二个 osc 的增量 = base_inc + (base_inc >> DETUNE_SH)
   ⇒ f2 = f1 × (1 + 2^-SH)   ⇒ f_beat = f1 × 2^-SH
   ⇒ ⭐ T_beat = 2^SH / f1
```

⭐ **所以：`SH` 从 8 → 9 ⇒ 拍周期【精确加倍】**：

| `DETUNE_SH` | 公式 | C3 (130.81) | D3 (146.83) | F#3 (185.00) |
|---|---|---|---|---|
| **8**（改动前） | `256/f` | 1.957 s | 1.744 s | 1.384 s |
| ⭐ **9**（本轮） | ⭐ **`512/f`** | ⭐ **3.914 s** | ⭐ **3.487 s** | ⭐ **2.768 s** |

📌 ⭐ **与实测吻合**：交接文档记的「C3 1.957 s（误差 2.1%）· D3 1.744 s（误差 0.2%）」**正是 SH=8 的值** ✅

## ⭐ 四、拍谷深度的客观预期值（判据 D2）

```
⭐ 加权 (9:7) ⇒ 反相时 vs = (9−7)/16 = 1/8
   ⇒ ⭐ 拍谷 = 20·log10(1/8) = 【−18.06 dB】
   ⇒ ⭐ 线性比 = 【0.125】（即拍谷电平 ≈ 拍峰的 12.5%）
```

| 项 | 改动前 | ⭐ **本轮预期** |
|---|---|---|
| 拍谷 / 拍峰 | **0**（−∞ dB，完全抵消） | ⭐ **0.125（−18.06 dB）** |
| 包络 `min/max` | ≈ **0** | ⭐ ≈ **0.125** |

⭐⭐ **仿真侧已实测确认**（`tb_tdm_render_mixer` 的新增判据 3b）：
```
[wgt] same-phase = 527824   anti-phase = 65824
⇒ 比值 = 65824/527824 = 0.12471  ≈ 1/8  ⇒ −18.08 dB  ✅ 与设计值 −18.06 吻合
```
⇒ ⭐ **所以 D2 是【已被仿真证实】的判据**，上板只是复核。

## ⭐ 五、响度的预期（判据 D6 —— "有没有把功能弄丢"）

```
⭐ 时均 RMS² ∝ w0² + w1²
   旧 (0.5, 0.5)      ⇒ 0.5000
   新 (9/16, 7/16)    ⇒ 0.5078  ⇒ ⭐ +0.067 dB
⇒ ⭐ 【听不出变化】；⭐ `gain = 88` 标定【不需要重做】
```
⭐ **同相时电平【逐位不变】**：`(9+7)/16 = 1` == 旧 `(1+1)/2 = 1` ✅
