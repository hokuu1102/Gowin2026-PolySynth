## 最新结论

| 项目 | 本次实测 |
|---|---|
| 工具/器件 | Gowin V1.9.12.03，GW5AT-LV60PG484AC1/I0，B版 |
| 时钟 | 系统50 MHz直接输入，音频分频不变；既有HDMI PLL保留 |
| 内部实现目标 | 16.4 ns |
| sys / pixel / serial Fmax | 61.081 / 41.488 / 807.346 MHz |
| Setup / Hold | +0.028 / +0.142 ns，违例端点0/0 |
| Recovery / Removal | +0.134 / +0.440 ns |
| Logic / CLS / Register | 37886 / 24889 / 18609 |
| DSP / BRAM | 22 / 69 |
| 功能已有判据 | 20项选定测试通过，4/32声部共200000配置周期差分及注错守卫通过 |
| 新功能诊断 | 5类继承问题、7个断言失败；不是全量功能通过 |
| 实板 | 未验收，不自动烧录 |

对比 AT：sys Fmax增加0.075 MHz、CLS减少69，但Logic增加229、Register增加59。
Recovery裕量和pixel Fmax更小，不宣称所有时序指标改善。
28 ps是16.4 ns严格目标下的余量，不是实际50 MHz仅剩28 ps。
最差路径：录音命令 → looper计数/节拍与组合控制 → ramp_mask。
源产品、原始报告、测试日志和比对结果见 `evidence/at_merge_sta_20261014/README.md`。
SHA256清单对应实际测定工作区字节；跨平台检出可能改变CRLF/LF，产品逻辑对照以Git blob为准。

## 队友待修清单（本交付没有代改）

1. **A模式切换无效**：漏入合法命令判断。真实UART发送A后，accepted=0、unknown=1。
2. **滑音数据/有效握手不一致**：首次valid送出旧值0；收尾更新目标与撤销active同拍，最终值未送到voice。
3. **滑音声部身份未固定**：反向滑动更新另一轴，原轴停在旧音高。
4. **W关闭不取消正在运行的滑音**：开关关闭后仍有pitch valid。
5. **比例位置跟随未实现**：两轴行程固定60:40，音高仍趋向B，不停在40%位置。

同一诊断台在队友未合并版本9bf2de6和合并版上得到逐项一致的关键输出。
判据 `tb/top/tb_at_merge_known_bugs.sv` 实例化真实top；A走真实UART，其它案例是公共边界定向注入，
不是物理ADC手势或听感验收。当前运行该诊断台**应失败**，不得隐藏或计入验收通过数。
修复时可直接复测，并同时保留旧功能回归。

矩阵键盘模块仍未接top；原 `tb_ctrl_keypad` 在本机Icarus的continue处编译失败，
已在队友原版同样复现。此前文档引用检查仍有173处既有硬错误，不声称全仓库检查通过。
