## 一、⭐⭐ 项目现有模式（⭐ 实测，照抄这个）

### 1.1 ⭐ 标准写法（⭐ `tb_beat_gen.sv:496`）

```verilog
initial begin
    #600_000_000;
    $fatal(1, "FAIL: tb_beat_gen timeout");
end
```

⭐ **就这三行**。⚠️ 关键点：
* ⭐ **`$fatal`**（⛔ 不是 `$display` + `$finish`）⇒ ⭐ 它让 **`vvp` 返回非 0** ⇒ ⭐ **回归器判失败** ✅
* ⭐ **延时用下划线分隔**（`600_000_000`）—— ⭐ 项目惯例，⭐ 可读
* ⚠️ **这个 `initial` 与主流程的 `initial` 是【并行】的** ⇒ ⭐ 主流程 `$finish` 后它自然失效 ✅

### 1.2 ⭐ 附加模式：任务内 `guard` 计数（⭐ `tb_beat_gen` 也有）

```verilog
guard = guard + 1;
if (guard > 400000) begin
    fail("wait_tick timeout -- no tick within 400000 clk");
    disable wait_tick;          // ⚠️ 跳出该任务
end
```

⚠️ **这只用在"等事件"的地方**（⭐ `wait_tick`）——
⭐ **`T64` 的核心是【全局】**（⭐ 它兜住"任何原因卡住"）⇒ ⭐ **优先做全局那条**。

## 三、⭐⭐ 统一改法（⭐ 三选一）

### 做法 A ⭐⭐ **在每个 tb 里加一个 `initial`**（⭐ 最直接）

```verilog
// ⭐ 加在 tb 顶层（⭐ 与主 `initial` 平级）
//   ⭐ 看门狗：⭐ 正常路径绝不会跑到这里；⚠️ 挂死时立刻失败
initial begin
    #30_000_000_000;                                    // ⚠️ 按上表填
    $fatal(1, "FAIL: tb_calib_span timeout");
end
```

⚠️ **注意**：
* ⭐ **`$fatal` 的第二个参数**（⭐ 消息）**必须带 tb 名** ⇒ ⚠️ 否则回归日志里**不知道是哪个 tb**（⭐ 27 个都写 `"timeout"` 就分不清）
* ⚠️ **放在文件末尾**（⭐ 与既有 21 个一致）

### 做法 B ⚠️ **用 `` `define `` 抽出来**（⭐ 更省字，但 ⚠️ 要改编译）

```verilog
// ⭐ 在 tb/checkers/ 下加一个 `tb_watchdog.vh`
`define WATCHDOG(ns, name) \
    initial begin #ns; $fatal(1, "FAIL: `name timeout"); end

// ⭐ 每个 tb 里：
`include "tb_watchdog.vh"
`WATCHDOG(30_000_000_000, tb_calib_span)
```

| ✅ 好处 | ⚠️ 代价 |
|---|---|
| ⭐ **一行就够** | 🔴 **要改 `sim/tb_all.ps1` 加 `-I` 包含路径**（⚠️ 改回归器 = 影响全部） |
| ⭐ 改延时只改一处 | ⚠️ 宏的**调试体验差**（⭐ 报错指向宏而非 tb） |

### 做法 C ⭐ **在回归器里加超时**（⭐ ⚠️ 已经有）

⚠️ **`sim/tb_all.ps1` 的 `-TimeoutSec 120`**（⭐ 实测参数默认值）
⇒ ⭐ **但它只覆盖单个 tb**，⚠️ 且**超时了也不知道是"挂死"还是"跑得慢"**。

## 五、⭐⭐ 判据（⭐ 改完必须验）

| # | 判据 | ⭐ 怎么验 |
|---|---|---|
| **1** | ⭐ **正常路径 ⛔ 不触发**（⭐ 48/48 仍全过） | ⭐ 跑全量回归 |
| **2** | ⭐⭐ **真挂死时【能报】** | ⭐ **故意制造一次挂死**（⭐ 例：把某个 tb 的驱动删掉）⇒ ⭐ 应看到 `FAIL: <tb名> timeout` + **`vvp` 非 0 退出**<br>⚠️ **⛔ 不能只看"代码写了"** —— ⭐ 必须**反向验证一次** |
| **3** | ⭐ **消息里带 tb 名** | ⭐ grep 全部 27 个 `$fatal` ⇒ ⭐ **每个字符串都不同** |
| **4** | ⭐ **27 → 0** | ⭐ 重跑"无看门狗"统计脚本 ⇒ ⭐ 应为 0 |

⚠️ **第 2 条最容易被跳过** —— ⭐ 项目教训（⭐ 库里 **`U-2`**）：
> ⭐ `uart_rx` 的自检原来是 `$display` ⇒ 🔴 **不阻止任何东西**
> ⇒ ⭐ 改成 `$fatal` 后**特意写了探针 tb 反向验证**：
> * 喂 `BAUD_DIV=1` ⇒ ✅ **`FATAL: ... START_MID would wrap to 65535`**，⭐ **仿真被中止**
> * 正常配置 ⇒ ✅ **仍 PASS**（⛔ 没误伤）
> 📌 ⇒ ⭐ **本任务也要这样做**（⭐ 正反两面都验）。
