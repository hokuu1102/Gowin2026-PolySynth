## 三、⭐ 串口命令表（⭐ 500 kbaud）

| 键 | 作用 | 备注 |
|---|---|---|
| `T` | ⭐ **tare**（逐轴零点） | ⚠️ 需所有轴静止 |
| `S` | ⭐ **span**（满行程标定） | ⚠️ 需把所有轴按到底 |
| `X` | 中止标定 | |
| `M` | Test Mode 下一档 | ⚠️ 本码流 `TEST_MODE_EN=0` ⇒ ⭐ **实际不生效**；✅ **但回包已说实话**（P0-07 已修 ⇒ ⭐ **回 `'-'`**，⛔ 不再永远回 `'4'`）|
| `P` | ⭐ 回传 `pos` 读数（按轴选片） | 诊断用 |
| `V` | 回传 span 状态 | |
| `N` | 回传 calib 后的 `pos` | |
| `R` / `L` / `C` | ⭐ looper 录/放/清 | `R` 切换录音、`L` 切换回放、`C` 清该层 |
| `I` | ⭐ 切音色（0→1→2→3→0） | |
| `B` | ⭐ 节拍器开/关 | |
| `D` | ⭐ 鼓机节奏型（0→1→2→3→0） | |
| `K` | ⭐ 键盘打鼓 开/关 | |
| `F` / `G` | ⭐ 变调 −1 / +1 半音 | 可连发 |
| `H` | ⭐ 变调**带帧绝对量**（下一帧第一个载荷字节） | 裸 `H` 只"臂化" |
| `J` | 推子档位切下一档 | |

⚠️ **帧格式**：⭐ `0xA5` + 8 字节载荷（共 9 字节）· ⭐ **帧内间隔必须 < 320 µs**（⭐ 否则会归位 ⇒ 载荷被当命令 —— ⭐ 这正是 P0-05 修的东西 ✅）
