### ⭐ A 与 B 的区别（⭐ 最重要的一条）
- ⭐ **A（`=1`，默认）**：⭐ **必须接着右手板**才烧。它会扫第 3 片 ADC —— ⚠️ 没接板子会读到悬空通道 ⇒ **可能出幻影音**。
- **B（`=0`）**：⭐ **⛔ 只接左手板**时用。第 3 片 ADC **不扫描**。
- ⚠️ `RIGHT_ADC_ENABLE` 是**编译期参数**（`rtl/top.v:292`，⭐ 现默认 `=1`），**没有运行时开关** ⇒ ⭐ **两个码流不能互换烧**。

## 二、⭐ 逐码流的测试步骤与预期

### ⭐ A · `=1` 右手板默认档（⭐ **先烧这个** —— 交付树默认就是它）

⚠️ **前提：右手板必须接着**（⭐ 它会扫第 3 片 ADC ✅）。测试顺序：

| 步 | 操作 | ⭐ 预期（过/不过的判据） |
|---|---|---|
| A1 | 接线（⭐ **接右手板**）→ 上电 | ⭐ **绝对静音**（不碰任何键）；⭐ **心跳灯在闪**（⭐ "设计活着"的唯一见证） |
| A2 | ⭐⭐ **先查幻影音**：右手板推子/摇杆**一动不动** | ⭐ **⛔ 不许有任何音自己触发**（⚠️ 第 3 片刚接上，通道映射不对就会"没碰就响"）—— ⭐ **这一条不过就别往下测了** |
| A3 | 右手板推子（CH2/CH3） | ⭐ 颤音**深度/速率**跟随；⭐ ⛔ 不出现"倒放"怪音（P0-19） |
| A4 | 右手板摇杆 / 音量 | ⭐ 音高 / 音量跟随 |
| A5 | ⭐ 串口 `T`（tare）→ `S`（span） | ⭐ **片 2 的轴能标上**（⭐ `'P'` 可读片 2 的 pos）· ⚠️ 需所有轴静止 / 按到底 |
| A6 | 右手板按键 | ⭐ 音高对（⭐ 对照 `axis_map`） |
| A7 | ⭐ **满力度**（P0-01） | ⭐ 用力敲到最大 ⇒ **音量不掉**（🔴 改前瞬间掉到 −31 dB、带 ~1.5 kHz 颤音） |
| A8 | ⭐ **串口屏 + 演奏**（P0-02） | ⭐ 屏刷新数值的同时演奏 ⇒ **不出现"按所有键都清不掉的挂音"**（🔴 改前必现，⭐ 你实测过的症状） |
| A9 | ⭐ **命令分块发**（P0-05） | ⭐ 脚本把一条 9 字节命令**分两次 `write()`** ⇒ **不被当命令执行**（🔴 改前载荷里的 `'S'/'C'/'R'` 会被当命令 ⇒ 静默启动标定/清 loop） |
| A10 | ⭐ **HDMI 波形**（P0-18） | ⭐ 满幅信号**不再削平**（🔴 改前 −6.58 dBFS 就饱和：满幅正弦像方波、满幅方波**整屏纯绿**） |
| A11 | 力度 / 变调 / looper / 鼓机 / 节拍器 | ⭐ 逐项过（⭐ 见 §三 命令表） |
| A12 | 失谐拍频 | ⭐ 长音有 ~1.72 Hz 的缓慢起伏（⭐ 这是**设计**，⛔ 不是 bug） |
| A13 | 4 音色切换（`'I'`） | ⭐ 音色明显不同 |

🔴 **已知功能盲区（⭐ 诚实说）**：⭐ `=1` 档的**功能判据只到"第 3 片扫描通路是活的"**
（⭐ `tb/top/tb_right_adc.sv` 双实例差分 **7/7**）⇒ ⭐ **通道映射/标定对不对只能上板看** ✅
⚠️ 且硬件那边还有"右手板板/接线问题"未修（⭐ 10-08 诊断：极性正确、UP 不触发、DOWN 响应前推 ⇒ **非 RTL**）。

## 三、⭐ 串口命令表（⭐ 500 kbaud）

| 键 | 作用 | 备注 |
|---|---|---|
| `T` | ⭐ **tare**（逐轴零点） | ⚠️ 需所有轴静止 |
| `S` | ⭐ **span**（满行程标定） | ⚠️ 需把所有轴按到底 |
| `X` | 中止标定 | |
| `M` | Test Mode 下一档 | ⚠️ 本码流 `TEST_MODE_EN=0` ⇒ ⭐ **实际不生效**（⭐ P0-07 待修） |
| `P` | ⭐ 回传 `pos` 读数（按轴选片） | 诊断用 |
| `V` | 回传 span 状态 | |
| `N` | 回传 calib 后的 `pos` | |
| `R` / `L` / `C` | ⭐ looper 录/放/清 | `R` 切换录音、`L` 切换回放、`C` 清该层 |
| `I` | ⭐ 切音色（0→1→2→3→0） | |
| `B` | ⭐ 节拍器开/关 | |
| `D` | ⭐ 鼓机节奏型（0→1→2→3→0） | |
| `K` | ⭐ 键盘打鼓 开/关 | |
| `F` / `G` | ⭐ 变调 −1 / +1 半音 | 可连发 |
| `H` | ⭐ 变调**带帧绝对量**（下一帧第一个载荷字节） | 裸 `H` 只"臂化" |
| `J` | 推子档位切下一档 | |

⚠️ **帧格式**：⭐ `0xA5` + 8 字节载荷（共 9 字节）· ⭐ **帧内间隔必须 < 320 µs**（⭐ 否则会归位 ⇒ 载荷被当命令 —— ⭐ 这正是 P0-05 修的东西 ✅）
