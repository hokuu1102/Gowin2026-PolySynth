# 🚀 开工指南（**按底层先后顺序**）

> **本文件位置**：`files/20-代码/开工指南.md`
> **读法**：**从 L0 往上做，下层没通不要碰上层** —— 每一层的"验收标准"都是下一层的前提。
> **权威细节**：模块层次与接口表见 `RTL代码结构与接口规划.md`；模块边界见 `代码总览图.md`；**问题一律记进 `已知问题与风险清单.md`**（本文只引用 `K` 编号）。
> **一句话**：⭐ **RTL 可以全线开工，不依赖任何待定项**；卡住的只有 **CST/P&R**（等 `K-22`/`K-23`）和 **BSRAM 预算**（等 `K-28`）—— 它们只挡"上板"和"申报数字"，不挡写代码与仿真。

## L0 · 环境、目录与仿真脚手架 ✅

| 项 | 内容 |
|---|---|
| **做什么** | RTL 目录结构、`top.v` 空壳、**统一的仿真脚本**（照现有 `sim/run_tlc5916.ps1` 的样式，收敛成一条命令跑全部 tb）、`.cst` 占位 |
| **依赖** | 无 |
| **验收** | ⭐ 一条命令跑通全部 tb，**无 X 传播**；工程路径**全 ASCII**（中文路径会让综合报 `SORT-1002`） |
| **注意** | ⛔ 不用 PLL、不引第二时钟域（铁律）；⛔ 集成层文件（`top.v`/`clk_gen.v`/`top.cst`）改动要通知全员 |

## L1 · 时基 `clk_gen.v` ✅

| 项 | 内容 |
|---|---|
| **做什么** | 50 MHz → `MCLK 12.5 MHz`（÷4）、`BCLK 3.125 MHz`（÷4）、`LRCLK 48.828 kHz`（÷256） |
| **依赖** | L0 |
| **验收** | ⭐ 三个分频比精确为 **÷4 / ÷4 / ÷256**；⭐ **全部用 clock-enable，不做门控时钟、不产生第二时钟域**；无毛刺 |
| **注意** | 系统时钟脚用 **`V22`/`LVCMOS33`**（官方 60K 示例），⛔ **不是旧基石板的 `F13`**（`K-23`）；`F13` 那条如果写进 CST 一定过不了 |

## L2 · 音频输出 `i2s_tx.v` ✅

| 项 | 内容 |
|---|---|
| **做什么** | 按 `LRCK`/`BCLK` 把并行样点串出到 `I2S_DIN`；`PA_EN`（**低有效**）驱动 |
| **依赖** | L1 |
| **验收** | ⭐ testbench 喂固定样点，波形上 `BCLK`/`LRCK`/`DIN` 的相位与手算一致；改 `parameter` 能切 I2S / 左对齐与 `LRCK` 极性 |
| **参数化后门** | `I2S_MODE` / `LRCK_POL` / `DATA_BITS` —— 等 `K-24`（DAC 型号）定了只改 parameter |
| **⭐ 里程碑** | **M1：`i2s_tx` + L3 的最小 DDS → 板载 3.5 mm 耳机口听到干净持续音** |

## L3 · 最简发声单元（单振荡器 DDS） ✅

| 项 | 内容 |
|---|---|
| **做什么** | ⭐ **独立 `phase_acc[31:0]` + `phase_inc[31:0]`** + 波表查表 + 幅度 |
| **依赖** | L2 |
| **验收** | ⭐ 仿真里量出输出频率 = `phase_inc × fs / 2^32`；⭐ **改 `phase_inc` 变调时不清零 `phase_acc`**（`K-10`，清零 = 咔哒声） |
| **注意** | 「独立振荡器」的判据是 **相位/频率寄存器是否每路私有**；加法器/乘法器**允许 TDM 共享** |

## L4 · 包络 `adsr` ✅

| 项 | 内容 |
|---|---|
| **做什么** | 每 voice 独立 ADSR 状态机 |
| **依赖** | L3 |
| **验收** | 按键按下→起音→保持→松手→释音，波形包络形态正确；⭐ **每 voice 状态独立**（这是"独立发声单元"定义的一部分，⛔ 不能共用） |
| **⭐ 里程碑** | **M2：按键出声、松手衰减** |

## L5 · 参数与音高接口 ✅（已冻结）

| 项 | 内容 |
|---|---|
| **做什么** | 按 `W3接口冻结表.md` 落地两条通道：<br>① **音高**：**直接传 `phase_inc`**（`pitch_update_t`），**不传音名**<br>② **表情**：`expr_param_t` = `valid` + `axis_id` + `vibrato_depth` + `vibrato_rate` + `master_volume` + `timbre` |
| **依赖** | L3/L4 |
| **验收** | 接口与冻结表**逐字段一致**；⛔ 结构体里**不得再出现 `pitch_fine`**（已于 2026-09-16 删除，`K-04`） |
| **注意** | ⛔ **颤音不走 `pitch_update_t`** —— 那要求 ≥1 kHz 更新率，精度反不如内部 LFO，还白占带宽 |

## L6 · 复音与复用 ✅（⚠️ 先做保守版）

| 项 | 内容 |
|---|---|
| **做什么** | `POLY_TARGET` / `OSC_PER_VOICE` 参数化；N 路 voice 并行；加法器/包络乘法器 **TDM 共享**；混音 + 饱和 |
| **依赖** | L3/L4/L5 |
| **验收** | 32 复音无溢出、无丢样；⭐ **综合报告里能数出对应数量的独立相位/包络状态寄存器** |
| **⚠️ 关键后门** | ⭐⭐ **波表 ROM 先按"每 lane 独立 ROM bank"实现**（`K-28` 未定）—— 保守版在**两种答复下都安全**；若先做共享版而官方说不算，**代码要推翻重写** |
| **⛔ 别急着做** | 效果器（合唱/延迟）**先不做**，它和吞吐量抢 BSRAM，`K-28` 定之前不宜占 |
| **⭐ 里程碑** | **M3：Test Mode `4/8/16/32`，频谱能数出 N 个独立谱峰** |

## L7 · 控制量（映射到合成参数） ✅

| 项 | 内容 |
|---|---|
| **做什么** | ① ⭐ **数字音量对数映射**（`B10K` 线性 ⇒ 32~64 点查表，`K-09`）<br>② ⭐ **颤音 LFO**：速率 1–12 Hz、深度可调（`K-11`）<br>③ **变调**：只改 `phase_inc` |
| **依赖** | L5 |
| **验收** | 音量：输入 0 → 静音、满量程 → 满幅，**相邻档差值≈常数百分比**（听感线性）<br>颤音：**深度两端有死区 + 迟滞**（否则阈值附近断续）；**速率变化有斜率限制**（否则听到音高跳变）<br>变调：连续变调无咔哒声 |
| **注意** | 曲线放**固件**里，⛔ 不要靠换电位器 |

## L8 · 采集链 `adc_spi_master` → `chan_scan` → `calib` ✅

| 项 | 内容 |
|---|---|
| **做什么** | SPI 主机读 3 片 `MCP3208`；通道时隙扫描；逐通道零点/灵敏度标定 |
| **依赖** | L0（不依赖合成核心，可与 L3~L7 并行） |
| **⭐ 已冻结的硬件事实** | ① **3 组各自四线**：`SCLK`/`MOSI` 可在 FPGA 内同一调度器生成后**扇出**，但 **`MISO` 必须是 3 个独立输入**（⛔ 不能并、`K-05`/`K-06`）<br>② **每片各自一个 `CS`**<br>③ **节拍**：模拟 RC = `1 kΩ + 10 nF`（τ=10 µs）⇒ **整片帧 `0.5 ms`（每通道 2 kHz）**，⛔ 不再有"每通道 ≥5 ms"（`K-07`）<br>④ `MCP3208` 的 `VCC` = `VREF` = `3V3` → **比例式换算**（`K-16`）<br>⑤ ⛔ **灯的移位 `CLK` 与 ADC 的 SPI `SCK` 不是同一条**（`K-13`） |
| **验收** | testbench 里放**假 `MCP3208` 从机模型**（按 `DS21298E` 的 `Start/SGL/D2..D0/Null/B11..B0` 帧回数据），`chan_scan` 的通道索引与数据一一对应；⛔ 三片**不能同时被选中** |
| **注意** | ⭐ 通道编号**照抄 `files/10-硬件/` 的硬件文档**（`K-17`），⛔ 不要按物理顺序假设 |

## L9 · 人机底层 ✅

| 项 | 内容 |
|---|---|
| **做什么** | ① `debounce`（**编码器 A/B/SW、4 按键**，直连 FPGA，无并串器件）<br>② **OLED `SSD1306`/SPI** 驱动（`D0/D1/RES/DC/CS`，⛔ 只写不读，SPI mode 待确认 `K-14`）<br>③ **4 个双色灯**（共阳，1 片 `TLC5916`）+ ⭐ **给现有驱动加 `OE` 安全门控** |
| **依赖** | L0 |
| **验收** | 去抖：注入抖动序列，**只产生一次事件**<br>⭐ TLC 用例必须含 **"注入单周期 `OE` 误脉冲"** 并证明输出不受影响（`K-01`）；**`OE` 低才亮**（`K-02`）、**`LE` 移位期间为低**（`K-03`）、**移位 `CLK` 不与 SPI `SCK` 共用**（`K-13`） |
| **后门** | 端口分组（`SDI×3` 独立 + `CLK/LE/OE_n` 共用或分开）**先按一种实现并留增删位**（`K-32`）；等板 B 画完再冻结（`K-33`） |
| **⛔ 今天就该做** | **给 `tlc5916_driver.sv` 加 guard** —— 这是唯一"已有代码就带隐患"的事 |

## L10 · 映射与演奏语义 ✅（已定）

| 项 | 内容 |
|---|---|
| **做什么** | ⭐ **两种模式共用同一张音高表**（模式切换只换第 1 层映射）：<br>· **键盘模式**：**轴过阈值即响**（自动 Note On）<br>· **指板模式**：**先选轴，拨弦（`UP`/`DOWN` 事件）才响**<br>+ `UP`/`DOWN` **同时有效时优先 `UP`**（`K-19`）<br>+ **Test Mode**：启用前 N 个 lane，`4/8/16/32`（`64` 只留参数位，`K-21`/`K-29`） |
| **依赖** | L5 + L7 + L8 |
| **验收** | ⭐ 两种模式切换时**音准天然一致**（同一张表）；⭐ 拨弦事件延迟 = `LM393` 直路 **µs 级**（前提：比较器接 `PICK`，`K-08`）；Test Mode **现场可切档**且视频里读得出 `N` |
| **注意** | 滑音不在这条参数量里 —— 走"相邻轴位双压插值"在映射层算出 `phase_inc` |
