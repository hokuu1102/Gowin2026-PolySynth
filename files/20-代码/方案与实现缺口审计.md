## 三点五、⭐⭐ 「`adc_spi_master` / `chan_scan` 不存在」是**误判**（2026-09-22 夜核实）

> **背景**：⚠️ 本文 §一 原把 W3a 列为"缺 6 个模块"，⭐ **但其中 2 个的功能其实早已实现**。
> ⭐ **本节是核实记录** —— ⛔ **不要再去新建 `adc_spi_master.v` / `chan_scan.v`**（重复劳动）。

**⚠️ 教训**：⭐ **"文件名不存在" ≠ "功能不存在"**。
⭐ 本文档 §一 的方法论是「**用脚本扫模块名**」⇒ ⚠️ **只能发现"名字对不上"，发现不了"功能已并入别的文件"**。

### 核实证据链

| # | 证据 | 内容 |
|---|---|---|
| **1** | `rtl/drivers/adc_farm.sv`（9159 B） | ⭐ **只有一个 `module adc_farm`**，端口完整覆盖 T11/T12 全部要求 |
| **2** | 端口签名 | ⭐ `adc_cs_n[N_ADC]` · `adc_sclk[N_ADC]` · `adc_mosi[N_ADC]` · ⭐⭐ **`adc_miso[N_ADC]`（每片独立 ✅ 满足硬约束）** · `sample_valid` · `sample_ch[2:0]` · `sample_data_packed` · `frame_done` · `fault` |
| **3** | `tb/drivers/tb_adc_farm.sv` **存在** | ⭐ 且 `sim/tb_all.ps1:56` 是**自动发现** `tb/**/tb_*.sv` ⇒ ⭐ **它就在那 33/33 通过里** |
| **4** | `files/00-总览/第二周/任务清单.md:39-40` | T11/T12 标 ✅，⭐ 写明"片 0 `mcp3208_scanner` 当主控、CS/SCLK/MOSI **同源扇出**、三路 MISO **独立经 `sync_input` 2 级同步（K-62）**、影子反串行器锁步取 12 位" |
| **5** | 同文件 T12 验收文本 | ⭐ **"帧周期 25_000 周期 = 0.5 ms（实测 `tb_adc_farm` 帧间隔精确 500000 ns）"** |
| **6** | `files/20-代码/给队友的审查反馈.md:109-114` | ⚠️ **审查者当时就提过这个问题**，⭐ 建议把验收文本改成"由 `adc_farm` + `mcp3208_scanner` 达成（`chan_scan.v` **未单独实现**）" |

### ⭐ 结论

| 设计文档点名的 | 实际情况 |
|---|---|
| `adc_spi_master.v` | ✅ **功能已实现** —— 并入 `rtl/drivers/adc_farm.sv`（三片并行总控） |
| `chan_scan.v` | ✅ **功能已实现** —— 并入 `adc_farm`（并行三片）+ `mcp3208_scanner.sv`（片内通道扫描） |

⭐ **两者均已通过单测（M21/M22 变异体被抓）** ⇒ ⭐ **不是"从未创建"，是"已交付但改了名字"**。

### ⚠️ 因此 W3a 的真实缺口是 **3 个（语义层）**，⛔ 不是 5 个

⭐ **采集的【物理层】已经有了**（ADC → 数字样本，0.5 ms 一帧）；
⭐ **缺的是【语义层】**（样本 → 音符事件）：

```
ADC 样本 ──[已有 adc_farm]──> sample_data / sample_ch
                                    │
                                    └──🔴 缺 axis_map      : 轴位 → phase_inc
                                       🔴 缺 event_extract : 触发/拨弦/不应期
                                       🔴 缺 param_extract : 力度/颤音/表情
                                              ↓
                                        note_manager（已有）
```

⭐ **这条结论直接影响排工**：⚠️ 若按"5 个模块"排，会在**已完成的采集层上浪费工时**。
