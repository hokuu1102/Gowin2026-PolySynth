## 0. 确认板子在广播（只要插着 USB）

⭐ 一条单行命令（不含换行，可直接粘贴）：

```powershell
cd C:\Users\hokuu\Desktop\FPGA\FPGA2026-esp32\esp32\tools; python -X utf8 read_log.py --port COM29 --baud 115200 --seconds 4 | Select-String 'advertising|set_rand_addr'
```

⚠️ 端口会漂 ⇒ 先用上面 0-A 的办法查 ESP32 实际的口，把 `COM29` 换成它。
⚠️ `read_log.py` 只有 `--port/--baud/--seconds/--reset/--save`
⇒ ⭐ **没有 `--grep`**，过滤用 PowerShell 的 `Select-String`（上面就是这样）。

**预期**：
```

advertising as "FPGA2026-Synth2"
```
⚠️ 地址每次上电**都不同**（这是设计如此 —— 绕开 Windows 的 MAC 级 GATT 缓存）。
⛔ 若没有这两行 ⇒ 板子没起来，先按 `build.ps1 -Action flash -Port COM29` 重烧。
