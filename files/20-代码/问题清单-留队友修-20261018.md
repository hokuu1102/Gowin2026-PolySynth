## P1 🔴 回传的 MIDI 把之前几次录制的内容也带进来了

### 现象
新录一段 → 按 loop 发送 → 上位机收到的 MIDI **包含之前几次录制的内容**，不是只有本次这一段。

### 复现步骤（关键：**不点清空**）
1. 录一段 loop（内容 A）
2. **不按清空**，直接再录一段新的 loop（内容 B）
3. 按 loop 发送
4. 看上位机收到的 MIDI

**实际**：A 和 B 混在一起
**期望**：只有 B

### 备注
- 录制过程中**没有点过"清空"按钮**，是直接重新录的新 loop
- 这条留给队友定位（⛔ 本轮不查代码）
