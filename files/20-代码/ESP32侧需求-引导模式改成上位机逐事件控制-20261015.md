# ESP32 侧需求：引导模式改成【上位机逐事件控制】（2026-10-15）

> **收件人**：FPGA 线
> **提出人**：ESP32 线（用户 2026-10-15 拍板：**这个功能放上位机做更符合直觉**）
> **紧急度**：🟡 **不阻塞**灌谱通路；但它决定"练习/引导模式"能不能真正可用
> **前置**：`ESP32侧需求-鼓机同时响多件（单声部问题）-20261015.md`（同一轮的相邻需求）

---

## 〇、需求一句话

**让"哪些音符只亮灯不出声"由【上位机逐事件指定】**，
而不是由 FPGA 的一个**全局**开关（现在的 `'U'` 指引模式）决定。

---

## 一、现状：为什么上位机现在做不到

### 1.1 上位机够不到命令口（已查证）

| 环节 | 事实 | 出处 |
|---|---|---|
| 命令解析器吃谁 | `u_calib_cmd.rx_done_i ← ur_done ← u_uart_rx` | `top.v:1203 / 1078-1088` |
| 那条线在哪 | **D14/D15 · J9 N26/N25**（USB-TTL 的口） | `constr/top.cst:376-379` |
| ESP32 接哪 | `G22` → `u_uart_rx_esp` → `esp_rx_done/esp_rx_data` → **只喂曲谱链**（`:1553`） | `top.v:1130-1140 / 1553` |
| 板载 USB-C | 🔴 2026-09-24 起 **BL616 那路 UART 不接了** | `constr/top.cst:343-369` |

⇒ 上位机（BLE → ESP32 → `G22`）**够不到 `calib_cmd`**，所以
**切不了 `'U'` 指引模式**，也**设不了节拍器 BPM（`'Q'`）**。

### 1.2 就算切得动，全局模式也满足不了需求

`top.v:5353`：

```verilog
.score_valid_i ((SCORE_UART_ENABLE & ~guide_only_r) ? ps_note_valid : 1'b0)
```

🔴 **门掉的是【整条曲谱流】** —— 而**鼓机（含我们想拿来当节拍器的鼓事件）走的是同一条流**
（`seq_arb.v:204` 只是把 `axis==15` 标成 `SRC_KDRUM`，**valid 还是 `score_valid_i`**）。
⇒ 引导模式一开，**节拍器也不响了** ✗

而且 LED 指引链吃的是**同一条流**：

```
play_seq.note_valid_o ─┬─> seq_arb（出声）
                       └─> guide_lamp（LED 指引）   ← top.v:6702
```

⇒ FPGA **无法区分**"这一轨只亮灯"和"那一轨要出声" ✗

## 二、需求：用保留位 `bit6` 当"仅指引"

### 2.1 位域现状（`bit[6:0]` 保留，现在必须写 0）

```text
bit 63..44 tick(20) · 43..23 inc(21) · 22..19 axis(4) · 18..11 vel(8)
    · 10..9 kind(2) · 8..7 timbre(2) · [6:0] 保留（必须写 0）
```

### 2.2 请你们做的事（就两处）

1. **解码 bit6**：`wire evt_guide_only = data[6];`（与其它字段同一处切片）
2. **路由**：
   - `guide_lamp.note_valid_i`（`top.v:6702`）= `ps_note_valid & evt_guide_only`
     ⇒ ⭐ **LED 只指引被标记的那一轨** ✅
   - 出声那一路（`seq_arb` 的 `score_valid_i`）= `ps_note_valid & ~evt_guide_only`
     ⇒ ⭐ **被标记的音符不出声** ✅

📌 **效果**：

| 谁 | bit6 | 结果 |
|---|---|---|
| 用户选中的**引导轨** | 1 | 只亮灯、不出声（自己弹） |
| **其余轨**（背景） | 0 | 正常出声 ✅（用户点名想要这个） |
| **节拍器**（鼓机事件） | 0 | 正常出声，且**跟着谱面变速**（tick 制）✅ |
| 全局 `'U'` 模式 | — | **可以不用了**（上位机逐事件决定） |

### 2.3 备选方案（若不接受动位域）

**方案 B**：保留全局 `'U'` 模式，只把**鼓（`axis 12..15`）从门控里豁免**：

```verilog
.score_valid_i ((SCORE_UART_ENABLE & (~guide_only_r | is_drum)) ? ps_note_valid : 1'b0)
```

- ✅ 引导模式里**节拍器能响**
- ✅ 上位机只上传"引导轨 + 节拍器"⇒ LED 只指引那一轨
- 🔴 **但背景轨就没有了**（全局门掉，背景轨要么不出声、要么不能上传）
- ⚠️ 还要解决"上位机够不到 `'U'`"（同 §1.1）

⇒ ⭐ **我方推荐 2.2（bit6）**：它一次把三件事都解决（选轨 / 背景 / 节拍器），
而且**改动量比方案 B 还小**（一个位 + 两处 `&`）。
