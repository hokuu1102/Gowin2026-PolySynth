### ⚠️ 为什么"凭印象"会错得这么离谱

```
⚠️ `W3接口冻结表.md` 里写的是【字段列表】：
   logic [3:0]  axis_id;    // ⭐ 顺序：axis → phase_inc → velocity → kind
🔴 而真实位【置】是**反过来的**（tick 占最高位、axis 在中间）
⇒ ⭐ **字段的"声明顺序" ≠ 它在字里的"位位置"** —— ⚠️ 这正是我踩的坑。
```

## 四、⭐⭐ 教训（⭐ 值得进经验库）

```
🔴 **跨模块的位域，必须回到【打包那一侧】核实。**
   ⛔ 不能：⚠️ 按接口表的【字段顺序】推位【位置】
   ⛔ 不能：⚠️ 凭印象（⭐ 我第一版就是这么错的）
   ✅ 应该：⭐ grep 打包函数里的 `*_SH` / `*_W` 常量 ⇒ ⭐ **那才是唯一真值**
📌 **一个更硬的判据**：⭐ 若两侧都有 RTL 实现（⭐ 如 `mid2evt.py` 打包 + `play_seq.v` 解包）
   ⇒ ⭐ **两边都 grep 一遍**，⭐ 一致才敢用。
⚠️ **这类错误的危险点**：🔴 **它不报错** ——
   ⭐ 曲谱照样"发出来了"，⚠️ 只是**轴号和音高全错** ⇒ ⚠️ 表现成"噪音"而不是"故障"
   ⇒ ⭐ `K-87` 同族：⭐ **路径能错却不可见**。
```
