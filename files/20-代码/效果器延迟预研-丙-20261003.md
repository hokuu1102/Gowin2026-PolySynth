## 〇、结论先说（TL;DR）

1. **Delay（回声）是唯一"资源可控、价值最高"的首发效果器**。混响（Reverb）需多条延迟线（≈600 kb）且算法复杂、合唱（Chorus）听感增益低——**先做单条可变延迟的 Delay**，把 BSRAM 环形缓冲这条骨架打通，后续效果器都复用同一套「环形缓冲 + 读写指针 + 干湿混合」结构。
2. **资源结论**：200 ms Delay @ 48.83 kHz × 24 bit = **234 kb ≈ 13 块 BSRAM**，占 60K 总量（2124 kb）的 **11%**——**放得下，且有充足余量**。当前 BSRAM 只用了 1 块（0.8%），几乎全空。
3. **挂载点**：`master_mix` 之后、`i2s_tx`（或外置 DAC 的 `i2s_tx_ext`）之前——即「干声主音量之后」的**总线级效果器**（全局一个，不分 voice），这样一条延迟线服务整个混音，资源最省。
4. **关键设计约束**：① 本项目单时钟域 + 无 PLL + 无门控时钟；② `valid` 流**不反压**（`master_mix` 透传），效果器必须**零插入延迟透传干声、延迟声走旁路**，否则会破坏「控制→出声 ≤10 ms」和「确定性无抖动」两条判据。

## 一、为什么是 Delay 先做（三选一）

| 效果器 | BSRAM | 算法复杂度 | 听感价值 | 首发建议 |
|---|---|---|---|---|
| **Delay（回声）** | 234 kb（200ms）/ 条 | ⭐ 低（一条环形缓冲 + 读写指针 + 反馈） | 高（明显可闻、易演示） | ✅ **首选** |
| Chorus（合唱） | 49 kb（3×1024×16） | 中（LFO 调制读指针） | 低（需精细听感才明显） | ⬜ 后置 |
| Reverb（混响） | ≈600 kb（4 梳状 + 2 全通） | 高（多级滤波器级联） | 中（需空间感场景） | ⬜ 后置 |

> 依据：`FPGA平台与资源评估.md` §3.8 已有同样口径（Delay 154kb@16bit / Reverb 600kb / Chorus 49kb）。
> 竞赛评分「拓展要求 2 点名要混响/延迟/合唱」——**Delay 是唯一能以最小资源换到「点名项命中」的**。

## 二、精确资源预算（60K，GW5AT-LV60）

### 2.1 器件基线（已核实，来自 `FPGA平台与资源评估.md` §3.4）

| 资源 | 60K 总量 | 当前占用 | 备注 |
|---|---|---|---|
| LUT | 59,904 | ~37% | 富余 |
| FF | 59,904 | ~22% | 富余 |
| **BSRAM** | **2124 kb（118 块 × 18 kb）** | **1 块（0.8%）** | ⭐ **几乎全空，效果器的最大空间** |
| DSP（乘法器） | **118** | ⚠️ 128 振荡器已让包络乘法吃紧 | ⭐ 效果器干湿混合**不能各占 1 个乘法器** |

### 2.2 延迟线容量 → 地址位宽 → BSRAM 块数

采样率 **fs = 48.83 kHz**（`LRCK = 48.83 kHz`，1024 clk 一帧），样点 **24 bit**。

| 延迟时长 | 样本数 D = fs×t | 24bit 容量 | 地址位宽 | BSRAM 块数（18kb/块） | 占总量 |
|---|---|---|---|---|---|
| 100 ms | 4,883 | 117 kb | 13 bit | 7 块 | 5.5% |
| **200 ms** ⭐ | **9,766** | **234 kb** | **14 bit** | **13 块** | **11%** |
| 300 ms | 14,649 | 352 kb | 14 bit | 20 块 | 16.5% |
| 500 ms | 24,415 | 586 kb | 15 bit | 33 块 | 27.6% |
| 1 秒 | 48,828 | 1,172 kb | 16 bit | 66 块 | 55% |

> ⚠️ **结论**：200 ms 是「听感足够 + 资源安全」的甜点。1 秒延迟吃掉 55% BSRAM，⛔ 不推荐（会挤压混响/合唱/波表的余量）。

### 2.3 干湿混合（Wet/Dry mix）的乘法器预算

- 干声 × (1−mix) + 延迟声 × mix = **2 次乘法**（各 24×8 bit，mix 用 8 bit 足够平滑）。
- 但 ⚠️ **DSP 只剩 118 个、128 振荡器的包络乘法已吃紧**（§2.1）。对策：
  1. **干湿混合用移位近似**：mix 取 `1/2`、`1/4`、`3/4` 这类 2 的幂组合（`>>1`/`>>2`），**零乘法器**；
  2. 或复用 `master_mix` 已有的 `gain_i × sample` 结构（那套「乘法 + 定标 + 饱和」是现成的、已验过 K-101）。
- **建议**：首发版用**移位近似 mix**（省 2 个 DSP），留乘法器给振荡器包络。

### 2.4 反馈（Feedback）系数

- 回声衰减系数 feedback ∈ [0,1)，每拍 `delayed = delayed × feedback`。用 8 bit 分数即可，1 次乘法（或移位近似）。
- 反馈路径**必须在环形缓冲内**（读出的延迟样点 × feedback 再写回，形成反复回声），这是「真回声」vs「单次重复」的区别。

## 三、挂载点与信号链

```
tdm_render_mixer (干声 dry_sample_o)
        │
        ▼
master_mix (主音量 + 静音斜坡)   ← ⭐ 现有，最后一册增益
        │  sample_o [24bit] / valid_o（不反压透传）
        ▼
┌─────────────────────────────────────────────┐
│  fx_delay (总线级，全局一个)                  │
│   干声: dry → 直通（零插入延迟）              │
│   延迟声: 环形缓冲读 → ×feedback → 湿声       │
│   输出: out = dry×(1−mix) + wet×mix          │
└─────────────────────────────────────────────┘
        │
        ▼
i2s_tx (u_i2s_tx)  +  i2s_tx_ext (外置 DAC)
```

**关键判断**：
- 挂 `master_mix` **之后** = 总线级，一条延迟线服务整个混音，资源最省（⛔ 不要挂 voice 级，128 个 voice 各一条延迟线会爆炸）。
- `fx_en`（使能）/ `fx_sel`（效果器选择）来自 `uart_ui` 的 `fx_en_o`/`fx_sel_o`——这两个接口**已在 `uart_ui.v` 留位**（当前恒 0），P4 预研后、第四周接真效果器时**只需把它们接进来**。

## 四、设计要点（遵守三条纪律）

1. **单时钟域 + 无 PLL + 无门控时钟**：环形缓冲读写都用 `clk` + `sample_tick_i` 节拍使能（`master_mix` 已有 `sample_tick_i` 的用法，直接复用）。
2. **零插入延迟透传干声**：`valid` 流不反压，`out_valid = valid_i`（干声当拍透传），延迟声走旁路不影响干声时序——这保住了「控制→出声 ≤10ms」和「确定性」两条判据（`端到端延迟预算` §⑥ 明确要求）。
3. **环形缓冲 = 读写两个指针**：写指针每 tick 自增写当前样点；读指针 = 写指针 − D（D = 延迟样本数）。**无需搬移数据**，这是 BSRAM 延迟线的标准做法（也是为什么资源只跟「深度」线性相关，不跟「时延×带宽」平方相关）。
4. **Verilog-2001**：Gowin 按 2001 编译，⛔ 用 SV 专有构造（`K-91`）。
5. **可观测性**（`K-106`）：读写指针、反馈系数、mix 档位都要引出，便于上板诊断「延迟没生效」。

## 五、接口契约草案（供第四周实现参考）

```
module fx_delay #(
    parameter integer SAMPLE_W = 24,     // 样点位宽
    parameter integer DELAY_SAMPLES = 9766,  // 200ms @ 48.83kHz
    parameter integer ADDR_W = 14        // = clog2(DELAY_SAMPLES)
) (
    input  wire                     clk_i,
    input  wire                     rst_n_i,
    input  wire                     sample_tick_i,   // 节拍使能（复用 master_mix 的）
    input  wire                     valid_i,
    input  wire signed [SAMPLE_W-1:0] sample_i,
    input  wire                     fx_en_i,         // ← uart_ui.fx_en_o（第四周接）
    input  wire [7:0]               mix_i,           // 干湿比（Q0.8，[0,1)）
    input  wire [7:0]               feedback_i,      // 反馈系数（Q0.8，[0,1)）
    output wire                     valid_o,
    output wire signed [SAMPLE_W-1:0] sample_o,
    output wire [ADDR_W-1:0]        wr_ptr_o,        // ⭐ K-106 可观测
    output wire [ADDR_W-1:0]        rd_ptr_o
);
```

## 七、待核实项（不改结论，仅影响精确数字）

| # | 项 | 影响 |
|---|---|---|
| 1 | GW5A-60K 的 BSRAM 单块**实际可用位宽**（18 kb 是否为纯数据、有无奇偶位占用） | 块数可能有 ±1 的偏差 |
