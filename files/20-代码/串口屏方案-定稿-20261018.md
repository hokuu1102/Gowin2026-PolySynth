# 串口屏方案 · 定稿（2026-10-18）

> 本文是**给串口屏开发用的最终规格**，取代此前所有版本的串口屏文档。
> 内容只描述**当前方案**，不包含历史取舍与已废弃内容。
>
> **配套**：FPGA 侧接口（命令、帧格式）由 FPGA 线提供，本文只定义**屏要显示什么、怎么交互**。

---

## 1. 总体

| 项 | 值 |
|---|---|
| 屏数量 | **2 屏** |
| 尺寸 / 分辨率 | 7 寸 · **1024 × 600** |
| 通信 | 与 FPGA **共用调试串口**（`D14` / `D15`） |
| 波特率 | **500000**，8N1，无流控 |
| 屏的角色 | **显示状态** ＋ **开关效果器** ＋ **选择调节对象** |

```
屏 1  演奏与节奏
  └─[效果器]─►  屏 2  效果器链
```

---

## 2. 屏 1 · 演奏与节奏

### 2.1 显示内容

| 区域 | 显示内容 | 取值 |
|---|---|---|
| 音色 | 当前音色 | `BASS` / `GUITAR` / `PIANO` / `PAD` |
| 演奏模式 | 指板 / 钢琴 | `指板` / `钢琴` |
| 键盘打鼓 | 开 / 关 | `开` / `关` |
| 速度 | BPM 数值 | `40` ~ `240` |
| 节拍器 | 开 / 关 | `开` / `关` |
| 鼓机 | 开 / 关 ＋ 节奏型 | `开 I` / `开 II` / `开 III` / `开 IV` / `关` |
| 循环 | looper 状态 | `空闲` / `录音` / `回放` |
| 变调 | 当前半音偏移 | `-12` ~ `+12`，0 显示 `0` |
| 音高颤音 | 深度 | `0` ~ `100`（百分比） |
| 音量颤音 | 深度 | `0` ~ `100`（百分比） |
| 效果器总览 | 失真 / 合唱 / 延迟 各自的开关 | 三枚小圆点：亮 = 开，暗 = 关 |

### 2.2 ⭐ 进入屏 2 的入口

屏 1 **必须**放一个**明显的按钮**，文字 `效果器`：

- 点击 ⇒ 跳转到**屏 2**
- 按钮旁用三个小圆点显示"失真/合唱/延迟"的开关状态，**不用进屏 2 也能一眼看到有没有开**

### 2.3 屏 1 只显示，不改值

屏 1 上**不放任何可调节控件**（无滑条、无加减按钮、无输入框）。所有参数由 EC11 或推子改，屏 1 只反映结果。

## 3. 屏 2 · 效果器链

### 3.1 链的显示顺序

```
音高颤音 ──► 失真 ──► 合唱 ──► 延迟 ──► 音量颤音
```

5 个节点，从左到右排列，节点之间用箭头连接。

| 节点 | 可开关 | 参数 | 由谁调 |
|---|---|---|---|
| **音高颤音** | 无（深度 0 即为关） | 深度 · 速率 | **推子（档 1）** |
| **失真** | 是 | 增益 · 补偿 | EC11 |
| **合唱** | 是 | 长度 | EC11 |
| **延迟** | 是 | 长度 · 反馈 | EC11 |
| **音量颤音** | 无（深度 0 即为关） | 深度 · 速率 | **推子（档 2）** |

补充说明：

- **干湿比（mix）由合唱与延迟共用**，在屏上单独放一个控件，标注"合唱/延迟共用"。
- **音高颤音画在最左是准确的**：它作用在"音还没生成"的阶段，物理上位于整条音频链之前。
- **变调不在这条链上**，它由推子的另一档控制（见 4.2）。

### 3.2 ⭐ 点节点的行为：**翻转开关 ＋ 选中**

点一下节点，做两件事：

1. **翻转该节点的开关**（开 → 关，或 关 → 开）
2. **把它设为"当前调节对象"**（节点高亮，EC11 从此调它的参数）

```
点 [失真]  → 失真 开，选中失真，EC11 调增益
点 [合唱]  → 合唱 开，选中合唱，EC11 调长度
              ⭐ 失真【仍然开着】，不会因为你去看合唱就被关掉
再点 [失真] → 失真 关，仍选中失真
```

**因此：**

- 屏上**必须同时显示全部节点的开关状态**（不只高亮当前那个）
- 开关状态与"选中"是两件独立的事，**不能用一个高亮表示两者**

### 3.3 参数控件：**圆形旋钮式**

每个参数做成一个**圆形旋钮**，模仿真实旋钮：

- 优先使用屏控件库中的**圆形表盘 / 指针类控件**
- 若没有圆形控件，改用**圆弧进度条**（画一段圆弧，按比例填色）
- 若两者都没有，退回**横向进度条**，并在交付说明中注明

每个旋钮显示：参数名 ＋ 数值 ＋ 圆形指示。

### 3.4 颤音节点

音高颤音与音量颤音**没有开关**，因为它们的"关"就是深度为 0。

- 点它们 ⇒ **把推子切到对应档**（音高颤音 → 档 1，音量颤音 → 档 2），并选中
- 屏上显示它们的深度与速率
- **两个颤音可以同时生效**，屏上**同时**显示两者的数值

### 3.5 底部状态区

常驻一行，显示：

| 项 | 内容 |
|---|---|
| 当前对象 | 如 `失真 · 增益`、`音高颤音` |
| 推子档位 | `变调` / `音高颤音` / `音量颤音` |
| 推子是否锁定 | `锁定`（此时推子不改变数值）/ `实时` |

## 4. 交互约定（屏侧必须与 FPGA 一致）

### 4.1 EC11 旋钮：**只旋转，没有按压**

- 旋转 ⇒ 修改"当前对象"的数值
- **不存在"按压切换对象"这个动作** —— 对象只由**点屏**决定

### 4.2 推子：三档，由点屏切换

| 档 | 管什么 | 推子两路分别控制 |
|---|---|---|
| **0** | 变调 | 两路取**差值**：都在 0 = 不变调 |
| **1** | 音高颤音 | 左 = 深度，右 = 速率 |
| **2** | 音量颤音 | 左 = 深度，右 = 速率 |

- 点【音高颤音】⇒ 推子切档 1；点【音量颤音】⇒ 切档 2；点【变调】⇒ 切档 0
- 切换档位时，**另一档的数值保持不变**（两个颤音因此可以同时生效）

### 4.3 屏上的开关与 FPGA 的关系

- 开关的**唯一入口是屏**（EC11 没有按压动作）
- 屏本地维护开关状态并与 FPGA 同步；FPGA 侧的权威状态以回读为准

## 5. 数值更新与串口

### 5.1 更新策略

| 策略 | 说明 |
|---|---|
| **按需更新** | 数值**变化时**才发送，不周期刷新 |
| **总开关** | 提供一个命令用于开启/关闭屏的数值推送；默认**开启** |

采用按需更新，是因为屏与调试串口共用一条线；周期刷新会干扰调试输出。

### 5.2 屏侧不需要关心的

- 帧格式、校验、字节序 —— 由 FPGA 侧按屏的文本指令直接生成
- 屏只需按约定的**控件名**接收文本指令

## 6. 控件与触摸号约定（需屏侧确认后固定）

### 6.1 文本控件建议命名

| 位置 | 内容 | 建议名 |
|---|---|---|
| 音高颤音 | 深度 / 速率 | `p_d` / `p_r` |
| 失真 | 开关 / 增益 / 补偿 | `d_on` / `d_g` / `d_t` |
| 合唱 | 开关 / 长度 | `c_on` / `c_l` |
| 延迟 | 开关 / 长度 / 反馈 | `l_on` / `l_l` / `l_f` |
| 干湿（共用） | mix | `m_x` |
| 音量颤音 | 深度 / 速率 | `v_d` / `v_r` |
| 状态区 | 当前对象 / 推子档 / 锁定 | `cur` / `gr` / `lk` |

### 6.2 触摸控件号

| 号 | 点击后 |
|---|---|
| `0` | 模式 指板 / 钢琴 |
| `9` | 选中【音量颤音】⇒ 推子档 2 |
| `10` | 选中【音高颤音】⇒ 推子档 1 |
| `11` | 选中【变调】⇒ 推子档 0 |
| `12` | 失真：翻转开关 |
| `13` | 选中 失真·增益 |
| `14` | 合唱：翻转开关 |
| `15` | 选中 合唱·长度 |
| `16` | 延迟：翻转开关 |
| `17` | 选中 延迟·反馈 |
| `18` | 选中 干湿 mix |

控件号是**屏侧与 FPGA 侧的契约**，任一侧变更需同步另一方。屏侧若已有占用，请提供实际占用表以便调整。

---

## 7. 屏侧不需要做的内容

| 不做 | 说明 |
|---|---|
| 测试模式入口 | 控制板已有对应按键 |
| 引导模式显示 | 由上位机灌谱决定，与屏无关 |
| 标定页 / 调试页 | 不做 |
| 混响节点 | 不做 |
| 滑条、输入框、加减按钮 | 数值只由 EC11 / 推子修改 |
| 鼓机节奏型的图形表示 | 只用罗马数字 `I` `II` `III` `IV` |

## 8. 交付清单

1. **2 屏**：演奏与节奏 / 效果器链，1024 × 600
2. **屏 1** 含进入屏 2 的按钮，并显示三个效果器的开关状态
3. **屏 2** 链顺序：`音高颤音 → 失真 → 合唱 → 延迟 → 音量颤音`，5 个节点
4. **点节点 = 翻转开关 + 选中**；开关状态与选中状态分别显示
5. **参数用圆形旋钮式控件**（无圆形则用圆弧进度条，并在交付说明注明）
6. **鼓机节奏型用** `I` `II` `III` `IV`
7. **波特率 500000 8N1**
8. 交付时提供：**实际控件名表** 与 **实际触摸控件号表**
