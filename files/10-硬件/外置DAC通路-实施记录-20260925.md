### ③ ⭐ 变异体（⭐ 硬约束要求"加变异体"）

⭐ 新增 **M114 ~ M117**（⭐ `rtl/top.v` 的外置 DAC 通路）：

| ⭐ ID | ⭐ 变异 | ⚠️ 为什么值得守 |
|---|---|---|
| **M114** | ⭐ `I2S2_BCK` 改接 `I2S2_LRCK` 网 | 🔴 外置模块拿到 **LRCK 当 BCK** ⇒ 完全没位时钟 ⇒ **没声** |
| **M115** | ⭐ `I2S2_LRCK` 改接 `I2S2_BCK` 网 | 🔴 帧时钟跑到 3.125 MHz ⇒ 模块**永远看不到帧边界** |
| **M116** | ⭐ `sample_l` 改送**全 0** | 🔴🔴 **最危险的一种**：⭐ 时钟全对、⭐ 模块正常、🔴 **输出纯数字静音**<br>⇒ ⚠️ "**看着全活、就是没声**"（⭐ `K-87` 同族） |
| **M117** | ⭐ 把 `I2S2_DIN` 也强行并到帧时钟上 | 🔴 数据脚变成静态 ⇒ 模块收到垃圾 |

⭐ 变异体总数：**111 → 115**（⭐ 已确认脚本读到 `M114~M117`，⛔ 没有 `C72` 静默丢元素）

## 四、🔴🔴 接线前必读（⭐ 三条硬警告）

### ① 🔴🔴 **⛔ 绝对不能接到板载 `J5`**

```
⚠️ `U-26` 原文：⭐ "板载 `J5` 是 **BTL 输出** ⇒ ⛔ **不能接有源贝斯音箱（会烧！）**"
```

✅ **正确接法**：
```
⭐ `PMOD1_IO3/4/5`（`F20`/`E22`/`D22`）
   → ⭐ **`PCM5102A` 模块**（⭐ 3.3V 供电 + GND）
   → ⭐ 音箱的 **`Line In`**（⛔ 不是功放输入/BTL 输入）
```

### ② 🔴 **模块必须带【板载晶振】**

```
⭐ `PCM5102A` 可以不接 `MCLK`（⭐ 内部 PLL 从 BCK 恢复）
🔴 **前提：⭐ 模块带晶振** ⇒ ⛔ 否则**没声或爆音**
⇒ ⭐ 买模块时**确认这一条**（⭐ `U-26` 备注已写）
```

### ③ ⚠️ **`PA_EN_n` 保持不动**

```
⭐ 它仍接板载 `MAX98357A` 的 `SD_MODE`（⭐ 高 = 出声）
⭐ 且 `PA_ON_DELAY` 有"上电防啪声"的作用
⇒ ⭐ **保留**（⛔ 别删）—— ⭐ 它由 `K-42`/`R-16` 的守卫测着
```

## 五、⭐⭐ 上板验收（⭐ 模块到货后）

| # | ⭐ 判据 | ⭐ 怎么验 |
|---|---|---|
| **1** | ⭐ **示波器量 `F20`/`E22`/`D22`** | ⭐ `BCK ≈ 3.125 MHz` · `LRCK ≈ 48.83 kHz` |
| **2** | ⭐⭐ **音箱真的出声** | ⭐ 听（⭐ 板载那路**应同时**也有声） |
| **3** | ⚠️ **若声音"移位/噪声"** | ⭐ 调**外置这一路**的 `JUSTIFY`/`MSB_DELAY`（⭐ `C-6`）<br>📌 ⭐ **板载那路已验证是对的** ⇒ ⚠️ 优先动外置那路 |
| **4** | ⚠️ **若完全没声** | ⭐ 先查：⭐ ① 模块有没有晶振 ② 3.3V 供电 ③ 接的是不是 `Line In` |

📌 **最省事的排查**：⭐ **板载那路出声、外置没声** ⇒ ⭐ 问题在**外置接线/模块**（⭐ 因为两路信号是**逐拍相同**的）。
