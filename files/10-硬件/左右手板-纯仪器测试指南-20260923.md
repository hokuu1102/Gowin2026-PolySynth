## 一、⭐⭐ 先搞清楚：这块板上有哪些"可测点"

### 1.1 供电（⭐ 两路独立）

| 座 | 供电 | 给谁 | ⭐ 电流预算 |
|---|---|---|---|
| ⭐ **模拟电源** | **`5V_A` / `AGND`** | ⭐ **各板 LDO → `3V3_A`** ⇒ 供**8 路霍尔 + ADC** | ~80~100 mA |
| ⭐ **数字电源** | **`5V` / `GND`** | ⭐ **`TLC5916` + LED（大电流）** | ⚠️ 峰值较大 |

> ⚠️ **`VREF` = `3V3`，霍尔 `VDD` 也是同一路 `3V3_A`** ⇒ ⭐ **这是"比例式测量"**
> （`files/10-硬件/电源方案.md:156`）⇒ ⭐ **电源波动同时作用于传感器和基准 ⇒ 互相抵消**。

### 1.2 信号座

| 座 | 内容 | 针位 |
|---|---|---|
| ⭐ **`J3L` / `J3R`**（8P） | **SPI 到 FPGA** | ① `CS` ② `GND` ③ `MOSI` ④ `GND` ⑤ `MISO` ⑥ `GND` ⑦ `MCP_CLK` ⑧ `GND` |
| ⭐ **`LED_1`**（8P） | LED 到 FPGA | `SDI` / `CLK` / `LE` / `OE` + `GND` |
| ⭐ **供电 4P** | `5V`/`GND` + `5V_A`/`AGND` | 见 §1.1 |

> ⚠️ **供电【不在】`J3` 座上** —— ⭐ 走**独立的 4P 座**（⭐ 别在 `J3` 上找电源）。

### 1.3 板内关键节点（⭐ 万用表/示波器要量的地方）

| 节点 | 期望 | 在哪 |
|---|---|---|
| **`3V3_A`** | ⭐ **3.3 V ± 5%** | LDO 输出（⭐⭐ **先量这个**） |
| **`MCP3208.VDD`(15) / `VREF`(16)** | ⭐ **= `3V3_A`** | `U1` 脚 |
| **`MCP3208.AGND`(14)** | `AGND` | `U1` 脚 |
| **霍尔 `U3`~`U11`：`.1` = `3V3`、`.2` = `AGND`** | ⭐ **8 路都要有 3.3 V** | 逐颗量 |
| ⭐ **霍尔输出 `.3`** | ⚠️ **静磁下有中间电平**（见 §三） | ⭐ **`1 k` 串阻 → `10 nF` → `CHn`** |

| # | 测什么 | 怎么测 | ⭐ 期望 |

| **2** | 🔴 **`5V_A` ↔ `AGND` 短路？** | 同上 | ⛔ **不通** |
| **3** | ⚠️ **`3V3_A` ↔ `AGND` 短路？** | 同上 | ⛔ **不通** |
| **4** | ⭐ **`J3` 每根信号对 `GND` 的阻抗** | 万用表**电阻档** | ⭐ **不是 0 Ω**（0 = 短路） |

## 三、⭐⭐ 第 2 步 · 上电但不接 FPGA（⭐ 核心步骤）

### 3.1 给电（⭐ 用可调电源，⛔ 先限流！）

```
① 可调电源设 5.0 V，⭐ 限流先设【100 mA】（⚠️ 关键！）
② 接到【模拟电源 4P 座】：5V_A / AGND
③ 观察电流：
   ✅ 正常：~30~60 mA（空载，8 路霍尔 + LDO 静态）
   🔴 若瞬间撞限流 ⇒ ⚠️ 立即断电，查短路
④ 万用表量 3V3_A ⇒ ⭐ 应 3.3 V ± 5%
⑤ 再给【数字电源 5V】（⚠️ 如果只测霍尔/ADC，这路可以先不给）
```

> ⚠️ **为什么要限流**：⭐ 焊错时**限流能救板子** —— ⚠️ 无限流可能**烧铜箔**。

### 3.2 ⭐⭐ 量 8 路霍尔的【静态输出】（⭐ 这是最关键的一步）

**目标**：⭐ 证明**每颗霍尔都活着、且输出在合理区间**。

```
① 示波器 DC 耦合、探头 ×1
② 逐颗量【霍尔输出脚 `.3`】（⭐ 8 颗：U3/U5/U6/U7/U8/U9/U10/U11）
③ ⭐ 记录每颗的电压
```

| 观察 | 判定 |
|---|---|
| ⭐ **都在 1.0 ~ 2.5 V 附近** | ✅ **正常**（⭐ 霍尔静态输出通常是 `VDD/2` 附近） |
| ⚠️ **某颗 = 0 V 或 = 3.3 V（贴轨）** | 🔴 **该霍尔坏 / 虚焊 / 磁铁位置不对** |
| ⚠️ **某颗 = 浮空漂移** | 🔴 **`.3` 脚虚焊** |

> ⭐ **判据的物理依据**：霍尔是**比例式**输出 —— ⭐ **无磁场时约 `VDD/2`**。
> ⚠️ **本项目磁轴用的是"磁铁靠近/远离"** ⇒ ⭐ **按下去电压会明显变化**。
> ⇒ ⭐⭐ **所以第 3.3 步更重要：用手按一下，看电压变不变。**

### 3.3 ⭐⭐ 按一下键，看霍尔输出是否【跟着变】

```
① 示波器接某一颗霍尔的 `.3`
② ⭐ 用手（或磁铁）把这颗对应的磁轴【按下去/松开】
③ ⭐ 观察电压变化
```

| 观察 | 判定 |
|---|---|
| ⭐ **按下/松开有明显变化**（⚠️ 幅度视磁场而定） | ✅ **这颗霍尔 + 磁路都正常** |
| ⚠️ **完全不变** | 🔴 **磁铁没装 / 装反 / 霍尔坏** |
| ⚠️ **变化很小（< 100 mV）** | ⚠️ **磁铁距离太远** ⇒ ⭐ 记下来（⚠️ 可能要靠 `span` 标定补） |

> 📌 ⭐ **把每颗的"松手值 / 按下值"记进 §六 表格** —— ⭐ **这就是零点与量程的实测依据**。

### 3.4 ⚠️ 顺手确认：**别把两路霍尔并到同一通道**

⭐ 左手板评审记录里有一个**已修的致命缺陷**：*"8 路霍尔并到同一通道"*。
⇒ ⭐ **验证方法**：⭐ **按下第 1 颗时，只有 1 个通道电压变**。
⚠️ **若按一颗、两颗同时变** ⇒ 🔴 **仍并在一起**（⭐ 回查焊接）。

## 四、⭐⭐ 第 3 步 · 用信号源模拟 SPI，验证 ADC（⭐ 可选但很有价值）

> ⚠️ **这一步需要能产生 SPI 的源**。⭐ 若只有"可调电源+示波器+万用表",⚠️ **做不到完整读取**
> ⇒ ⭐ **但有【两个便宜办法】**：

### 4.1 ⭐ 办法 A：直接用【万用表量 `CHn` 直流电压】（⭐ 最简单）

⭐ **`CHn` 的电压 = 霍尔输出经过 `1 k` + `10 nF` RC 后的电压**。
⇒ ⭐ **把 §3.2/3.3 的测量挪到 `CHn`**（⭐ 即 ADC 的输入脚）,⭐ **这样量到的就是 ADC 真正看到的**。

| 测点 | ⭐ 期望 |
|---|---|
| `CHn`（`MCP3208` 的 1~8 脚） | ⭐ **= 霍尔 `.3` 的电压**（⚠️ 经 `1 k` 串阻，⭐ 空载时几乎不降） |
| ⭐ **换算** | ⭐ **码值 = `V / 3.3 × 4095`**（⭐ `VREF` = `3V3`） |

⚠️ **若某路 `CHn` 与霍尔 `.3` 差很多** ⇒ 🔴 **串阻/电容焊错，或该脚虚焊**。

### 4.2 ⭐ 办法 B：用【可调电源当 DC 信号源】注入 `CHn`

```
① 可调电源设【1.0 V】，⚠️ 限流 10 mA
② 通过 1 kΩ 串到某个 `CHn`（⭐ ⛔ 不要直接怼，⚠️ 防冲突）
③ 用万用表确认 `CHn` ≈ 1.0 V
```
⇒ ⭐ 这样明天 FPGA 到了,⭐ **预期 ADC 读到 `1.0/3.3×4095 ≈ 1241`**
⇒ ⭐ **成为上板时的"已知输入"基准**（⚠️ 比"随便按一下"严谨得多）。

### 4.3 ⭐ 办法 C：示波器看 SPI 时序（⭐ 明天 FPGA 到了再做）

⚠️ **需要 FPGA 产生 `MCP_CLK`/`CS`/`MOSI`** ⇒ ⭐ **本步今天做不了**,⭐ **已写进 `bringup/06`**。

## 七、⚠️ 常见故障 → 先查什么

| 现象 | 先查 |
|---|---|
| 🔴 **上电就撞限流** | ⭐ **立即断电** ⇒ 查 `5V`/`3V3` 对地短路（§2） |
| 🔴 **`3V3_A` 不是 3.3 V** | ⭐ LDO 虚焊 / 输入不足 / 负载短路 |
| 🔴 **某颗霍尔贴轨（0 或 3.3 V）** | ⭐ 该颗虚焊 / 坏 / 磁铁位置不对 |
| ⚠️ **按下电压不变** | ⭐ 磁铁没装 / 装反 / 霍尔方向错 |
| ⚠️ **两颗霍尔同时变** | 🔴 **通道并了**（⭐ 左手板曾有此致命缺陷，已修 ⇒ ⚠️ 回查焊接） |
| ⚠️ **`MISO` 电阻为无穷大** | ⭐ **不用管**（⭐ 已更正：FPGA 侧有内部上拉，`MISO` 上拉⛔ 非必需） |
