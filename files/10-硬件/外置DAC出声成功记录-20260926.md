| ⭐ # | ⭐ 纪律 | ⭐ 为什么 |
|---|---|---|
| **1** | 🔴 **有示波器就必须用示波器** | ⚠️ **万用表分不清"方波"和"直流"**：3.3V 方波 50% 占空比均值 = 1.65V，⭐ **而"引脚恒定 1.65V"读数完全一样** ⇒ ⭐ 我当初把 `1.707V` 当成"在翻转"是**无效证据** |

## 一、💡 正确的接线（⭐ 最终确认版）

| ⭐ 模块脚（`JP1`） | ⭐ 接到 | ⚠️ 备注 |
|---|---|---|
| `VCC`（×2） | ⭐ **5V** | 🔴 **⛔ 不是 3.3V**（模块有 `MIC5219` LDO，需要压差） |
| `GND` | GND | — |
| `LRCK` | ⭐ **`E22`** | ⚠️ 极易接错 |
| `DIN` | ⭐ **`D22`** | ⚠️ 极易接错 |
| `BCK` | ⭐ **`F20`** | ⚠️ 极易接错 |
| `SCK` | ⭐ **GND** | ⭐ 内部 PLL 需要它**确定地低** |
| `XSMT` | ⭐ **3V3** | 🔴 浮空 = 软静音 |
| `FMT` | ⭐ **3V3** | ⭐ = 左对齐（⭐ 实测出声的档） |
| `FLT` | GND | 安全值 |
| `DEMP` | GND | 安全值 |

### 🔴🔴 接线教训（⭐ 用户原话）

> ⭐ **"Console 的排针丝印有点反直觉，要注意一下"**

📌 **三根信号线必须【逐根】按丝印核对**，⛔ 不能按"位置顺序"推。
⚠️ 它们**在排针上挨着**（`JP1` 的 pin 3/4/5）⇒ **一次全接错**。

## 二、🔴🔴 格式：⭐ 模块要【左对齐】，⛔ 不是标准 I2S

### ⭐ 实测证据（⭐ 决定性 —— 三档 bitstream 逐个烧）

| ⭐ 档 | ⭐ 位序 | ⭐ 结果 |
|---|---|---|
| `FORMAT_SEL=0` | 标准 I2S（MSB **延后 1** BCK） | 🔴 **没声** |
| ⭐ **`FORMAT_SEL=1`** | ⭐ **左对齐（MSB 无延后）** | ✅ **出声** |
| `FORMAT_SEL=2` | 右对齐（LSBJ） | （未试） |

⭐ 且模块 `FMT` 脚接 **3V3** ⇒ ⭐ 与数据手册一致：
`FMT = "I2S (Low) / Left-justified (High)"`

### 🔴 术语陷阱（⭐ 差点被名字骗了）

```
⚠️ `i2s_tx.v` 这个模块里的 `JUSTIFY` 参数：
   · `JUSTIFY = 0`  ==> ⭐ **"Philips 标准 I2S"**（⭐ 数据在 WS 翻转后【延迟】
                         `MSB_DELAY` 位）
   · `JUSTIFY = 1`  ==> ⭐ 右对齐（LSBJ / 日本格式）
🔴 ⛔ **`JUSTIFY=0` 并不是字面意义的"左对齐"** —— ⚠️ 别被参数名误导!
⭐ 真正要"左对齐" ⇒ ⭐ **`JUSTIFY=0` + `MSB_DELAY=0`**（⭐ 把延迟去掉）
```

### ⭐ `MSB_DELAY` 的精确语义（⭐ 从 `i2s_tx.v:161` 算出）

```verilog
i2 = b - MSB_DELAY;                    // b = 时隙内第几位
if (i2 >= 0 && i2 < DATA_BITS) calc_bit = d[DATA_BITS-1-i2];
```
| ⭐ `MSB_DELAY` | ⭐ MSB 出现在 | ⭐ 等价说法 |
|---|---|---|
| **0** | ⭐ 第 **0** 位 | ⭐ **左对齐** ✅（⭐ PCM5102A 要这个） |
| **1** | ⭐ 第 **1** 位 | ⭐ 标准 I2S（⭐ 板载 `MAX98357A` 要这个） |

## 四、⭐⭐ 排查过程回顾（⭐ 哪些是真的、哪些是我的误判）

| ⭐ 步骤 | ⭐ 结论 | ⭐ 评价 |
|---|---|---|
| ⭐ 万用表量 `F20`/`E22`/`D22` | ⭐ `1.7V` / `1.7V` / 跳变 | ⚠️ **不充分** —— 🔴 **万用表分不清"方波"和"直流"**（⭐ 两者均值都≈1.65V）<br>⇒ ⭐ **示波器才是判据**（⭐ 后来确认是方波 ✅） |
| ⭐ `XSMT` = 0.1V | 🔴 **出厂软静音** | ✅ **真的**（⭐ 数据手册确认）⇒ 拉高到 3V3 |
| ⭐ 镊子短接 `BCK`–`SCK` | 🔴 **反效果** | ✅ **真的** —— ⭐ 手册："PLL 在外接 SCK 时被**禁用**" |
| ⭐ 我说"`FLT`/`FMT`/`XSMT` 三个都下拉到 GND" | 🔴 **我读错了** | ❌ **错** —— ⭐ 那些 470Ω 在 `LRCK`/`DIN`/`BCK`/`SCK` 上（串联匹配），⛔ 不在配置脚上<br>📌 后来从**模块完整原理图**读出：⭐ `XSMT`/`FMT` **直连排针、板上无电阻** |
| ⭐ `SCK` 必须接 GND | ✅ **真的** | ✅ 手册原文："`SCK` remains at ground level for 16 successive LRCK periods" |
| ⭐ 怀疑"我的位序写错了" | 🔴 **不是** | ✅ 探针实测位序**正确**（⭐ 解出 6/24/56/112 递增） |
| ⭐ 怀疑"`VIN` 该接 5V" | ✅ **真的** | ✅ 厂商接线图接 5V |
| 🔴 **接线错位** | 🔴 **真凶之一** | ✅ **三根全错**（⭐⭐ 这个我**一直没怀疑过**） |
| 🔴 **格式（左对齐）** | 🔴 **真凶之二** | ✅ 实测 `fmt1` 才出声 |
