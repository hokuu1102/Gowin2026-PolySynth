## 〇、⭐ 一句话设计原则（原稿照录）

> **以 25 mm 轴网格为核心基准，以 PCB 外边界定义模块边界，以磁吸实现模块自由组合，
> 以三明治结构实现 PCB/外壳固定；普通音符采用圆润键帽，多轴音符采用大键，
> 钢琴模式采用钢琴式键帽，鼓点采用大面积鼓垫；所有键帽统一考虑蓝色导光柱与侧刻发光，
> 外观采用白色大理石 + 黑白键 + 蓝光 + 少量橙色图标。**

⭐ **再压缩成四个词**：`白大理石壳` ＋ `模块化左手` ＋ `钢琴式键帽` ＋ `统一蓝光`

## 一、⭐ 整体机械架构（原稿）

左手部分 = **两个可独立使用的模块**，可磁吸拼成一个整体。

```text
┌────────────────┐  ┌────────────────┐
│    左手模块 A   │  │    左手模块 B   │
│  ○ ○ ○ ○ ○ ○   │  │  ○ ○ ○ ○ ○ ○   │
└────────────────┘  └────────────────┘
         ↕ 磁吸自由拼接
```

**核心要求**

| # | 要求 |
|---|---|
| 1 | 两块板**可以独立使用** |
| 2 | 可以**磁吸拼成一个整体** |
| 3 | 拼接后**轴中心仍保持统一间距** |
| 4 | **PCB 边界基本就是模块外壳边界** |
| 5 | ⛔ **不希望额外留一个很宽的外壳框**把两块 PCB 隔开 |
| 6 | ⇒ 因此采用**上下三明治结构**最自然 |

**三明治（原稿）**：`键帽` → `上壳/面板` → `PCB` → `下壳/底板`，螺丝固定。

**磁吸的定位**（原稿原话）

> 磁铁主要负责**拼接和定位**，⛔ 不要让磁铁单独承担全部机械剪切力。
> 最好再加 **定位凸台 + 定位槽** —— 这样两块模块拼起来以后
> 不会因为磁铁位置误差发生**横向错位**。

## 二、⭐ 先建立统一的轴网格（原稿 · ✅ 已裁定 25 mm，见 §〇-A 裁定 1）

> 轴间距 = **25 mm** ⇒ CAD 里**首先**建立 `25 × 25 mm` 基准网格。

⭐ **一切从网格派生**：轴 · 键帽 · PCB · 外壳 · 拼接面 · 磁铁 · 定位结构。

```text
模块 A                 模块 B

○────○────○────○────│────○────○────○────○
                    ↑
                 拼接基准线
```

⭐ **关键做法**：⛔ **不要从「外壳边缘」去量轴距** —— 应当是
**「轴中心 → 25 mm → 轴中心 → 25 mm → 轴中心」**，然后外壳**再围绕这个轴网格生成**。
这样以后把外壳圆角改掉，也不会把键位搞乱。

> ✅ **这条与项目现行做法完全一致**（⭐ 只是数值不同）：
> `files/10-硬件/左手区方案.md:186-201` §6.2 的「跨缝间距」就是同一个道理 ——
> ⭐ **让两块板的留边之和 = 列间距**，拼接后间距才统一。

## 三、⭐ 键帽分三种（原稿）

| 类型 | 原稿定义 | 图示 |
|---|---|---|
| **普通键** | **一个音 = 一个轴 = 一个键帽**；⭐ 键帽可做**比较大的水平圆角**（核心动作是滑弦） | `○` |
| **大键** | **一个音 = 两个或更多轴**（例：E3）⇒ ⛔ 不让两个轴各露一个小键帽，而是**多个轴共同支撑一个大键帽** | `○──────○` / 「\______/」（历史引用，当前未收录） |
| **鼓垫** | ⭐ **直接归入「大键」**（例：BD）⇒ 大面积触发区 | `┌───────────┐ │ BD │ └───────────┘` |

**大键的好处（原稿）**：按压更稳定 · 演奏区域更连续 · 外观更像真正的乐器 · 更适合滑弦。
**鼓垫的好处（原稿）**：大面积触发区比几个小按钮更适合鼓的演奏感觉。

> ✅ **与项目现有需求吻合**：⭐ 鼓垫 / 键盘打鼓见
> `files/00-总览/新需求分析-键盘打鼓与loop转鼓机-20261001.md` ＋ `files/10-硬件/鼓垫.drawio.svg`。
> ⚠️ 但「多轴共撑一个大键帽」在项目里**还没有对应任务**（⭐ 见 §十一）。

## 四、⭐ 钢琴区单独设计（原稿）

钢琴模式**不强行使用普通圆润键帽**，直接按钢琴的视觉语言做：

```text
白键  白键  白键  白键
┌───┬───┬───┬───┐
│   │   │   │   │
└───┴───┴───┴───┘
   ██      ██
   ██      ██
   黑键    黑键
```

⭐ **但机械结构仍遵循轴网格**（原稿 25 mm；⚠️ 项目实际见 §十-1）——
即：**外观模仿钢琴，机械布局仍服从 PCB/轴网格**。

| 件 | 材料（原稿） | 理由 |
|---|---|---|
| 白键 | **纯白 PLA** | — |
| 黑键 | **黑 PLA** | ⭐ 这样大理石白外壳**不会和白键融成一片** |

> 🔴🔴 **项目硬约束（⭐ 优先级高于原稿）**：⛔ **绝不引入键帽高度差** ——
> 定位**只能靠颜色 / 纹理 / 刻印 / LED**（`files/10-硬件/机械与硬件待做任务表.md:70` A9 ·
> `files/30-方案决策/当前方案总览.md:29`）。
> ⭐ 理由已实测：**黑键高出白键 ~10 mm ⇒ 钢琴上根本无法从 C 滑到 D**。
> ⇒ ⭐ **原稿的「钢琴式键帽」必须理解为「等高等距 + 黑白配色」**，⛔ 不是真钢琴的立体黑键。

## 五、⭐ 键帽透光（原稿）

原稿前提：**轴体本身有导光柱** ⇒ 不用考虑「LED 能不能直接穿透整个键帽」。

```text
       键帽
┌────────────────┐
│       C        │ ← 侧刻
└───────┬────────┘
        │  导光柱
      0603 LED
```

**原稿建议**

| # | 建议 |
|---|---|
| 1 | 字/图标直接做成**凹刻或者贯穿** |
| 2 | 键帽主体可以是不透明**黑 PLA** |
| 3 | **蓝光从内部通过导光柱送到侧刻** |
| 4 | ⛔ 不额外购买透明耗材 |
| 5 | ⭐ **先打印实验件确认亮度** |
| 6 | ⭐ 蓝色 0603 LED 本身就可以成为**统一的视觉元素** |

> ⚠️ **与项目已定口径的差异见 §十-5**（项目已实测的是「**下缘开窗**」，不是「侧刻」）。

## 六、⭐ 颜色体系（原稿）

| 类别 | 颜色 | 用途 |
|---|---|---|
| **实体材料** | 🩶 **白色大理石 PLA** | 外壳 |
| | ⚫ **黑 PLA** | 黑键、指板、控制件 |
| | ⚪ **白 PLA** | 钢琴白键 |
| **电子视觉** | 🔵 **蓝色 LED** | 键帽 / 状态光 |

> ⭐ 整台琴的颜色实际上就是：**白大理石 + 黑白 + 蓝光 + 少量橙色**。
> ✅ **与项目一致**：`files/10-硬件/机械与硬件待做任务表.md:70` A9 已列「黑键位涂深色」。
