# 🧱 硬件结构待讨论清单

> **这份是什么**：整机**结构**层面**需要一起讨论才能定**的事项。
> **⛔ 不是选型清单** —— "买哪个型号"看 `files/方案抉择/硬件选型表.md`；
> 这份回答的是「**这些东西怎么搭成一个乐器**」。
> **为什么单独一份**：结构问题**互相耦合** —— 定了一处会连带约束另外几处，
> 逐项打勾式表决没用，必须坐下来一起看**关系**。
> **日期**：2026-09-13 ｜ **状态**：🔴 待讨论

---

## 〇、结构性问题的特点（说明为什么不能用"逐项表决"）

| 选型问题 | **结构问题** |
|---|---|
| 各件**互相独立** | 各件**互相耦合**：改了 A 就约束 B |
| 可逐项打勾 | 必须**一起看关系图** |
| 例：霍尔选 `HAL49E` 还是 `HAL4904` | 例：屏放哪 → 影响手的位置 → 影响轴位高度 → 影响定位板厚度 → 影响霍尔间距 → **影响量程与精度** |

> ⭐ **一句话**：选型错了换一个器件；**结构错了要重新画板、重新建模。**

## 二、✅ 已经定死的结构事实（讨论时的**约束边界**）

来自 `files/方案抉择/左手区方案.md`（M1 定稿）—— **这些不要再讨论，只能在此基础上做**：

| 项 | 值 | 为什么是硬约束 |
|---|---|---|
| 轴位布局 | **2 行 × 8 列 = 16 轴位** | 映射表（钢琴/指板双模式）已按 16 轴位定 |
| **列间距** | **15 mm** | 由轴体底座外廓（14.4 mm）决定 → 不能再小 |
| **排间距** | **12～15 mm** | ⛔ **不是 6～8 mm**（那是早期设想，会撞轴体底座） |
| 拼版 | 两块 **2×4**（≈60×40 mm）拼成 60×80 | 打样尺寸 |
| 跨缝 | 左板右 **8** / 右板左 **7** → **15 mm** | 拼版一致性硬要求 |
| 成品轴中心跨距 | **105 mm** | |
| 两排 | **严格等高** | 🔴 设计铁律 1：同一只手移动切换的操作必须同平面同高度 |
| 轴体 | 普通磁轴（标准 MX 兼容） | |

## 三、🔴 待讨论项（按耦合链分组）

### 组 1：左右手分界与"手的位置"

| # | 待定 | 耦合到 | 备注 |
|---|---|---|---|
| **1.1** | **左手区与右手区的相对位置**（并排？呈角度？左右各一块？） | 影响整机宽度、支撑结构、线缆走向 | 🔴 铁律 1 只管"同一只手"，**左手/右手可以不同面** |
| **1.2** | **右手区支数**：拨弦件 1 个还是 2 个？推子 1 个？ | 影响右手板尺寸、IO 数量 | 拨弦件形态未定（见组 1.3） |
| **1.3** | 🔴 **拨弦件形态**：A 自制摆杆+磁铁+`HAL2033` / B 成品霍尔摇杆 / C 光电遮断 / D 微动 | **卡下单**（HAL2033 买不买）+ 卡结构 | 倾向 A；⛔ D 是"按"不是"拨" |
| **1.4** | **推子行程与位置**（多少 mm、放拇指位还是其他） | 影响颤音手感、右手板尺寸 | 采购清单已要求行程 ≥30 mm 导电塑料 |

### 组 2：屏与 LED 的位置（**最容易和"手"打架**）

| # | 待定 | 耦合到 | 备注 |
|---|---|---|---|
| **2.1** | 🔴 **串口屏放哪**：正前方 / 侧上方 / 后方？朝向？ | ⚠️ 会影响演奏时的手部空间与视线；屏 7 寸不小 | 若挡住手 → 轴位要挪 → **回到组 1** |
| **2.2** | **LED 的位置与数量**（键帽下 16 个？还是另加一排指示） | 影响灯珠数量 → 影响下单与电流预算 | LED 单色/双色/RGB 未定（卡下单） |
| **2.3** | **LED 走线与霍尔的距离** | ⚠️ **这是结构问题不是电路问题** | LED 的 PWM 纹波标不掉 → 走线必须成对紧贴、远离霍尔 |

### 组 3：支撑与形态

| # | 待定 | 耦合到 | 备注 |
|---|---|---|---|
| **3.1** | **整机怎么放**：桌上平放 / 立式倾斜 / 手持 | 影响所有分层高度与外壳 | 建议桌面平放（最省事） |
| **3.2** | **倾斜角**（0° / 10~20°） | 影响演奏舒适度、外壳复杂度 | 平放 = 0°，建模最简 |
| **3.3** | **外壳做不做**（做 → 何时做） | 占用 3D 打印时间与建模工时 | 建议**先不做外壳**，优先功能 |

### 组 4：电气装配与走线（**结构决定 EMC**）

| # | 待定 | 耦合到 | 备注 |
|---|---|---|---|
| **4.1** | **左手区 ↔ FPGA 板怎么连**：排线（多长）/ 排针直插 | ⚠️ 采集链已选"就地数字化"，长线**只走 SPI 数字** → 结构要保证这一点 | 这是"就地数字化"方案的**全部价值所在**，别结构上又拉长模拟线 |
| **4.2** | 🔴 **模拟区 / 数字区 / 功率区怎么分区** | 影响板子摆位与屏蔽 | 音频输出走线要**远离时钟线与 LED 驱动线** |
| **4.3** | **音频输出怎么出**：3.5mm 装哪、线怎么走 | 🔴 路线未定（板上耳机口 / 外接 I2S DAC / ADDA） | 见 `files/开发板与引脚资料.md` §三 |
| **4.4** | **电源怎么进、怎么走**：适配器 / 电池 / 两者 | 影响结构与演示方式 | 铁律：模拟侧必须 **Buck→LDO 两级** |
| **4.5** | **调试口怎么留**：UART（`AB20`/`T14`）要不要引到面板 | 影响调试便利性 | 板载 USB 转串口已存在 |

### 组 5：装配与可维护性

| # | 待定 | 耦合到 |
|---|---|---|
| **5.1** | **装配顺序**（先装哪层、能不能一次装好） | 所有层 |
| **5.2** | **能不能拆开维修**（换轴、换霍尔、换灯） | 定位板与 PCB 的固定方式 |
| **5.3** | **重复装配的一致性**（16 个轴的霍尔间距怎么保证一致） | ⚠️ 直接决定"力度一致性" → 见 §四 |

## 四、⭐⭐ 结构 × 性能的耦合（这份清单真正的价值）

**下面每一条都是"结构决定性能，事后改不了"：**

| # | 结构决定的事 | 机制 | 事后能否补救 |
|---|---|---|---|
| **1** | **力度一致性** | 霍尔在 PCB、磁铁在轴体 → **磁铁↔霍尔间距由定位板厚度决定**。间距不一致 → 每轴灵敏度不同 → 力度曲线不一致 | 🔴 **极难** —— 要拆整机重做定位板 |
| **2** | **量程/线性度** | ⭐ 铁律 3：**「间距」是霍尔类器件唯一的量程/阈值调节旋钮**（磁场 ≈ 1/r³） | 🔴 同 1 |
| **3** | **LED 是否干扰采集** | LED 的 PWM 纹波**标不掉** → 走线距离与成对程度决定干扰量级 | 🟠 可加屏蔽/降电流，但**改不了走线** |
| **4** | **采集精度** | "就地数字化"的价值全在**长线只走数字**；结构若把 ADC 挪到 FPGA 板 = 把方案最大优点丢掉 | 🔴 要重画板 |
| **5** | **音频底噪** | 功放是全板电流最大器件 → 供电与摆位决定底噪 | 🟠 可加磁珠/屏蔽 |
| **6** | **手感一致性** | 两排**严格等高**、16 轴**同平面** → 结构公差直接变成手感差异 | 🟠 定位板可重做，但代价高 |

> ➡️ **所以结构讨论必须在画板之前完成**（⛔ 顺序不能反）。
> 一旦投板 + 3D 打印定稿，上面 6 条里有 3 条**只能靠重做整个机械部分**来改。

## 五、讨论顺序建议（按依赖关系）

```text
① 整机怎么放（组 3.1/3.2）        ← 决定一切的基准面
      ↓
② 左右手分界与手的位置（组 1.1/1.2/1.3/1.4）  ← 决定输入层布局
      ↓
③ 屏与 LED 放哪（组 2.1/2.2）      ← 会反过来挤手的位置，可能要回到 ②
      ↓
④ 电气分区与走线（组 4.x）          ← 由 ①②③ 的摆位决定
      ↓
⑤ 装配与可维护性（组 5.x）          ← 最后校核
      ↓
⑥ 外壳（组 3.3）                   ← 全部定了才建模
```

> ⚠️ **注意 ②→③ 的回环**：屏是 7 寸，很容易挤掉手的位置。
> 建议**先剪纸/纸板摆一摆**（几分钟），比在 3D 里改快得多。
