## 三、🔴🔴 探针版为什么是**错的**（⭐ 本轮最有价值的发现）

探针版（`note_manager.v.ROT32-probe`）把三条写路径**共用一个** 3 选 1 mux 的移位器：

```verilog
wire [PHASE_W-1:0] wr_src = pitch_upd_valid_i ? pitch_upd_value_i
                           : (cmt_en_r         ? cmt_inc_r
                                               : cur_inc);
wire [PHASE_W+1:0] wr_shift = {2'b00, wr_src} << base_oct_r;
```

🔴 **两条独立的错误**（⭐ **只跑综合【永远】发现不了**）：

1. 🔴 **(e) 滑音段与 FSM 写【可以同拍、写【不同】lane】**
   —— ⭐ `pitch_upd` 是**组合段**（⭐ 每拍都可能写，⭐ 命中 `(axis,src)` 匹配的 lane），
   而 `ST_RETRIG` / `ST_COMMIT2` 是**另一条写路径**（⭐ 写 `same_idx_r` / `cmt_idx_r`）
   ⇒ ⭐ **一个 mux ⛔ 表达不了"两个 lane 各拿自己的值"** ✅
2. 🔴 **`cmt_en_r` 是【锁存标志】**：⭐ 它只在下一次 `ST_DECIDE` 才被改写
   ⇒ ⚠️ **进 `ST_RETRIG` 时它可能还是 1**（⭐ 上一次提交留下的）
   ⇒ ⭐ 选择子会把**陈旧的 `cmt_inc_r`** 写进重触发 lane ✅

⭐ **实测（⭐ `tb/w3b/tb_rot32_diff.sv`，⭐ 与【改动前 RTL 的逐字节副本】逐拍差分）**：
```
探针版口径：逐拍比较 50266 拍   phase_inc 不同 = 48932   ← 🔴 97%（⭐ 主路径，⛔ 不是边界情况）
正式版口径：逐拍比较 50266 拍   phase_inc 不同 = 0       ← ✅
```
⇒ ⭐ **若直接照 §八 的探针版落地，就是静默错 97% 的拍** ✅

### 3.1 ⭐ 正确拆法（⭐ 两个移位器就够，⛔ 不需要三个）

```verilog
wire [PHASE_W-1:0]   fs_src   = (state == ST_COMMIT2) ? cmt_inc_r : cur_inc;
wire [PHASE_W+1:0]   pu_shift = {2'b00, pitch_upd_value_i} << base_oct_r;
wire [PHASE_W+1:0]   fs_shift = {2'b00, fs_src} << base_oct_r;
```
* ⭐ **(e) 滑音独占一个**（`pu_shift`）
* ⭐ **FSM 两条共用一个**（`fs_shift`）—— ⭐ 它们**互斥**（⭐ 不同状态）✅
* ⚠️ 选择子用 **`state == ST_COMMIT2`**，⛔ **不用 `cmt_en_r`**（⭐ 见上面第 2 条）✅

### 3.2 ⚠️ 为什么这 705 LUT 躲不掉（⭐ 结构原因）

⭐ `phase_r[i]` 的 **D 输入**要选几个**不同的数据源**：

| 版本 | 数据源 | 每位 LUT |
|---|---|---|
| 探针版 | `wr_shift`（⭐ 1 个写值）＋ 重算移位 | **1** |
| **正式版** | `pu_shift` ＋ `fs_shift`（⭐ **2 个写值**）＋ 重算移位 | **2** |

⭐ 1024 位 × 1 LUT ≈ **1088** ⇒ ⭐ 与实测的 **+705** 同量级 ✅
🔴 **换句话说：探针版省下来的 LUT，⭐ 主要来自"让两个 lane 共用一个写值"这件【错事】**。

## 四、⭐ 正式版改了什么（⭐ 已回退，⭐ 留档）

### 4.1 RTL（`rtl/w3b/note_manager.v`）

| # | 改动 |
|---|---|
| ① | `phase_r` **32 → 34 位**（⭐ 存 `X << base_oct_r`，⭐ 精确不丢高位）|
| ② | ⭐ **换档控制**：`base_oct_tgt_r` / `base_oct_r` / `oct_done_r` / `oct_busy_r` / `oct_up_r` / `rot32_cnt` |
| ③ | ⭐ **只在静音时换档**：`oct_any_gate = \|gate_vec_w`；⭐ `base_oct_r` 只在 `oct_allow = ~oct_any_gate` 时跟随目标 |
| ④ | ⭐ **两个写移位器**（`pu_shift` / `fs_shift`）|
| ⑤ | 三条写路径改走移位器（⭐ 滑音 / 重触发 / 提交）|
| ⑥ | ⭐ **换档轮转重算**（⭐ **`endcase` 之后**，⭐ 每拍 1 个 lane）|
| ⑦ | 输出端**零逻辑**：`g_t2` / `g_t3` 都取 `phase_r[g][31:0]` |
| ⑧ | T3 侧 `rot_base = rot_phase;`（⭐ 删掉那次额外移位）|

🔴 **两条"差一条就差很多"的细节**：
1. ⭐ **重算段必须在 `endcase` 【之后】**（⭐ 重算赢过写 ⇒ 每位 1 个 2:1 D-mux）
2. ⭐ 写移位器**不能三条路径共用一个 3 选 1**（⭐ 见 §三）—— 但**两个**是对的

### 4.2 ⭐ 只在静音时换档

* 🔴 **为什么**：⭐ 重算要 **32 拍**才轮完一圈 ⇒ ⚠️ 那 32 拍里一部分 lane 已是新档、
  一部分还是旧档 ⇒ 🔴 有音在响时就是**可闻的音高毛刺**
  ⇒ ⭐ **`gate_r` 全 0 时才真正换档**（⭐ 有音 ⇒ 请求挂起，⛔ 不丢）✅
* 📌 **为什么用 `gate_r` 而不是 `live_mask`**：⭐ `live_mask` 含 **Release 尾巴**
  （⭐ 振荡器**还在出声**）⇒ ⭐ 那时换档**照样听得见** ✅
* ⚠️ **代价（⭐ 明说）**：⭐ 用户一直按住不放时，⭐ 新档要**等松手**才生效。

## 六、⭐ `tb_transpose` / `tb_base_semi` 的【激励】改了什么（⭐ 为什么不算放宽判据）

### 6.1 🔴 为什么必须改

⭐ ROT32 的换档要 **32 拍**才轮完一圈 ⇒ ⚠️ 那 32 拍里"已重算的 lane"与"还没轮到的 lane"**输出不同**。
⭐ 而 `T1` / `T7` 比的是 **`voice_phase_inc_o` 整条 1024 位总线**，
🔴 **包含静音 lane 的相位**（⭐ 判据看的是**存储值**，⛔ 不是"能不能听到"）
⇒ ⭐ **"只在静音时换档"（RTL 的性质）⛔ 不足以保证判据成立** ——
⚠️ 松手只让 `gate_r` 落 0，⭐ `phase_r` 仍有旧值 ⇒ ⭐ 那 32 拍照样不同。

### 6.2 ⭐ 改法（⭐ 激励口径，⛔ 判据一个字没改）

| tb | 改动 | 为什么⛔ 不是放宽 |
|---|---|---|
| `tb_transpose` **T1** | ⭐ 每个八度档**先复位**（⭐ `phase_r` ⇒ 全 0）**再提交**换档，⭐ 然后照旧跑 **5000 拍随机激励** | ⭐ 比较语句（`if (d_ph !== r_ph)`）**一个字没动**；⛔ 无"N 拍不计"、⛔ 无改容差；⭐ 每档仍是 5000 拍 ✅ |
| `tb_transpose` **T2 换档** | ⭐ 新增 `oct_switch()`：**清零相位表** → **松手** → **等 `gate` 全 0** → **提交** → **等重算** → **重布** | ⭐ 期望式仍是 `exp_ph(P0[v], oct, idx)`（⭐ 与改动前**逐字相同**）✅ |
| `tb_transpose` **`check_lanes`** | ⭐ 探针从 `u_t3on.phase_r[vv]` 改成**换档前快照** `P0[vv]` | ⭐ 新 RTL 的 `phase_r` 存的是**移位后**值 ⇒ 若仍读它就会**移两次**；⭐ `P0` = 移位前的 `X` ⇒ ⭐ 期望式**逐字不变** ✅ |
| `tb_base_semi` **T1~T6** | ⭐ 新增 `set_oct()`：**松手 → 等 gate 全 0 → 提交 → 等重算**，⭐ 然后**再按** `TV` | ⭐ 判据仍是"`base_semi=12` ⇒ **精确 ×2**"（⭐ 一条没删、没改容差）✅ |

🔴 **一个字都没改的东西**：`T1`/`T7` 的 `!==` 比较、`T2` 的容差（1 LSB）、
`T3`/`T4`/`T6` 的全部判据、`t2_cases == 7`、`T1` 的 3×5000 拍、`T7` 的**全程**逐拍 ✅
📌 ⚠️ **一条 ROT32 专用的【附加】判据已删**（⭐ "存储里确实存着移位后的值"）——
⭐ 回退后 `phase_r` 存的是**移位前**值 ⇒ ⭐ 它必然红；⛔ **它不是原有判据**（⭐ 原有判据一条没动）✅
