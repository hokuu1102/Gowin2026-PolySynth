### 1.1 ⭐ 接线要点（⭐ 三条容易被"看起来对"骗过去的地方）

1. **跨 generate 的三根线必须由两个互斥分支各自驱动**（⭐ 与 `led_blink` 同一手法）：
   `g_sound` 给真值、`g_silent` 显式给 0 ⇒ ⛔ 否则静音档悬空成 `x`。
2. **鼓机"开"的算式必须与 `g_sound.src_b_valid` 逐项一致**
   （`SEL_DRUM==1 && METRONOME_ON!=0 && met_on_r`）⇒ ⭐ 否则指示灯会说"鼓机在响"而实际不响。
3. **looper 三态用 `loop_rec_on_r`/`loop_play_on_r`**，⛔ 不用 `looper.layer_state_o`
   （⭐ 后者只有 1 位，分不出"录"和"放"）。

### 4.1 ⭐ tb 里两条"踩过才写进去"的教训

1. 🔴 **拍点闪拉伸会跨测试段存活**：生产实例的拉伸是 **100 ms**，
   ⇒ ⚠️ "节拍器开但还没拍点 ⇒ 灭"这条判据**只能放在第一个拍点之前**做，
   ⛔ 放在后面必**假红**（⭐ 第一版就栽在这）。
2. 🔴 **快闪周期⛔ 不能用 `(末沿−首沿)/(边数−1)` 量**：⭐ 那会把窗口首尾的**半个周期**平均进去
   （⭐ 实测量出 974 而不是 1024）⇒ ⭐ 改成**相邻上升沿间隔的 min/max**（⭐ 实测 `[1024..1024]`）✅
