## 二、⭐ 结果：`K-91`（`calib` 根本没过综合）

第一次跑综合，**直接失败**：

```
ERROR (EX3863) : Syntax error near '''(calib.sv:90)
ERROR (EX3863) : Syntax error near '''(calib.sv:93)
ERROR (EX3863) : Syntax error near 'else'(calib.sv:99)
ERROR (EX3863) : Syntax error near '''(calib.sv:137)
ERROR (EX3928) : Module 'calib' is ignored due to previous errors(calib.sv:149)
Verilog file 'calib.sv' ignored due to errors
```

**根因**：`calib.sv` 里 4 处 **SystemVerilog 带宽度强制转换** `N'(expr)`：
`24'(FULL)` / `IW'(ITER)` / `PW'(FULL)` / `DW'(FULL)`。
⭐ Gowin 把 `.sv` 按 **Verilog-2001** 编译（工程里登记为 `type="file.verilog"`）。

⚠️⚠️ **最坑的地方**：**iverilog 接受这些写法** ⇒ **仿真 100% 全绿**（`tb_calib` 一直过）。
⭐ **只有跑真综合才暴露** —— 这就是 `T47` 的全部价值。

**修法**（纯语法、零行为变化）：改成 Verilog-2001 的有宽度 `localparam`：

| 原（SV） | 改（Verilog-2001） |
|---|---|
| `24'(FULL) << 8` | `localparam [23:0] DIVIDEND = FULL << 8;` |
| `IW'(ITER)` | `localparam [IW-1:0] ITER_CNT = ITER;` |
| `PW'(FULL)` | `localparam [PW-1:0] FULL_EXT = FULL;` |
| `DW'(FULL)` | `localparam [DW-1:0] FULL_CODE = FULL;` |

⚠️ 顺带发现：⛔ **不能对 `integer` 参数做位选**（`FULL[DW-1:0]` 在 Verilog-2001 同样非法）
⇒ **必须先落成有宽度的 `localparam` 向量**再比较/赋值。
