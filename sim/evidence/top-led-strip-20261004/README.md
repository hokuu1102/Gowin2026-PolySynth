## 3. ⭐⭐ 新 tb 第一跑就抓到的东西（⭐ 值得记住）

```
FAIL: (3d) led5 推子 = 灭（g_silent 把 led_gear_st 驱动成 0）[led5] = 8000ff want 000000
```

🔴 **现象**：`g_silent`（静音档）下 `led5` 显示 **紫 `8000FF`**。
🔎 **根因**：⭐ 我原来在 `g_silent` 里写 `assign led_gear_st = 2'd0;`
—— ⚠️ 而指示层的表里 **`2'd0` = "变调"（紫）**，⭐ 可这一档**根本没有推子**
⇒ 🔴 **指示灯在说谎**（⭐ 它会让人以为推子处在变调档）。
✅ **修法**：改成 `2'd3`（= **"无"** ⇒ **灭**）⇒ ⭐ 语义与事实一致 ✅

📌 **同族口径（⭐ 一并定死，写进注释）**：`led_looper_st` 仍是 `2'd0`（空闲 ⇒ 暗蓝）——
⭐ 因为用户的 looper 语义里**没有"无"这一档**（只有 空闲/录音/回放）
⇒ ⭐ "没有 looper" 与 "looper 空闲" 在灯上**本就是同一个状态**（⭐ 也是它的复位态）✅

> ⭐ **教训**：⭐ **"状态码 0 等于什么"必须逐路核对** ——
> `gear` 的 0 是"变调"（有语义！），⛔ 不是"没接"；
> ⭐ 这正是"缺一个集成判据"时**最容易漏掉**的一类错（⭐ 模块级 tb 永远看不到它）。
