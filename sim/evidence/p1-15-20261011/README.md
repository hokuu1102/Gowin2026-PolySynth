## 一、⭐ 缺陷（⭐ 审查的原文 ＋ 我的实测更正）

## 二、✅ 改法（⭐ 三处 ⇒ 三个常量查表函数）

⭐ 关键观察：⭐ **操作数是 4 位 BCD 数字**（⭐ `cur_digit`/`cur_ten` 取值 **0~9**、
⭐ `cur_thou` 取值 **0~4** ✅）
⇒ ⭐ 可以**直接查表**（⭐ 就是同一张真值表 ⇒ ⭐ **行为逐位等价** ✅）

```verilog
function [11:0] d_x100;                  // ⭐ cur_digit × 100（⭐ 0~9）
    input [3:0] d;
    begin
        case (d)
            4'd1: d_x100 = 12'd100;
            ...
            4'd9: d_x100 = 12'd900;
            default: d_x100 = 12'd0;
        endcase
    end
endfunction
// ⭐ 同理 d_x1000（⭐ 0~4）· d_x10（⭐ 0~9）
```

⭐ 然后三处调用 ✅：

```verilog
wire [11:0] cur_x100 = d_x100(cur_digit);
rem  <= rem - d_x1000(cur_thou);
rem  <= rem - d_x10(cur_ten);
```

### ⭐ 为什么这样能省 DSP

| ⭐ 写法 | ⭐ 综合结果 |
|---|---|
| 🔴 `{8'd0, d} * 12'd100` | ⭐ Gowin 推成 **`MULT12X12`**（⭐ 实测 6 个 ✅） |
| ✅ `case (d) ... endcase` | ⭐ **纯 LUT 常量表** ⇒ ⭐ **零 DSP** ✅ |

📌 ⭐ **代价**：⭐ 每个函数约 10 个常量项 ⇒ ⭐ 几十个 LUT ✅
⇒ ⭐ **用 LUT 换 DSP** ✅（⭐ 而本设计 `CLS 82%` 紧、⭐ `DSP 22%` 松 ✅ —— ⚠️ 见 §五 的诚实评估 ✅）

## 五、✅ 第二次尝试：**移位相加**（⭐ 原始注释早就给了这个写法）

⭐ 而 `:175-176` 的**原始注释**其实写着 ✅：

> *"⭐ 当前该减多少（⭐ **常数移位加法**，⛔ 不用乘法器 ⇒ 时序好）
> ⭐ `cur_digit × 100` = `(cur_digit×64) + (cur_digit×32) + (cur_digit×4)`"*

⇒ ⭐ **作者早就知道正确写法** ✅ —— ⚠️ 只是**后来换成了乘法**（⭐ `:177-178` 说"为了可读性" ✅）✅

### ⭐ 改法

```verilog
function [11:0] d_x100;      // ⭐ 100 = 64 + 32 + 4
    input [3:0] d;
    begin
        d_x100 = ({8'd0, d} << 6) + ({8'd0, d} << 5) + ({8'd0, d} << 2);
    end
endfunction

function [11:0] d_x1000;     // ⭐ 1000 = 512+256+128+64+32+8
    input [3:0] d;
    begin
        d_x1000 = ({8'd0, d} << 9) + ({8'd0, d} << 8) + ({8'd0, d} << 7)
                + ({8'd0, d} << 6) + ({8'd0, d} << 5) + ({8'd0, d} << 3);
    end
endfunction

function [11:0] d_x10;       // ⭐ 10 = 8 + 2
    input [3:0] d;
    begin
        d_x10 = ({8'd0, d} << 3) + ({8'd0, d} << 1);
    end
endfunction
```

### ⭐ 为什么移位相加比 `case` 查表更省

| ⭐ 写法 | ⭐ 综合结果 | ⭐ 代价 |
|---|---|---|
| 🔴 `d * 12'd100` | ⭐ `MULT12X12` ×2 | ⭐ 2 个 DSP ✅ |
| ⚠️ `case (d) 10 项` | ⭐ **纯 LUT 常量表** | ⚠️ **10 项 × 12 位** ⇒ ⭐ **+172 LUT / +419 CLS** 🔴 |
| ✅ `(d<<6)+(d<<5)+(d<<2)` | ⭐ **2 个 12 位加法器** | ✅ **约 24 LUT** ✅ |

📌 ⭐ 关键：⭐ **移位相加【不是乘法模式】** ⇒ ⭐ 综合器**⛔ 不可能**把它推成 DSP ✅
（⭐ 而 `d * 常量` 是乘法模式 ⇒ ⭐ Gowin 会推 ✅ —— ⭐ 这正是原注释"Gowin 会用 LUT 拼"的**错处** ✅）
