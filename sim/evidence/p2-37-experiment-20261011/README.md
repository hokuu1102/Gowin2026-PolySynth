> *"判据：综合报告 LUT 下降 **≥ 500** 且所有 tb 全绿 ⇒ 白付确认，落地"*

⇒ ⭐ 本实验是**预注册**的：⭐ **没达到 ⇒ 不落地** ✅（⭐ 所以回退**不是**"失败了"，
⭐ 而是**判据正常工作** ✅）

### ⭐ 审查的论证（⭐ 我逐条查过源码，⭐ 论证**本身是对的**）

| # | ⭐ 事实 | ⭐ 出处 |
|---|---|---|
| 1 | ⭐ `test_phase_inc_o[...] = (selected && (o == 0)) ? VOICE_INC : 0` ⇒ ⭐ 奇数 lane 的增量是**常量 0** | ⭐ `test_mode_ctrl.v:81-82` ✅ |
| 2 | ⭐ `test_lane_active_o[LANE] = selected && (o == 0)` ⇒ ⭐ 奇数 lane 在 test 档下 `lane_active = 0` | ⭐ `test_mode_ctrl.v:80` ✅ |
| 3 | ⭐ `lane_inc` 的**唯一消费者**是 `phase_q <= phase_q + lane_inc`，⭐ 在 `if (lane_active)` 内 | ⭐ `oscillator_bank.v:725` ✅ |
| 4 | ⭐ `OSC_IDX` 是**编译期常量**（`localparam = g % OSC_PER_VOICE`） | ⭐ `oscillator_bank.v:526` ✅ |
| ⇒ | ⭐ **三条合起来**：⭐ 奇数 lane 在 test 档下"**相位冻结 ⇒ 增量是 don't-care**" ✅ | ⭐ **论证成立** ✅ |

### ⭐ 实施的改动

```verilog
//  只给主 lane 留 test 覆盖（⭐ 奇数 lane 的 mux 应当被折掉 ✅）
wire [PHASE_W-1:0] lane_inc = (test_mode_i && (OSC_IDX == 0))
                 ? test_phase_inc_i[g*PHASE_W +: PHASE_W]
                 : lane_inc_base;
```

⭐ 并按 **铁律④** 同步了 `tb/models/oscillator_bank_ref.v` ✅

## 三、⭐ 为什么没降（⭐ 根因，⭐ 这比结论本身有用）

⭐ 综合器**早就把它折掉了** ✅ ——
⭐ 因为 `lane_active = 0` 时 `phase_q <= phase_q + lane_inc` **整条不执行** ✅
⇒ ⭐ 综合器能证明"**test 档下奇数 lane 的 `lane_inc` 是死逻辑**" ✅
⇒ ⭐ **那个 mux 早就不存在了** ⇒ ⭐ **审查的估算（≈1000 LUT4）是错的** ✅
📌 ⭐ 而审查**恰恰因此写着"先做实验判定"** —— ⭐ **它的方法是对的，⭐ 只是估算错了** ✅
