## 功能与配置

16 轴 Hall 输入、力度跟随、四种音色、32 声部且每声部两个振荡器、滑音、延音、三档推子及独立锁定、鼓机、手弹键盘鼓、Looper、64 身份曲谱指引、双路 I2S 和 HDMI 波形/XY/FFT 均保留。默认 source-B 是鼓机；节拍器是 SEL_DRUM=0 的源配置，不与默认固件混称。

FX 为运行时可控，默认 mask=0、颤音 depth=0；可经 UART 0x71 帧启用失真、合唱、延迟并调颤音。混响和预留掩码位未实现。矩阵键 9 锁定当前推子档，键 15 仅释放时 tare；E 循环三种视图。BLE 设备名为 FPGA2026-Synth2。以手册为准，不沿用历史 README 的编译期 FX 旁路、四档推子或长按 span 操作。

## 工程入口

FPGA 工程为 Gowin2026.gprj，约束为当前 CST/SDC，主顶层是 rtl/top.v。RTL 回归入口是 sim/tb_all.ps1，ESP32-S3 工程是 esp32/ble，网页工具是 esp32/tools/score_studio.html 与 upstream_studio.html。

最新固件必须由同版源码构建并按 SHA256 核对。仓库中的历史 impl、sim/evidence 或实验目录不自动代表当前交付固件；setup/hold/recovery/removal 均须读取实际原生报告，生成 .fs 不等于时序达标。
