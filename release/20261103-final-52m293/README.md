## 本轮修复与功能范围

实机 UART 抓到旋钮回包与下一条屏幕赋值粘成一条指令，例如 `Ee16+5\r\nz_ll.val=52`；后面的数字文本指令独立，因此可能出现数字变化而指针不动。实体按键的单字节回包也可影响下一条状态文字。

本版在主 UART 的非屏回包与下一条屏幕指令之间发送三个 FF，并等待实际发送结束后再放行显示帧。隔离符不进入 ESP32 线路；纯电脑调试、未启动屏幕显示时保留原回包格式。详细依据见 [HMI 边界修复记录](../../docs/hmi-protocol-boundary-20261103.md)。

串口屏仅在 page1 后初始化事件中，为 `t_dg_val`、`t_dt_val`、`t_cl_val`、`t_mx_val`、`t_ll_val`、`t_lf_val` 设置 `pco=65535`。中间失真、合唱、延迟三列的六个中央数字与百分号为白色；左右颤音两列仍为黑色。原页号通知和 88 握手两行保留，数值、指针、按钮和 DSP 控制不变。颜色在运行时进入页面后应用，编辑画布可能仍显示原默认颜色，以模拟器运行和屏端效果为准。

保留 16 轴采集、力度跟随、四种音色、32 声部、滑音、延音、三档推子和分档锁定、四种鼓机节奏循环、键盘鼓、Loop 录停播、64 身份曲谱指引、实时上行、双路 I2S、HDMI 波形/李萨如/频谱的单模式切换。没有通过减少功能、容量或降低工作频率取得时序结果。混响及预留效果掩码位仍未实现，不列作已交付功能。

原实际 50 MHz 门禁未放宽；只有符合既定条件的 clk_sys R→R、关系 16.4 ns 路径按实际 20 ns 周期复核，其他时钟、半周期、保持和复位检查不借用该差额。本版并非更严预算零违例。上版 Fmax 53.436 MHz、实际建立余量 +1.286 ns，本次重新布局后余量略低，但仍满足实际 50 MHz。`clk_d` 的 PR1014 警告在上版也存在，本次未屏蔽。

7 项仿真覆盖实际线缆完整字节流消费、模式/鼓垫/滑音/回传、旋钮正反转和指针数字、纯 PC 回包、ESP 隔离、页面同步、key15、完整帧仲裁、115200 实际分频前十帧、Loop 录停播和短音指引灯。保留原始日志，不以所有回归均已重跑表述。屏幕模拟器运行已目视确认六个白字与两侧黑字，尚未替代实际屏幕复测。
