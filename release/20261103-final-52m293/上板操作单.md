# 最终配套版上板操作单

1. FPGA 下载选择同目录 firmware 下的 `Gowin2026-51-hmi-boundary-50MHz-20261103.fs`，目标为 GW5AT-60B / GW5AT-LV60PG484AC1/I0。SRAM 下载用于本次通电测试；需要固化时，按 Tang Console 官方流程选择 `External Flash Mode Arora V` 和 `exFlash Erase,Program thru GAO-Bridge Arora V`，启动地址 0，成功后完整断电再上电确认自动加载。固化会更新原有启动镜像。[板卡官方说明](https://wiki.sipeed.com/hardware/en/tang/tang-console/mega-console.html#getting-started)
2. 串口屏用原成功下载流程选择 `p0-final-20261103.tft`。型号 TJC1060X570_011，1024×600、UTF-8、115200。颜色版必须更新 TFT，仅更换 FPGA FS 不会改变字体颜色。
3. 恢复屏幕 TX→FPGA RX（D14/J9 N26）、屏幕 RX←FPGA TX（D15/J9 N25）及共地。电脑被动监听只接 RX 和 GND，避免电脑 TX 与屏幕 TX 同时驱动 FPGA RX。
4. 进入效果器页再返回主页，重新发送页号与握手；FPGA 单独复位后仍需要页面重新报告。
5. 实体模式、键盘鼓、滑音和实时上行各切换两次，确认对应文字能更新。实体回传键在松手时切换。
6. 效果器页中间失真、合唱、延迟三列的六个中央数字与百分号应为白色；最左音高颤音和最右音量颤音仍为黑色。各选一个参数并正反转 EC11，确认指针和数字同步变化、声音变化正确；切页再进入后配色仍应保持。
7. 检查 HDMI 每次只显示当前选择的波形、李萨如或频谱；检查推子分档锁定、鼓机四节奏循环、Loop 录制/停止/播放/停止以及同音重触发指引灯。
8. 完整功能、接线和长稳测试继续使用 [完整上板验收手册](../20261028/上板验收手册.md)。该手册中的旧烧录路径以本目录配套文件替换；实体按键和屏幕新增行为以本页及当前源工程为准。

以上为待执行的实机操作，不表示已替操作者完成烧录或通过验收。
