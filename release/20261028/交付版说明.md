# 2026-10-28 功能交付版说明

本版已完成实际 GW5AT-LV60PG484AC1/I0 原生构建，生成 20705823 字节的 FPGA 码流；完整 RTL 回归 233/233 通过。它是用于后续上板验收的功能交付版，setup 时序仍明显不足，尚未完成实机验收，不能据此保证 50 MHz 板上稳定性。

## 功能与修复

保留 16 轴 Hall 输入、力度跟随、四种音色、32 声部且每声部两个振荡器、滑音、延音、三档推子和锁定、鼓机、键盘鼓、Looper、64 身份曲谱指引、双 I2S、HDMI 波形/XY/FFT、BLE 曲库、串口屏和运行时效果器。默认 source-B 为鼓机，节拍器是另一个源配置；混响和预留功能不宣称已实现。

RC1 之后，修复实时上行与八字节诊断帧的 UART 占用竞态、异步校准回复穿插，以及忙时连续拒绝通知被合并。真实 UART 专项分别收到 live14+FX8 精确 22 字节、live14+三次拒绝精确 17 字节；完整 Hall 录制、双口导出及逐字节重导出一致性用例通过。指引改为平衡选择/归约树，保持容量、32 位重复计数、最小索引选择和输出周期，12000 拍逐周期对照通过。

## 验证范围

本轮完整 RTL 回归 233/233 通过。软件自检为 44 个工具、1062 项 OK、0 项 RED；ESP32 生产代码在该构建之后未改变，实际 ESP-IDF v5.5 的 esp32s3 构建成功，BLE_MODE=1、BLE_HMI_ENABLE=1，应用映像 757328 字节，校验和与映像验证哈希正确。

三项默认排除单列：两项 WAV 导出工具，以及旧滑音诊断。旧诊断的 3 个 FAIL 原始日志保留，不计为通过；其输入和查表钳制不符合当前的位置跟随契约。当前滑音以位置控制器及真实 UART/ADC 端到端用例验收，详见[交付审查结论](交付审查结论.md)。

## 原生构建与时序

选用“自动 scope 布局、解除旧 h5_ret 回传区域限制”的实际成功结果，物理配置提交 434b596，最后功能 RTL 提交 5708266。保留 serializer reset 区域、全部 124 条 IO 约束与 SDC；实际 place_option=0、route_option=0、correct_hold=1，未裁减功能或放宽时钟要求。原生工具完成布局布线、时序分析和码流生成，退出码为 0。复现采用随源码提供的[交付构建脚本](build_delivery.tcl)，与实际调用的 Tcl 内容一致。

clk_sys 约束为 50 MHz，报告 Fmax 为 27.163 MHz；pixel_clk 约束为 25 MHz，报告 Fmax 为 80.278 MHz。最差 setup 路径为乐谱 note_data 到指引灯寄存器，检查关系 16.400 ns、数据延迟 36.748 ns。本次指引结构优化没有使原生 setup 收敛，也不能把剩余欠裕量描述为“差一点”。另保留 PR1014 警告：clk_d 使用通用布线，延迟/偏斜风险随原生日志记录，留待时序优化与上板观察。

该结果使用 Logic 49751/59904、CLS 27957/29952（94%）、BSRAM 105/118（89%）。自动 scope 但保留旧回传区域的对照曾实际失败于 PR0004、380 条未布通网络，无新码流；解除回传区域后才完成布线。其他两个候选在成功结果确认后停止，不能计为通过。CT2065 本身只是部分坐标无效警告，旧 RC1 同范围曾成功生成码流，不能仅凭该警告判失败；所有原始失败证据单列保留。

## 上板与交付使用

按用户约定，本轮先交付可烧录文件与[上板验收手册](上板验收手册.md)，实机验收随后进行。60 项[逐项验收记录](逐项验收记录.csv)均保留待上板，不预填 PASS。仿真通过不能替代板卡上的音频、显示、串口、BLE 和长稳验证。

最终交付包包含本版 FPGA 码流、ESP32 引导/分区/应用映像、完整源码、原生报告、回归证据、Word/PDF/Markdown 手册及测试素材。具体提交号与文件 SHA256 以包内交付清单和校验文件为准。源码中历史 impl/evidence 材料只供追溯，不能替代本包选定的固件目录。新版本在本地封存，不擅自推送远端。
