# PolySynth 20261028 RC1 交付说明

这是当前可交付的功能修复候选版。RTL 实现版本为 f37804e，基于远端 cd63b0773480e43b19d47f7b541d202a0a66df4d；包含其后的本地功能修复。源代码、可烧录 ESP32-S3 固件、上板手册和测试素材一并交付。本版没有完成实机全功能验收。

## 已完成

- 指引身份账本扩展至 64 槽，重复身份使用引用计数。
- 接通 Looper 实体录制/播放踏板及去抖。
- 隔离手弹键盘鼓模式与旋律/原生鼓乐谱事件。
- 修复 ESP 曲库 STOP/RESET/重播、自然结束后的 OFF 清理、引用计数、灯光/路由元数据和失败重试。
- FXSTAT 输出完整 16 位值，支持 FIFO/仲裁背压、active/pending 独立快照。新格式为 Zz<n><4hex>LF，共八字节，旧六字节接收器需调整。
- 实际 ESP-IDF v5.5 / ESP32-S3 编译成功，模式 B 曲库、HMI 启用；应用映像 757328 字节，16 MB Flash 配置。
- 上板手册、58 项验收记录表、四份 MIDI 和实际网页转换器验证后的 .hex 测试素材。

## 本次尚未完成的部分

1. 最新 RTL 的 Gowin 全流程正在执行，尚未生成本版 FPGA .fs。因此本包不提供冒充本版的旧 .fs，不能仅凭此包直接给 FPGA 烧录最新版。源代码中历史 impl/ 或 evidence/ 下的构建产物不属于本版可烧录交付物。
2. 最新全量 RTL 回归尚在执行；交付清单记录封包时的已完成数量。专项测试通过不等于全量回归已结束。
3. 本版没有接入实体板卡。音频、BLE、屏幕、接线和长稳均需按手册验收，不能称作实机已通过。
4. 时序允许延期，但本版原生时序结果尚未产生。历史版本存在显著负 setup 裕量，不能描述为仅有轻微退化或已收敛。
5. FXSTAT 逐字节避免丢失，但共享 UART 的其他诊断回包仍可能插入其行内；验收回读时停止其他诊断请求和 EC11 操作，逐条发送并等待完整响应。连续诊断混流的整帧隔离仍待后续处理。

## 使用顺序

先阅读本说明和交付清单。ESP32 固件位于 ESP32固件 目录，必须保留 flash_args 指定的相对目录结构；替换 COMxx 后按手册烧录。FPGA 在最新 .fs 补齐前继续保留已知版本，不要从源码压缩包里的历史产物中任取一个刷入。

测试素材中的 .mid 用于检查网页转谱；.hex 是使用同版 score_studio 实际转换器生成的 64 位谱面词，可由网页导入。它们不是 FPGA bitstream，也不是原始 UART 上行回传文件。

本包是用户要求先行交付的 RC1，不能作为“全部功能已验证、时序已通过”的结论。
