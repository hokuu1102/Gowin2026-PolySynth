## 本次功能

- 屏幕 `71 05 <0/1/2> FF FF FF` 直选推子档位；实际切到不同档位时锁存离开的档位，重复点击当前档不改锁定，非法档位不别名到合法档。实体循环切档保持原有手动锁定规则。
- 修复音量颤音锁定后切档丢失效果，三档效果可以叠加；实体解锁立即跟随当前推子。
- 鼓机按Ⅰ→Ⅱ→Ⅲ→Ⅳ→Ⅰ循环，独立启停，关闭时可预选节奏。
- z_pr改用音高颤音真实原始速率，并随其变化重发；零移调只显示0 SEMI。
- 真实115200串口核实EC11八参数选择及可选FF尾；保留回传关闭、Loop和踏板行为。
