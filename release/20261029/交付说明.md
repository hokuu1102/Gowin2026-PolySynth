# 2026-10-29 时序优化交付版

本版保留当前完整功能，通过原有真实 50 MHz 工程时序门；实机验收待执行。远端分支为 `codex/delivery-20261029`，保留 `main` 的 `cd63b07`（59.245 MHz 历史版）供对照。

## 与远端 59.245 MHz 版的区别

| 项目 | 历史 main：cd63b07 | 本版 |
|---|---|---|
| 指引状态 | 16 个物理键分别计数 | 64 个独立音符身份，保存 ON 时的键位 |
| 重复 ON | 每键 3 位，达到 7 后饱和 | 每身份 32 位，保持既有模 2^32 行为 |
| OFF 配对 | 按 OFF 当时模式、变调重新查键 | 按 ON 时保存的身份及键位释放 |
| 指引模块寄存器 / LUT | 90 / 148 | 3050 / 4257 |
| clk_sys Fmax | 59.245 MHz | 51.464 MHz |
| 实际 20 ns 周期余量 | 历史交付记录 +3.121 ns | 本次原生报告换算 +0.569 ns |
| 时钟约束 | clk_sys 50 MHz | 相同 top.sdc，未放宽 |

旧版同一键的引用达到 7 后不再累加；例如 8 次 ON 后 7 次 OFF 可能提前灭灯。旧版在音符保持期间切换模式或变调，OFF 可能无法释放原键。本版保留这些功能修复，不以回退计数宽度或身份追踪换频率。

相对历史 main，本版还包含 UART 整包仲裁、HDMI 复位和音量渐变等修复。布局约束也有差异：历史 main 有 h5_ret/h5_scope 区域限定，本版使用已完成原生验证的自动合法 scope 放置和局部 OSER reset 区域。逻辑规模及布线均会影响频率，尚未通过逐项实验量化各项差异的贡献，不能把全部频率差归因于单项改动。历史 59.245 MHz 报告也记录了 182 个 setup 违例端点，不能称为 16.4 ns 优化预算零违例。

## 当前时序结果与状态更正

原说法：2026-10-28 功能交付基线 `8c05c95` 的 Fmax 27.163 MHz，真实 50 MHz 未通过。

更正：本版指引模块采用分组计数、直接写使能、无效载荷预置及分组匹配归约，原验收门通过。原因是缩短了指引账本组合路径；没有裁剪功能或放宽 SDC。逻辑与测试来源为 `50c7bb3`，完整本地验证封存为 `55c64c3`。远端整理提交只改变提交组织和交付文档，不改变实际编译的 RTL。

| 指标 | 本次实际结果 |
|---|---:|
| clk_sys Fmax | 51.464 MHz |
| 原生 setup，16.4 ns 优化预算 | -3.031 ns |
| 对真实 20 ns 周期换算的最差余量 | +0.569 ns |
| Hold | +0.184 ns，满足原 0.05 ns 下限 |
| Recovery / Removal | +0.250 / +0.203 ns |
| 原有 P0-30 门 | PASS，退出码 0 |

16.4 ns 优化预算仍有 3404 个 setup 违例端点、TNS -4098.715 ns。不能将真实时钟验收通过写成该优化预算全部收敛。换算只应用于原验收门确认的 clk_sys 16.4 ns 同沿路径，其他时钟及 CDC 不获取差额。

器件 GW5AT-LV60PG484AC1/I0，工具 Gowin V1.9.12.03；place_option=0、route_option=0、correct_hold=1。相对 8c05c95，86 项设计输入中仅 guide_lamp.v 改动，124 行 IO 约束、SDC 与工程选项保持。实际编译 guide_lamp.v 的 SHA256 为 `1069d3383ff4d37160a0bffe43c125ab6dcb7e1a6956321e5047d28473094e75`（工作区换行转换可能改变字节哈希，应另核对规范化后的源码内容）。

## 功能与验证范围

保留 16 轴 Hall、力度、四音色、32 声部双振荡器、滑音/延音、三档推子与锁定、鼓机及键盘鼓、Looper、64 身份指引、双 I2S、HDMI 波形/XY/FFT、BLE 曲库、串口屏和运行时效果器。默认 source-B 为鼓机；混响及预留功能不宣称已实现。

功能基线的完整 RTL 回归为 233/233，详见 [2026-10-28 功能交付说明](../20261028/交付版说明.md)。本次时序改动只跑影响范围内的 11 项定向回归，全部通过，没有声称重新运行全部回归。包含 12000 拍输出对照、多容量连续事件、32 位回绕/下溢以及 4096 次任意账本状态迁移。所有输出及有效账本逐拍等价；无效计数可预置 1、无效元数据可预写，重新分配生效拍必须与原实现一致。

两级优先选择候选虽达到 53.764 MHz，但 hold 仅 +0.043 ns；分组灯图候选 Fmax 46.415 MHz、hold +0.042 ns。两者均未通过原门，未进入本版。完整试验记录见 [指引灯时序优化](../../files/20-代码/指引灯时序优化-20261029.md)。
